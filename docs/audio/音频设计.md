# 音频设计

> 状态：骨架 ｜ 维护者：音频 ｜ 最后更新：2026-10-04
> ⚠️ 待细化：本文件目前只定义结构与规范，具体音乐主题、乐器编制待音频负责人补充。

## 1. 设计目标

音频要服务"**慢积累 + 快相变**"的节奏（v3.0 §3.3）：课间的喧闹日常感与上课段的压抑发酵感形成对比，压力爆发时形成一次听觉上的"破裂"，让玩家不靠数值也能感知格局变化。

## 2. 音乐（BGM）

| 场景 | 情绪功能 | 备注 |
|---|---|---|
| 主菜单 | 校园日常、轻快、留白 | 循环，可短 |
| 课间段（三类共用一个池） | 嘈杂、松散、信息密度高 | 建议可用分层（人声嘈杂层可随压力/围观人数增减） |
| 上课段（发酵） | 安静、压抑、时间感凝滞 | 与课间形成强对比；时长仅 15 秒实时，需可无缝循环 |
| 每日简报 | 收束、叙事感 | 短主题 |
| 学期报告 | 回望、完整弧线 | 可与主菜单主题呼应 |
| 压力爆发瞬间 | 刺破感 | 与 BGM 的分层配合，避免纯音效撞击 |

实现建议：Godot `AudioStreamPlayer` + 母线（bus）分组 `Music` / `SFX` / `Ambience`，音量由设置界面控制并持久化。

## 3. 音效（SFX）清单

| 类别 | 事件 | 规格来源 |
|---|---|---|
| 交互 | 粉笔书写、板擦擦拭、标记掉落 | 线索板原型已有交互 |
| 交互 | 按钮点击、面板开合、翻页 | UI 通用 |
| 社交 | 搭话、被拒绝、敷衍、尬聊 | 主文档 §10 搭话 / 闲聊 |
| 社交 | 递纸条、纸条传递铃声 | 主文档 §10 传纸条 / 流言 |
| 社交 | 起哄/围观哄笑、调侃过火 | v3.0 §10 R10 |
| 情绪 | 压力临界的心跳、爆发瞬间 | v3.0 §8.5 |
| 情绪 | 安慰生效的柔和提示音 | v3.0 §10 R12 |
| 事件 | 举报、秘密泄露的尖锐提示 | 主文档 §10 举报 / 告密 |
| 系统 | 天数切换、简报生成、存档 | — |

**约束**：音效只作为**事件的提示**，不得泄露玩家看不到的信息（例如不要用音效暗示低透明度角色的真实态度）——与 v3.0 §9 的信息可见性规则保持一致。

## 4. 混音与规范

- 响度：SFX 峰值 ≤ −3 dBFS，BGM 平均 −18 LUFS 左右，避免移动端喇叭削波。
- 格式：BGM 用 OGG；SFX 用 OGG 或 WAV（短音效）。
- 命名与目录：`assets/audio/bgm/`、`assets/audio/sfx/`，见 `assets/README.md`。
- 第三方素材必须登记到 `assets/CREDITS.md`。
