## 1. 两条贯穿红线（违反即为实现缺陷）

1. **不得用音效泄露玩家看不到的信息**（主文档 §9 信息可见性）
   假信息的真假、低透明度角色的真实态度、流言的内容与倾向——一律不得有辨识性音效。
2. **NPC ↔ NPC 的判定必须静默**（主文档 §10.32.1）
   一个课间可能发生几十次判定；给 NPC 之间的成败配音，既会淹没玩家，也会泄露别人的关系状态。
   ⇒ 三拍音效（`roll_*`）**只对涉及玩家的判定播放**。

播放点表中的「约束」列专用于标出这两条红线的落点（记作 ⚠️）。

## 3. 素材总表（50 条原始素材）

> **这是要真正做出来的音频文件，按优先级分三段。**「覆盖播放点」列即复用关系：一条素材服务多个事件，靠**变体参数**（音高 / 音量 / 播放方向 / 滤波）区分语义。变体一律在 Godot 侧用 `AudioStreamPlayer.pitch_scale` / `volume_db` / `AudioEffectFilter` 实现，**不额外出素材**。
>
> **优先级判定口径**：一条素材的优先级 = 它覆盖的播放点中**最高的那一档**（素材必须先服务最早交付的批次）。「类别」列保留素材的原始分类，便于按工种分派。

## 6. 命名与目录（遵循 [`assets/README.md`](../../assets/README.md)）

- 命名：`sfx_<对象>_<动作>_<序号>.wav`，全小写蛇形，序号两位（`_01`）；BGM / 循环层用 `bgm_*.ogg`。
- 目录：音效 `assets/audio/sfx/`；BGM 与 ambience 暂归 `assets/audio/bgm/`（见 §8 待定项 1）；**第三方素材必须登记 [`assets/CREDITS.md`](../../assets/CREDITS.md)**。
- 体积：单条音效 ≤ 200 KB，BGM 单曲 ≤ 3 MB。
- 母线：`Music` / `SFX` / `Ambience` 三组，音量由设置界面控制并持久化（[`音频设计.md`](音频设计.md) §4）。
- 响度：SFX 峰值 ≤ −3 dBFS；BGM 平均 ≈ −18 LUFS，避免移动端喇叭削波。
