# 文档归档（archive）

> 状态：生效 ｜ 维护者：策划 ｜ 最后更新：2026-10-04

## 归档什么

1. **被取代的规格正文**：当 v3.0 升级为 v3.1 / v4.0 时，旧版本的 Markdown 正文移入本目录（原始 docx 仍留在 `../references/`）。
2. **废弃的设计方案**：明确不再实施的方案，保留其结论与废弃原因，避免后人重复讨论。
3. **过期流程文档**：被新规范取代的工程/流程说明。

## 归档规则

- 文件名前缀日期：`YYYYMMDD-<原文件名>.md`，便于排序。
- 每篇归档文档头部必须写明：
  ```
  > ⚠️ 已归档 ｜ 归档日期：YYYY-MM-DD ｜ 替代文档：<链接>
  > 归档原因：<一句话>
  ```
- 归档**不删除内容**；只做标记与迁移。
- 在 `CHANGELOG.md` 中记录"文档"类变更。
