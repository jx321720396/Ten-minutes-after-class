# 玩家行动倍速实施计划

> 状态：实施与回归完成 ｜ 依据：2026-10-09 用户要求（行动期间默认 3 倍，NPC 和倒计时同步，预留事件正常速度接口）。
> 执行：当前会话直接实现，采用测试先行与真实场景验收。

## 设计

新增表现层 `TimeFlow`（Node + 可复用场景）。配置来自 `data/rules/time_flow.csv`；正常 1 倍，玩家占用型行为期间 3 倍，走路保持 1 倍。仅 NPC 活动不触发倍速，世界在玩家行动期间共同加速。按帧统一采样倍率；时钟、Roam、Walker、玩家移动共用缩放后的 delta，内核仍逐 tick 推进，保留帧预算、相位边界和暂停语义。

事件通过 `request_normal_speed(owner: StringName)` / `release_normal_speed(owner: StringName)` 持有正常速度锁。锁按拥有者去重，最后一个释放才恢复自动倍率；锁不是暂停。时钟 hold、树暂停、简报/学期结束优先于正常速度锁。倍率组件属于场景，退出无需恢复全局引擎状态。

UI 与转笔演出使用真实 delta；聊天气泡的世界动作使用缩放 delta。时间 HUD 保留原剩余秒数口径（基准播放秒），倒计时以倍速消耗，并显示运行倍率。
