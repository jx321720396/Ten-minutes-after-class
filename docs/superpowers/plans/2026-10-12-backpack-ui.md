# 书包物品界面 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 在当前工作区执行；用户已要求按照概念图实现。

**Goal:** 将概念图的实物书包融入教室，提供零食、课外书、MP3 的点击与拿取。

**Architecture:** 独立 BackpackPanel 只消费行为栏已有状态，发出既有自指行为意图。面板打开时隐藏行为栏，教室继续播放；Esc 优先关闭书包。素材分为透明空包和独立物品区域，无书与零食耗尽时不显示物品。

**Tech Stack:** Godot 4.7.2 / GDScript / 内置 imagegen 透明 PNG。

**Spec:** 本聊天已确认的概念图及局部展开方案；玩法以 core-gameplay-v3.1.md 的 P0-3 入口与 v4 §17.3、§21.2 为准。

## Global Constraints

- 不写模拟矩阵，不改行为数值，不增加脚本剧情。
- 状态与数量来自既有行为栏刷新快照，执行仍由内核裁决。
- UI 尺寸、颜色、热点与文字集中于 data/ui/backpack.json。
- 保留当前工作区已有改动，不提交或推送。

## Review Focus

- 零食耗尽与无书：保留可选择入口，拿取灰置且解释原因。
- 世界相位切换：打开期间实时更新不可用原因。
- Esc：关闭书包时不同时唤起暂停菜单。
- 拿取：每次只发出一次既有行为意图，不扣库存两次。
- 布局：实际教室截图检查物品热点、纸卡与底部导航重叠。
