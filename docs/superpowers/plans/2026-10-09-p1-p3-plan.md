## 1. P1（目标 10/11–10/12）

### 1.1 学习打断 + 快速学习（裁决 v4/17 开放问题②③）

- **打断源集合**：被发起交互（搭话 / 加入闲聊邀请 / 调侃 / 安慰 / 求助）必打断；**老师进教室不打断**（学习是合法状态，v4/17 §17.2.3 已豁免）；打闹 / 排挤波及是否打断 → 标定观察后定，默认否。
- **打断后果**：退出快速学习模式；`study_acc` 是否清空（开放问题②）建议：**非自愿打断清空、自愿切换保留**——学习投入有风险才有博弈，标定轮复核。
- **参数**（`time_runtime.csv`）：`fast_study_after_s=10`、`fast_study_speed=2.0`。实现只改时间组件 tick 步长，**不改 tick 总数与结算语义**——对拍按 tick 计数逐位一致不受影响。

### 1.2 提问 / 讲题（用户清单细项 17）

- 玩家→NPC 提问：玩家成绩收益 + 对方信任小增；玩家→NPC 讲题：对方成绩收益 + 玩家信任小增。次数限制 / 冷却进参数。
- **成绩收益走 v4/17 §17.1.2 累加器（等效学习 tick 直充 `study_acc`）**，不直加 grade——保住「成绩只经由学习时长产生」的单一因果，且自动继承分段递减语义。
- 事件落 `w_events.csv`（`ask_question` / `teach_lesson`，T 轴常规档）+ 等效 tick 数进 `grade_table.csv`（如 `ask_question_bonus_ticks` / `teach_lesson_bonus_ticks`，标定起点）。
- 与皇帝位联动：在 P0 座进行的提问 / 讲题 / 共同学习享受加成（见 1.3）。

### 1.3 换座位 + 皇帝位（用户清单细项 13）

- **流程**：每天第一个课间开始时触发（频率进参数）；NPC 在 4×4 网格随机洗牌（P0 不参与洗牌、保持空置）→ 玩家任选一格（含空格）→ 若选中有人之格，其人挪入 P0（皇帝位）。
- **皇帝位加成**：坐 P0 者——学习 / 提问 / 讲题 / 共同学习的成绩与 A/T 增益 ×`emperor_bonus`（建议 1.5，标定起点，落 `grade_table.csv`）。P0 邻居仅 3 人：加成是「社交孤立换学习效率」的权衡，与 `seats.csv` 既有设计意图一致。
- **UI**：4×4 选座面板（座位网格 + 现坐者头像 + P0 特殊标识）；走 `EventBus`，表现层不碰矩阵。

### 1.4 信息反哺分享（用户清单细项 10）

- 增量于现有闲聊线索（`player_chat_intel.gd`，按透明度透露 1–2 条）：对方额外透露一条「玩家已知信息」做共鸣——信任小增；若该信息与玩家已知矛盾 → 假信息破绽提示（为 M2 推理板留接口，本版只做提示）。

## 2. P2（目标 10/13）

> 实现级规格（2026-10-09 定稿）：[`docs/gdd/v4/19-P2功能细分规格.md`](../../gdd/v4/19-P2功能细分规格.md)——本节计划升格为该章，裁决 v4/17 §17.6 开放问题④。

### 2.1 周考 + 奖励（用户清单细项 19；裁决开放问题④）

- 节点：第 7/14/21/28 天（新表 `data/rules/exam.csv`：`exam_days="7,14,21,28"`），settle 段结算；期末考 = 第 30 天（v4/17 §17.1.3，HUD 已含倒计时）。
- **进步奖**：较上次周考 ≥ +50 分（`progress_prize_delta=50`）→ 取回被没收课外书；P3 未就绪时降级为纯荣誉简报，实现时按 P3 进度裁剪。
- **特等奖**：班级前 N（`top_prize_rank=3`）→「免罚卷」= 下周一次没收 / 巡查处罚豁免（豁免计数器，进存档）。
- 周考是固定学制节点（世界结构，与课程表同级），不受不变式 1 约束（同 v4/17 §17.1.3 口径）；奖励阈值全进 `data/`。

### 2.2 事件触发状态前置（用户清单细项 4；替代「推翻重做」）

- `social_event_triggers.csv` 增加行为类 metric 条件（近期互动量、压力档位、在场人数等，进可计算指标注册表）；**明确否决「事件机制全部推翻重做」**——5 天窗口 + 六道门全链重标定不可承受，且细项 4 的意图（事件随行为受限）用条件行即可达成。

### 2.3 多结局结算报告（用户顶层 1 / 细项 20）

- 统计口径：累计学习 tick（折算游戏内小时）、成绩净增、按行为分类的交互次数、Top-3 双向好感对、孤立警示。
- 结局分档：由统计量阈值分派文案模板（阈值进 `data/`，如 `ending_grades.csv`）；呈现于第 30 天 settle 的结算画面，衔接《学期格局报告》M2 形态。
