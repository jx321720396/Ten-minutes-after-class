# 共同活动背影实施计划

目标：为全班 16 人生成与现有立绘对应的透明背影视图；共同活动中靠镜头、面向后方同伴的站立者显示背影，结束恢复正面。

约束：仅 main-mobile；保留当前未提交工作；不改 core、不按身份分支、不消耗 RNG、不提交推送。使用现有 student_poses.json 存放资产绑定和朝向阈值。

- [x] 用 imagegen 内置工具逐人参考生成 standing_back_v1，检查透明度、发型、全身及脚底。
- [x] 先写朝向回归测试：前后、横排、相机反向、多人分组、结束、抖动缓冲、只读；观察失败后实现独立表现组件。
- [x] classroom_actors 按 sprite 配置注册正背资源，classroom 在行走之后更新共同活动朝向。沿用正面像素尺寸并按各贴图脚底校正，坐姿和移动保持原表现。
- [x] 真实教室截图；验证所有背影绑定可加载和 alpha 有效；运行专项、格式静态及快门禁，记录版本限制。

判定：以镜头前向在地面上的投影计算成员至其他可见静止成员平均位置的纵深；纵深超过配置阈值且不是横向为主时转背。只读真实会话；学习坐姿、离场或行走均不强制转身。坐姿同伴作为站立请教者的朝向目标，保持坐姿自身贴图。

验证记录：GUT 先见 3 个朝向测试失败，实施后 5/5 通过；真实教室夹具验证全部16资源、前后/横排、脚底、移动与结束恢复。独立复核指出站立者未面向坐姿同伴的问题，新增场景断言观察失败后修复并通过，复核关闭 P2。配置180、内核132、公式9、文档与CSV导出检查通过。无提交、推送；本机4.6.3与GUT兼容提示及目标4.7.2/安卓复验边界见验收文档。
