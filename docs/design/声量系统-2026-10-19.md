# 声量系统设计（提案）

> 日期：2026-10-19｜状态：设计定稿，**未实装、未改代码、未改 `data/`**｜范围：老师版办公室的训斥、安抚、鼓励。
> 依据：[主文档](../gdd/core-gameplay-v3.1.md) §6（老师操作）、§7（鼓励与交流目标）、§5.3（崩溃）、§3.1（暂停例外）。
> 2026-10-19 用户裁定：输入以**麦克风为主、按住蓄力兜底**；**鼓励接入声量**（改未指定目标池）；**表扬暂不接入**。
> 2026-10-19 补充裁定：声量模式是**可选功能**，开关放在设置里，**默认关闭**；**每次开启都要再次确认“使用本功能可能无法通关”**；关闭时按现行固定数值结算。
>
> 术语说明：现有文档里的“音量”是教室环境音量（`data/rules/environment.csv`）；本文件把玩家出声的力度统一叫**声量**，避免撞名。用户口中的“安慰”对应现有“安抚”。

## 0. 一句话

玩家在办公室出声越用力，训斥／安抚／鼓励的**主效果越强**；但压力、动力、崩溃风险和社交目标会随档位改变，所以不是“永远吼”。本功能是**可选挑战模式**，默认关闭；关闭时完全按现行固定数值结算。

## 1. 术语与边界

| 词 | 含义 |
|---|---|
| 声量 | 玩家本次谈话的出声力度，0–100，四档 |
| 教室音量 | 现有 `data/rules/environment.csv` 的环境标量；本功能不读取、不修改 |
| 档位 | 轻声／平常／提高／吼；只有档位参与结算，连续声量只用于判定档位 |

- 只作用于训斥、安抚、鼓励（仅在模式开启时）。
- **默认关闭**：设置内开关；关闭时不采样、不请求麦克风、不显示声量条，训斥／安抚／鼓励按 §6.1 固定数值结算，鼓励仍按“距离最近的娱乐同学”。
- **开启前二次确认**：每次从关到开都提示“使用本功能可能无法通关”；取消则保持关闭。
- 表扬、打听、调解、调座位、搜包、全班训斥不接入（表扬是私下肯定；打听要小声；其余不是“对一名学生喊话”）。
- 不改变 20 秒谈话、召唤／遣返、上课延后、考试日封锁等现有命令规则。
- 不按角色名／ID 分支；档位对所有学生一致，差异只来自学生当前压力／动力、公开被动和目标关系。
- 不新增暂停例外；采样期间只改变播放速度，不暂停世界。

## 2. 流程

仅在设置开启声量模式后执行；关闭时直接按基础值结算，不进入本流程。

```text
0.0s      点 训斥/安抚/鼓励 → office_chat 开始（20 秒，4× 快进）
0.0–0.3s  “喊！”提示，不采样
0.3–2.8s  采样；临时释放 4×，按玩家自选 1/2/3× 播放
2.8s      锁定档位，恢复 4×
20s       结算：基础效果 × 档位倍率
```

- 20 秒仍是游戏内秒数；采样窗口在 20 秒之内，不额外增加游戏时间。
- 采样期间取消谈话：无效果；已流逝课间时间不退（沿用现有 `cancel_office_chat` 口径）。
- 上课打断：保留已采档位；不足 1 秒按平常，不要求重喊。
- 考试日没有办公室谈话，本功能不参与。

## 3. 数值

以下数值仅在声量模式开启时生效；关闭时使用基础值。基础值来自 `data/rules/activities.csv`，倍率只乘一次：

| 档 | 声量 | 倍率 | 训斥 压力＝动力 | 安抚 压力＝动力 |
|---|---:|---:|---|---|
| 轻声 | 0–24 | 0.6 | +18 | −12 |
| 平常 | 25–49 | 1.0 | +30 | −20 |
| 提高 | 50–74 | 1.4 | +42 | −28 |
| 吼 | 75–100 | 1.7 | +51 | −34 |

- **平常档 = 1.0 = 现行数值**。这是本设计最重要的不变量：不改变现有标定、六道门与旧存档的手感。
- 训斥、安抚都走 `add_stress` 的一般联动；动力随压力同向变化，不要单独再乘一次。
- 崩溃阈值是压力 >90。按当前压力算崩溃线：

| 训斥档 | 增量 | 当前压力超过此值会崩溃 |
|---|---:|---:|
| 轻声 | +18 | 72 |
| 平常 | +30 | 60 |
| 提高 | +42 | 48 |
| 吼 | +51 | 39 |

- 安抚越大声，减压越多，动力也扣得越多：−34 很容易把学生压进 <30 的游戏状态，下一段还要表扬拉回来。**“吼安抚”不是无脑最优**。
- 轻声不是纯惩罚：训斥轻声可以“不逼崩”，安抚轻声可以“少扣动力”，鼓励轻声可以“只找邻座”。四档都是工具，不是四个强度等级。

## 4. 鼓励：声量决定“敢去找谁”

鼓励按 D09 不直接加好感、动力或学业，实际聊天才结算；因此声量不能直接乘数值，而是改**未指定目标的选人池**。**声量模式关闭时，仍按现行的“距离最近的娱乐同学”**；下表仅在开启时生效：

| 档 | 目标池 | 选谁 |
|---|---|---|
| 轻声 | 前后左右邻座中正在娱乐的人 | 距离最近 |
| 平常 | 全班正在娱乐的人 | 距离最近（现行） |
| 提高 | 最近的 3 名娱乐同学 | 被鼓励者对其好感最高 |
| 吼 | 全班娱乐同学 | 被鼓励者对其好感最高 |

- 好感读**被鼓励者 → 对象**的有向好感；并列时距离近者优先，再使用带种子的随机选择（保持确定性）。
- 这只是选人规则，不是隐藏数值修正；投票仍是 §9.1.2 的确定投票（好感 − 敌对 ≥ 10、严格过半），不掷概率、不加隐藏修正。
- 好感越高，投票越容易过，聊天的正向效果也越强（`_m_relation` 的净态度调制）；所以“吼”的成功率确实更高，但好感最高的人可能很远／很忙，等待更久，4 个课间可能等不到。
- 重复鼓励、有效期 4 课间、完成／拒绝／到期规则都不变；不新增固定数值奖励。
- 指定对象优先：老师指定了对象时，声量不改变目标，按平常结算（当前 UI 走自主模式，指定模式是既有规格）。
- 目标池在**鼓励完成时**随档位写入该学生的目标；实际选人发生在学生下一次可行动时，因此档位要跟着目标存，不能只存全局。

## 5. 输入

### 5.1 麦克风（开启后默认）

- 用 `AudioEffectCapture` 取 50 ms 帧的 RMS，按校准归一化：

```text
I     = 100 × clamp((rms − gate) / (shout − gate), 0, 1)
gate  = max(floor × 1.5, ref × 0.15)
shout = clamp(实测喊声, ref × 2.2, ref × 4.0)
```

- 平常说话大约落在 30–40（平常档）；喊声落在 75–100。
- 校准三步：
  1. 安静 1.5 秒 → `floor`
  2. 平常音量说一句 2 秒 → `ref`
  3. 最大声喊 1.5 秒 → `shout`
- 首次校准可跳过；跳过时用保守默认值并在设置里提示，之后可随时重做。
- 校准存本地（`user://`），不录音、不上传；设置里提供“重新校准”和“试喊”。
- 环境太吵（`floor > 0.5 × ref`）提示改用按住模式；不要用绝对 dB 阈值，避免设备差异。
- 设备／输入源变化时（保存的 device 名不一致）提示重新校准。

### 5.2 按住蓄力（开启后兜底，完整可玩）

- `I = 100 × (t / 2.5)^1.2`，松手定档：
  - 轻点 = 轻声
  - 约 1.3 秒 = 平常
  - 约 1.9 秒 = 提高
  - 2.2 秒以上 = 吼
- 四段条实时显示档位；松手前能看到，松手后锁定。
- 触屏按住期间不触发页面滚动；与现有 `TouchBind` 的触摸处理保持一致。

### 5.3 关闭声量模式（默认）

- 设置里的总开关关闭时：不采样、不请求麦克风、不显示声量条，训斥／安抚／鼓励按基础值（1.0）结算；鼓励仍按“距离最近的娱乐同学”。
- 这是默认状态，也是现有玩家、直播、评委试玩和自动化测试的安全路径。
- 关闭只影响下一次谈话；进行中的谈话按已锁定档位结算。

### 5.4 权限、隐私与音频

- Android：导出预设勾选 `RECORD_AUDIO`；`project.godot` 设 `audio/driver/enable_input=true`。
- 首次使用：先说明“只在本地计算音量，不录音、不上传”，再请求系统权限；拒绝就切按住模式，不再反复弹。
- 新增 `Mic` 总线 + `AudioEffectCapture`；总线输出静音（或 −80 dB），只读 capture buffer，防止回授。实装时真机确认 mute 不影响 capture。
- 采样期间 Music/SFX 压低 12 dB，结束后恢复玩家原设置；这既防外放被收进去，也提示“现在在听”。
- 无头／桌面无输入设备时禁用麦克风；无输入环境直接用关闭状态（固定数值），不要因初始化失败阻塞启动。

## 6. 判定与边界

- **持续度**：某档需在 2.5 秒窗口内达到 ≥40% 的时间（约 1 秒）才算该档；取满足条件的最高档。喊 0.3 秒不会直接满档，避免咳嗽、拍桌子刷满。
- **没听到声音**：整窗最大声量 <5 → 按平常结算 + 提示重新校准（不因麦克风故障白花 20 秒）；5–24 → 轻声。
- **校准失败／环境过吵**：自动切按住模式，当次不阻塞谈话；提示可在设置里重试。
- **上课打断**：窗口暂停；已采到的档位保留；不足 1 秒按平常；不要求重喊。
- **取消**：采样期间或采样后取消谈话都不产生效果；已流逝课间时间不退。
- **存档**：`chat_tier` 进 `export_state/restore_state`，默认 2（平常）；鼓励目标另存 `encourage_tier`，因为选人发生在之后。
- **被动顺序**：先乘倍率，再 `add_stress`；听劝固定 +10 动力、弹簧按最终压力增量触发，都**不再乘声量**（否则一次吼可能 +80 动力）。
- **不重复结算**：一次谈话只结算一次倍率；上课延后后继续使用原档位，不重新采样、不重复发放。
- **不改变随机序列**：声量不消耗随机数；鼓励并列的种子随机仍走原 `_rng`，保证同种子可复现。

## 7. UI 与反馈

### 设置与开启

- 设置 → “声量模式（挑战）”开关，默认关闭；行内说明：开启后办公室操作随你的声量变化；可能让考核更难，极端情况下无法通关。
- 每次从关到开：弹确认框，标题“开启声量模式？”，正文重复“使用本功能可能无法通关”；按钮“取消／仍然开启”。取消则开关保持关闭。
- 开启后办公室／HUD 显示“声量模式”小标记；读档／新局不重复弹窗。
- 输入子选项只在开启后出现：麦克风（默认）／按住；另提供重新校准、试喊、权限状态。
- 关闭时不出现声量教学、不请求麦克风权限、不显示声量条。

### 谈话内

```text
┌ 声量 ─────────────────┐
│ 轻声  平常  提高  吼   │
│ ▓▓▓▓▓▓▓░░░░░░░░░░░░  │
│ 训斥 · 提高 → 压力 +42 │
│ 预计 78 · 安全         │
└───────────────────────┘
```

- 谈话面板加“声量”四段条；采样时显示“喊！”与实时档位；结束后显示“训斥 · 吼 → 压力 +51 · 动力 +51”。
- 预测行：`预计压力 94 · 会崩溃`（红色）；鼓励显示“吼：他会找好感最高的同学”。
- 结果行沿用现有日志；鼓励显示目标与完成／拒绝／到期。
- 首次进入办公室的一次性说明（仅在开启后）：训斥／安抚／鼓励要出声，**平常音量 = 现在的效果**；表扬和打听是低声私下交流，不接声量；提供“用麦克风／按住蓄力”两个入口，选麦克风时做一次校准（可跳过）。
- 隐私提示：采样时显示“正在听”小标记，窗口结束即停。

## 9. 平衡与风险

- **关闭时 = 现行数值**；开启后平常档也 = 现行数值。现有标定与六道门不受影响（Python 参考内核不模拟玩家操作）。
- 默认关闭把风险隔离在 opt-in 挑战模式里；开启时的“可能无法通关”是明确告知，不是隐藏难度。
- “全天吼”理论上把老师单日动力输入上限从约 450 抬到约 765（15 人次 × 51），但训斥受崩溃限制、安抚受动力反噬限制；`docs/production/一天动力与老师时间预算-2026-10-17.md` 的 450 是“平常档”口径，实装时补一行双口径说明。
- 听劝 + 弹簧会在 +51 训斥上叠加，可能出现“一次吼 = +80 动力”的组合；这是公开被动的合法联动，验收要专门跑一遍。
- 最大风险不是数值，是**麦克风**：设备差异、权限、公共场合。按住模式必须是完整可玩的一等模式，而不是“降级”。
- 不建议现在加“嗓子”资源：现有老师输入上限已经偏紧，再砍一刀会让经济更紧；如果之后确定要防“全程吼”，再单独裁定。
- 字体子集与 Android 权限是实装阶段最容易漏的两项，验收清单单列。

## 10. 分阶段实施

1. **Phase 1（先验证数值）**：设置开关 + 二次确认 + 默认关闭 + `voice.csv` + core 档位／倍率 + 按住模式 + 四段条 + 鼓励选人。无需权限，手机上直接可玩。
2. **Phase 2（麦克风）**：`AudioEffectCapture` + 校准 + 权限 + 外放压低；真机测安静室内、开外放、嘈杂三种环境。
3. **Phase 3（打磨）**：结果提示、震动、首次引导、失败重校准、日志记录档位。
