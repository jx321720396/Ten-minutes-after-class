# NPC 行为决策

> 状态：草案 ｜ 维护者：程序 ｜ 最后更新：2026-10-04
> 关联：[`统一影响公式.md`](统一影响公式.md)（效果怎么算）｜ [`信念矩阵.md`](信念矩阵.md)（谁看得见什么）
> 一句话：NPC 的行为**既不是纯随机，也不是"五轴直接当概率"**，而是「门槛 → 意向 → 采样」三段式。

---

## 1. 为什么两端都不可行

| 方案 | 后果 |
|---|---|
| **纯随机** | 行为与状态脱钩（好感高的不找好感高的）→ 涌现退化为噪声，检验一（换成脚本还成立吗）直接失败 |
| **确定性取最大**（argmax） | 25 个 NPC 评分相同 → **同时做同一件事**，全场刻板同步；也没有意外，戏剧性消失 |

结论：**随机性必须保留**（用来打破对称），但必须被"意向"塑形。

## 2. 三段式

```
① 门槛（硬条件 · 布尔）    这个行为此刻可不可行
② 意向（软偏好 · 连续）    可行的话，我有多想做
③ 采样（概率）            把意向转成概率，温度 τ 控制随机程度
```

**五轴的作用分布在前两段**：门槛是五轴的阈值判定（确定性）；意向是"各轴变化的预测"加权（影响概率大小）。

## 3. 三类触发方式（总则）

| 类型 | 判据 | 行为 | 设计意图 |
|---|---|---|---|
| **环境类** | 固定基础概率 × 修正系数 | 闲聊、传纸条、走动、窃听、睡觉 | 不需要"想"——有条件就按概率发生 |
| **阈值类** | 确定性（条件满足即发生） | 举报、压力爆发 | 制造"积累到临界点突然发生"的相变手感 |
| **意向类** | 门槛 → 意向评分 → softmax | 搭话、调侃、安慰、求助、道歉、秘密交换 | 需要"选择"，因此受性格与信念影响 |

环境类的修正形式（例）：

```
闲聊每 tick 触发概率 = base_p
                     × 相邻修正（×1.5，见主文档 §8.15）
                     × 双方外向度修正
                     × 压力修正（≥70 时 ×0.5）
```

## 4. 意向类的完整算法

### 4.1 门槛（硬条件，直接取自主文档 §10 的"触发条件"）

```
搭话： A[i][j] ≥ 30 且 stress_i ≤ 80 且 j 不在对话中      【软门槛，见 join_gate_utility】
调侃： 周围 ≥3 人 且（A[i][j] ≥ 40 或 B_H[i][j] ≥ 25 或 A[i][j] < 25）  【好意 / 挑衅双轨，§8.12】
安慰： stress_j ≥ 70 且 A[i][j] ≥ 门槛（E ≥ 50 → 50，E = 0 → 70）        ✅ 已实装
求助： A[i][j] ≥ 门槛（E = 50 → 30，E = 0 → 50，E = 100 → 20）           ✅ 已实装
道歉： H[i][j] ≥ 30（**决策侧只看我的真值**；§8.11 的「双方」由判定侧的 H[j][i] 承接）
                                                                          ✅ 已实装
秘密交换：T[i][j] ≥ 60
```

> ⚠️ **门槛一律读「我自己的立场」`X[i][j]`，不得读 `X[j][i]`**（§14.7 不变式 3：决策路径
> 不得读「别人对我的态度」）。所以 §8.11 的「双方敌对」不能照字面写进门槛 —— 拆成
> 「**我的真值敌对** ≥ 30」（决策侧）+「**他的真值敌对** 进入接受概率」（判定侧）。
> 对方的反应预期要用，只能走**信念** `B_*[i][j]`（§4.2 的读取规则）。

门槛不通过的组合**不进入候选集**（概率恒为 0，不允许"小概率硬做"）。

### 4.2 意向评分

```
U_b(i) = Σ_X  α_X(i) · Δ_X^pred(i, b)
```

**读取规则（最容易写错的地方）**：

| 需要什么 | 读哪里 |
|---|---|
| 我自己的立场（我要不要做） | 真值 `A[i][*]`、`T[i][*]`、`stress_i` |
| **对方的反应预期**（他会不会接纳我） | **信念** `B_A[i][*]`、`B_T[i][*]` —— **绝不是真值**（见 [`信念矩阵.md`](信念矩阵.md) §6） |
| 行为本身的成败概率 | 主文档 §10 各行为的判定式 |

### 4.3 性格权重 α（由 MBTI 四维派生）

```
α_A      ∝ 0.5 + 0.5·F/100 + 0.3·E/100          情感型 / 外向型更在意好感
α_T      ∝ 0.5 + 0.5·J/100                       判断型更在意信任
α_H      ∝ 0.5 + 0.5·(1−F/100) + 0.3·(1−J/100)   思考型 / 随性型更在意敌对
α_stress ∝ 0.5 + 0.5·(1−E/100)                   内向型更在意压力消解

归一化：α_X = α_X_raw / Σ α_X_raw   （Σα = 1）
```

系数落在 `data/balance/npc_weights.csv`，初始为经验值，按"性格像不像"批量标定。

### 4.4 温度与采样

```
p(b) ∝ exp( U_b / τ_i )

τ_i = τ0 · (1 + 0.3·(1 − J_i/100)) · stress_modifier
  τ0 = 1.0（基准） ｜ stress_modifier = 1.0（<70） / 1.5（≥70，冲动）
  高 J → τ 小 → 更确定、更按计划    高 E → τ 略大 → 更即兴
```

τ 的物理含义：**τ → 0 就退化成 argmax（刻板），τ → ∞ 就退化成纯随机（噪声）**。1.0 附近是"有偏好但不死板"。

## 5. 候选集与性能

```
候选 = { (行为, 目标) | 通过门槛 }
```

- 实测规模通常只有 **3~8 个**（门槛已经筛掉了绝大多数组合）；
- 不必对全部做 softmax：**先算 `U_b` → 取 top-5 → 只对这 5 个采样**；
- 复杂度与 NPC 总数无关（空间索引已在门槛阶段完成：相邻 / 围观判定）。

## 6. 可复现性与并发

| 约束 | 做法 |
|---|---|
| 采样 | 必须用**种子化 RNG**（同种子同局面，回放的先决条件） |
| 决策顺序 | 同一 tick 内按**角色索引升序**依次决策（确定性） |
| 冲突 | 一 tick 内已被占用（处于对话中）的角色不再接受新交互 |
| 涓流 vs 事件 | 环境类走涓流结算（每 `settle_interval`）；意向类与阈值类的事件触发即结算 |

## 7. 手算示例

NPC 06（ENFP：E=85 / N=75 / F=70 / P=20 → 高 E、高 F、低 J）在一个课间有三个候选：

| 候选 | `Δ_A` | `Δ_T` | `Δ_H` | `Δ_stress` |
|---|---|---|---|---|
| 找 07 搭话 | +3 | +2 | −1 | −2（聊天减压） |
| 传纸条给 08 | +2 | +1 | 0 | −1 |
| 原地学习 | 0 | 0 | 0 | −1（压力 +1，取负号） |

取 `α_A = 0.40`、`α_T = 0.25`、`α_H = 0.20`、`α_stress = 0.15`：

```
U(搭话)   = 0.40×3 + 0.25×2 + 0.20×(−1) + 0.15×2 = 1.80
U(传纸条) = 0.40×2 + 0.25×1 + 0.20×0    + 0.15×1 = 1.05
U(学习)   = 0.40×0 + 0.25×0 + 0.20×0    + 0.15×(−1) = −0.15

τ = 1.0 →
p(搭话)   = e^1.80 / (e^1.80 + e^1.05 + e^−0.15) ≈ 6.05 / 9.09 ≈ 67%
p(传纸条) ≈ 26%
p(学习)   ≈ 7%
```

注意：**"赵蕊爱搭话"完全是 E=85 / F=70 经 `α` 与意向评分的自然结果**，代码里没有任何角色名判断（四维纯函数铁律）。

## 8. 工程不变式

| # | 约束 | 校验 |
|---|---|---|
| 1 | 决策只读信念 `B`（对方态度）与真值（自己的立场）；**禁止读 `A[j][i]`** | 静态扫描 `scripts/npc/` |
| 2 | **禁止角色名 / 角色 ID 判断**：α 与 τ 只由 MBTI 四维 + 压力派生 | 同上 |
| 3 | 同种子同结果 | 同种子跑两遍，逐 tick 状态哈希一致 |
| 4 | 门槛不通过的行为概率恒为 0 | 单测 |
| 5 | `τ > 0`（τ=0 会退化为确定性 argmax，属于配置错误） | 启动校验 |
