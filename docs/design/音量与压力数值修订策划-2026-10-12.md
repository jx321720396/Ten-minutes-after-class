## 1. 目标与范围

玩家能直接回答：“现在有多吵？我有多紧张？再升一档会改变什么？”

将压力、音量统一为四档呈现，每档必须对应真实结算差异。效果按档查表；连续量只负责音量平滑与爆发风险。保留性格差异、原事件公式、库存和行为流程，不添加按日期或角色指定的剧情。

本提案修改：压力状态倍率与正负分类、音量目标尺度、音量压力和定向敌对、相关 UI。保留：行为时长、减压道具数值、日末压力保留率、老师压场倍率、概率爆发与心结机制。暂不引入“压力改变透明度”，删除其未实装承诺，透明度仍采用种子和既有观测规则。

## 2. 现状问题

- 当前压力 ≥90 时倍率由 1.5 回到 1.0，不符合“越紧张越危险”的直觉。
- 当前负面分类按 base 正负判断；敌对增加甚至可能被当作正面，关系反转后的方向也没有重新分类。
- 当前音量超过 20 就影响人物，36 时一项敌对强度已封顶；UI 的 70 警示色却不对应新效果。
- 音量按人数累加，9/17/25 节点局不能公平共用档位。旧文档又混有“按场计”“60 达阈”说明。
- 当前环境压力与“2.8 基础怕吵”相乘，不容易向玩家解释强度与结算时机。

## 3. 玩家压力：四档且不回落

S 为压力，值域 0–100；显示一位小数，避免 39.9 被四舍五入成 40、却仍显示平稳。档位使用原始值判断。

| 原始压力 | 等级 L | 名称 | 关系伤害倍率 | 关系修复倍率 | 提示 |
|---|---:|---|---:|---:|---|
| 0 ≤ S < 40 | 0 | 平稳 | 1.00 | 1.00 | 心态平稳，互动正常结算 |
| 40 ≤ S < 70 | 1 | 紧张 | 1.25 | 0.90 | 关系更容易受伤，修复稍难 |
| 70 ≤ S < 90 | 2 | 高压 | 1.50 | 0.80 | 关系更易恶化，日末可能爆发 |
| 90 ≤ S ≤ 100 | 3 | 危急 | 1.75 | 0.70 | 关系伤害更重，日末爆发风险更高 |

查表等价的简单公式：

```text
关系伤害倍率 = 1 + 0.25 × L
关系修复倍率 = 1 − 0.10 × L
```

它们只用于原来经状态倍率结算的好感、敌对、信任事件，不额外加压力，不改变行为接受概率，也不把压力倍率重复乘入决策公式或传导。使用受影响者当前压力；若双方都有事件，双方分别结算。

### 3.1 伤害和修复按实际方向判定

先按原公式得到事件推动量（含性格、允许时的关系调制），再依据轴与推动量正负分类，最后乘压力档倍率。

| 数值变化 | 分类 |
|---|---|
| 好感增加、信任增加、敌对减少 | 关系修复 |
| 好感减少、信任减少、敌对增加 | 关系伤害 |
| 零变化 | 不产生效果 |

普通事件仍可因关系调制发生方向反转，反转后必须按实际方向选倍率。重大事件仍不受关系调制，但其真实关系效果也按此表乘状态倍率。压力轴不受以上两种倍率，保持其既有结算。

例：在不考虑原公式其他修正的倍率演示中，同样的 2 点关系伤害，四档对应 2/2.5/3/3.5；同样的 2 点修复，对应 2/1.8/1.6/1.4。它们是倍率示例，非最终事件收益承诺。

### 3.2 爆发保留简单线性概率

```text
日末爆发概率 = 50% × clamp((S − 70) / 30, 0, 1)
```

| 日末判定时压力 | 当日判定概率 |
|---:|---:|
| ≤70 | 0% |
| 80 | 16.7% |
| 90 | 33.3% |
| 100 | 50% |

保留每日一次判定；爆发后压力减 40、产生心结、按原规则扩散。不是一达到阈值就爆发，100 也不是必爆。UI 如展示概率，必须写“按当前压力估算的日末风险”，避免将当前值误解为今天最终风险。

日末先判爆发、再沿用既有心结与衰减顺序，压力保留率仍为 0.65。不改成“每日减固定点数”。

### 3.3 其余既有压力机制

保留 NPC 压力 ≥70 时决策温度 ×1.5、安慰目标压力 ≥70 的入口、既有闲聊接受压力惩罚与意向效用压力项。本次档位倍率不再次乘入这些概率。UI 的档位说明只解释共有的状态后果，不把性格不同的决策描述为“高压一定拒绝聊天”或“有人必然安慰你”。

## 4. 教室音量：四档，对应环境结算强度

V 为平滑后的教室音量，值域 0–100。

| 原始音量 | 等级 Q | 名称 | 中性人物每次环境压力 | 对发声邻座的敌对事件基础值 |
|---|---:|---|---:|---:|
| 0 ≤ V ≤ 20 | 0 | 安静 | 0 | 0 |
| 20 < V ≤ 40 | 1 | 活跃 | +1 | 0 |
| 40 < V ≤ 70 | 2 | 嘈杂 | +2 | +1 |
| 70 < V ≤ 100 | 3 | 喧闹 | +3 | +2 |

```text
环境压力增加 = Q × 怕吵倍率
音量敌对事件基础值 = max(0, Q − 1)
```

环境压力不再额外乘旧 stress_k、noise_base_fear；敌对不再乘旧 excess/noise_scale。移除两套重复入口，不能新旧效果叠加。

音量保持旧边界习惯：刚好 20 不影响人物，超过 20 才进入活跃；刚好 40、70 仍属于低一档。阈值判断不用 UI 四舍五入后的值。显示一位小数并让说明与档名一起更新，不做延迟档位或隐藏滞回。

“活跃”不代表所有人讨厌聊天：仅有轻微环境压力，不产生音量敌对。“嘈杂”开始出现邻座摩擦，“喧闹”加重两类效果；不自动禁言、阻止玩家操作或必然召来老师。

### 4.1 音量目标按在场人数归一化

采用一个明确口径：音量是全班发声强度的平均刻度，按人物当前公开行为计，不按会话数量计。替换旧文档“按场计”的描述，不再将同一场多人聊天视为只发出一人的声音。

```text
目标音量 = 100 × 在场人物噪音贡献总和 / (3 × 在场人数)
新音量 = 旧音量 + 0.2 × (目标音量 − 旧音量)
```

目标值 clamp 至 0–100；在场人数为 0 时目标为 0。包括在场玩家、睡觉者等安静人物；出门者从人数与贡献两者中排除。老师不算班级节点，老师在場仍沿用目标音量 ×0.5。

统一噪音等级：

| 行为类型 | 单人噪音贡献 |
|---|---:|
| 学习、睡觉、空闲、听音乐、看书、递纸条、走动 | 0 |
| 吃零食、安慰、道歉、举报等低声或轻微声响 | 1 |
| 闲聊 | 2 |
| 当众调侃、追逐打闹 | 3 |

没有在此表明确覆盖的行为，须在行为表中显式配置 0–3，不以“其他”硬编码默认发声。原来 study/move 的 1 改为 0，确保安静行为不会共同把教室推成活跃档。

例：全班学习目标 0；全班闲聊目标 66.7（嘈杂）；一半打闹、一半安静目标 50（嘈杂）；全班打闹目标 100（喧闹）。9/17/25 节点局相同比例近似同强度，离散人数造成的小差别正常存在。

这是较现状更大的尺度修订，必须与行为频率一起验收；不声称旧标定分布仍然成立。

### 4.2 怕吵倍率保留温和性格差异

复用性格四维里的专注与内向偏差 J、I，均为 −1～1：

```text
怕吵倍率 = 1 + 0.3 × J + 0.2 × I
```

自然范围 0.5～1.5；中性为 1。玩家与 NPC 使用同一公式，不按名字或 ID 判断。

环境压力直接按 Q × 怕吵倍率结算并 clamp 至 0–100；全局写入精度按既有 0.1。敌对的怕吵倍率作为原事件公式的外部 scale，只乘一次，继续走 UIF 的性格修正、允许的关系调制、软饱和与压力状态倍率。因此表里的敌对值是基础值，不是最后必定写入的点数。

### 4.3 结算时机与作用对象

- 保留现有全局每 240 tick 的环境结算入口，一天两个检查点。用该点的即时音量，不新增连续积分或每秒扣点；后来若改为整段均值，应另行提案。
- 环境压力作用于在场且未睡觉的人；出门者、睡觉者豁免，符合既有睡觉排除条款。
- 敌对只指向自己邻座内正在发声、未睡觉的人，最多取噪音贡献最高的两人；同强度按稳定索引顺序处理，以保持可复现性。选择不按角色名。
- 不开新的从众压力机制；deviance_k 仍为 0，不能暗示“安静教室说话也会额外加压”。

## 5. 减压行为与体验

沿用自然完成才减压：零食 1.5、音乐 2、课外书 2.5、睡觉 3。被铃声打断不获得减压；三个道具行为按原规则加中断压力 0.5。安慰仍走原事件公式，不把基础 −5 宣传成必定减 5。

以中性人物为例：一次活跃环境 +1，吃零食自然完成 −1.5；一次喧闹环境 +3，听完音乐 −2。玩家能理解“环境可能抵消一部分放松收益”，但不能以这个例子承诺一天净变化，其他事件与日末衰减仍在运行。

## 6. UI 与文案

- 音量卡：当前值/100、档名、20/40/70 分段刻度。提示依次为“无音量额外影响”“环境带来轻微压力”“开始产生邻座摩擦”“环境压力与邻座摩擦加重”。
- 自身压力卡：当前值/100、档名、40/70/90 分段刻度，放在音量卡下方；底部行为栏继续显示剩余时间和进度。
- 两卡均只用上述真实分界染色，不增加另一个 high_fraction。音量与压力仍有不同标题、图标；压力仅显示玩家自身，不显示 NPC 隐藏压力。
- 档位变化是状态反馈，不提示“到 70 必爆”“压力高会让所有收益变好”“喧闹必召老师”等不存在的保证。
- 颜色建议：平稳/安静青绿，紧张/活跃暖金，高压/嘈杂橙，危急/喧闹砖红；同时保留文字，避免只靠颜色理解。
- 旧 UI 规格的“压力数字永不做”与本次用户要求冲突；正式采纳后改为“玩家自身可显示，NPC 不显示”，同步解决 Q3。

## 8. 验收与标定纪律

功能验收：

1. 检查压力 39.9/40/69.9/70/89.9/90 与音量 20/20.1/40/40.1/70/70.1；表、公式与 UI 必须同档。
2. 各档同一关系伤害单调增强，同一修复单调减弱；敌对增加必须判伤害，普通关系反转后重新判方向；压力轴不重复放大。
3. 相同在场行为比例跨难度近似同音量；无人在场、睡觉、出门与老师压场都按明示规则处理。
4. 档位变色不提前/延后；读数 39.9 不显示 40；NPC 压力不泄露。
5. 爆发一次判定，不因跨档反复掷骰；同种子一致，Python/GDScript 对拍误差 ≤1%。

效果验收：全套六道门、现有测试与至少 100 局分布检查；不引用旧参数下的达标结果，不放宽门槛。依次检查压力分布、四档停留时间、爆发覆盖/次数、音量四档出场率、NPC 行为参与与关系分化。音量高档不要求每局出现，不能为保证演出写定日触发。

改参顺序：先统一分类与读表，再检验音量归一化，最后调环境压力与事件频率；每轮只改一个参数组并保存相同种子的对照。新档位与系数是合理起点，是否满足比赛切片的体验和既有指标须由模拟与试玩决定。

## 9. 决策摘要

推荐四档查表，而非保留旧连续音量公式再添加仅用于配色的档名；后者改动更小，却不能兑现每次跨档的实际反馈。也不建议两套量都用连续倍率：公式短，但不符合本次“档位与效果一致”的需求。

本提案采用“离散效果档位 + 连续音量平滑 + 线性日末风险”，公式少、数值单调、说明可直接从规则表生成。下一步应先评审本提案，再修改权威规格、实现与标定；这份文档不构成已修复或已验证的结论。
