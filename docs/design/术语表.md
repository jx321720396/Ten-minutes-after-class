# 术语表

> 状态：草案 ｜ 维护者：策划 / 程序 ｜ 最后更新：2026-10-04

术语定义以 [`../gdd/core-gameplay-v3.1.md`](../gdd/core-gameplay-v3.1.md) 为准；本表只做**中英对照与代码标识符约定**，避免各处命名漂移。新增标识符请先在此登记。

## 核心概念

| 中文 | 英文 / 代码标识符 | 说明 |
|---|---|---|
| 涌现 | Emergence | 本作主题：整体性质不由任何个体意图产生 |
| 班级格局 | class configuration | 涌现主体：小团体、孤立、阵营对立 |
| 社交节点 | social node | 矩阵中的一个角色；本局节点数 = 难度抽取 NPC 数 + 1 玩家 = 9/17/25 |
| 角色池 | `character_pool` | 24 个 NPC 种子，开局按难度随机抽取 8/16/24 个（简单/标准/困难） |
| 课间段 | break phase | 可操作段，每天 3 段（上午/中午/下午） |
| 上课段 | class phase | 发酵过场段，每天 2 段，玩家不可操作 |
| 学期 | term | 一局 = 30 个上学日 |
| tick | `tick` | 最小模拟步长；课间 1 tick = 6 秒游戏内；上课 1 tick = 30 秒游戏内 |

## 数值轴

| 中文 | 代码标识符 | 类型 |
|---|---|---|
| 好感 | `Affinity` / `A[i][j]` | 有向矩阵 N×N（N=9/17/25），0–100 |
| 敌对 | `Hostility` / `H[i][j]` | 有向矩阵 N×N（N=9/17/25），0–100 |
| 信任 | `Trust` / `T[i][j]` | 有向矩阵 N×N（N=9/17/25），0–100 |
| 透明度 | `Opacity` / `O[i]` | 个体属性，0–100 |
| 压力 | `Stress` / `S[i]` | 个体属性，0–100，唯一累积情绪变量 |
| 性格四维 | `MBTI` / `E, N, F, P`（外向/直觉/情感/感知） | 个体属性，各 0–100 连续值 |
| 性格系数 | `M_personality` | 由四维派生的纯函数，`clamp(1 + Σw_t·d_t, 0.1, 1.2)`（性格只能温和放大或削弱） |
| 状态系数 | `M_state` | 由压力区间决定 |
| 事件权重 | `W_event` | 查表得到的基础增量 |

## 影响力传导（主文档 §7）

| 中文 | 代码标识符 | 说明 |
|---|---|---|
| 听从度 | `w_ij` | i 对 j 的听从权重，由 `A[i][j]` 经性格修正 |
| 好感传导阈值 | `theta_A` | 初始 30 |
| 敌意传导阈值 | `theta_H` | 初始 40 |
| 饱和尺度 | `U_X` | 软饱和尺度：`u_a`=25 `u_h`=25 `u_t`=20 `u_o`=20 `u_s`=30 |
| 传导系数 | `beta_X` | 好感 0.12、敌意 0.18、信任 0.09、透明度 0.06（**每天 2 次结算**，见 §3.3）|
| 感知态度 | perceived attitude | 经透明度 + 信任两层过滤后 i 看到的 j 对 k 态度（最终版本使用） |

## 人物行为与观察层

> 行为清单来自主文档 §10「人物行为设计」；**不再使用 R1–R13 编号**。

| 中文 | 标识符 | 类型 | 说明 |
|---|---|---|---|
| 闲聊 | `chat` | 主行为 | 双方在闲聊范围内按概率触发；可传播流言、可被窃听 |
| 搭话 | `join_chat` | 主行为 | 加入他人正在进行中的闲聊 |
| 举报 | `report` | 主行为 | 对某人的敌对累积到阈值（或特殊行为）触发 |
| 告密 | `inform` | 主行为 | 把掌握的流言单独告诉目标，无法被窃听 |
| 传纸条 | `pass_note` | 主行为 | 闲聊的「不可被窃听、不可被搭话」版本 |
| 睡觉 | `sleep` | 主行为 | 本课间不做其他事，课间结束减压 |
| 走动 | `move` | 附加行为 | 下课瞬间执行位置更新 |
| 窃听 | `eavesdrop` | 附加行为 | 捕获范围内别人的闲聊内容 |
| 流言 | `rumor` | 附加行为 | 携带倾向 ∈ [−2, 2] 的社交信息；最多在记忆中停留 3 个课间 |
| 学习 | `study` | 默认行为 | 无主行为且未走动时的默认项，压力上升 |
| 共同学习 | `study_together` | **联合事件**（非独立行为） | 相邻（≤1 格）且双方主行为均为「学习」时触发：好感 +1、信任 +1；**每天 2 次结算**（上午 / 下午，§3.3） |
| 求助 | `ask_help` | 主行为 | 对目标好感 ≥30 发起；被拒有代价，被帮则对方进入「被亏欠」（§10.10） |
| 道歉 / 和解 | `apologize` | 主行为 | 双方敌对 ≥30 时发起；修复敌对关系，代价是发起者压力（§10.11） |
| 当众调侃 | `tease` | 主行为 | 需 ≥3 人围观；成功加好感，过火加敌对且围观者分裂（§10.12） |
| 安慰 | `comfort` | 主行为 | 目标压力 ≥70 时凑过去；深度关系的主要建立方式（§10.13） |
| 秘密交换 | `share_secret` | 主行为 | 双方信任 ≥60；守密成同盟，泄密则信任崩塌（§10.14） |
| 簇标签器 | `cluster_tagger` | **观察层（只读）** | 读矩阵输出「成团」标签，不回写任何数值 |
| 孤立标签 | `isolated` | **观察层（只读）** | 连续 10 tick 未进入对话且距最近者 ≥2 格 |
| 强连接 | `strong_link` | 判定 | `A[i][j] ≥ 60 且 A[j][i] ≥ 60 且 T ≥ 50 双向` |
| 打听 | `ask_about` | 玩家行为 | 消耗一次课间动作主动获取观测（见信念矩阵 §11.6） |


## 人物系统（主文档 §11）

| 中文 | 代码标识符 | 说明 |
|---|---|---|
| 性格层 | `personality` | 只有数值，没有行为 |
| 身份层 | `identity` | 姓名、原型、初始关系、初始标签；**只写开局种子** |

## 统一影响公式（UIF）

> 全部行为与 NPC 自主决策共用的一个公式，定义见 [`统一影响公式.md`](统一影响公式.md)。

| 中文 | 代码标识符 | 说明 |
|---|---|---|
| 推动量 | `P` | 事件推动与传导推动的代数和（写入前的合成量） |
| 事件推动 | `E` | 由行为事件产生的推动量（含性格 `d_t` 修正） |
| 传导推动 | `C` | 由他人超阈值态度产生的推动量（阈值 + 竞争归一化） |
| 软饱和 | `sat_X(u) = u / (1 + \|u\|/U_X)` | 小量近似直通、大量收敛于 `U_X` |
| 饱和尺度 | `U_X` | 各轴软饱和尺度（`u_a` `u_h` `u_t` `u_o` `u_s`） |
| 意向值 | `U_b` | NPC 对候选行为的评价（`Σ α_X · Δ_X^pred`） |
| 偏好权重 | `alpha_X(i)` | NPC 对各轴的在意程度（由性格四维派生，Σα = 1） |
| 意向温度 | `tau` | softmax 采样温度（高 J 更确定、高 E 更随机） |
| 透明度回归速率 | `lambda_o` | 把 `O` 缓慢拉回「基础透明度 × 压力系数」的速率 |
| 行为决策三段式 | 门槛 / 意向 / 采样 | 谁做什么的决策流程：硬条件筛选 → 意向评分 → softmax 采样，见 [`NPC行为决策.md`](NPC行为决策.md) |
| 标签可见性 | `tag_visibility` | 标签默认不可见，经「观察 / 被告知 / 推断」三条路径解锁（主文档 §9.6、[`信念矩阵.md`](信念矩阵.md) §11.8） |
| 关系调制 | `M(i, s)` | `clamp((A[i][s] − H[i][s])/50, −1, +1)`：按**净态度**调制互动事件的收益——态度不明显时只削弱，敌对压过好感时反转（[`统一影响公式.md`](统一影响公式.md) §2.1） |
| 可见性档位 | `VisibilityTier` | 透明度映射的观测能力档位（通透 / 可见 / 模糊 / 封闭），见 [`信念矩阵.md`](信念矩阵.md) §11 |
| 观测分类 | `classify()` | 立场三分类：亲近（绿，`A ≥ 60`）/ 敌对（红，`H ≥ 40`）/ 中立（灰） |
| 打听 | `ask_about` | 消耗一次课间动作、主动获取关于某人的观测；透露度 = 对方对你的信任 |
