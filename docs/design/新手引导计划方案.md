# 新手引导计划方案

> 制定：2026-10-12 ｜ 状态：待评审提案，未实现 ｜ 目标：10/18 提交版
> 本文是设计与落地计划，不替代玩法规格。评审确定后再将新增交互契约同步到玩法主文档及相关 UI 规格。

## 1. 目标与依据

让第一次进入教室的玩家知道自己是谁、如何完成一次行动、如何理解反馈，以及接下来能自由做什么。完成教程不以交到朋友、收到情报或出现小团体为条件。

依据：[玩法主文档](../gdd/core-gameplay-v3.1.md)第一至三章、第九章、§10.5、§10.32、第十二章、第十四章；[架构总览](架构总览.md)；[路线图](../production/路线图.md)；[冲刺计划](../production/聚光灯21天冲刺计划.md) D13 的开局三行说明。

默认假设：首版优先 Windows 鼠标操作，可跳过，与正式新局共用场景和规则。移动端提供可点击入口，快捷键不能成为唯一完成条件。

玩家要学会：

1. 我是班级的一员，同学们会自己行动。
2. 点地面走动；对人通常先选行为，再点同学；对自己做的事直接点按钮。
3. 行动和移动消耗课间时间，上课后不能继续课间操作。
4. 拒绝和铃声打断都是正常结果，一次互动不保证交到朋友。
5. 消息是线索，推理板记录自己的猜测，两者都不等于后台真相。

首版不要求理解公式、人格四维、全部行为或长学期策略。

## 2. 方案比较

| 方案 | 优点 | 成本与局限 |
|---|---|---|
| **推荐：短开场＋实际操作引导＋首次情境提示** | 学真实操作，随机结果都可继续，复用教室 | 需要步骤状态、UI 锚点与弹窗优先级管理 |
| 仅三行说明＋帮助页 | 工期最低，符合原冲刺任务 | 读完可能仍不懂点地面与点同学的区别 |
| 独立教学关卡 | 便于单独复习 | 多一套入口、初始化和退出流程，容易引入固定剧情 |

首版采用推荐方案。若工期不足，降级为开场卡、操作便签、结果解释和帮助页。

## 3. 玩家流程与文案

### 3.1 入口与重复规则

- 首次新游戏：教室、人物与 UI 就绪后显示开场卡，此前不推进世界。
- 开场提供「带我熟悉一下」「直接开始」。后者跳过主动教学，不代替玩家执行行动。
- 后续新局：不强制重复完整教程；暂停菜单保留「操作帮助」「重新引导」。
- 继续游戏：不补播开场；完整存档接入后恢复教学步骤，上课或忙碌时等待合法阶段。
- 重新引导：在当前局重新介绍操作，不重置种子、日期、关系、人物或库存。

### 3.2 开场三行

标题：**欢迎来到新班级**

> 你是新来的转学生，也是班级里的一员。  
> 下课后可以找人聊天、走动，或做自己的事。  
> 同学们会自己行动；听消息、看变化，拼出你理解的班级。

补充：`没有规定的交友路线，先试一次操作就好。`

### 3.3 主引导步骤

| 步骤 | 呈现与建议文案 | 完成条件与分支 |
|---|---|---|
| A 找到自己与时间 | 高亮玩家与时间卡：`这是你。每天有三段课间，铃响后同学们会回座位。` | 点「知道了」；不暴露 NPC 隐藏信息 |
| B 走动 | 指向可通行地面：`点空地走过去，也可以用 WASD。走动会花掉课间时间。` | 实际发生合法移动后完成；不可达点击不算完成，保留业务错误提示 |
| C 对人行动 | 高亮闲聊：`先选「闲聊」，再点一个同学。需要靠近时，你会自动走过去。` | 选行为、选对象后跟随真实提交与反馈；对象由玩家自由选择 |
| D 看一次互动 | 新聊天：`行动进行时会占用时间，看这里的进度。`；加入：`加入已有聊天需要对方接受，圆盘只是你估计的把握。` | 新聊天结束或中断后继续；加入等待原请求结果揭晓。拒绝、对象失效或其他失败均解释并提供「继续了解」，不要求反复尝试 |
| E 查线索与记判断 | `按 Tab 可以翻聊天记录。消息只是线索，未必是事实。推理板可以记下你的猜测。` | 打开日志或点「知道了」；空日志显示真实空态，不编造示例消息。推理板仅介绍入口，不强制画线 |
| F 自由尝试 | `接下来由你决定：继续聊天、主动学习，或听音乐歇一会儿。班级会继续变化。` | 点「开始我的课间」结束主引导；不强制消耗零食、出门或参与高风险行为 |

体验目标为约 2–3 分钟真实时间，含阅读；不因此改变课间长度。无需第一段课间完成，铃响后保留步骤，下个可操作课间继续。玩家随时可以改选行为、移动或跳过。

教程只高亮当前存在的入口，不为教学启用被规则禁止的行为，不额外设置行动次数限制。

### 3.4 首次情境提示

按真实事件触发，默认每条一局一次；这些事件不出现也能完成教程。

| 情境 | 提示 | 限制 |
|---|---|---|
| 首次上课 | `上课了，课间行动暂时停下；同学之间的影响仍会发酵。` | 不承诺下课必然冲突，不延长课堂 |
| 首次 NPC 邀请 | `你可以接受或拒绝；不回应也不会自动参加。` | 非阻塞，不挡按钮，不额外延长邀请有效期 |
| 首次暂不可用 | `暂时不能做？看看按钮提示的原因。` | 原因取自业务接口，不另写门槛 |
| 首次主动学习 | `学习会逐渐加快世界，走动或切换行为会结束学习。` | 遵循最新持续学习契约，不说“不点也会涨成绩” |
| 首次减压活动 | `听音乐等活动可以让你缓一缓；铃响打断时，不会获得完成后的效果。` | 不显示压力数字，不保证指定情绪 |
| 首次获得课外书 | `现在可以看课外书了；被老师看到正在看书，书会被收走。` | 复用原风险提示，不叠加相同卡片 |
| 首次推理板 | `拖入头像、画线，记下你的想法；这块板记录的是你的判断。` | 不宣称已有自动矛盾高亮或真相校验 |
| 首次日末 | `今天结束了，关系会延续到明天。` | 绑定现有日末界面；完整每日简报接通后再增加解读 |

压力、音量、库存、成绩与老师风险按需介绍，不在开场集中灌输。活动圈说明为“正在参与活动”，不能解释成“已经成为朋友的小团体”。

## 4. 节奏与异常处理

沿用校园纸面主题与霞鹜文楷。一张便签、一个明确高亮、正文最多两句；动词放前面，不只靠颜色指示。1080p 基准正文按现有视觉指南的可读字号验收，遮罩不能挡住当前目标。

阅读卡暂停世界，点「试一试」释放教程自己的暂停；操作时便签不阻塞，移动、互动与 NPC 行动照常运行。教程不修改行为倍率或学习加速规则。

冻结必须覆盖时钟、NPC 移动、行为占用、玩家学习现实秒累计。现有 `SimulationClock.hold()` 与场景暂停并非同一机制，实施时须核对所有世界消费者；不能只停时钟让人物继续走。关闭教程仅释放自己的暂停来源，不能解除转笔、推理板或暂停菜单的锁。

已有确认弹窗、转笔揭晓、暂停菜单和推理板优先，教学说明排队。实时邀请出现时收起非阻塞教学便签，不遮挡、不代点邀请。退出、跳过和切场景清除教学高亮及自身锁。

铃响按真实边界执行：不延后、不补收益。主操作步骤挂起，上课提示单独显示，下个课间继续。对象忙碌、睡着、离开或路径失效时撤销失效高亮，允许另选。无合法对象时允许查看帮助或稍后继续。

## 5. 涌现与工程边界

- 只控制说明顺序和高亮，不写人物行为、关系、压力、库存或观察标签。
- 不按 NPC 名字／ID 指定友好对象。推荐对象只能依据当前公开状态、合法性与可达性，仍允许自由选人。
- 不提高接受率、不保证情报、不额外掷随机数、不重复提交直到成功。
- 不设计“第一天必成团”等剧情；首次解释由真实事件触发。
- 不读取未过滤真值；可见线索沿用业务接口。教程不向玩家承诺尚未实现的能力。
- 展示参数集中在 `data/ui/`，内核不引用教程节点。

**检验一**：将同学变化替换为固定脚本，就会失去玩家自由选择后产生不同关系与格局的核心体验。教程只教操作和理解，不规定格局；接受、拒绝与平静开局都能完成教学。

## 6. 落地任务

以下是拟新增／接入位置，不表示已经实现；不包含无关内核重构。

| 模块 | 建议位置 | 职责 |
|---|---|---|
| 引导控制器 | `scripts/game/tutorial_controller.gd`、`scenes/game/tutorial_controller.tscn` | 步骤、已读记录、挂起恢复；订阅结果，不判定或结算 |
| 便签与高亮 | `scripts/ui/tutorial_overlay.gd`、`scenes/ui/tutorial_overlay.tscn` | 锚点、阅读卡、跳过、帮助；仅发 UI 意图 |
| 配置 | `data/ui/tutorial_steps.csv` | 标识、文案、锚点、完成事件、显示模式；尺寸与时长沿用／扩充现有主题配置 |
| 装配 | `scripts/game/classroom.gd` | 就绪后注入时钟、玩家、行为栏、反馈与信息入口 |
| 通知 | 现有玩家／交互控制器和反馈 HUD | 复用移动、选行为、揭晓、完成／中断事件；缺失处补只读语义信号 |
| 帮助入口 | `scripts/ui/pause_menu.gd` | 操作帮助、重新引导 |
| 进度 | 独立 `user://` 教学偏好记录；未来接完整存档 | 全局记开场已读；局内记步骤、提示项与版本 |

状态区分未开始、进行中、已完成、主动跳过，跳过不算完成。事件按请求编号去重，不因重新引导而重提行动。首版退出可丢失局内步骤，重进可主动重引导；不宣称已支持完整存档续教。文案更新仅提示新增帮助，不强迫老玩家全程重学。

| 批次 | 交付 | 粗估 |
|---|---|---|
| 1 | 确定范围与文案，同步主文档、UI 清单、冲刺任务 | 0.25 人日 |
| 2 | 开场、便签、高亮、A–F、帮助入口 | 0.75–1 人日 |
| 3 | 失败分支、暂停仲裁、首次提示、偏好记录 | 0.5–0.75 人日 |
| 4 | 多开局回归、画面验收、新玩家试玩 | 0.5 人日 |

总计约 2–2.5 人日，是计划估算。实施前核对通知接口和冻结链路；建议 10/13 接主流程，10/14 补分支与试玩，10/15 前收敛，给构建回归留时间。

首版必做：A–F、跳过与帮助、失败解释、跨相位处理、暂停释放。后续扩展：完整续教、全部行为实操、自动证据校验、独立教学关卡。

## 7. 验收

1. 首次新局显示开场；跳过后恢复操作，后续新局不强制重播。
2. 点地面移动、选闲聊再点人可以走通；UI 点击不穿透为移动。
3. 新聊天、加入接受／拒绝、对象失效、铃声中断和零情报都不阻塞教学。
4. 阅读卡冻结所有世界推进，恢复不补跑；与 Esc、转笔、推理板、出门确认叠加时不误解除他人的暂停。
5. 连点、跳过、重引导、退出不重复提交行动，不遗留遮罩或锁。
6. 上课／日末不要求课间操作，不伪造成功结算或隐藏真值。
7. 至少三种随机开局人工走查；技术回归用可复现种子覆盖失败、忙碌、无线索和边界，不把固定种子绑定正式教学。

关键自动测试聚焦暂停仲裁、提交幂等和状态恢复；文案、高亮、可读性用实际教室截图检查。实施后执行仓库规定的适用门禁与 Godot 测试。本次只提交方案，不声称引导通过游戏测试。

找 3–5 名未接触项目的玩家，不口头指导：目标至少 80% 在约 3 分钟内独立完成一次行动或解释失败；能说出操作顺序、找到聊天记录，知道消息未必真实、班级自行变化，并能选一个自己想尝试的下一步。以上是目标，非实测结果；小样本只用于发现卡点，不据此修改关系数值。

## 8. 评审重点

默认采用同局渐进教学、Windows 优先、可跳过与按需解释。重点确认：约 2–2.5 人日是否符合冲刺预算；日志与推理板是否保留为提交版可见入口。若最终隐藏入口，同步移除对应教学内容。
