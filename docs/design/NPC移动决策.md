# NPC 移动决策

> 状态：设计稿  \n+> 维护日期：2026-10-07  \n+> 关联：[`../gdd/core-gameplay-v3.1.md`](../gdd/core-gameplay-v3.1.md) §10.4、§10.20、§10.31；[`NPC行为决策.md`](NPC行为决策.md)；[`架构总览.md`](架构总览.md)
>
> 本文定义 NPC 在课间的空间决策：先判断是否留在座位，再决定去找谁，最后决定到达后做什么。关系效果仍由既有行为规则计算。

---

## 1. 目标与边界

NPC 的移动是状态层，不是关系事件。移动只改变课间临时位置和时间占用，不直接修改好感、敌对、信任或压力。

每次移动决策解决三个连续问题：

1. **是否留在座位**：当前课间是否值得离座。
2. **去找谁**：如果离座，应靠近哪个角色或活动圈。
3. **到达后做什么**：根据目标状态和自身关系，选择闲聊、搭话、安慰等既有行为，或回到学习/独处。

禁止按角色名、角色 ID、固定日期或固定课间触发行为。

## 2. 空间模型

### 2.1 两种位置

- `seat_of`：角色的固定座位，跨天保留，决定上课位置和默认邻接关系。
- `position`：课间临时位置，离座后用于距离、活动圈和目标可达性判定。

课间开始时，未离座角色的 `position` 等于 `seat_of`；课间结束或上课开始时，所有角色回到 `seat_of`。

### 2.2 站立点与占用

移动目标必须是教室内有效站立点。站立点来自座位表或空间配置，不从角色名称推导。每个站立点同时只能容纳一个移动目标；已被占用、不可达或不在当前相位的点不进入候选。

被举报离开教室的状态沿用既有规则；它不是普通移动目标，也不参与活动圈。

### 2.3 距离与活动圈

距离使用空间层提供的网格距离或邻接关系。移动层只提供目标可达性、互动范围和附近活动圈；观察层只能读取这些状态，不能回写位置、关系矩阵或压力。

## 3. 课间时序

```text
段首状态清理
→ 睡觉判定
→ NPC 判断是否离座
→ 选择目标角色或活动圈
→ 选择抵达后的行为
→ 执行移动并占用时间
→ 到达后调用既有行为规则
→ 课间结束归位
```

睡觉者跳过移动和交互。上课阶段位置固定，不能移动。同一 tick 内按角色索引升序决策；已睡觉、离场、移动中或处于行为 busy 期的角色不重复决策。

## 4. 第一步：是否留在座位

### 4.1 硬条件

以下任一条件成立时必须留在座位：当前不是课间；正在睡觉；正在移动或处于其他行为的 busy 时间槽；没有有效站立点或可达活动圈；无法承担移动时间成本。留在座位后交给既有行为决策。

### 4.2 移动意愿

非硬条件下，NPC 对 `move` 做一次段首概率判定。基础概率来自 `data/rules/behavior_probs.csv`，不在脚本内写常数。

允许的修正因素：

- 外向度 E：E 越高越愿意离座，E 越低概率下降，但永不降为零；
- 当前压力：高压力可提高寻找他人或离开原位的意愿，系数必须配置化；
- 可达目标数量：没有目标时不产生无意义移动；
- 当前行为状态：已有明确主行为时不重复离座。

性格四维、透明度和当前状态通过纯函数参与修正，禁止使用角色名、角色 ID 或预设人格标签分支。

判定失败输出 `stay`；判定成功进入目标选择，不立即修改关系数值。

## 5. 第二步：去找谁

### 5.1 候选类型

候选分为角色目标和活动圈目标。角色目标用于安慰、求助、搭话等有明确对象的行为；活动圈目标用于加入附近已有活动。候选必须未睡觉、未离场、未处于不可打断的 busy 状态，且位置有效、可达。

### 5.2 目标评分

```text
score(i, target)
= relation_fit(i, target)
 + state_fit(i, target)
 + activity_fit(i, target)
 + distance_fit(i, target)
 + personality_fit(i, target)
 + seeded_noise(i, target)
```

`relation_fit` 使用好感、敌对、信任及对方反应信念；`state_fit` 使用目标压力和活动状态；`activity_fit` 奖励可加入活动圈；`distance_fit` 让近处成本更低但不把远处绝对禁用；`personality_fit` 由自身四维和透明度派生；`seeded_noise` 用带种子的随机数打破完全相同的分数。关系值只用于意向和行为门槛，移动层不写关系矩阵。

### 5.3 加权抽样

先按配置取 top-N，再用温度 `tau` 做 softmax：

```text
p(target) = exp(score(target) / tau) / Σ exp(score(k) / tau)
```

`tau` 必须大于零，并沿用 [`NPC行为决策.md`](NPC行为决策.md) §4.4 的配置。所有候选低于最低分时取消移动并保持在座位。

### 5.4 选择站立点

确定角色或活动圈后，从目标附近有效站立点中选择：优先目标临时位置附近；被占用则选择距离目标最近的空闲点；同分使用带种子的 RNG；无有效点则取消移动。目标选择与站立点选择分开，避免把座位编号直接当作社交意图。

## 6. 第三步：到达后做什么

到达后使用既有“门槛 → 意向 → 采样”算法。移动层只提供位置和上下文，不绕过行为规则。候选包括：附近闲聊时的 `join_chat`/`chat`；目标压力达标时的 `comfort`；关系和信任达标时的 `ask_help`/`share_secret`；敌对和围观条件达标时的 `tease`/`exclude`；无可行行为时的 `study` 或等待。

具体门槛、接受概率、影响值和耗时分别由主文档、`data/rules/behavior_thresholds.csv`、`data/rules/behaviors.csv` 和 `data/balance/w_events.csv` 提供。

状态流转：

```text
seat → deciding → moving → arrived → acting
                              └────→ waiting/study
```

移动成功不等于行为成功；移动期间不能发起或接受新交互；行为失败仍承担移动成本；行为被拒绝使用对应既有拒绝效果。没有合适行为时停留到移动耗时结束，再学习或等待。

## 7. 时间成本与中断

移动使用 `data/rules/behaviors.csv` 中 `move.duration`，当前规格为 15 tick。移动开始设置 `busy_until`，busy 期间不参与其他主行为；课间结束或相位切换统一归位；铃声打断按主文档 §10.4 的 `interrupted_stress` 结算。归位不产生关系变化。移动噪音只进入环境层，不自动造成敌对。

## 8. 玩家与 NPC 的区别

玩家主动选择站立点，不经过 NPC 移动概率和意向采样；仍受空闲站立点、移动耗时、行为门槛、busy 和课间剩余时间限制。到达后与 NPC 共用行为效果 API。

## 9. 可复现性与并发

| 约束 | 规则 |
|---|---|
| 随机数 | 移动概率、目标抽样、站立点抽样使用带种子的 RNG |
| 决策顺序 | 每 tick / 段首按角色索引升序 |
| 占用冲突 | 先决策者锁定站立点，后决策者重新计算候选 |
| 对话冲突 | 已在活动圈或 busy 的角色不能接受第二个主行为 |
| 回放 | 同种子、同配置、同输入得到相同位置和行为序列 |
| 观察层 | 只读位置与活动圈，不写移动或关系状态 |

## 10. 配置建议

| 参数 | 建议位置 | 用途 |
|---|---|---|
| `move` 基础概率 | `data/rules/behavior_probs.csv` | 每段课间离座判定 |
| `move.duration` | `data/rules/behaviors.csv` | 移动时间成本 |
| 外向/内向修正 | `data/rules/behavior_probs.csv` 或移动配置表 | 离座概率修正 |
| 目标邻接权重 | 移动配置表 | 近邻和活动圈偏好 |
| `tau0`、`top_n` | `data/balance/npc_weights.csv` | 目标和行为采样温度、候选数量 |
| 目标最低分 | 移动配置表 | 防止无意义移动 |

第一版尽量复用已有配置；未新增参数时，沿用主文档 §10.4 的外向修正、§10.20 的空间邻接和现有 NPC 决策温度。

## 11. 测试与验收

### 11.1 单元测试

- 睡觉角色不会移动，也不会成为移动目标；
- 上课相位不会产生移动；
- 无空闲站立点时，即使概率通过也保持原位；
- 移动期间不能发起或接受第二个主行为；
- 移动不改变 A/H/T/Stress；
- 课间结束所有临时位置回到固定座位；
- 行为门槛不满足时，靠近目标不会强行产生行为。

### 11.2 可复现性与多样性

同一 seed、同一配置、同一输入连续运行两次，逐段比较是否离座、目标、临时位置、到达行为、`busy_until` 和归位结果，必须完全一致。多种子运行时，离座率不能为 0 或全员每段离座，目标选择应有跨局差异，且不能压缩关系结果的良性方差。

### 11.3 静态检查

移动逻辑不得出现角色名或角色 ID 分支；阈值、概率、耗时来自 `data/`；观察层没有移动或关系写入；RNG 不使用全局 `randi()`；`scripts/core/` 不引用场景或 UI 类型。

## 12. 实施顺序

1. 为空间层补齐 `position`、站立点占用和归位接口；
2. 在课间段首加入“是否离座”判定；
3. 实现角色目标与活动圈目标评分和 seeded softmax 抽样；
4. 将到达后的行为选择接回现有 NPC 行为决策入口；
5. 添加并发锁、busy 和中断处理；
6. 补齐单元测试、同种子回放测试和多种子机制上场率检查；
7. 运行六道门，并同步主文档 §10.4 的实现状态、`CHANGELOG.md` 和相关架构说明。

## 13. 设计结论

```text
先决定要不要离座
→ 再决定接近谁或哪个活动圈
→ 最后决定是否执行具体行为
```

移动改变互动机会，却不把“靠近”直接变成关系变化；社交结果仍由底层关系、性格、透明度和行为规则共同产生。
