# 数据模型

> 状态：草案 ｜ 维护者：程序 ｜ 最后更新：2026-10-04
> 规格依据：`../gdd/core-gameplay-v3.0.md` §5（态度轴）、§8（情绪）、§11（人物四层）、§3.5（跨天结算）

## 1. 运行时状态（一局的全部可变数据）

```gdscript
# 关系矩阵：17×17 有向，0–100
class Relations:
    var affinity: PackedFloat32Array   # A[i][j] = i 对 j 的好感
    var hostility: PackedFloat32Array  # H[i][j] = i 对 j 的敌对（与 A 独立，不是负数）
    var trust: PackedFloat32Array      # T[i][j] = i 对 j 的信任

# 个体属性（长度 17）
class ActorState:
    var opacity: PackedFloat32Array    # O[i] 透明度
    var stress: PackedFloat32Array     # S[i] 压力（唯一累积情绪变量）
    var mbti: PackedFloat32Array       # 4×17：E/N/F/P 各维度 0–100 连续值
```

- 索引 0–15 为 NPC，索引 16 固定为玩家（转学生），玩家与 NPC 共用同一套结构与规则。
- 有向存储：`A[i][j] ≠ A[j][i]`，读写一律用"谁对谁"的语义，避免矩阵转置错误（建议提供 `a(i, j)` 访问器而非裸下标）。
- 所有轴 `0–100`，钳制在写入点统一处理（v3.0 §6.1 的 `clamp`）。

## 2. 静态配置（`data/`，只读）

### 2.1 角色种子表 `data/characters/seeds.csv`

对应 v3.0 §11.4 的 24 角色种子表。字段：

| 字段 | 说明 |
|---|---|
| `id` | 编号 01–24 |
| `alias` | 代称（仅显示用，**不得用于逻辑判断**） |
| `archetype` | 原型（用于抽取去重与初始关系规则） |
| `mbti` | 四字类型（展示用；数值以下面四列为准） |
| `e` `n` `f` `p` | 四维连续值 0–100 |
| `opacity_init` | 初始透明度 |
| `identity_seed` | 身份层种子（如"班长""小情侣绑定 02"） |
| `tags_init` | 初始标签（如"玩手机"）— **环境事实**，需在文档中明示 |
| `initial_relations` | 特殊初始关系（如"对 01 好感 85/信任 80"） |

### 2.2 规则参数 `data/rules/*.csv`

| 文件 | 内容 | 规格来源 |
|---|---|---|
| `transmission.csv` | `theta_A` `theta_H` `sigma` `beta_affinity` `beta_hostility` `epsilon` | v3.0 §7.2 参数表 |
| `decay.csv` | 跨天衰减系数（好感/敌对/信任/压力） | v3.0 §3.5 |
| `phases.csv` | 各相位 tick 数与规则启用子集 | v3.0 §3.2、§3.3 |

### 2.3 数值表 `data/balance/w_events.csv`

统一增量公式的 `W_event` 全表（v3.0 §6.1）。字段：`event_id`、`axis`（A/H/T/S）、`delta`、`delta_min`、`delta_max`、`note`。

**所有数值必须可追溯到 v3.0 的某条规则或标定目标（§3.4）**，不允许无出处的数字。

## 3. 派生数据（只读，不存储）

| 数据 | 派生方式 | 规格 |
|---|---|---|
| 情绪标签 | 压力区间 × 近期事件效价 × 性格底色 | v3.0 §8.3 |
| 簇标签 / 孤立标签 | 强连接图连通分量 + 稳定性滤波（≥5 tick / ≥10 tick） | v3.0 §10 O1 |
| 感知态度 | 真实态度经透明度过滤 + 信任校准 | v3.0 §9.1、§7.4 |
| 力量指数（用于可视化） | 由 A/H/T 与压力组合，仅表现层使用 | 待定（见 `../art/视觉风格指南.md`） |

## 4. 存档模型

- 关卡粒度：**单日 = 一个自然存档单元**（v3.0 §3.1）。存档点位于每天"放学结算"完成后。
- 存档内容：关系矩阵 + 个体属性 + 当日事件日志引用 + 玩家推理板状态 + 随机数种子。
- 格式：`user://savegame.dat`（现有原型路径）+ 版本号字段，便于后续迁移。
- 单局回放（进阶，v3.0 §14.3）依赖事件日志的完整记录：**日志必须可重放**，因此随机数必须来自可复现的种子化 RNG。
