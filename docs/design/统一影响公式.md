# 统一影响公式（UIF）

> 状态：草案 ｜ 维护者：程序 / 策划 ｜ 最后更新：2026-10-04
> 规格依据：[`../gdd/core-gameplay-v3.1.md`](../gdd/core-gameplay-v3.1.md) §5（底层态度轴）、§6（数值公式）、§7（影响力传导）、§8（情绪状态）
> 一句话：**所有行为（玩家的与 NPC 自主涌现的）对任何连续量的改变，都只填一张表，然后走同一条公式。**

---

## 1. 为什么要合并

| 现状 | 问题 |
|---|---|
| §6.1 事件公式 `Δ = base × clamp(1 + Σwᵢdᵢ, 0.1, 1.2)` | 纯乘性修正，无阈值无饱和，多个事件叠加会爆表 |
| §7.2 传导公式 `Δ = β × tanh(net/σ)` | 只作用于态度，与事件侧没有接口 |

两者输出的其实是同一种东西——**某条边 / 某个体量的一个增量**。因此合并为「**一个公式主体 + 一张参数表**」：
行为规则只负责填 `base` 与四个性格权重，NPC 决策与效果计算共用同一公式。

## 2. 公式主体（三段式）

对任意受影响量（有向边 `i→k` 上的轴 `X`，或个体量 `i` 的轴 `X`），每 tick 汇总后**只写一次**：

```
① 推动量   P = E + β_X · C
② 软饱和   Δ = M_state · sat_X(P),      sat_X(u) = u / (1 + |u| / U_X)
③ 写入     X ← clamp( X + round(Δ, 1) , 0, 100 )    ← 全局精度 0.1
```

### 2.1 事件推动 `E`

沿用 §6.1 的形式（**不推翻已填的权重表**）：

```
E = Σ_events  base_e(X) × clamp( 1 + Σ_{t=1..4} w_{e,t} · d_t , 0.1, 1.2 )

  d_t = (MBTI维度_t − 50) / 50        顺序固定：d₁=E/I, d₂=S/N, d₃=T/F, d₄=J/P
  base_e(X)   该事件对轴 X 的基础变化量（正=增、负=减），策划填表（§6.3）
  w_{e,t}     该事件对第 t 维的敏感度（策划填表）
```

同一 tick 内若有多个事件作用于同一 `(i,k,X)`，`E` 取**代数和**。

> **性格系数区间 = 0.1 ~ 1.2**：性格对效果的影响**温和**——最敏感者最多放大到 1.2 倍（+20%），最迟钝者降到 0.1 倍。因此文档中「敏感 ×1.5」「内向 ×2」之类的表述，一律理解为**通过该事件的 `w` 系数实现，且最终倍率落在 0.1~1.2 之间**（敏感者接近 1.2、普通人接近 0.6、迟钝者接近 0.15）。
> 例外：**概率类修正**（成功率 +25%、守密概率 −30%）与 **`M_state`**（压力区间系数）不是这个倍率，不受此限。


#### 关系调制（所有"与特定对象互动"的事件都适用）

按**净态度**（好感 − 敌对）调制：**态度不明显时只削弱、敌对明显压过好感时反转**：

```
M(i, s) = clamp( (A[i][s] − H[i][s]) / 50 , −1, +1 )
正向事件（好感 / 信任类）：Δ = base × M
```

| `A` | `H` | `M` | 效果（`base = 3`） |
|---|---|---|---|
| 65 | 0 | +1.00 | +3.0（满额） |
| 30 | 20 | +0.20 | +0.6（削弱） |
| 30 | 45 | −0.30 | **−0.9（反转）** |
| 10 | 55 | −0.90 | **−2.7** |

- **不对称是天然的**：A 与 C 各自用自己的 `A/H` 算 `M` → 同一场聊天一方加、一方减；
- **透明度不参与调制**（它管的是传导与观测）；敌对的三条独立路径（意向抑制 / 阈值触发 / 敌对传导）与调制并行。

### 2.2 传导推动 `C`

沿用 §7.2 的阈值与竞争归一化（**这两条是涌现的关键，不可省**）：

```
C_X = ( Σ_j w_ij · σ_X[j→k] ) / ( Σ_j w_ij + ε )

  w_ij  = A[i][j] / 100                        听从度（i 愿意听 j 的程度）
  σ_A   = max(0, A[j][k] − θ_A)                他人对 k 的超阈值好感
  σ_H   = max(0, H[j][k] − θ_H)                他人对 k 的超阈值敌对
  σ_T   = max(0, T[j][k] − θ_T)                他人对 k 的超阈值信任

  好感： C_A = ( Σ w_ij·σ_A − Σ w_ij·σ_H ) / ( Σ w_ij + ε )
  敌对： C_H = ( Σ w_ij·σ_H − Σ w_ij·σ_A ) / ( Σ w_ij + ε )
  信任： C_T = ( Σ w_ij·σ_T ) / ( Σ w_ij + ε )
  透明度：C_O = 0        （初始版本，见 §2.4）
  压力： C_S ≡ 0         （压力不传染，只由自身事件与消解驱动）
```

- 好感与敌对**互相反向抑制**（他人对我讨厌的人有好感 → 拉低我好感），两轴仍独立写入，不互相扣减。
- M2 增强项：`w_ij` 改用 `(A[i][j] + T[i][j]) / 200`，让信任也参与"听谁的"。

#### 传导输入 = 感知态度（正式条款）

`C` 里的 `A[j][k]`、`H[j][k]`、`T[j][k]` **一律使用 i 感知到的值**，而不是后台真实值：

```
σ_X[j→k]      = max(0, 感知_X(j→k) − θ_X)
感知_X(j→k)   = 真实_X(j→k) 经 j 的透明度档位过滤（见 [`信念矩阵.md`](信念矩阵.md) §11）
```

含义：**低透明度的人，他的真实态度不扩散，只有他"演出来"的那部分才扩散**。这是"藏得住的人真的藏得住"在机制上的保证——否则这类设计只是一句愿望。

### 2.3 软饱和与写入

```
sat_X(u) = u / (1 + |u| / U_X)

  |u| ≪ U_X  →  sat ≈ u        小量近似直通：现有事件权重表不必重新标定
  |u| → ∞    →  sat → U_X      单 tick 单条边变化有界，一次冲击不会把关系推到底
```

- 对 **好感 / 敌对 / 信任 / 透明度**：`Δ = M_state · sat_X(P)`，其中 `M_state` 由压力区间给出（§6.2 的区间）：
  `0–40 → 1.0` ｜ `40–70 → 负面 1.5、示好 0.5` ｜ `70–90 → 1.5` ｜ `90+ → 按性格`（好斗/敏感 0，随和/外向 1.5）
- 对 **压力**：`Δ_S = sat_S(P_S)`，**不乘 `M_state`**（避免用自身状态修正自身）。

> **精度**：所有写入前一律 `round(Δ, 1)`。因此**单次结算幅度应设计为 ≥ 0.1**，否则会被舍入归零（涓流类现为 0.5–2，安全）。

### 2.4 透明度的处理（乘性基座 + 统一公式偏移）

保留 §6.2「压力高则被看穿 / 封闭」的语义，同时允许透明度被事件与传导**偏移**：

```
O[i] ← clamp( O[i] + Δ_O + λ_O · ( O_init[i] × M_stress(stress_i) − O[i] ) , 0, 100 )

  Δ_O   = M_state · sat_O( E_O + β_O · C_O )
  E_O     暴露类事件的推动：实名举报、当众发言、当众爆发 → 推高；独处、沉默 → 拉低
  λ_O     回归速率（初值 0.03）：越小则暴露事件的痕迹越持久
```

第一项是**偏移**（临时暴露/隐藏），第二项是**基座回归**（缓慢拉回"基础透明度 × 压力系数"）。两者共存，既满足"透明度可被增减"，也保留原设计的压力形态。

### 2.5 数值范围与结算频率（全局铁律）

> 目的：**防止班级快速两极分化**。所有数值都必须小步累积；戏剧性来自阈值相变，而不是单次大数字。

#### 2.5.1 基础增减范围：常规 `1–3`，重大 `4–5`

| 档位 | 范围 | 适用事件 |
|---|---|---|
| **常规** | `base ∈ [1, 3]` | 日常互动：搭话、闲聊、调侃、安慰、求助、道歉、被拒绝… |
| **重大** | `base ∈ [4, 5]` | **前置条件苛刻**者：举报（须敌对累积到阈值）、秘密泄露（须先有秘密交换）、被团体排斥（须先有团体）、信任者背叛（须高信任） |

- **判据是「前置条件」，不是主观感受**：任何角色都能轻易触发的事件，只能是常规档；
- 越界即配置错误：`config_loader` 启动时校验 `w_events.csv`，越界直接报错；
- "重击"优先用「多轴联动 + 状态标签 + 阈值相变」表达（见 2.5.3），而不是抬高 `base`。

#### 2.5.2 三类结算频率

| 类别 | 例 | 结算方式 | 单次幅度 |
|---|---|---|---|
| **事件类** | 搭话、闲聊、调侃、安慰、举报、递纸条 | 事件触发时结算 | `base ∈ [1,5]` |
| **涓流类**（**含影响力传导**） | 共同学习、独处恢复、**传导 `β_X·C`** | **每 `settle_interval` tick 结算一次**（初值 10） | 1–5（传导约 0.5–2） |
| **状态类** | "心结""委屈"等标签的每日影响 | 每天结算一次 | 1–5/天 |

> ⚠️ **传导必须归入涓流类**：它每个 tick 都在发生，若按 tick 结算，`β·C` 会在一个课间段内把关系推到上限（旧值 `β_A=0.30`、`C≈49` → 每 tick +10.8）。

#### 2.5.3 重大事件的表达模板（不用大数值）

```
① 多轴联动   一次事件同时动 2–3 个轴，各 ±5
② 状态标签   追加持续影响（如「心结」3 天，每天初始压力 +5）
③ 阈值相变   叠加后冲过压力 90 → 爆发（全班事件，周围人按性格分裂）
```

示例——**被举报**（旧版为压力 +20 / 敌对 +25）：

| 项 | 新值 |
|---|---|
| 被举报者压力 | +5 |
| 举报者 → 被举报者敌对 | +5 |
| 被举报者 → 举报者敌对 | +5 |
| 附加状态 | 「委屈」3 天，每天初始压力 +3 |
| 可能结果 | 累积推过 90 → 爆发（全班事件） |

即时只有 ±5，但持续 3 天 + 高爆发概率，体感强于单次 +25，且不会瞬间撕裂班级。

#### 2.5.4 事件去重（控制频率）

**同一对子在同一个课间段内，同一规则只结算一次**（再次发生同样互动仍产生观测、写入信念，但不再改数值）。

- 这**不是**"社交预算"：不限制你能跟多少人互动；
- 它只排除"对同一个人在一节课间里被反复 +5 几十次"，把频率压回合理量级；
- 没有这条约束，`base ≤ 5` 也挡不住一天内的两极分化。

#### 2.5.5 与标定目标的关系

玩法文档 §3.4 要求"好感 20 → 60 用 2–3 天"。按本铁律：每次 +1–3（均 2）、去重后每天有效互动有限、跨天衰减 ×0.95 —— 恰好落在 2–3 天。**跨天衰减系数是标定的主要可调旋钮。**

## 3. 作用面一览

| 量 | 类型 | 公式写入 | 传导项 C | 备注 |
|---|---|---|---|---|
| 好感 `A` | 有向矩阵 N×N | ✓ | ✓（含敌对反向抑制） | 慢变量 |
| 敌对 `H` | 有向矩阵 N×N | ✓ | ✓（含好感反向抑制） | 与 A **独立**两轴 |
| 信任 `T` | 有向矩阵 N×N | ✓ | ✓ | 需要持续维护 |
| 透明度 `O` | 个体 | ✓ | 初始 0 | 乘性基座 + 偏移 |
| 压力 `Stress` | 个体（**状态量，不属于底层态度轴**） | ✓ | **≡ 0** | 只累积/消解，不传染 |
| 信念 `B_A` `B_H` `B_T` | 个体对他者的估计（N×N×3，**只读**） | ✗ | ✗ | 由真值 + 对方透明度 + 我方信任派生；**NPC 与玩家的决策只读它**，见 [`信念矩阵.md`](信念矩阵.md) |
| 性格四维 | 个体（固定） | ✗ | ✗ | 仅作 `d_t` 系数 |

> 玩家看不到以上任何准确数值——公式只算**真实后台值**；玩家看到的是经 §9 透明度 + 信任两层过滤后的**感知值**，与公式无关。

## 5. 可手算的验证例

| 场景 | 计算 | 结果 |
|---|---|---|
| 对高 E 角色（E=85）搭话成功，`base_A = +5`、`w_E = +0.2` | `d_E = 0.7` → `E = 5 × 1.14 = 5.7`；非结算 tick，无传导 → `sat(5.7, U_A=25)` | 好感 **+4.64** |
| 同一 tick 恰逢涓流结算：你还听从（A=85）的第三人，他对目标好感 80 | `C = 49.4` → `β_A·C = 0.99` → `P = 6.69` → `sat(6.69, 25)` | 好感 **+5.28**（事件 + 传导合成） |
| 平静且非结算 tick | `P = 0` | **Δ = 0**（不会自发漂移） |
| 纯涓流结算（无事件），`C = 49.4` | `P = 0.99` → `sat(0.99, 25)` | 好感 **+0.95**/次（一个课间段约 10 次结算 ≈ +9） |
| 被举报（重大事件，`M_state = 1.5`） | 压力 `E = 5` → `sat(5, U_S=30) = 4.29` → `Δ = 1.5 × 4.29`；另加敌对双轴各 +5、状态「委屈」3 天 | 压力 **+6.4**、敌对 **±5**、持续 3 天 |

## 6. NPC 自主行为：同一个公式算两遍

```
NPC i 面对候选行为 b（搭话 / 闲聊 / 传纸条 / 举报 / 安慰 / 走动 / 睡觉 …）：

  意向   U_b = Σ_X  α_X(i) · Δ_X^pred(i, b)
         Δ_X^pred 用同一个公式：E 取行为 b 的 base（对每个候选目标各算一次）、C 取当前传导状态
         α_X(i)   NPC 对各轴的偏好权重，由性格四维派生（Σα = 1），函数放 data/ 标定
         ⚠️ 其中牵涉"**对方态度**"的输入一律取**信念矩阵** `B`，牵涉"**我自己态度**"的取真值 —— 见 [`信念矩阵.md`](信念矩阵.md) §6、§8

  选择   p(b) ∝ exp( U_b / τ_i )        τ_i：高 J 更确定、高 E 更随机
```

于是整条链同源：**性格 → α/τ → 意向 → 行为 → 效果**。
行为层没有任何按角色名 / 角色 ID 的判断，守住四层分离铁律（§11.1）。

## 7. 涌现保障（为什么"不过于简单"）

| 机制 | 作用 |
|---|---|
| 阈值 `θ` | 弱态度不扩散 → 派系不会被整体拉平 |
| 竞争归一化 | 多方拉扯 → 墙头草（`P` 在 0 附近反复翻转符号） |
| 软饱和 | 多个稳定吸引子共存；一次冲击不把关系推到底 |
| A/H 互抑 | 立场翻转可能（喜欢的人讨厌谁，会影响你） |
| 跨 tick 累积不受限 | 单 tick 有界 ≠ 长期有界 → 「慢积累 + 快相变」仍成立 |

反例：若改成线性求和，全班态度会收敛到同一均值，涌现提前死亡。

## 8. 实现要点

- **每 tick 顺序**：汇总 `E`（本 tick 事件）→ 计算 `C`（**读本 tick 开始时的矩阵快照**）→ 一次性写入。
  传导必须用快照，否则同 tick 内的写入互相污染，结果不可复现。
- **复杂度**：`C` 为 O(N³)（N ≤ 25 → 15,625 次/tick，约 750 万次/天）。先无头实测；超预算时改稀疏更新（只处理 `σ > 0` 的对子）。
- **随机性**：`softmax(U_b/τ)` 采样必须用种子化 RNG，保证同种子同局面（回放与标定的前提）。
- **可观测**：每 tick 可 dump `(i, k, X, E, C, P, Δ)`，批量标定与异常定位都依赖它。

## 10. 标定影响

- 小额事件近似直通 → 现有事件权重表可沿用；
- 大额事件（`|P|` 接近或超过 `U_X`）会被压缩 → 按 主文档 §3.4 的三条目标重跑批量局，主要调 `U_X` 与 `β_X`；
- 需要新增/扩展的表：`data/rules/transmission.csv`（§4 的 12 个参数）、`data/balance/npc_weights.csv`（`α_X`、`τ`）。
