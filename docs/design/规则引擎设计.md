# 规则引擎设计

> 状态：草案 ｜ 维护者：程序 ｜ 最后更新：2026-10-04
> 规格依据：`../gdd/core-gameplay-v3.0.md` §3（时间与相位）、§6（增量公式）、§7（传导）、§10（R1–R13 + O1）

## 1. 主循环

```
一局 = 30 天 × 每天 480 tick
for day in 1..30:
    for phase in [上午课间, 上午上课, 中午午休, 下午上课, 下午课间]:
        for t in 1..phase.tick_count:
            run_rules(phase.active_rule_set)     # §3.3：上课只跑规则子集
            apply_transmission()                 # §7.2，每 tick 末
            observer.update()                    # §10 O1，只读
            emit(log_event)                      # 简报与推理解释的唯一数据源
    settle_day()                                 # §3.5 跨天结算 + 生成《每日简报》
```

每天 480 tick（课间 3×100 + 上课 2×90），学期 14,400 tick（v3.0 §3.2）。

## 2. 相位与规则启用（v3.0 §3.3）

| 相位 | 启用规则 |
|---|---|
| 课间段 | 全部规则 R1–R13 + 玩家操作 |
| 上课段 | R1（座位固定生效）、R5（每 3–5 tick 低频）、压力事件发酵（独处恢复减半）；**R3 禁用**；传导继续 |
| 放学结算 | 不跑规则，执行衰减与简报生成 |

`data/rules/phases.csv` 定义相位时长与启用集合，代码不写死。

## 3. 规则实现约定

每条规则实现为独立的 `Rule` 资源/类，统一接口：

```gdscript
class Rule:
    func gather(ctx: SimContext) -> Array[CandidateAction]   # 谁能对谁发起
    func resolve(ctx: SimContext, action: CandidateAction) -> Array[Effect]  # 结果
    func apply_effects(ctx: SimContext, effects: Array[Effect]) -> void
```

- **决策与效果分离**：`gather` 处理触发条件（读 A/H/T/S/O/MBTI），`resolve` 处理结果判定（含概率），`apply_effects` 统一走 §6.1 增量公式并钳制。
- **纯函数约束**：触发与判定中禁止出现角色名/ID；角色差异只能来自 `data/characters/` 的种子值与四维数值（v3.0 §11.1）。
- **数值外置**：所有增量、阈值、概率系数从 `data/rules/` 与 `data/balance/` 读取。
- **可测性**：每条规则须有确定性输入 → 期望效果的单元测试（随机判定通过注入 RNG 种子固定）。

## 4. 同 tick 冲突消解（待定）

多人互相发起、多人围观调侃等场景需要确定性的处理顺序。拟定策略：

1. 优先级：危机类规则（R13 举报、R12 安慰）> 主动类（R3/R10/R11）> 被动类（R2/R4）> 环境类（R1）；
2. 同级按角色索引升序，保证可复现；
3. 已被占用（处于对话中）的角色本 tick 不再接受新交互。

> 该策略直接影响涌现形态，需在 M1 用批量局验证后固定下来。

## 5. 影响力传导（v3.0 §7.2）

```
每 tick 末，对每个接收者 i、第三方 k：
    w_ij = A[i][j]/100（经性格修正）
    A' = max(0, A[j][k] - theta_A)      H' = max(0, H[j][k] - theta_H)
    net = (Σ w_ij·A' - Σ w_ij·H') / (Σ w_ij + epsilon)
    Δ = beta × tanh(net / sigma)
    Δ > 0 → A[i][k] += Δ      Δ < 0 → H[i][k] += |Δ|   # 两轴独立，不互相扣减
```

- **两阶段实现**：先用后台真实值跑通（M1），再切换到 §7.4 的"感知态度"（透明度 + 信任两层过滤），让信息可见性参与涌现。
- 性能：17×17×17 的三重循环在 14,400 tick 下的开销需实测；必要时改为稀疏更新（仅处理 `A'|H' > 0` 的对子）。

## 6. 观察层（只读）

`ObserverLayer` 每 tick 末执行：

- 强连接边：`A[i][j] ≥ 60 且 A[j][i] ≥ 60 且 T[i][j] ≥ 50 且 T[j][i] ≥ 50`；
- 连通分量 + 稳定性滤波（连续 ≥5 tick 成团、连续 ≥5 tick 不满足则消失）；
- 孤立：连续 ≥10 tick 未进入对话且距最近者 ≥2 格。

**输出只有标签**（供可视化、简报、日志），任何回写矩阵的代码都是缺陷。
