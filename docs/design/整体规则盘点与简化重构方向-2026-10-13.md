# 整体规则盘点与简化重构方向

> 日期：2026-10-13。对象：固定 16 名 NPC＋1 名玩家，共 17 个节点，无难度档位。
> 类型：现行规则盘点＋重构策划草案。用户已采纳音量与压力四档方向；本轮不修改生产代码或生效配置。新倍率仍须实现与标定。
> 证据：现行主文档、v4 分册、data/rules 与 data/balance、scripts/core、scripts/systems/behaviors。下述“代码有实现”仅指静态核查，不代表本轮重新运行了完整测试。

## 1. 重构的核心目标

保留社交涌现，把一个行为统一解释成：

**条件允许 → 发起 → 对方回应 → 开始活动 → 完成或中断 → 记录后果。**

玩家能说明自己为什么获得或损失某个数值。少公式不是简单删除机制，而是避免同一件事被多条隐藏通道重复计算、好事因倍率意外变坏、UI 档位与真实效果错位。

优先保留：有方向的关系、性格差异、认知误差、空间邻接、时间机会成本、压力与音量反馈、读关系得到的小团体。后续建议均是评审项，不能当作已经生效。

## 2. 当前世界与时间

- 固定 17 个班级节点；老师为环境角色，不进入同学关系矩阵。16 NPC 自主行动，玩家由输入驱动。
- 一局 30 天；每天上午课间100 tick→上午上课90→中午课间100→下午上课90→下午课间100→日末，总计480 tick。
- 课间开放主要交互；上课保留纸条、关系发酵等允许的机制。玩家不能将课间所有行为原样带到上课；实际权限由内核检查。
- 行为占用和走动互斥；铃声先结算已到期活动，再中断未完成活动，不能同时获得完成奖励与中断代价。
- 世界倍速不改变每个模拟 tick 的规则；玩家限时动作通常3倍，持续学习每满10现实秒增加1倍，不封顶，中断重置；暂停不累计。
- 当前环境/传导按全局240 tick结算；它不是“每段上课末”，一天检查点落在午间课间内与最后课间末。上课邻座好感另在两次上课段末结算。这两个时间口径需要在重构时统一解释。

建议：玩家说明只保留“课间做事、上课发酵、日末结算”。考虑将环境与关系发酵移到两次上课末，而非隐蔽的全局 tick 倍数；这是时机改动，尚未采纳，需对照验证，不可静默替换。

## 3. 所有底层状态

| 类别 | 现行含义 | 重构方向 |
|---|---|---|
| 好感 A[i][j] | 我喜不喜欢你，0–100，有方向 | 保留，不等于你的好感 |
| 敌对 H[i][j] | 我对你的反感/冲突，0–100，与好感独立 | 保留，喜欢与记恨可以并存 |
| 信任 T[i][j] | 我信不信你，0–100，有方向 | 保留，不与好感合并 |
| 压力 S[i] | 自身累积负担，0–100 | 四档、可见玩家自己的值 |
| 透明度 O[i] | 人物是否容易被看懂 | 保留种子口径；不声称现有代码随压力更新 |
| 性格四维 | 连续的E/S/F/J种子，驱动选择和修正 | 只影响意愿与有限强度，禁按角色名分支 |
| 成绩 G[i] | 平时学习水平，0–750 | 保留与考试分数分离 |
| 信念 B | 我以为别人是什么态度 | 保留，预览不是全知真值 |
| 深层敌对 | 重大伤害留下的较难消除部分 | 候选：包装成单一“记恨状态”，先保留实现，避免同时维护两种不易解释的心结 |
| 心结/库存/活动/位置 | 临时压力来源、持有物、时间占用、接触条件 | 保留，各自唯一账本 |

## 4. 当前效果计算

现行不是一个简单乘法：事件base→性格修正→部分关系调制→软饱和→压力状态倍率→部分正向轴负反馈→写入0–100；传导还有独立计算路径。

- 性格倍率一般 clamp 到0.1–1.2。
- 普通关系事件常乘 clamp((A−H)/50,−1,1)，可反转方向；重大伤害、部分和解事件不乘。
- 软饱和为 u/(1+|u|/U)，限制一次变化量。
- 现行压力倍率在40/70/90分段，但≥90又回到1；负面分类也不等于真实伤害方向。
- 高好感的正向增益可能乘“剩余空间”，避免全班满值；敌对和压力不使用同一负反馈。
- 事件写入、传导、自然减压、上课好感各有写入路径，需要统一账本与可追溯来源，而非宣称已有唯一写入点。

建议目标：**结果先定方向，倍率只改强度**。

```text
变化量 = 事件基础值 × 性格倍率 × 压力档倍率
最终值 = clamp(当前值 + 变化量, 0, 100)
```

这是目标公式，尚未替换原 UIF。关系影响应优先放在“是否接受/玩笑是否接住”的回应判定，避免正常好话被隐藏净态度乘法直接反转。软饱和与负反馈不宜同时未经评估删除：先保留其中必要的防饱和机制作为公共收尾，待100局对照决定删哪一层。此处不是要求这一轮同时砍掉两者。

## 5. 当前行为总表

下表“效果”讲方向；表内基础数值不是经过所有修正后的保证收益。组件、内核入口和界面是否可直接触发是不同层次。

| 行为 | 现行规则与后果 | 当前代码/接线 |
|---|---|---|
| 发起/加入闲聊 | 需要可交互与空间条件；加入按对方真实态度判定；成功增好感/信任、发起者减压；拒绝产生反噬 | 有会话与组件；玩家入口接通；NPC与玩家加入编排不同 |
| 观察 | 靠近、足够时间，获得只读线索，不打断目标 | 有组件及玩家入口 |
| 递纸条 | 写者选择/产生被说对象和话术；读取改变收件人对被说者的态度，可读/传/毁，不给目标本人全知通知 | 有纸条链与玩家接收选择；一张纸条只经手未见过的人 |
| 当众调侃 | 关系好且敌对低为接住玩笑；关系差/敌对高为嘲讽，围观者分立场，围观足够升级羞辱 | 有组件与NPC执行；边界和UI入口需重构核对 |
| 追逐打闹 | 参与者增好感，附近旁观者对参与者增敌对，发声强 | 有组件与玩家/NPC路径 |
| 排挤 | 群体近期重大敌对记录、人数与冷却决定NPC候选；目标压力与各方关系受损 | 有组件；玩家入口与NPC候选门槛不完全同路 |
| 举报 | NPC有敌对、公开行为依据等概率条件；被举报者加压力/敌对，举报者对目标敌对回落 | 有组件及巡查相关路径；组件本身不等于完整“离场找老师”演出 |
| 安慰 | NPC选择高压目标且有足够好感；施助者承担压力，目标减压、增加对施助者好感/信任 | 有组件与NPC候选；≥90共情额外倍率等文档细节未完整落实 |
| 道歉 | 有冲突才进入NPC候选，对方接受概率取决于关系/性格；接受双向修复，拒绝使发起者更难受 | 有组件与NPC路径；临时透明度增加未落实，玩家直接入口未完整开放 |
| 学习 | 自己座位主动开始、持续；学习tick按成绩档折算，每涨一分产生学习压力 | 接通；有学习圈与世界加速 |
| 邻座共同学习 | 相邻双方在座位学习，20 tick检查点结算好感/信任与自身压力 | 有实现；事件去重与会话形成另有条件，不能承诺每20 tick必加一次 |
| 提问 | 对方不明显落后、双方可交流；自己获得等效15学习tick，对方对自己增信任 | 有玩家入口；课间同对子同方向一次 |
| 讲题 | 对方不明显领先；对方获得等效15学习tick，自己对对方增信任 | 有玩家入口；互惠方向可能不符合教学直觉，列评审项 |
| 睡觉 | 占剩余课间，不参与通常交互，段末减压3 | 有实现；环境加压通道未完全遵守睡眠排除条款 |
| 听音乐 | 30 tick自然完成减压2，默认可用，期间占用 | 已接通书包 |
| 吃零食 | 15 tick自然完成减压1.5；玩家每局5份，开始扣份，中断不退 | 已接通书包；NPC不受玩家份数限制 |
| 看课外书 | 40 tick自然完成减压2.5；需持书；老师可能没收并中断阅读 | 已接通书包；玩家开局0本 |
| 出门 | 结束自己剩余课间机会，世界继续；邻座对玩家好感有代价；玩家缺席排除交互/发酵 | 玩家独有已实现，不虚构NPC同权 |
| 走动 | 改临时位置，不直接增减关系；寻路、忙碌、相位限制影响能否接触 | 表现层与内核位置同步；不是按名字行动 |
| 秘密交换 | 文档仍有规格与配置，完整内容和泄密链不齐 | 不作为本轮已完成玩法 |
| 独立流言/告密/窃听/求助 | 已在现行分册删除 | 不恢复为当前可玩行为；纸条与未来内容层另论 |

建议统一行为的三种后果时点：

1. **开始成本**：时间占用、零食扣份等，开始时扣。
2. **回应结果**：被接纳、被拒、被举报、当众羞辱等即时事实，即时结算。
3. **完成收益**：聊天的持续关系收益/减压、吃完、读完等，只有自然完成才结算；打断不倒扣已经发生的即时事实。

目前聊天关系收益多在成立时写入，线索/赠书在自然完成时发放，道具减压也在完成时发放。统一上述口径是重构提案，不是现行行为描述。尤其应规定群聊旧成员不重复涨、只新增参与关系；减压按每人一次，而非按边数倍增。

## 6. 已采纳的压力/音量方向

### 压力

| 压力 | 档名 | 关系伤害倍率 | 关系修复倍率 |
|---|---|---:|---:|
| <40 | 平稳 | 1 | 1 |
| 40–<70 | 紧张 | 1.25 | 0.9 |
| 70–<90 | 高压 | 1.5 | 0.8 |
| ≥90 | 危急 | 1.75 | 0.7 |

敌对增加/好感减少/信任减少判伤害；相反方向判修复；按最终实际方向分类。压力轴不乘关系倍率。日末爆发 p=0.5×clamp((S−70)/30,0,1)，每日一次；爆发减压40并产生/扩散心结，不到点必爆。

### 音量

| 音量 | 档名 | 每次环境压力基础值 | 邻座发声者敌对基础值 |
|---|---|---:|---:|
| ≤20 | 安静 | 0 | 0 |
| >20–40 | 活跃 | 1 | 0 |
| >40–70 | 嘈杂 | 2 | 1 |
| >70 | 喧闹 | 3 | 2 |

归一化目标为100×噪音总和/(3×在场人数)，固定17节点；仅出门等缺席使分母变化，不涉及难度。音量按0.2向目标靠近。贡献0/1/2/3，学习/睡觉/走动等0，轻微声响1，聊天2，打闹调侃3；旧打闹噪音5需随新表迁移。

怕吵倍率=1+0.3J+0.2I，范围0.5–1.5；环境压力=档级×怕吵倍率；定向敌对按上表base走公共关系公式。只影响附近最多两名实际发声者，出门/睡眠排除按提案落实。

这些已获用户方向认可，但代码仍为旧参数。旧草案中的难度举例不再作为本项目要求；本轮不再次修改用户已完成的人数/难度内容。

## 7. 信息、认知与NPC

- NPC选择用自己的性格、状态、立场与信念，不读取“别人真实怎样看我”来当上帝。
- 对方是否接受，要由对方真实态度决定；玩家看到的是自己的估计。
- 当前闲聊预览有精确成功率，但与实际真值概率不同；预览还读取对方真实压力/外向度，不能笼统声称预览已完全基于玩家可知信息。
- 观测随透明度加噪、随信任调整学习率；每天以0.02向先验遗忘回归。
- NPC目前先尝试道具减压、学习等，再进入社交意向。顺序会影响“为什么总选音乐”，不能把所有选择都说成同一个公平概率池。
- 班级发酵：按“我喜欢谁就更听谁”的权重，将可感知的态度传播到真实关系；还有见到邻座欺负某人后跟随的敌对通道。
- 小团体/孤立只读标记，不写回关系。当前簇判定用双方好感≥60并高于各自关系75分位，至少3人，不是简单“信任也≥50就成团”的实现。
- 观察层采用三档可见性，其他观测入口采用四档；收口为一套规则是必要重构项。

建议：保留真实态度与信念的区分，UI用“我觉得容易/不确定/很难”，避免把估计包装成精确承诺；意向选择统一为同一候选池与一次采样，候选只按合法性过滤，性格/压力影响意愿。

传播先保留现有强度，再考虑限制为“公开行为见证、实际转述、明确线索”驱动，避免两个没有信息接触的人暗中被全班强迫改态度。这个改动影响涌现主体，不能与倍率修订同时未经验证删除传播。

## 8. 学业、老师与书包

- 成绩上限750，玩家初始250，NPC种子化初始200–650。低于300每10学习tick涨1，之后每50分增加3tick成本，最高档37tick/分。
- 上课末清醒在场邻座双向好感+0.2，另有共同学习事件与全局发酵，三个渠道要分别记账。
- 课间老师在25/65 tick各有25%到场机会，一段最多来一次，停留30 tick；压场目标音量×0.5，调侃/打闹/排挤意愿×0.3。
- 老师到场为未学习、未睡眠且在场者结算压力事件；听歌/吃零食被看见提示，看课外书会收走一本并停止阅读。
- 同场闲聊自然完成，持书NPC对玩家好感≥60、信任≥40，10%概率赠书；每课间最多一本，赠书者有每局只赠一次的记录。不是固定某天送书。
- 考试日7/14/21/28与期末30，属于学校日历，非预定社交剧情。考分=平时成绩＋考试扰动−15×压力/100，不写回平时成绩；当前调用在日末压力衰减后，因此考分使用衰减后的压力。
- 前3奖励免罚卷；当前考试奖励在ExamSettle账本、没收消耗在TeacherPatrol账本，静态代码未见互通。不能向玩家承诺目前获得卷就能免没收。
- 书包是入口，不是一套额外规则；当前仅展示并发出既有行为意图，不直接扣库存或改压力。

建议：物品/免罚卷唯一库存账本；考试使用考试发生时的压力快照，不用睡过一夜后的值；接受讲题的人对讲题者增加信任，作为方向修订候选。保持学校日历与概率巡查，不增加固定日期社交事件。

## 9. 日末、记恨与报告

现行日末：爆发→信念遗忘→心结加压及天数处理→关系/压力衰减→考试→学期记录。当天有互动的好感保留98%，无互动90%；表层敌对95%，深层敌对99.5%，信任93%，压力65%。不是“敌对永不衰减”。

日报与学期报告已有记录/界面，但多结局阈值、完整内容与话题系统、完整存档恢复、换座等分册不能凭策划标题算全部完成。第27章明确是未开工的内容层提案。五子棋、完整石头剪刀布、秘密链与班级社会事件也不应混入最小核心的已实现清单。

建议日末给玩家三类解释：今天发生了什么、自己的状态怎样变、哪些关系值得留意。底层保留必要衰减，但不要用每日大量精确NPC关系数字取代信息博弈。

## 11. 建议重构的六条总规则

1. **关系是单向的**：每个后果明确“谁对谁、哪个轴、什么方向”。
2. **结果决定方向，性格与状态只改强度**：不允许隐藏倍率把伤害变奖励。
3. **开始付成本，完成领收益，回应立即留后果**：所有行为共享时点语义。
4. **能做与想做分开**：玩家/NPC合法条件同源；NPC再根据性格、信念选择。
5. **环境按档影响，信息按接触传播**：每档有真实作用，不能用纯颜色假装机制变化。
6. **所有变化都有来源**：库存唯一、结算去重、固定时间点、同种子可复现；簇标签只读，不安排成团剧情。

建议行为配置统一列：合法条件、对象/范围、是否需要回应、时长、开始成本、回应事件、完成收益、中断规则、噪音、冷却。各行为只填表并提供少量特有条件，不再自行另算公式。

## 12. 重构顺序

1. 整理权威来源与当前规则清单，保留固定16NPC＋玩家，不重做用户已完成的人数变更。
2. 合并合法性、真实变化方向分类、库存账本和活动生命周期，先处理解释不一致，尽量保持数值基线。
3. 实装已采纳的压力/音量表，使用同表驱动UI；单独对照并标定。
4. 再讨论简化关系调制、结果分支、传播与日末时机；每次只改一个机制组，避免多个新系统互相掩盖失败。
5. 最后接入未开工的内容系统与更多玩法，不能靠新增行为掩盖核心不清楚。

每阶段更新权威规格、配置、Python/GDScript实现及CHANGELOG。用边界测试、单次结算、同种子对拍与100局分布验证；不改验收门槛来掩盖结果。涌现检验：朋友/冲突/团体仍由局部关系及选择累积，不能替换成固定事件日期或角色脚本。
