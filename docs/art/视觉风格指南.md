| 项 | 取值 | 说明 |

| 最小可读字号 | 正文 ≥ 28 px（1080p 基准） | 触屏可读性下限，随 UI 缩放同比例 |

## 2. 玩法决定的可视化要求（主文档 §14.1，硬性）

教室视图必须让玩家**不开面板就能看出格局**：

1. **空间聚散**：角色在教室的物理位置即第一画面。好感高者不自觉靠近，敌对高者保持距离；簇标签圈出淡轮廓表示"成团"；被排斥者移到边缘。
2. **情绪图标**：每个角色头顶极简表情（开心 / 平静 / 焦虑 / 愤怒 / 低落 / 兴奋），**只表达派生情绪，不暴露数值**。
3. **关系氛围线**：仅在质变瞬间闪现（好友柔和细线、敌对小闪电），不常驻，避免画面噪音。

上课过场（§14.2）：角色回座位、相邻座位的「共同学习」缓慢发酵（好感/信任 +1 级）、纸条偶发传递、情绪图标缓慢变化，玩家可随时切到情报日志/推理板。

## 4. 信息呈现规则（与玩法强绑定，不得自由发挥）

透明度与信任决定玩家看到的信息形态，UI 必须严格对应（主文档 §9.2、§9.3）：

| 透明度 | 态度线呈现 |
|---|---|
| 高（80+） | 实线，颜色清晰，粗细准确反映强度 |
| 中（40–80） | 半透明虚线，颜色偏淡，方向可辨、强度不确定 |
| 低（20–40） | 时隐时现，带问号 |
| 极低（<20） | 完全不显示（"这是个谜"） |

- 暖色 = 好感，冷色 = 敌对；**颜色语义必须在整局内保持一致**。
- 矛盾高亮（§9.5）需有独立且醒目的视觉语言，且不与其他状态色冲突。
