# 《下课十分钟》UI 制作盘点与视觉方向

日期：2026-10-11。本文是美术建议与静态源码盘点，不是玩法规格变更，也不是运行验收。玩法依据为 `docs/gdd/core-gameplay-v3.1.md`；实施顺序参考聚光灯冲刺计划。

## 视觉方向

延续宣传图的暖光校园水粉插画、米白纸面、青绿色墨色、金色笔触。大幅插画用于主菜单与过场；游戏内保留教室实际画面，面板使用安静纸面，纹理只放在边缘。标题可用笔触字体，正文与数字使用清晰中文字体。正式 UI 的文字由 Godot 渲染，概念图里的文字不作为可点击素材。

建议色板：纸面 #F5F0DF、主墨色 #284536、强调青绿 #17606A、金色 #BF8835、警示赭红 #A65342。颜色仍需在实际教室背景上检查对比度。禁用、暂不可用、选中必须同时用文字或形状区分。

## 建议制作顺序

1. 公共组件：纸面面板、五态按钮、标签页、关闭/返回、滚动条、提示浮层；图标优先延续既有 SVG 系统，纸纹与插画用位图。
2. 主菜单与核心游戏 HUD：先建立一致视觉，避免遮挡人物和目标选择。
3. 纸条、聊天与邀请反馈：补齐高频状态。
4. 每日简报：保证本次切片的收尾可读，设计时区分真实数据与示例内容。
5. 档案、情报日志、推理板；最后统一设置和百科。

## 交付与验收

概念稿按 1920×1080 横屏设计，检查 2560×1440 与宽屏适配；Android 横屏检查触控尺寸和文字可读性。可复用面板建议九宫格拉伸，Logo 与插画单独导出，正文不要烘焙进图片。每个弹窗需覆盖正常、空、禁用、长文本状态，检查键鼠焦点与触摸输入。此次只交付盘点和视觉概念，不修改代码、玩法规格或 Godot 资源。
