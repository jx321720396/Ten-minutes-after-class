# 小幅向右跟随镜头试验（2026-10-12）

玩家相对入场位置向右走超过 0.35 米后，相机以 0.35 倍横向位移跟随，最多右移 0.8 米；采用现实时间指数平滑，走回起点恢复原位。仅平移相机，不改变高度、角度和视野，也不写回玩家位置或模拟内核。

## 试用和撤回

- 启动游戏正常移动即可观察；按 **F8** 关闭试验并立即恢复原固定镜头，再按 F8 开启。
- 永久恢复原固定镜头：将 `data/ui/classroom_art.json` 中 `camera.follow.enabled` 改为 `false`，重新进入教室。
- 原相机的 `position`、`target`、`fov` 保持原值；关闭时恢复初始化保存的完整相机变换。

`follow_right.png` 与 `follow_fixed.png` 是带界面的实机对照。为了固定人物位置，截图工具在冻结场景中将玩家表现节点放到右侧安全站点；这是取景预览，不是一次真实行走记录，不修改生产场景或开局配置。

效果：右侧桌阵与人物向画面左侧移出一部分，左侧则会更多进入音量面板覆盖区。轻量镜头跟随只能缓解遮挡；右侧行动抽屉仍是彻底腾出观察与点击空间的后续方案。本试验未调整现有界面。

回归覆盖向右跟随、偏移上限、相机朝向不变、走回起点恢复、关闭立即恢复及关闭后不跟随。沿用教室碰撞、通道、内核 RNG 和人物拾取体检查。
