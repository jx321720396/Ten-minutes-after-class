# 教室逐件优化：暖木色手绘 3D

日期：2026-10-12。根据本次用户的原始教室参考、已完成的 Blender 书架小样继续制作。

## 本轮方向

先生成整室概念，再按小件完成建模、导出、实机验收。主教室的结构与玩法保持既有边界；实际替换之前先在独立预览中验证尺寸、遮挡和材质。概念图中的桌阵、物件数量与文字都是视觉示意，不作为玩法或场景布局的新规格。

概念图：`classroom_warm_blender_concept_v1.png`，由内置 image_gen 生成，属于美术目标，不是游戏截图。提示词见 `concept_prompt.txt`。

视觉统一：蜂蜜木色，米白/灰绿墙面，灰蓝金属与窗帘，低对比米色地面，柔和午后日照。模型用清晰大形体、适度倒角、克制木纹和少量生活细节。近景渲染和游戏镜头分别验收，所有源工程/模型可单独打开。
