## 常驻信息（v01布局参考）

- 左上：日期、当前课间、剩余时间、周考倒计时及目标差距。
- 左侧中部：平均成绩、平均压力、平均动力、今日平均学业收益；提供“查看全部概况”入口。
- 左下：高压预警和普通争吵的简短提醒，以及学习／娱乐／其他实际状态人数。
- 右侧：老师行动与对象档案入口。
- 底部：老师当前状态、同学档案、全班概况和推理板入口。
- 教室保持可见，全班详细概况通过入口另行打开。
