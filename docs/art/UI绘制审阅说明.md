## 本轮方向

依据《UI图清单》《视觉风格指南》与玩法主文档，采用暖色校园像素风：米白纸面、黑板绿、木色、克制的琥珀色强调。核心提案展示课间主视图、加入活动判定、每日简报。第一轮用于审阅风格与布局，后续逐页绘制及组件拆分仍待完成。

## 绘制前发现的冲突

1. 主文档 §1.4 的流程列表漏掉下午课间，与同节说明及 §3.1、§3.2、§17.1 的三段课间矛盾。提案按三段课间绘制六阶段相位条；这是建议收口方案，尚未修改玩法规格。
2. UI 清单把三档难度列为第一版，但冲刺计划 §1 明确不做标准／困难难度。首稿按 8 NPC + 玩家，共 9 人；后两档建议转后续交付。
3. 第一版上课过场要求进入情报日志／推理板，而两者明确属于 M2。首稿不设置这些入口。
4. 每日简报的“真相对照”按主文档 §14 依赖推理板结论，第一版缺少该来源。首稿保留版面，不编造报告数据；正式接入前需确定空状态或第一版替代来源。
5. 清单的“25 张界面”混合整屏、组件与状态，应按完整效果图、组件资源、交互状态分别交付。按钮三态实际列出四态；走动同时出现在行为与状态图标中，应复用资源。
6. 视觉指南可视化引用仍为 §14，应指向 §15；风格、字体、色板尚未定稿。
7. 1280×720 与 1920×1080 均为 16:9，不能验证“更窄横屏”；应另测不同比例。44 px 命中区需在最终显示尺寸验收，不能仅按1080p设计像素判断。

## 正式制作约束

- 概念图中的文字、时间、成功率和角色分布仅为排版示意。正式界面使用 Godot Label、Button、ProgressBar 等动态绘制；不把数字烘焙进底图。
- 动作耗时取自 data/rules/behaviors.csv：闲聊30（加入路径 10）、调侃30、安慰50、纸条10、走动15 tick；学习为默认状态、睡觉占整段。加入活动按实际活动规则显示，不虚设统一成本。
- 活动圈与长期簇用不同线型和明度；关系线仅在质变时闪现；未知关系不画为中立。
- 接受／拒绝采用颜色加勾叉，不能仅靠红绿区分。
- 不展示好感、敌对、信任、透明度、压力原始数值；不凭观察标签移动模拟角色。
- 正式资源需另交透明PNG、面板九宫格边距、按钮四态、节点对照与实际导入验收；一张概念图不等于可接线资源包。
- 首稿由内置 image_gen 生成，提示词与结果随本轮文件保存。生成画面尚不代表逐项规格验收通过。
