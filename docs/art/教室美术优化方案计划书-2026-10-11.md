# 《下课十分钟》教室美术优化方案计划书

日期：2026-10-11　｜　状态：提案，待评审　｜　本轮交付：方案，不实施场景改动

## 1. 目标与推荐方向

把教室从“摆着桌椅的校园空间”优化成“学生每天在这里上课、做题和聊天的中国普通高中班级”，并让现有像素人物自然融入其中。

**推荐：生活化的中国高中教室，采用克制的像素贴图与简化 3D 结构，保留现有像素纸片人物。** 关键词：粉笔绿、旧木色、米白墙、蓝白校服、课本试卷、午后自然光。环境有使用痕迹，但整体整洁；校园感来自物件和空间用途，人物始终是画面的视觉中心。

本提案暂以“当代普通高中、略有年代感的教学楼”为美术假设，不指定真实学校或地区。用户尚未指定地域、年代和新旧程度，这些属于可调整项。计划中的颜色、资产数量和工时为制作建议，不是玩法规格。

成功标准：第一眼认出中国高中；人物与桌椅处在同一个视觉世界；细节有生活感；仍能清楚看出谁在走动、谁在聊天、玩家选中了谁。

## 2. 现状与问题判断

依据：现有 `scenes/game/classroom3D.tscn`、桌椅组件、人物生成脚本、角色原图、教室贴图，以及仓库保存的教室截图。截图不含人物，也不代表本次运行实拍；人物与教室同框的问题需在实施第一步实机核验。

| 已核实的现状 | 对画面的影响 | 优化方向 |
|---|---|---|
| 主菜单进入 `classroom3D.tscn`，另有降分辨率像素版场景 | 当前入口不会自动使用像素版；单纯降低全屏分辨率不能保证融合 | 在实际入口统一材质和镜头，单独评估像素版 |
| 人物为绕 Y 轴朝向相机的 Sprite3D，使用最近邻过滤；现有角色原图为像素画 | 人物边缘和色块明确，环境若过细、过亮或阴影过重，会显得分离 | 统一纹理颗粒、明暗层级和接地感 |
| 教室已有绿墙裙、木桌椅、窗帘、后墙黑板报和公告栏 | 基础校园元素已具备，可继续利用 | 优先改质感和物件组合，避免整间重建 |
| 现有截图中桌面基本空白、课桌几乎完全重复 | 更像布置完成的空教室，缺少高中生的学习痕迹 | 补课本、试卷、水杯、书包等，并做有限变体 |
| 地砖缝、木纹重复和几何边缘比较突出 | 大面积重复纹理容易抢过人物 | 减弱地砖与木纹对比，控制磨损密度 |
| 现有镜头以俯视透视展示桌阵和后墙 | 后墙及桌面投入最容易被看见；讲台前侧不一定充分入镜 | 按游戏镜头分配细节预算 |

人物当前高度参数为 1.35，桌面高度为 0.74。这里的数值只是工程现状，不能据此认定真实身高比例错误；需要检查角色透明边距、头身比和屏幕投影后的桌面位置。

## 3. 三种路线比较

| 路线 | 收益 | 成本与风险 | 建议 |
|---|---|---|---|
| A. 像素人物 + 简化 3D 中国高中教室 | 复用现有工程，保留空间移动与遮挡，能重点解决融合和生活感 | 需要认真校准纹理、光照与比例 | **推荐，适合本次冲刺** |
| B. 整体改成纯 2D 像素教室 | 人物与背景的绘画语言更容易统一 | 需重做背景、深度、拾取和空间表现，迁移范围大 | 后续若确定纯 2D 方向再评估 |
| C. 教室进一步写实，并重做 3D 人物 | 光照、接触和透视容易统一 | 人物、动画、资产与性能成本最高，现有像素人物需大改 | 当前不采用 |

路线 A 的关键不是增加写实程度，而是让教室的细节精度服从人物画法。

## 4. 人物与环境的统一规则

### 4.1 色彩与材质

- 墙面：偏米白，墙裙为低饱和灰绿；保留与当前校园 UI 的纸色、墨绿的呼应。
- 桌椅：蜂蜜棕与旧木色，桌腿为深灰金属；降低木纹的规则条纹感。
- 地面：浅灰米色地砖或简化水磨石，地面明暗与纹理对比低于人物和活动圈。
- 窗帘：灰蓝或浅米色，先比较其与蓝白校服、绿墙裙的整体关系，再定色。
- 红色：用于少量标语、书脊和通知标题；环境中的红绿标记不能模拟交互成功或失败反馈。

贴图采用清楚的大色块、少量像素纹理与适度磨损。避免写实照片贴图、密集法线细节、镜面地板和亮金属。最近邻过滤只是技术手段，仍需在游戏镜头下校准纹理密度。

### 4.2 比例与接地感

先用同一个座位和同一个人物做对照，检查头部、肩部、桌面、椅背及脚底的关系。优先调整环境材质和表现，不先重画整套人物。

人物脚下可增加低对比软接触阴影，让站位落在地上；阴影与活动圈须可区分，不能变成第二套圈。人物受光需做实机比较：保持五官和校服清楚，避免因强光把像素颜色洗白，或因环境变暗而像发光贴纸。具体方式由样板验证决定。

### 4.3 镜头与信息层级

画面层级为：人物、选中与行为反馈 → 桌椅和通道 → 墙面与装饰。保持主要移动区和脚下圈所在区域干净。

先保留现有镜头做基准，再小范围调整俯角和取景。不能为了展示墙面装饰，让后排人物过小或让前排物件遮住角色。柜子、吊扇和灯具必须从实际镜头检查；必要时隐藏遮挡镜头的顶部结构。

## 5. 中国高中细节清单

### 5.1 P0：最先落地，决定整体效果

| 区域 | 改造内容 | 制作要点 |
|---|---|---|
| 全室 | 墙、地面、桌椅、窗帘的色彩与纹理统一 | 先统一，再加物件 |
| 课桌 | 课本、练习册、摊开的试卷、笔袋、水杯 | 高中感主要来自学习资料堆叠；保持桌沿可辨 |
| 桌椅 | 少量边缘磨损、椅背挂书包、桌斗露出的书本 | 磨损集中在常接触处，避免遍布噪点 |
| 后墙 | 主题黑板报、课程表、值日表 | 现有大标题适度缩小；加入粉笔擦痕、分栏和手绘边饰 |
| 人物脚底 | 比例校准、软接触阴影、地面亮度校准 | 与活动圈同时验证 |

桌面先做 4 种装饰组合：整齐书本、复习资料较多、摊开作业、较少物件。通过座位装饰配置分配，不能按角色名写分支，也不把装饰当成性格、关系或成绩的证据。不同座位有差异，但整班仍共享一套视觉语言。

### 5.2 P1：增加“这间教室有人在用”的感觉

- **后墙生活角**：扫把、簸箕、垃圾桶与一个班级储物柜；替换或弱化现有铁柜偏办公空间的观感。
- **窗边**：铝合金窗框、窗台、窗帘褶皱，少量绿植；窗外加入教学楼或树冠的简化轮廓，避免大片纯蓝空背景。
- **讲台**：粉笔盒、板擦、教案、少量粉笔灰；只有进入镜头的部分优先精细化。
- **墙面**：广播喇叭、挂钟、班牌；课程表与值日表用可校对的中文内容制作。
- **学习氛围**：书立、资料夹、折角试卷、桌角课程贴。高中感来自这些组合，不依赖大量励志标语。

中文标题需要真实可读，正文在远景形成合理版式即可；避免伪文字和每张纸都要求逐字可读。装饰性表格不列真实角色排名，也不展示未经玩法授权的成绩、关系或私密信息。

### 5.3 P2：时间允许再做

可见区域的日光灯或吊扇、极轻的窗帘摆动、窗外树影，以及基于现有时段的温和光色变化。午后光保持角色辨识度，不做大幅变暗的影视效果。

会阻挡镜头的天花板资产、看不见的建筑外立面、大量精细桌面小物、天气系统与全套坐姿动画，留到后续版本。当前已有坐姿锚点，但接入新坐姿动画属于人物表现任务，应单独估工。

## 6. 空间布置原则

中国高中常有密集桌阵，但本作必须支持课间走动和聚散。保留现有桌阵与座位编号，以资料堆叠和墙面功能增强真实感；本轮不通过增加空桌、收窄过道或改变座位邻接来追求现实人数。

主文档当前空间底座描述为 17 座，而项目总体目标包含最多 25 个节点。此差异需要独立核对，不能在美术优化中顺便扩座或改模拟规则。

- 中央和桌列间通道：地面保持清楚，不摆落地书包、纸团或高对比杂物。
- 桌面与桌斗：承载主要生活细节，优先采用不参与碰撞的装饰。
- 后墙：承载黑板报、公告和生活角，是现有镜头下最值得投入的区域。
- 窗边：承载柔和采光与校园外景轮廓，避免把花盆或柜体伸入可走区域。

新装饰应落在现有家具占位或非通行区域。若确需新增实体障碍，导航、点击遮挡和内核交互几何必须同步验证。

## 7. 工程落点与约束

| 位置 | 预计工作 |
|---|---|
| `scenes/game/classroom3D.tscn` | 环境、光照、镜头、装饰分组 |
| `scenes/components/desk_chair.tscn` | 桌面装饰挂点，保护既有座位与站位锚点 |
| `scenes/components/` | 可复用课本、书包、生活角等组件 |
| `assets/textures/classroom/` | 地面、墙面、木纹、纸张和黑板报贴图 |
| `resources/materials/` | 用 Godot 编辑器调整材质资源 |
| `data/ui/` | 新增环境样式与座位装饰配置，具体文件名在实施时确定 |
| `docs/art/视觉风格指南.md` | 方案获认可后登记最终美术规范 |

装饰分配使用独立、带种子的表现层 RNG，不消耗模拟 RNG，防止一次美术调整改变同种子玩法结果。环境层只读取已有状态；不修改矩阵、角色决策或簇标签。不能用桌面物品暗示谁注定成团、被孤立或触发某个剧情。

保留原有 `Seats`、`StandSpot`、`SitPoint` 等接口。材质 `.tres` 使用编辑器修改，不手改 `.godot/`；项目设置如有必要调整，单独说明影响。新增第三方资源记录许可与署名。

“检验一”适用性：本次优化只增强空间表现，不增加事件规则；人物之间的格局仍必须由原有系统涌现，环境不承担脚本化剧情。

## 8. 实施阶段与工时

工时按熟悉 Godot 的一人制作、复用现有资源估算，尚未经过资产生产验证。结合仓库冲刺计划的 10/14 内容冻结安排，先安排约 2–3 人日的 P0 与少量 P1，其余作为冻结后的候选工作。

| 阶段 | 预计投入 | 交付及通过条件 |
|---|---|---|
| 1. 同框基线与样板 | 0.5 人日 | 记录游戏实际入口、分辨率和人物同框截图；制作一组桌椅、人物、地面、墙面样板，先确定融合效果 |
| 2. 全室统一 | 0.5–1 人日 | 扩展样板材质，统一光照、地面与墙面；保持移动和点击正常 |
| 3. P0 生活细节 | 0.5–1 人日 | 四种桌面组合、书包、黑板报与表格；不影响桌间通道和反馈 |
| 4. 有选择地补 P1 与验收 | 0.5 人日 | 优先生活角、窗外轮廓；完成实机对照、性能与回归检查 |

冻结前若只剩 1 人日：完成样板、全室色彩材质统一、两种桌面组合和接地感。优先交付“人物融进教室”，再继续扩展装饰。

每阶段留同镜头对照图；样板未解决融合前，不批量制作小物件。新资产尽量共享材质和图集，不为每张纸、每本书增加独立动态灯光或独立脚本。

## 9. 验收标准

1. **识别度**：未经介绍的试看片者能认出中国普通高中，并指出至少三种有辨识度的物件或布置；若主要印象仍是空房间、办公室或小学，则继续调整。
2. **融合度**：同镜头对照中，人物脚底落地，桌面与身形关系合理，人物边缘与环境细节精度协调，没有明显发光贴纸感。
3. **生活感**：桌面存在有限变体，后墙表格与生活角有明确用途，避免整班完全复制同一套摆设。
4. **可玩性**：桌间和房间边缘可正常移动；人物拾取、接近聊天、回座位、活动圈、气泡与姓名显示不因装饰失效或难以辨认。
5. **适配**：在实际游戏分辨率及 UI 缩放下检查前后排。人物密度覆盖当前支持的规模；若困难模式 25 节点尚不支持，明确记录限制，不宣称通过。
6. **性能**：同机器、同镜头、同人数与同种子比较修改前后帧时间，建议预算为平均帧时间增幅不超过 10%；实际绝对性能目标以项目目标设备为准。
7. **确定性**：同种子模拟关键结果与改造前一致，装饰随机不改变玩法 RNG 的消费顺序。

实施后跑 Godot 场景检查与相关交互回归；若改导航或几何，重烘焙并验证阻挡一致性。推送前执行仓库快门禁与 GDScript 格式、静态检查；如改动玩法规格，另外按仓库要求更新主文档与 CHANGELOG。

## 10. 首轮交付包

首轮应包含：带人物的样板截图与前后对照、优化后的教室场景、统一材质与贴图、桌面装饰组合、黑板报与课程/值日表、配置与资源许可记录，以及验收结果。

本计划书不修改玩法主文档，不替代现有生产日历。推荐先采用路线 A 和 P0 清单；第一块样板验证通过后，再铺开整间教室。
