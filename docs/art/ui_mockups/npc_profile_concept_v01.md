## 设计重点

- 米白纸张与墨绿边框，延续转笔卡片的视觉风格。
- 基本资料、近期交集、行动入口放左侧；已知关系及历史记录放右侧。
- 已知关系明确标出方向，例如“许静 → 陈阳”，每条线索仅对应好感／敌对／信任中的一个轴。
- 闲聊记录来自自然完成时的真实矩阵快照，不标注真假或可信度；显示获知来源、时间与距今时长。
- 未获得的轴显示“未知”，不当作中立；不展示后台原始数值。
- 只能提示“此后关系可能变化”，不能根据后台变化自动标记“已失效”。
- “他对我的态度 · 我的判断”独立低强调展示，不与已知第三人关系混淆。
- 人名、座位、关系档位、日期和互动均为排版示例，不代表真实存档；文字档位映射与交互仍需后续实现。
- 背景为生成的3D教室示意，不是当前场景运行截图。
