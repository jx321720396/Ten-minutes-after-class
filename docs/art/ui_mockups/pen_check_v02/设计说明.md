## 实景依据

底图为 Godot 4.7.2 Movie Maker 直接运行 `scenes/game/classroom3D.tscn` 导出的第二帧，1920×1080，D3D12 Mobile。原图：`classroom_capture00000001.png`。使用场景原有 Camera3D，fov=42，不改变机位、家具或灯光。

当前文件包含 UI/PauseMenu，但没有人物节点。人物素材来自 `assets/textures/characters/安静女.png` 和 `安静男.png`。设计图中的人物位置、大小和标记为合成示意，不能视为实际3D锚点投影或遮挡验证。

## 本轮布局

- 1920×1080基准下卡片建议矩形：x=730、y=808、宽460、高240，底距32。
- 保留米白底、墨绿细边与橙色72%，本次只展示接纳结果，同一张卡片承载状态切换。
- 内容为：向「同学」提出求助、✓ 对方答应了、横停的笔、我的把握72%、根据目前了解估计。
- 双方保持小尺寸纸片人；屏幕UI层显示“我／同学”标记，回应者显示“接纳”。无新增表情立绘。
- 当前镜头的讲桌位于屏幕下方中央，因此卡片会遮住部分讲桌。这是底图中实际存在的布局取舍。人物接入后还需检查前排站位与移动路径。
- 底距32采用用户本轮指定值；它小于旧视觉指南的上下5%安全区（54px），移动端最终布局应单独适配系统安全区。
- 72%仅为锁定的信念估计示例。求助仅为复用组件示例，不改变冲刺版行为范围。
