# 第十一章 社会事件

社会事件 = **多阶段、跨相位、全体参与、结果改变结构**的班级级过程。

> ⚠️ 它**不是剧本**：触发、过程、结果全部由数值决定（见 §8 总则「一切由数值驱动」）。任何"第 N 天举行 X"的写法都视为错误实现。

## 11.1 层级位置

```
行为层       逐 tick、15 个行为、个体决策（§8）
社会事件层    多阶段、跨相位、全体参与、结果改变结构      ← 本章
结算层       跨天衰减、座位重排、简报（§2.5、§12）
```

## 11.2 通用规范

| 项 | 规范 |
|---|---|
| **触发** | 由数值条件满足触发，**不看日期** |
| **阶段** | 每个事件由 N 个阶段组成，每阶段绑定一个相位（课间 / 上课 / 放学） |
| **过程** | 每阶段内部仍走既有机制（流言、意向评分、阈值判定），**不写死台词或结果** |
| **结束** | 产出结构变化（身份 / 标签 / 关系），并归档进日志供简报引用 |
| **玩家** | 各阶段参与方式不同，且**不能操纵结果** |
| **并发** | 同一时间至多一个社会事件在进行中 |

## 11.3 数值档位

社会事件的直接数值影响使用**重大档**（`base ∈ [4,5]`，见 §4.3），并可附加状态标签（如「落选」3 天）。

## 11.4 班委选举

### 触发条件（任一满足，全部为数值判据）

1. **权威崩解**：现任班长（身份层持有「班委」标签者）曾压力爆发（≥90），且其影响力 `influence` 跌至班级中位数以下；
2. **阵营分裂**：班级存在 ≥2 个稳定簇（簇标签），且两簇之间的平均敌对 ≥ 阈值；
3. **玩家提议**：玩家消耗一次课间动作提议改选，并满足支持门槛（≥N 人对玩家好感 ≥ 阈值）。

> `influence(c)` = 有多少人愿意听 `c` 的话，可由矩阵直接读出：`Σ_j max(0, A[j][c] − θ)` 归一化。

### 五个阶段

| 阶段 | 相位 | 机制 | 玩家可参与 |
|---|---|---|---|
| ① 酝酿 | 课间 | 「改选」作为一条**流言**进入系统（§8.1：带倾向、会染色、会被窃听） | 打探 / 表态 / 传话 |
| ② 提名 | 课间 | 候选人 = 各强连接簇的**话事人**（簇内 `influence` 最高者）；玩家可自荐（需支持门槛） | 自荐 / 支持他人 |
| ③ 模拟投票 | 课间 | 非正式试探：通过闲聊 / 打听探口风 → 影响各方**信念** | 拉票 / 试探 / 虚张声势 |
| ④ 实际投票 | **上课** | 正式投票，玩家**不可操作**（上课是发酵层） | 只能看情报日志 |
| ⑤ 结果公布 | 放学 | 计票 → 新身份 + 簇标签重算 + 简报条目 | 看《每日简报》 |

> ③ 与 ④ 的相位安排（模拟投票下课、实际投票上课）是刻意的：**结果在你无法干预时产生**。

### 投票算法

```
选民 i 对候选人 c 的投票倾向：
  U_vote(i, c) = α_A · A[i][c] + α_T · T[i][c] + α_I · influence(c)
  倾向转概率：softmax(U_vote / τ)，每人一票

开票：得票最高者当选；平票按 influence 破平
```

注意：**「我信任他」与「他说话管用」是两件事**——因此会出现"人缘好但没实权者落选"这类结果。

### 结果的结构影响

| 对象 | 影响 |
|---|---|
| 当选者 | 获得「班委」身份标签 → 影响后续（举报倾向、责任种子、被拉拢概率） |
| 落选者 | 压力 **+4~5**（重大档）+ 可能对当选者敌对上升 |
| 支持者 | 通过关系调制自然产生"阵营效应"（支持落选者的人对当选者好感下降） |
| 全班 | 簇标签重算 → 格局可能重新洗牌 |
| 玩家 | 参选并当选则获得身份，同时背上相应责任种子 |

## 11.5 同层可扩展的其他社会事件

| 事件 | 触发（数值） | 结构影响 |
|---|---|---|
| 班级冲突爆发 | 两个簇的敌对同时过阈值 | 全体站队 |
| 真相揭露 | 推理板矛盾累积到阈值 | 秘密 / 诬告公开 |
| 集体活动（春游 / 运动会） | 学期中段 + 班级压力中位数偏高 | 强制互动、关系重排 |
