## 15.1 全链路总览

```text
【每 tick】（课间 100 tick / 上课 90 tick；1 天 480，学期 14,400）
  ① 决策侧「想不想」（读信念 B + 自己真值；玩家跳过此层）
       环境类  s = p_base × Π 修正系数（相邻 ×1.5、压力≥70 ×0.5 …）
       阈值类  s = σ((x − θ)/scale)
       意向类  s = softmax(U_b/τ_i)（先取 top-5 候选）
  ② 判定侧「成不成」（读真值；sigmoid + 掷骰）
       p = σ((score − θ)/scale)；结果 = Bernoulli(p)
       展示口径：涉玩家时成功率改用信念 B_A 重算（NPC 静默）
  ③ 效果层（事件类，即时结算 + 去重）
       E → ×M(i,j)（仅常规档）→ Δ = M_state · sat(E) → ×room（仅正向轴）→ clamp 写入
       major 敌对同时写深层 H_deep（软上限 70）
【每 240 tick · 洽流 · 每天 2 次】
       传导（感知值 + 阈值 + 竞争归一化 + 负反馈）
       共同学习（相邻双学习：A+1 / T+1）
       压力洽流（学习 +0.4 / 独处 −2 / 睡觉段末 −3）
       音量趋近（volume ← volume + 0.2×(target − volume)）
【每天 settle_day】
       跨天衰减（A/H/T/压力/深层×0.995）＋ 信念遗忘 λ_b=0.02
       心结结算与传染、座位重排、《每日简报》；第 30 天《学期格局报告》
```

## 15.2 全局铁律

| # | 铁律 | 内容 | 出处 |
|---|---|---|---|
| 1 | base 分档 | 常规 `base ∈ [1,3]`（任何角色都能轻易触发）；重大 `base ∈ [4,5]`（前置条件苛刻）。判据是**前置条件**，不是主观感受；越界启动报错 | §4.3、UIF §1.5.1 |
| 2 | 三类结算 | 事件类（即时，每对子每规则每课间段最多 1 次）；洽流类（每天 2 次，`settle_interval=240`，判据用全程 tick 计数）；状态类（跨天，§2.5） | UIF §1.5.2 |
| 3 | 精度 | 写入前 `round(Δ, 0.1)`；单次结算幅度设计 ≥ 0.1，否则被舍入归零 | UIF §1.7 |
| 4 | 事件去重 | 同一对子、同一规则、同一课间段只结算一次（再次发生仍写信念，不改数值） | UIF §1.5.4 |
| 5 | 维度方向 | `dims[3]` **直读为 J 强度**（50=中性）；公式要表达 J 一律用助手 `arg_j(i)`，禁止手写 `(dims[3]±50)` | §2.4.1 八 |
| 6 | 信念/真值分离 | 决策读信念 B（对方态度）＋真值（自己立场）；判定读真值；展示（玩家成功率）读信念。禁止 `A[j][i]` 进决策路径 | §4.4、§8.22.3 |
| 7 | 纯函数 | 行为逻辑 = `f(性格四维, 透明度, 当前状态)`，禁角色名/ID 判断；随机一律种子化 RNG；标签是结果的调制器不是身份 | §9.11、§8.19 |
| 8 | 观察层只读 | 簇标签/孤立标签不回写任何矩阵、不参与判定 | §8.20 |

| 10 | 事件侧不含传导 | 事件结算与传导结算在时间上分离（传导只在洽流点）；`P = E + β·C` 的合并式是同一写入点的语义表达 | 实现口径（§15.17-⑦） |

## 15.3 统一影响公式（UIF）—— 效果层

### 15.3.1 三段式（语义形式）

```text
① 推动量   P = E + β_X · C
② 软饱和   Δ = M_state · sat_X(P)      sat_X(u) = u / (1 + |u|/U_X)
③ 写入     X ← clamp( X + round(Δ, 0.1), 0, 100 )
```

### 15.3.2 事件推动 E 与性格倍率

```text
E = base × scale × clamp( 1 + Σ_{t=1..4} w_t · d_t , 0.1, 1.2 )
  d_t = (维度_t − 50)/50，顺序固定 d₁=E d₂=S d₃=F d₄=J
  scale = 外部幅度系数（默认 1.0；音量敌对等随情境缩放，非旁路）
```

性格倍率区间 `0.1 ~ 1.2`（温和）：敏感者接近 1.2、普通 0.6、迟钝 0.15。**例外**：概率类修正（成功率加成等）与 `M_state` 不受此限。

### 15.3.3 关系调制 M(i,s)（仅「与特定对象互动」的常规档事件）

```text
M(i,s) = clamp( (A[i][s] − H[i][s]) / 50, −1, +1 )      # 按净态度调制
正向事件（好感/信任类）：Δ = base × M
```

态度不明显时只削弱；敌对明显压过好感时**反转**（同一场聊天一方加一方减）。修复类行为（道歉）整条跳过调制（`no_modulation`）——否则「越道歉越糟」。

| A | H | M | 效果（base=3） |
|---|---|---|---|
| 65 | 0 | +1.00 | +3.0 满额 |
| 30 | 20 | +0.20 | +0.6 削弱 |
| 30 | 45 | −0.30 | −0.9 反转 |
| 10 | 55 | −0.90 | −2.7 强反转 |

### 15.3.4 M_state 压力区间系数

| 压力区间 | 系数 | 含义 |
|---|---|---|
| 0–40 | ×1.0 | 心态平稳 |
| 40–70 | 负面 ×1.5 ／ 正面 ×0.75 | 越慌越敏感、听不进劝 |
| 70–90 | ×1.5 | 临界区 |
| ≥90 | ×1.0 | 相变交给 §6.5 概率爆发 |

⚠️ **v4.0 落点注（2026-10-09）**：本系数硬编码于 `tools/core_sim.py m_state()` 与 `scripts/core/sim_core.gd _m_state()`（两处一致）；主文档 v3.1 所写 `data/rules/axis_coef.csv` 未落盘（§15.17-①）。

### 15.3.5 负反馈 room（阻止 30 天全班封顶）

```text
room(axis, X[i][k]) = max(0, 1 − feedback · X[i][k]/100)    # feedback = 1.0
仅作用于正向轴（好感/信任）；敌对/压力不适用
```

作用在**统一写入点**（事件侧正向轴 + 传导好感轴）；**深层 H_deep 不参与**（否则仇恨自我封顶）。稳态关系式：`A* ≈ 每日增益 / (1 − 跨天保留率)`。

### 15.3.6 传导 C（洽流类，每 240 tick）

```text
w_ij   = A[i][j] / 100                          # i 对 j 的听从度
σ_X(j→k) = max(0, 感知_X(j→k) − θ_X)            # θ_A/θ_H/θ_T = 30/40/40
感知_X(j→k) = 真实_X 经 j 的透明度过滤（低透明度者真实态度不扩散）
net_A = ( Σ w_ij·σ_A − Σ w_ij·σ_H ) / ( Σ w_ij + ε )
net_H = ( Σ w_ij·σ_H − Σ w_ij·σ_A ) / ( Σ w_ij + ε )
net_T = ( Σ w_ij·σ_T ) / ( Σ w_ij + ε )
Δ_A = round( room_A · sat(β_A·net_A, U_A), 0.1 )     # β_A = 0.20, U_A = 25
Δ_H = round( sat(β_H·net_H, U_H), 0.1 )              # β_H = 0.30, U_H = 25（无负反馈）
Δ_T = round( sat(β_T·net_T, U_T), 0.1 )              # β_T = 0.15, U_T = 20
```

- **竞争归一化 + 阈值不可省**（墙头草/派系不拉平的来源）；好感与敌对互相反向抑制，两轴独立写入、不互相扣减。
- 传导必须读本结算点开始的**矩阵快照**（实现已把感知表预计算提到外层，n² 而非 n³ 次纯函数重算，结果逐位不变）。
- `C_O = 0`（透明度不传导）；`C_S ≡ 0`（压力不传染，只由事件与消解驱动）。
- M2 增强项（待定）：`w_ij` 改用 `(A[i][j]+T[i][j])/200`。

### 15.3.7 透明度 O

```text
O[i] ← clamp( O[i] + Δ_O + λ_O·( O_init[i] × M_stress(stress_i) − O[i] ), 0, 100 )
  Δ_O = M_state · sat_O(E_O + β_O·C_O)     C_O 当前 ≡ 0
  λ_O = 0.03（回归速率）
基础透明度 = 种子 opacity_init（§15.14.3 生成公式）
```

### 15.3.8 作用面一览

| 量 | 类型 | UIF 写入 | C | 备注 |
|---|---|---|---|---|
| 好感 A / 敌对 H / 信任 T | N×N 有向 | ✓ | ✓（A/H 互抑） | 慢变量；H 与 A 独立两轴 |
| 透明度 O | 个体 | ✓ | ≡0 | 乘性基座＋事件偏移 |
| 压力 S | 个体 | ✓ | **≡0** | 快变量；不传染 |
| 深层敌对 H_deep | N×N | ✓（仅 major 敌对） | — | 软上限 70、×0.995/天、不参与 room |
| 信念 B_A/B_H/B_T | N×N×3 | ✗（只读派生） | ✗ | 决策专用，§15.5 |
| 性格四维 | 固定 | 仅作 d_t 系数 | ✗ | |

### 15.3.9 事件结算完整顺序（实现口径）

```text
apply_event(i, j, event_id, scale=1.0):
  去重检查（(i,j,event_id,day,phase) 已结算 → 跳过）
  E = base × scale × mult_personality(w·d)
  若 tier=normal 且非修复行为：E ×= M(i,j)          # major 档 M_eff=1
  Δ = round( M_state(i, negative) × sat(E, axis), 0.1 )   # 压力轴不乘 M_state
  边量：Δ = round( room_for(axis, X[i][j]) × Δ, 0.1 )     # 敌对轴 room=1
  写入 clamp；若 hostility 且 major：H_deep += min(70, |Δ|)
```

### 15.4.2 概率爆发（不是到点必爆）

```text
入口阈值 70（behavior_thresholds.burst）；跨过后每天判定一次：
severity = (stress − 70) / 30                    # 0 = 刚过阈，1 = 满压
p_burst  = burst_p_max × severity                # burst_p_max = 0.5
爆发成功：stress −= 40；本人获「心结」，天数 ×(1+severity)
          传染范围 = spread_max × (1+severity)，被波及者心结天数同 ×(1+severity)
```

心结（`status_tags.csv`：`heart_knot`，3 天、每天初始压力 +5）传染：`spread_ratio=0.25` × 在场人数，上限 `spread_max=2`；对象按 `|A−H|` 排序取最鲜明者。**连环爆发 = 爆发→传染→他人压力↑→再爆发的结构来源。**

## 15.5 信念矩阵（感知层，只读派生）

### 15.5.1 三份矩阵与转置语义

`B_A/B_H/B_T[i][j]` = i 猜测「**j 对 i**」的态度（对应真值 `A[j][i]` 等，**转置**）；对角线恒 0；先验 40/20/40。

### 15.5.2 初始化（先验 + 系统性偏差，纯性格函数）

```text
perceived(j) = (E_j−50)/50·0.5 + (F_j−50)/50·0.5     # 对方「看起来」多友善
observer(i)  = (F_i−50)/50·0.5 + (E_i−50)/50·0.5     # 我多倾向把人往好处想
B_A[i][j] = prior_a + w_bias · perceived(j) × (1 + k·observer(i))    # w_bias=10, k=1.0
B_H[i][j] = prior_h − w_bias · perceived(j) × (1 + k·observer(i))
B_T[i][j] = prior_t + bias_trust_ratio · w_bias · observer(i) × 0.1  # 信任只受观察者影响
```

乘法而非加法：对方友善＋我乐观 → 强烈高估；对方友善＋我多疑 → 略高估；对方冷淡＋我乐观 → 仍略低估。天然不对称（实测 92% 对子双向差异）。

### 15.5.3 观测与更新

```text
obs_X = 真值_X(j→i) + σ_X·z(i,j,axis) + bias_X(j)·w_bias
  实现口径：σ_X = sigma_max_X × (1 − O[j]/100)（连续线性衰减，非四档定值）
           z = hash 确定性伪随机 ∈ [−1,1]；模糊档再 ×1.5；封闭档观测为 0（不更新）
           bias 项仅 affinity 轴实现（perceived(j)）
B_X[i][j] ← clamp( B_X + η_X·(obs_X − B_X), 0, 100 )
  η_X = eta0_X · ( 0.3 + 0.7·T[i][j]/100 )·weight     # 越信任越采信
遗忘（每天）：B_X ← B_X + λ_b·(prior_X − B_X)，λ_b = 0.02
二手情报保真度 = 0.7^hops；失真复用「流言倾向偏移」
```

`belief.csv` 快照：eta0 = 0.25/0.25/0.20；sigma_max = 25/25/20；prior = 40/20/40；lambda_b = 0.02；w_bias = 10。

### 15.5.4 可见性档位（透明度决定能看见什么）

| 档位 | O[j] | 立场分类 | 变化信息 | 精确数值 |
|---|---|---|---|---|
| 通透 | 80–100 | 绿/红/灰 清晰 | 方向+粗档 | ✗ |
| 可见 | 50–79 | 同上（淡） | 仅方向 | ✗ |
| 模糊 | 20–49 | `null`（?） | 仅「有变化」提示（冷却：每段 ≤1 次，p=0.5） | ✗ |
| 封闭 | 0–19 | `null` | `null` | ✗ |

分类阈值（复用系统既有阈值）：亲近 A≥60、敌对 H≥40、中立其余。**`null ≠ 0`**（「看不见」≠「看见了没变」）。

### 15.5.5 打听（玩家独有）三级透露度

| T[target][i] | 表现 |
|---|---|
| < 40 | 敷衍，且**可能给假信息**（必须留可验证破绽） |
| 40–70 | 表面话（粗分类，可能不准） |
| ≥ 70 | 真心话，准确度 = O[target] × T[target][i] |

二手（关于第三人 k）：准确度 = O[被问者] × T[i][被问者] × 0.7^hops。

## 15.6 NPC 行为决策（门槛 → 意向 → 采样）

### 15.6.1 三类触发

| 类型 | 判据 | 行为 |
|---|---|---|
| 环境类 | 固定基础概率 × 修正系数 | 闲聊 0.06、走动 0.05（段首）、睡觉 0.03、传纸条 0、调侃 0.09、打闹 0.05、流言 0.03、安慰 0.35、求助 0.04、道歉 0.05、举报 0.10（每 tick，`behavior_probs.csv`） |
| 阈值类 | 条件满足即发生（sigmoid） | 举报、压力爆发 |
| 意向类 | 门槛 → U_b → softmax | 搭话、调侃、安慰、求助、道歉、秘密交换 |

闲聊修正链：`p = 0.06 × 相邻(×1.5) × 双方外向修正 × (压力≥70 ? ×0.5 : 1)`。

### 15.6.2 意向评分与采样

```text
U_b(i) = Σ_X α_X(i) · Δ_X^pred(i, b)
  自己的立场 → 真值；对方的反应预期 → 信念 B（绝不是真值）
p(b) ∝ exp(U_b / τ_i)，先取 top-5（top_n = 5）
τ_i = tau0 × (1 + tau_j·(1 − J_i/100)) × (压力≥70 ? tau_stress_mult : 1)
  = 1.0 × (1 + 0.3·(1−J/100)) × (≥70 ? 1.5 : 1)
```

α 派生（`npc_weights.csv`，归一化 Σα=1）：

```text
α_A ∝ 0.5 + 0.5·F/100 + 0.3·E/100      α_T ∝ 0.5 + 0.3·J/100
α_H ∝ 0.5 + 0.5·(1−F/100) + 0.3·J/100  α_S ∝ 0.5 + 0.5·(1−E/100)
```

### 15.6.3 移动决策（状态层，不改关系数值）

```text
段首离座概率 p = move_p(0.05) × 外向修正 × 压力修正（配置化，不写死）
score(i,target) = relation_fit + state_fit + activity_fit + distance_fit
                + personality_fit + seeded_noise
p(target) = softmax(score/τ)（top-N）；站立点被占则取最近空闲点
到达后走既有「门槛→意向→采样」；移动期间 busy（move.duration=15 tick）不接新交互
```

已知问题：实现与 §3.1 存在「边走边聊」不一致（`NPC移动决策.md` §12）。

## 15.7 统一判定式（决策侧 / 判定侧）

### 15.7.1 决策侧（想不想，读信念，概率化）

```text
环境类  s = p_base × Π 修正系数
阈值类  s = σ((x − θ)/scale)
意向类  s = softmax(U_b/τ)
软门槛项 = w_gate × [ σ((A[i][j]−θ_A)/scale_A) + σ((θ_S − Stress[i])/scale_S) − 1 ]
  # join_chat: gate_affinity=30, gate_stress=80, gate_scale=8, gate_weight=4
```

### 15.7.2 判定侧（成不成，读真值，sigmoid + 掷骰）

```text
score = f(参与者 A/H/T + 性格四维 + 当前状态)
p = σ((score − θ)/scale) = 1/(1 + exp(−(score−θ)/scale))
结果 = Bernoulli(p)
```

`θ` 是 p=0.5 拐点（不是闸门），`scale` 控坡度，均在 `behavior_thresholds.csv`。**压力是程度不是闸门**（压低 score 而非 p 归零）。

### 15.7.3 玩家三拍（NPC 静默，玩家掷骰）

```text
展示成功率 = f(B_A[i][j])     # 信念——不泄露真值
结算掷骰   = f(A[j][i])       # 真值
```

两侧必须分开实现（曾同侧导致展示永远精准、认知偏差被架空）。适用一切「成功率/概率修正」的玩家侧呈现。

### 15.7.4 事件判定分类 A–E

| 类别 | 读什么 | 方向来源 | 例 |
|---|---|---|---|
| A 纯增益 | 无 | 固定正向 | 闲聊共鸣、共同学习、安慰 |
| B 纯损害 | 无 | 固定负向 | 流言（负）、举报、被拒 |
| C 信念驱动 | B_A/B_H/B_T | 信念定触发与倾向 | 搭话、求助 |
| D 信任·透明驱动 | T、O | T/O 定成败与可见性 | 秘密交换、告密、窃听 |
| E 混合判定 | A+H（+性格） | **绝对阈值分档** | 当众调侃、道歉 |

三条边界：① 信念只定「做不做」不定「效果多大」；② 重大档不做关系调制；③ 门槛用阈值（硬）、幅度用公式（软）。**不能用 M 的符号判方向**（M 零点在 A=H，而 A 基线 25–40 远高于 H → M 恒偏正，实测全班趋同）。

## 15.10 环境层

### 15.10.1 音量（班级级标量，有惯性）

```text
target  = clamp( Σ noise(各人当前行为), 0, 100 )      # 按「场」计：同一场闲聊只计 1 个声源
volume ← volume + 0.2 × (target − volume)             # adapt_rate=0.2，时间常数 5 tick ≈ 5 秒
excess  = max(0, volume − 20)                          # volume_threshold = 20
```

noise 档：无声 0（窃听）｜常规 1–3（学习 1、走动 1、流言 1、告密 1、闲聊 2、搭话 2、调侃 3）｜特殊 4–5（追逐打闹 5）。定标原则：**单人贡献必须小**（17 人 × chat=2 = 34 不爆表，10 人 = 20 恰达阈）。

### 15.10.2 超阈音量 → 压力 / 定向敌对（同源分岔）

```text
fear = noise_base_fear(2.8) + fear_j(0.6)·(J−50)/50 + fear_e(0.4)·(50−E)/50
Stress += excess × stress_k(0.40) × fear               # 全员受嘈杂影响（基础项教训 §9.9.1）
定向敌对（单向）：被吵到者 → 邻居中最吵的 2 人
  ΔH = noise_hostility_base(3.0) × (excess/noise_scale(8.0)，上限 2 倍) × 性格 × 关系调制，走 UIF
  仅「安静/学习者 → 敌视吵闹者」单向成立（被吵到的人记恨，吵的人浑然不觉）
deviance_k = 0.0（偏离氛围的压力代价，未启用，双稳态待开）
```

### 15.10.3 从众与氛围反馈

```text
conformity(i) = clamp( 0.5 + (F−50)/100 − (J−50)/100·0.5 − (N−50)/100·0.5, 0, 1 )
想社交意愿 += conformity × volume/100          （吵 → 从众者更想聊）
想学习意愿 += conformity × (1 − volume/100)    （静 → 从众者更想学）
偏离氛围 → 压力（不禁止行为）；反从众者完全不受影响（噪声源，可推系统翻态）
跟随概率（free 类活动）= free_join_rate(0.10) × conformity(i)
```

「学霸」不是规则：总在学习 = 高 J × 低从众 × 爱学习标签（study_bias +50%），全部是 f(性格,标签,状态)。

## 15.12 排挤与孤立 / 观察层

```text
排挤判据（施害者视角）：近 exclude_window(30) 天内对 j 做过重大敌对行为的人 ≥ exclude_count(2)
  + 冷却 exclude_cooldown(7 天) + 每 tick exclude_p(0.06)
效果：双向 exclude_affinity（major，base −4）——「他恨上排斥他的人」+「大家不跟他玩」
孤立指纹（观察层判据，只读）：被好感显著低于班级均值 且 给好感接近正常
```

簇标签器（每 tick 末，只读）：强连接边 `A≥60 双向 且 T≥50 双向` → 连通分量 + 稳定性滤波（连续 ≥5 tick 成团 / ≥5 tick 不满足则消失）；孤立 = 连续 ≥10 tick 未进入对话且距最近者 ≥2 格。输出只有标签。

## 15.13 社会事件

```text
触发：纯数值判据（social_event_triggers.csv，metric/op/value），禁日期类记号；并发至多 1；冷却 cooldown_days
influence(c) = Σ_j max(0, A[j][c] − θ) 归一化       # 多少人愿意听 c 的话
投票：U_vote(i,c) = α_A·A[i][c] + α_T·T[i][c] + α_I·influence(c) → softmax(U/τ)，每人一票
开票：最高票当选，平票按 influence 破平；落选者压力 +4~5（重大档）
```

数值档位用重大档（base 4–5）；阶段内部仍走既有机制（流言/意向/阈值），**不是剧本**。
