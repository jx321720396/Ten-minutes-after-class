## 17.1 P0-1 学业系统（成绩轴）

### 17.1.1 数据模型

`grade[i]`：**个体状态量**（与压力同层，不进 A/H/T 矩阵、不参与 UIF 与传导）。

```text
值域 [0, 750]，grade_max = 750
初始：
  玩家  grade = 250 固定（grade_init_player）
  NPC   grade ∈ [200, 650] 种子化 RNG 均匀抽样（grade_init_npc_min / grade_init_npc_max）
        —— 谱面覆盖学渣到学霸，「成绩不好的转校生」的相对位置由此成立
玩家与 NPC 共用同一套结构与规则（§10.1 玩家不是特权者）；初始值差异属**开局种子层**
（与玩家初始座位同级），运行期涓流 / 打断 / 考试规则完全同权。
```

**决策记录（2026-10-09 用户裁决）**：初始分化由「开局随机种子（NPC 200–650）+ 行为」共同产生，不做任何身份 / 角色 ID 判断；不按性格 J 维做初始偏置。「成绩好的人总在学习」仍由 高 J × 低从众 × 爱学习标签 涌现（§15.10）。若标定显示需要「角色固有成绩」（爱学习标签者开局偏高），P1 再评估改为 seeds.csv 按角色列配置。

### 17.1.2 成绩涓流：分段递减 + 学习时长累加器

**分段表**（`data/rules/grade_table.csv`，按「每 50 分一档、每档 +3s」推定；整列可调，改表不改代码）：

| 成绩区间 | 每 +1 分所需学习 | 对应每 tick 增量 |
|---|---|---|
| < 300 | 10 tick（=10s 实时） | 0.10 分 |
| 300–349 | 13 | 0.0769 |
| 350–399 | 16 | 0.0625 |
| 400–449 | 19 | 0.0526 |
| 450–499 | 22 | 0.0455 |
| 500–549 | 25 | 0.0400 |
| 550–599 | 28 | 0.0357 |
| 600–649 | 31 | 0.0323 |
| 650–699 | 34 | 0.0294 |
| 700–750 | 37 | 0.0270 |

**实现（学习时长累加器，绕开 0.1 精度铁律对小增量的舍入归零）**：

```text
每 tick 处于「学习状态」（主行为=学习或默认空闲，§8.15 注释语义）时：
  study_acc[i] += 1
  若 study_acc[i] ≥ ticks_per_point(grade[i])（按 §17.1.2 分段表查当前档）：
      grade[i] += 1；study_acc[i] -= ticks_per_point
  grade = 750 时 acc 清零不再累积
上课段不累积（上课是被动听讲，非自主学习；是否计入列为 §17.6 开放项）
跨天 study_acc 保留（不随 settle_day 清零——「学了一半」不该蒸发）
```

**打断语义预留（P1）**：打断是否清空 `study_acc` 在 P1「学习打断」规格中裁决；P0 先保留累积。

**量级预估（标定用）**：初始即铺开 200–650 成绩谱。低分段（<300 档）10 tick/分：全天课间 300 tick × 约四成在学 → 约 +12 分/天（玩家 250 起步正处此档，转校生追赶手感由此而来）；高分段（≥650）34–37 tick/分 → 约 +3–4 分/天，领先者自然放缓。谱系大体保持、谱内由行为再分化；若整体过平/过陡，调 `ticks_per_point` 整列（§17.4）。

### 17.1.3 HUD 与考试倒计时

- `time_hud` 扩展：右上角「成绩 NNN ｜ 距期末考 N 天」。
- 期末考日 = `term_days`（第 30 天，`time_runtime.csv`）。**这是学期制度（世界结构，与课程表同级），不属于"第 N 天必然发生 X"禁项**——禁项针对社会事件触发（§11.2）。
- 成绩只显示整数；玩家看不到 NPC 具体分数（P0 不做成绩打探交互）。

### 17.1.4 参数落点与校验

- 新表 `data/rules/grade_table.csv`：`band_upper,ticks_per_point` ×10 行 + `grade_max=750`、`grade_init_player=250`、`grade_init_npc_min=200`、`grade_init_npc_max=650`。
- `check_config.py` 扩展：分段表 band_upper 严格递增且末档 = grade_max；ticks_per_point 递增；grade 值域键存在。

## 17.2 P0-2 老师巡查

### 17.2.1 实体设计

老师是**世界实体，非社交节点**：

- 不占 N 个节点名额、不进 A/H/T/B 矩阵、不参与传导与信念更新；
- 状态只有位置（办公室 / 教室）与巡查用种子化 RNG（同种子可复现）；
- `kernel_params.csv` 已预留的「老师节点四维亦用 50」口径落为：非节点实体，无 MBTI。

### 17.2.2 巡查判定（不杀回马枪）

```text
每课间 2 个判定点：tick = 25 与 tick = 65（落点参数 visit_checks = "25,65"）
每点以 visit_p = 0.25 独立掷骰
单课间至少来一次概率 ≈ 1 − (1−0.25)² ≈ 43.75%
「不杀回马枪」：本课间已来过 → 第二判定点直接跳过（至多 1 次/课间）
停留 stay_ticks = 30（约半段课间），到时回办公室
上课段老师默认在教室（教学状态，不触发本章巡查/加压逻辑）
```

### 17.2.3 进教室效果

**到场瞬间（事件类，触发一次结算）**：

```text
全班压力 += teacher_visit_stress（base 3，常规档，走 UIF §15.3：性格修正经 w 系数）
豁免名单：睡觉（§8.8）、学习（默认状态）——两人被逮不到
看书 / 听音乐 / 吃零食 不豁免（"被逮风险感"，为 P3 没收做铺垫）
```

**在场期间（stay_ticks 内，状态修正）**：

```text
调侃 / 打闹 / 排挤 触发概率 × suppress_behavior_mult（0.3）
音量目标 × volume_target_mult（0.5）——压场经环境层自然传导，不写特例
```

### 17.2.4 与既有系统的接口

- **举报**（§8.2）：举报语义是"跑去老师那儿"——老师实体落地后举报的收件方从抽象变具体；P0 只接位置表现，不改举报数值与门槛（§15.8）。
- **观察层**：老师位置是环境事实，只读输出（可视化画讲台状态），不回写任何矩阵。
- **玩家**：老师在教室时玩家行为同样受限（概率修正是纯状态量输入，符合铁律）。

### 17.2.5 参数落点

新表 `data/rules/teacher.csv`：`visit_checks` / `visit_p` / `stay_ticks` / `visit_stress_base` / `suppress_behavior_mult` / `volume_target_mult`。
事件落 `w_events.csv`：`teacher_visit_stress`（axis=stress，base=3，tier=normal，w 系数按敏感者 1.2/迟钝 0.15 锚定填表）。

## 17.3 P0-3 状态减压第一批 + 出门 + 上课好感涓流

### 17.3.1 三个新状态层动作（NPC 同权）

与睡觉同构：**主行为**（占时段、期间不发起/接受交互）、段内涓流减压、老师进教室不豁免（§17.2.3）。NPC 走既有「门槛 → 意向 → 采样」同一条路（§15.6），触发概率进 `behavior_probs.csv`——**玩家与 NPC 无任何数值差异**（§10.1）。

| 动作 | 减压（每涓流结算） | 噪音 | 时段占用 | 前置 |
|---|---|---|---|---|
| 听音乐 `listen_music` | −2.0 | 0（耳机） | 30 tick | 玩家默认可用；NPC 全员可用 |
| 吃零食 `eat_snack` | −1.5 | 1 | 15 tick | 玩家每局 5 份（`snack_count_per_run`），用完即止；NPC 全员可用 |
| 看书 `read_book` | −2.5 | 0 | 40 tick | **需持有课外书**（见 §17.3.2） |

设计取舍：减压幅度均 ≤ 疲觉的 3（§15.15），但时段占用远短于睡觉的整段——形成「回血上限低但保留交互机会」的梯度；噪音差异经环境层自然产生社会后果（§15.10）。

### 17.3.2 物品门控（最小集）

- **课外书**：NPC 侧经 `seeds.csv` 新增环境事实列 `book`（0/1，建议 8–10 人自带）——自带者可看；**玩家 0 本，入口预留**（菜单项灰置，随 P3 物品系统开放）。「前三天有人送课外书」原案违反不变式 1，已废弃；P3 的赠送改为状态触发（好感/信任达阈值按概率赠予）。
- **零食**：玩家 `snack_count_per_run = 5` 份/局（计数器，不进存档回滚语义外的系统）；NPC 不限量（常物）。
- **耳机/音乐**：默认全员可用（常物），P0 不做门控。

### 17.3.3 出门（玩家独有）

```text
效果：跳过本课间剩余时间（快进）；NPC 照常结算，玩家不参与任何判定与涓流
社交代价（事件类）：对【邻居 = 8 邻域座位同桌】A −3（leave_absence，常规档上限；走 UIF）
限制：每课间限 1 次；上课段不可出；出门期间玩家的学习/减压全部不结算
```

> 用户原话「给他 4 减」超出常规档 `base ≤ 3` 铁律（§15.2），经确认取「邻居 −3」方案（范围换幅度的「全班 −1」备选未采用）。

### 17.3.4 上课好感涓流

```text
上课段每次涓流结算（沿用 settle_interval 机制，§15.15）：
  对每对「座位相邻（8 邻域，§9.1）且双方清醒（非睡觉）」的对子：A += class_affinity_gain（0.2）
每天上课 2 次结算 → 单对最高 +0.4/天；与共同学习（相邻双学习 A+1/T+1，§2.3）叠加后
仍远低于「一天涨很多」红线（§2.4 标定目标 1）
```

**门关联**：当前 `check_metrics` 唯一未达标项为好感均值 32.4（目标 45–65）——本涓流为正向拉抬项，与减压出口的压低效应反向，净效应以 100 局复跑为准（§17.5）。

### 17.3.5 参数落点

- 新表 `data/rules/leisure.csv`：`music_relief=2.0` / `snack_relief=1.5` / `book_relief=2.5` / `music_duration=30` / `snack_duration=15` / `book_duration=40` / 噪音列 / `snack_count_per_run=5`。
- 新表 `data/rules/player_absence.csv`：`max_per_break=1`（社交代价落在事件表）。
- `behavior_probs.csv` 新键：`music_p=0.02` / `snack_p=0.02` / `book_p=0.02`（NPC 触发概率，标定起点）。

## 17.5 实现顺序与验收

**实现顺序**：内核（grade 轴与累加器 → 老师实体与巡查 → 减压动作与出门状态）→ `data/` 表与 `check_config` 扩展 → HUD/菜单接线（表现层不碰矩阵，走内核 API）→ GUT + Python/GDScript 同种子对拍 → 六道门复跑。

**验收清单**：

1. **对拍**：同种子跑 7 天，`grade` 序列与 `study_acc` 逐位一致（Python ↔ GDScript 同种子逐位一致）；
2. **手算**：连续学习 100 tick（成绩 <300 档）→ grade +10；成绩 700 档 100 tick → +2（37 tick/分 → 2 分余 26 tick）；
3. **老师到场率**：批量统计 ≈43.75%/课间（±抽样噪声），且任意课间到场次数 ≤1；
4. **六道门复跑（100 局）**：
   - 爆发均值预期**下移**（减压出口 + 老师加压两者反向，净效应实测）——当前 28.1 贴 30 上限，下移安全，勿穿 15 下限；
   - 好感均值 32.4 ← 上课涓流为拉抬项，方向利好唯一未达标门；
   - 新减压项的失效方差检查进第五道门（机制上场率：音乐/零食/看书须有非零上场）；
5. **全学期形态**：初始 200–650 谱系保持到学末（低分段首档快速追赶、高分段逼近放缓），谱内再分化由行为分布产生（若过平/过陡调 §17.4 分段表）。
