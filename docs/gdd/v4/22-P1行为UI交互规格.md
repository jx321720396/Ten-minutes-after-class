# 第二十二章 P1 行为 UI 交互规格

> 状态：策划案 ｜ 实现状态：未开工 ｜ 制定：2026-10-09 ｜ 依据：第十八章《P1 功能细分规格》+ 第二十章《UI 交互总则与共享组件》
> 本章只写 **P1 批次**（学习打断+快速学习 / 提问讲题 / 换座位+皇帝位 / 信息反哺分享）的界面条目；共享组件定义见第二十章。
> 本批含**一个新增组件类型**：4×4 选座面板（§22.3）。

## 22.0 本批范围与本批不做

| 项 | 内容 |
|---|---|
| 覆盖 | 快速学习模式指示与打断文案、提问 / 讲题（开口说话组新增两项）、换座位面板、皇帝位标识与代价提示、信息反哺的共鸣 / 矛盾提示 |
| 依赖 | 第十八章全批 + P0 的自身状态条与成绩 HUD（第二十一章） |

**本批明确不做**：

| 不做 | 归属 |
|---|---|
| 推理板 / 矛盾高亮工作台 | M2（本批的矛盾提示只做一段文字） |
| NPC 自主提问 / 讲题的表现 | 第十八章 §18.2.1 已定：NPC 走既有共同学习，不新增表现 |
| 「谁在撒谎」的直接指认 | 永不做 —— 判断留给玩家（信息博弈的核心） |
| 换座的动画过渡（人物走去新座位） | 可用现有走动表现，不额外做动画 |

## 22.1 本批对共享组件的填充

| 组件 | 本批新增内容 | 章节 |
|---|---|---|
| 底部行为卡片 | 「开口说话」组新增 `提问` `讲题`；三项都带冷却文案（`这节课间问过了。` / `这节课间讲过了。`） | §22.2.2 |
| 自身状态条 | `专注学习中 · 时间过得更快` | §22.2.1 |

| 确认卡 | 选座面板的超时规则复用确认卡样式（§22.3） | §22.3 |
| 顶部 HUD | 加速标识的表述待 Q1 裁决（本批**不并列显示两个加速标识**） | §22.2.1 |

## 22.2 逐行为条目

### 22.2.1 学习打断 + 快速学习

| 项 | 内容 |
|---|---|
| 触发提示 | 进入快速模式时给**一次**短句：`你学进去了，时间过得更快。` 之后靠状态条常驻显示，不再重复弹 |
| 常驻显示 | 状态条 `专注学习中 · 时间过得更快`；徽标 `专注学习中` |
| 自愿切换 | 无额外提示（自己点走的，不需要解释） |
| 非自愿被打断 | 短句 `被叫住了，刚才学的东西有点断掉。`（对应内核里学习积累清空，§18.1.2） |
| 老师进教室 | **不打断**，不给任何提示（§18.1.2） |
| 上课铃响 | 短句 `上课了。`（与既有阶段切换提示合并，不重复弹两条） |
| HUD 加速标识 | **待裁决 Q1**：现有一套「玩家占用型行为期间世界加速」（默认 3 倍）的显示；快速学习改的是学习步长、那套改的是现实时间倍速。两者是否叠加、HUD 怎么写，**裁决前只显示其中较强的一条**，不并列两个加速标识（并列会让玩家以为同一个东西有两份） |

### 22.2.2 提问 / 讲题

| 项 | 内容 |
|---|---|
| 入口 | 他人卡片「开口说话」组，两项：`提问` `讲题` |
| 可用条件 | 双方离得近；对方不忙；**只看得到模糊比较**：玩家成绩明显高于对方 → 只有「讲题」可用；明显低于 → 只有「提问」可用；差距不大 → 两项都可用（避免暴露 NPC 具体成绩） |
| 前置文案 | 提问：`想问问他这道题怎么做。` / 讲题：`他好像不太明白，你可以说说。` |
| 冷却 | 同一对子同一方向每课间 1 次；用完按钮灰置 + `这节课间问过了。` / `这节课间讲过了。` |
| 结算（结果页，2 级） | 提问：`他把思路说了一遍，你听懂了。` / 讲题：`你讲了一遍，他点头了。`（另有信任变化，属隐藏值，不给数字） |
| 皇帝位联动 | 在讲桌旁那个位置进行时，结果页加一行 `坐在这儿，你听得更明白。`（**不写倍数**） |
| 降级 | 结果页来不及 → 降为 1 级短句 |

### 22.2.3 换座位

| 项 | 内容 |
|---|---|
| 触发 | 每天第一个课间开始时自动弹出选座面板（频率可由数据调成「每 N 天」） |
| 面板内容 | 见 §22.3 |
| 规则说明文案 | `挑一个位置坐下。本来坐在那儿的人，会去讲桌旁边。` |
| 落座反馈 | 点格子即落座 + 短句 `你换了座位。`；被挤走的是别人时不给提示（避免信息过载）；**玩家自己被挤到讲桌旁**时给短句 `你被安排到讲桌旁边了。` |
| 选座期间时钟 | **建议暂停课间计时（Q2）**：否则玩家读面板的时间在流逝，等于用真实时间扣玩家课间预算 |
| 降级 | 面板来不及做 → **文字列表选座**（一行一个位置 + 现坐者名），交互不变、表现变简 |

### 22.2.4 皇帝位

| 项 | 内容 |
|---|---|
| 视觉标识 | 讲桌旁那一格用特殊图标（讲桌 / 金色边）标识；玩家坐上后座位格给自己高亮 |
| 状态条 | 加一段 `讲桌旁 · 学得更专心的位置` |
| 代价提示 | **首次坐上**给一句：`这儿清静，就是旁边坐的人少。`（解释社交代价，不写数值） |
| 不做 | **不给加成数值、不做光环特效** —— 光环会把一个位置变成「奖励图标」，与「清静但没人陪你」的取舍意图相反 |
| 连续占据 | 超时或再次选中该格即继续占据，不给额外提示（§18.3.1） |

### 22.2.5 信息反哺分享

| 项 | 内容 |
|---|---|
| 触发 | 玩家与 NPC 闲聊成功后，在结果页（2 级）里**追加**两行之一 |
| 共鸣（信息一致） | `他也听说过这件事，你们聊得更投机了。` |
| 矛盾（信息对不上） | `他说的跟你听到的不一样 —— 有人记错了，或者有人在编。` |
| 落点 | 结果页 + 情报日志可回看；**不做推理板**（推理板属 M2，本期不做） |
| 纪律 | 只陈述「一致 / 对不上」，**不指出谁在撒谎** |

## 22.3 本批特有新组件：4×4 选座面板

```text
┌────────────────────────────────────────┐
│ 换个座位                                │
│  ┌────┐┌────┐┌────┐┌────┐              │
│  │头像││头像││ 空 ││头像│              │  ← 每格：现坐者头像（立绘缩略）/ 空
│  └────┘└────┘└────┘└────┘              │
│  ...（共 4×4 = 16 格）                   │
│  ┌────┐                                 │
│  │讲桌│  ← 讲桌旁那一格：特殊图标 + 金色边 │
│  └────┘                                 │
│ 挑一个位置坐下。本来坐在那儿的人，        │
│ 会去讲桌旁边。                           │
│ ████████████░░░░ 8 秒                    │  ← 超时倒计时条
└────────────────────────────────────────┘
```

| 项 | 规定 |
|---|---|
| 网格 | 4×4 座位 + 讲桌旁 1 格，与座位的空间关系一致（不做旋转 / 缩放） |
| 每格内容 | 现坐者头像（`appearance.csv` 的立绘缩略）；空格显示为空；讲桌格用讲桌图标 |
| 玩家自己 | 当前所在格加明显描边 |
| 点击 | 点任意格即落座并关面板（含空格）；点面板外不关（避免误触丢机会） |
| 超时 | 底部倒计时条；超时 = 留在原位（已在讲桌旁则继续占据） |
| 时钟 | 待 Q2 裁决：建议弹出期间暂停课间计时 |
| 触屏 | 每格热区不小于 44×44 px |
| 降级 | 文字列表选座（§22.2.3） |

## 22.4 降级与排期

| 优先 | 项 | 降级方案 |
|---|---|---|
| 1（必做） | 底部卡片分组改造 + 提问 / 讲题入口 | 不可降级 —— 没有它 P1 两项目标行为无处可点 |
| 2（必做） | 快速学习的常驻状态条（含打断文案） | 不可降级 —— 否则玩家不知道自己在加速、也不知道为什么被打断 |
| 3（必做） | 皇帝位视觉标识 + 代价提示 | 特效可砍，标识与提示不可砍 |
| 4（可降） | 选座面板 | → 文字列表选座（信息等价） |
| 5（可降） | 信息反哺结果页 | → 1 级短句 |
| 6（可降） | 行为的活动圈着色 | → 沿用现有两色（等 Q6） |

**排期提示**：选座面板是本批**唯一的新画面**，且每天第一个课间都触发（暴露频率最高），建议排在卡片改造之后、学期总结之前。

## 22.5 验收

1. 快速学习有常驻指示、被打断有解释；老师进教室**不**产生打断提示。
2. 提问 / 讲题只看得到模糊比较，界面上不出现任何 NPC 分数。
3. 同对子同方向冷却后按钮灰置且给原因。
4. 选座面板：16 格 + 讲桌格齐全、超时留在原位、玩家自己被挤走时有提示。
5. 皇帝位不给数值、不给光环；首次坐上看到代价提示。
6. 信息反哺只出现「一致 / 对不上」两种措辞，不指认撒谎者。
7. 按 §22.4 降级清单走一遍，信息完整可读。
