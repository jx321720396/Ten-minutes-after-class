# 第六章 情绪状态层

## 6.1 设计原则

情绪状态层只存压力值这一个累积变量。其他情绪（开心、焦虑、愤怒、低落）全部由压力值、近期事件效价、性格底色派生，不独立存储。

心理学依据：Russell情绪环形模型——所有情绪都可以落在唤醒度（高/低）x效价（正/负）两个维度上。压力值即唤醒度，近期事件的好坏决定效价，两者交叉定位出具体情绪。

## 6.2 压力值

| 属性 | 说明 |
| --- | --- |
| 数据结构 | Stress[i]，个体单值，0-100，快变量 |
| 定义 | 社交焦虑、窘迫、紧张的累积程度 |
| 特点 | 事件驱动不自然涨，达到阈值触发情绪事件 |

## 6.3 情绪标签派生表

| **压力** | **近期效价** | **外向/随和** | **敏感/内向** | **好斗** |
| --- | --- | --- | --- | --- |
| 低 | 正 | 放松、满足 | 安心、自在 | 得意 |
| 低 | 负 | 无聊、无所谓 | 低落、落寞 | 不耐烦 |
| 中 | 正 | 兴奋、活跃 | 羞涩但开心 | 亢奋 |
| 中 | 负 | 有点烦 | 焦虑、不安 | 愠怒 |
| 高 | 正 | 激动、热闹 | 紧张但强撑 | 亢奋到失控 |
| 高 | 负 | 烦躁 | 窘迫、快哭了 | 愤怒、要爆发 |

## 6.4 压力来源与消解

| **事件** | **压力变化** | **结算类型** | **性格修正** |
| --- | --- | --- | --- |
| 被当众拒绝/被打断聊天 | +3 | 事件 | 敏感 ×1.5，外向 ×0.7 |
| 被八卦谣言指向 | +3 | 事件 | 敏感 ×1.5 |
| 被小团体明确排斥（重大） | +5 | 事件 | 随和 ×1.3（更受伤） |
| 被多人同时搭话 | +2 | 事件 | 内向 ×2，外向 −1（人来疯） |
| 信任的人背叛/传秘密 | +5 | 事件 + 状态 | 全性格大幅上涨；附加「心结」3 天，每天 +5 |
| 和高好感+高信任的人聊天（话题共鸣） | −2 | **事件**（每次闲聊结算一次） | — |
| 默认学习（未参与任何互动） | **+1** | 涓流（**每天 2 次**，`behavior_probs.csv` 的 `study_stress`） | — |
| 独处（不在任何对话中） | **−2** | 涓流（**每天 2 次**，`alone_stress`） | 内向额外 −1（独处回血快） |
| 离开人群聚集区 | −3 | 事件 | — |
| **行为被相位切换打断** | **+0.5** | 事件（相位切换时判定一次） | — |
> **性格系数区间 = 0.1 ~ 1.2**：性格对效果的影响**温和**——最敏感者最多放大到 1.2 倍（+20%），最迟钝者降到 0.1 倍。因此文档中「敏感 ×1.5」「内向 ×2」之类的表述，一律理解为**通过该事件的 `w` 系数实现，且最终倍率落在 0.1~1.2 之间**（敏感者接近 1.2、普通人接近 0.6、迟钝者接近 0.15）。
> 例外：**概率类修正**（成功率 +25%、守密概率 −30%）与 **`M_state`**（压力区间系数）不是这个倍率，不受此限。


## 6.5 概率爆发（不是「到点必爆」）

压力跨过**入口阈值 70**（= §6.3 高压区的入口）后，**每天判定一次**：

```
severity = (stress − 70) / (100 − 70)            // 0 = 刚过阈；1 = 满压
p_burst  = burst_p_max × severity                // burst_p_max 初值 0.5
爆发成功 → stress −= 40
         本人获「心结」，天数 × (1 + severity)
         传染范围 spread_max × (1 + severity)，被波及者心结天数亦 × (1 + severity)
```

**三条设计意图**：

1. **概率化（而非阈值相变）**：高压区是一个**危险斜区**，而不是一堵墙。若做成"到 90 必爆"，行为会在阈值附近疯狂跳变（UIF §1.6 边界③）；
2. **越晚越猛**：`severity` 同时放大**波及范围**与**心结时长**——拖得越久，爆得越大。这制造了「他快撑不住了…」的张力；
3. **大爆放大传染**：而传染又推进下一轮爆发 → 这就是**连环爆发**的结构来源（§2.5 心结可传染）。

> 参数：`burst`（阈值 70）在 `behavior_thresholds.csv`；`burst_p_max`（0.5）在 `behavior_probs.csv`；
> `spread_ratio` / `spread_max` 在 `status_tags.csv`。三者皆可标定，设 `burst_p_max = 0` 即关闭概率爆发。
> **实测（30 天，seed=12345）**：爆发 **16 次** ✓（目标 15–30）、饱和率 0.0% ✓、压力峰值 53.6
> （爆发成为主要泄压出口，故峰值低于入口阈值）。
