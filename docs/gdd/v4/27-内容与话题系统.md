# 第二十七章 内容与话题系统

> 状态：策划案（形态与口径）｜ 实现状态：未开工（**本章只定规格**，代码留待后续批次）｜ 制定：2026-10-12
> 依据：用户 2026-10-12 裁示「先把方案落成文档、**不改代码**」；本章承接全仓多处挂账的 **「待聊天内容系统重建」**（§8.1 第 3 段、§5.2 事实通道、§13 涌现对照第 2 / 4 条、[`../../design/信念矩阵.md`](../../design/信念矩阵.md)、§14 观测三源之「二手转述」）。
> 本章只回答「教室里到底发生了什么、谁把它说出来、玩家听到什么、玩家能说什么」——**不含数值取值**（数值一律进 `data/`，表清单见 §27.12）；呈现层级与可见性口径沿用 §20.0.1 与 §20.1.7，本章不另立一套。

## 27.1 为什么要这一章

三条现状事实（均可复现）：

| 现状 | 出处 | 结果 |
|---|---|---|
| 闲聊**没有内容**，只有符号 | `scripts/ui/chat_activity_bubble.gd` 只发射符号粒子；`CHANGELOG.md` 2026-10-12 条明写「颜色和符号仅标识行为，**不表示好感、压力、聊天内容或结果**」 | 玩家看见自己与同学在「聊天」，却不知道聊了什么 |
| 「**不预设虚构对白**」是**当前硬约束** | `scripts/core/player_chat_intel.gd` 类注释第 ③ 条 | 玩家闲聊的产出只有一条关系数值线索 |
| 系统里**没有「发生过什么」的记录** | `scripts/core/term_record.gd` 的 `_frames` 记的是矩阵变化（轴 / 索引 / 变化前后 / 起因），不是事件叙述 | 即便现在想显示「他们聊了什么」，**也没有可读的事实可读** |

由此提出本章的**问题定义**：本作不缺玩法，缺的是**内容载体**——玩家的操作与反馈都停在抽象量上（时间、数字、符号），中间那层「具体到可以复述的事」从未被建模。学习只有成绩累加器（`data/rules/behaviors.csv` 的 `study` 为持续态、唯一产出是成绩），上课段只有快进与一行「正在上课」（§2.3），闲聊只有符号与数值线索——三处症状同源。

同批确定一条**取舍尺子**（用于回答「要不要做小游戏 / 下棋」）：

> 一个课外活动值不值得做，只看两条：① 它是否改变教室里人与人的关系（回写 A / H / T / 压力）；② 这件事能不能被别人**说起**（进入 §27.3 的事件记忆）。
> 只有 ① 没有 ② → 玩家自己爽、班级不变（棋类）；两者都有 → 它是班级政治的燃料。

## 27.2 与既有系统的边界（不许出现第二套公式）

本章是**纯内容层**，一切数值仍走既有通道：

| 本章产出 | 走的既有通道 | 依据 |
|---|---|---|
| 话题共鸣 / 冷场 | `data/balance/w_events.csv` 的 `topic_resonance`（信任 +3 / 好感 +3 / 压力 −2） | §4.3、第十五章 |
| 话题踩雷（说错话） | 纸条的「坏话 / 好话」分档结算口径 | §8.6 第 4 条 |
| 玩家选话题的成败 | 两段式统一判定（决策读信念、判定读真值） | §4.4 |
| 信息的真伪 | 信念矩阵与真值的差异 | §7.4 |
| 全部呈现 | 1 级短句 / 2 级结果页 / 3 级日终 | §20.1.7 |

硬约束逐条声明（违反即为缺陷）：

1. 内容层只做「事实 → 文案」的映射，**不新增第三套数值公式**（§8.16 的三条边界）；
2. 内容生成一律是 `f(性格四维, 透明度, 当前状态, 事件记忆)` 的纯函数，**不得出现角色名 / 角色 ID 判断**（§9.11）；
3. 内容的阈值、上限、权重全部落 `data/`，脚本零魔法数字；
4. **观察层只读**：内容生成不得回写任何矩阵，也不得把真值白送成玩家信息（§7、§20.0.1 第 2 条）；
5. **不引入脚本化剧情**：不得出现「第 N 天必然有人聊起 X」这类写法（§8 行为触发总则）。

## 27.3 事件记忆层（话题的燃料，本章的地基）

**定义**：一条事件记忆 = 一次**已被内核判定并结算过**的事实；它不改数值，只让「发生过什么」可被引用。

| 字段 | 含义 | 备注 |
|---|---|---|
| `kind` | 事件种类（闲聊 / 调侃 / 安慰 / 打闹 / 排挤 / 举报 / 纸条 / 成绩 / 老师巡查 / 考试…） | 与既有行为标识同名 |
| `actor` / `target` | 施者 / 受者 | `target` 可为空（如「全班被训话」） |
| `day` / `phase_id` / `tick` | 发生时间 | 用于「今天 / 昨天 / 上周」这类时间词换算 |
| `witnesses` | 目击者集合 | 由既有空间口径给出（同圈 / 邻近） |
| `delta` | 该事件真正写进矩阵的量 | **只用于内部强度分档，不进玩家可见文案** |

纪律：

1. **只增不改、只读**——事件记忆是观察层的上游，任何模块不得因它回写矩阵；
2. **只记结算过的事**，且判定失败 / 被拒绝 / 被打断**也要各记一条**（「他被拒绝了」本身就是话题）；
3. **容量有界**：保留窗口与单日条数上限进 `data/`，超限时按「与当前关系最鲜明」优先保留（容量参数与 §20.1.7 的呈现上限分列，不要混用）；
4. **不进决策的数值路径**：事件记忆只影响**说什么**，不影响**做什么**与**效果多大**（与 §8.16 边界第 1 条同源）。

## 27.4 话题生成（他们说什么）

**话题** = { 说话者, 被说的人, 说什么（谓词）, 真伪, 来源事件 }。

三个来源，按优先级：

1. **事实**（来自 §27.3）：「他昨天被举报过」「他俩上周打闹过」「他这次考进前三」「课上有纸条被老师收走」；
2. **关系切片**（说话者对被说者的 A / H / T 分档）：好感高 → 好话；敌对高 → 坏话；信任高 → 私事；
3. **状态**（说话者自己）：压力 / 标签 / 透明度——高压力者更倾向抱怨，八卦型更倾向说别人。

**说什么由谁定**（纯函数，权重全部在 `data/`）：

- **谁开口**：性格四维（外向 / 爱脑补）+ 标签 + 压力；
- **说谁**：`w ∝ 1 + |A − H| / 50`（态度越极端越容易被说起，与 §8.6 纸条选被说者同口径）；
- **好话还是坏话**：按 `A` 与 `H` 的**绝对阈值**分档（**不得用净态度的符号**判方向，理由见 §8.16 的反例）。

**呈现**（沿用 §20.1.7 的三级层级，不新增组件类型）：

| 级别 | 形式 | 用在哪 |
|---|---|---|
| 1 即时短句 | 头顶**文字气泡**（`scenes/components/speech_bubble.tscn` + `scripts/ui/speech_bubble.gd` 由「无字」扩为「有字」）+ 底部一行 | 玩家参与的闲聊、路过的对话 |
| 2 结果页 | 本次闲聊的「听到的话」清单 | 玩家主动发起的闲聊结束时 |
| 3 日终 | 《每日简报》的「今天班里在传什么」一段 | 既有简报扩行（§12） |

**容量纪律**：单屏气泡数与单次闲聊的话题条数都要有上限（参数在 `data/`），并且**只呈现真实发生过的判定**——不得为画面好看而补台词（与行为符号气泡「仅标识行为」的既有纪律一致）。

## 27.5 真假与信息博弈（本章的乐趣来源）

1. NPC 说的话**允许是错的**：来源可以是信念矩阵的误判（§7.4），也可以是二手转述的失真（转手一次的保真度口径见 [`../../design/信念矩阵.md`](../../design/信念矩阵.md)）；
2. 每条话题都带真伪与来源事件，**但玩家看不到这两个字段**——只看到话本身；
3. 玩家验证路径**全部是既有能力**，本章不新增：
   - **观察**（§10.3.1，单人版已实装）：读真值与对方的误判；
   - **纸条链**（§8.6）：把话传出去，看它怎么变形、谁截下来举报；
   - **交叉比对**：同一件事在不同人口中说法不一致 → 结论由玩家自己得出；
4. **不做「谁在撒谎」的直接指认**（与 P0–P2 UI 未完成清单的信息反哺项同一纪律）：判断留给玩家；
5. 情报日志（`ChatFeedbackHUD` 的 `Tab` 历史）可把同一来源事件的多个版本**并列**显示，只并列、不评判。

## 27.6 玩家表达（玩家能说什么）

**这是把玩家从观众变成参与者的关键一步**：现状玩家只能拨数值，无法「说一句自己的话」。

1. **闲聊选项**：玩家发起 / 参与闲聊时给出 2–3 个可选项，来源是**玩家自己已知的东西**（情报日志线索 + 对目标的态度 + 手头的纸条）；选项由系统按来源生成，**玩家选方向、不写文案**；结果走判定侧公式（§4.4）分成共鸣 / 冷场 / 踩雷，效果仍由统一影响公式调制；
2. **纸条话术**：§8.6 现有的几个硬编码模板改为从话题池取——**不改变纸条的判定、时长与结算分档**；
3. 纪律：
   - 选项**不显示成功率**（与 §8.5「不显示虚假成功率」、转笔判定的纪律一致）；
   - 玩家说的内容**不写回信念矩阵**（当前信念结构存不了第三人关系，沿 `player_chat_intel.gd` 约束③的口径）；
   - 玩家的文案选择**不产生额外数值收益**——避免把「会说话」变成刷分手段（与 §24.2.3 对猜拳连胜记录同一纪律）。

## 27.7 上课段内容化（承接 §2.3，**不改变「上课不可操作」**）

上课段保持「玩家不可操作」的既有设计（§2.3、§10.4），本章只给它**填只读内容**：

| 内容 | 来源 | 备注 |
|---|---|---|
| 老师讲的一句话 | 课程表 + 当天班级状态（班上吵 → 训话；有人崩溃过 → 多看一眼） | 老师是非节点实体（P0–P2 玩法未完成清单的老师巡查项），不产生判定 |

| 传到你手里的纸条 | §8.6 纸条链 | **上课唯一允许的主动行为**（§2.3） |
| 一句内心活动 | 你自己的压力 / 成绩 / 对某人的态度 | 只读、无判定 |

**硬约束**：本节的全部内容都是**只读**——不新增判定、不新增数值、不改变上课段的规则子集；玩家在上课段的可操作面仍只有纸条与查看类界面（§10.4）。

## 27.8 课外活动与「教室之外」（对「世界外因素」的口径）

本章**不新增玩法系统**，只给 §24.2.2 / §24.3 的棋类与猜拳**换一种实现口径**（形态改写建议，是否采纳见 §27.14）：

| 项 | 现规格 | 本章建议口径 |
|---|---|---|
| 五子棋（§24.2.2 / §24.3） | 棋盘弹层、落子、被铃声中断 | **不做棋盘**：3 步内结束的互动，产出 = 关系涓流 + 一条可传播的事实（「他连输三把」）+ 可能的情绪（输了 → 压力 ↑ → 可被安慰） |
| 猜拳 | 三选一 + 连胜记录 | **保留**（本已是 3 步），产出同上；连胜仍**不产生数值收益** |
| 小物件 | 无 | 新增**可传递的小物件**（卡片 / 漫画 / 玩具）：可传、可送、可被没收——物件是天然的冲突源，也是「教室外的东西」进入班级政治的通道 |

**「教室之外」作为话题源**：走廊、办公室、别的班、家里、考试——目前只有老师是实体（P0–P2 玩法未完成清单的老师巡查项）。本章允许把这类**外部传闻**作为 §27.3 的事件来源之一，且**只进话题池、不进任何数值判定**。

## 27.9 玩家自身状态的可见化（承接 §20.4 的 Q3）

该开放问题自陈的风险是：*「玩家自己的压力目前完全不可视……若玩家无感，这些行为会形同虚设」*。本章的建议口径（**不给数字**，与 §20.0.1 第 2 条一致）：

- **心绪文字**：状态条在既有文案后追加一句随压力档位变化的短句（「心里有点堵」「松快了些」）；
- **画面微变**：教室色调、呼吸节奏、脚步——表现层只读压力，不改判定。

目标只有一个：让「听音乐 / 吃零食 / 看课外书 / 出门」四条减压行为**在玩家心里真实存在**。

## 27.10 给「空闲」一个定义（承接 §10.2.3 的待定项）

§10.2.3 自陈：*「不选任何行为＝什么都没做（空闲），空闲状态本身是否要有代价（无聊 / 独处压力）尚未定义」*。本章给出**三个候选**（互不冲突，但**只选一条先落地**，否则「什么都不做」会变成比做事更划算的选项）：

1. **无聊**：连续空闲超过窗口即记一次无聊事件 → 压力涓流；
2. **独处**：空闲时他人的互动**会绕开你**（即既有文档里那条「独处恢复」的纸面条款，当前未生效，见第十四章的已知缺口表）；
3. **观察者**：把「空闲」变成玩家的**唯一特权**——只有你能什么都不做地看，因此获得额外的观测机会。

## 27.11 与「涌现」的接口（检验二）

单条话题是琐碎的，但**话题池 + 记忆窗口 + 真伪差异**叠加后，应能自然长出 §13 里两条目前挂着账的现象：

- 「同一条八卦不同人传出不同版本」（§13 第 2 条）；
- 「玩家被八卦误伤导致被孤立」（§13 第 4 条）。

**验收方式**：不脚本化、不预设剧本——跑多种子批量局，检查这两条现象在**存在性口径**（机制上场率）上有非零表现，与第五道门 `tools/diversity_report.py` 同一口径。
