# 第二十章 UI 交互总则与共享组件

> 状态：策划案 ｜ 实现状态：未开工 ｜ 制定：2026-10-09 ｜ 依据：第十三章 §13.1、第十七–十九章
> 本章是 P0–P3 新增行为的 **UI 总则与共享组件底座**；各等级的界面条目**按等级分册**：第二十一章 P0、第二十二章 P1、第二十三章 P2、第二十四章 P3（对应第十七–十九章四份功能细分规格）。
> 本章只回答「玩家**看到什么、点什么、读到什么话**」——**不含代码触点与参数表**（数值与落点见第十七–十九章）。

## 20.0 总则

### 20.0.1 三条不可越的线

1. **只读表现**：UI 只读内核、只显示，不写任何矩阵、不改任何数值（§3 观察层只读、§12.1）。
2. **不暴露 NPC 数值**：NPC 的好感 / 敌对 / 信任 / 压力 / 成绩一律不出数字，只给表情、公开行为与文字描述（§7 信息可见性）。
3. **数值与文案分离**：文案里出现的任何数量与时长都以 `data/` 为准，改表不改文案模板。

### 20.0.2 可见性口径表（一次定清，各级分册不再逐条重议）

| 信息 | 玩家可见形式 | 不可见 |
|---|---|---|
| 玩家自己成绩 | **具体数字**（顶部 HUD，§17.1.3） | — |
| NPC 成绩 | 只给模糊描述（「看起来学得不错」「好像不太跟得上」） | 数字 |
| 玩家自己压力 | 文字状态（「有点烦躁」「心里松快了些」） | 数字 |
| NPC 压力 | 头顶情绪图标（§12.1） | 数字 |
| 好感 / 敌对 / 信任 | 关系氛围线（质变瞬间）+ 文字描述 | 数字 |
| 行为收益（如减压、信任增益） | 只有文字（「放松了一点」） | 数字 |
| 玩家持有资源：零食份数 / 课外书本数 / 免罚卷张数 | **数字**（自己的东西，可数） | — |
| 老师位置 | 场景可见 + 状态提示 | — |

> **唯一的数字例外**：玩家自己的成绩与持有物。理由——成绩是玩家 30 天的主要目标轴（§17.1.3），持有物是玩家自己的库存；两者都不是「他人的隐藏状态」。

### 20.0.3 视觉与文案基线（沿用现有 UI，不另起一套）

- **外观**：纸感面板（米白纸色）+ 墨色正文 + 墨绿强调；不可用项用橙色文字说明原因 —— 与现有时间 HUD、底部卡片、结果页同一套风格。
- **字体**：微软雅黑系（与现有 UI 一致）。
- **语气**：同学之间的**口语**，不用系统词。不写「状态」「数值」「加成」「倍率」「触发」，改写「心情」「劲儿」「更专心」。
- **人称**：一律用「你」称呼玩家，NPC 用名字或「他 / 她」，不出现节点编号。

### 20.0.4 双端与操作

- 键鼠：左键点选，右键 / `ESC` 取消；触屏：点选，点空白取消。
- 所有新增入口热区不小于 44×44 px（D16 Android 真机验证用）。
- 上课段只允许查看类界面（§10.4）；新增**操作类**行为一律只在课间可用，上课段的按钮显示为不可用并给出「上课呢，下课再说」。

### 20.1.2 右侧行为栏（2026-10-10 定稿，取代「底部行为卡片」）

**形态**：屏幕**右侧**常驻竖排按钮栏（纸感面板，沿用现有配色），按 §10.2 的三组分组。

**交互是两步**（2026-10-10 用户裁决）：

```text
① 点行为按钮  →  按钮选中（高亮），行为栏底部提示「现在点一个人」
② 点一个人物  →  选对象 → 触发；需要接近的行为**先走过去**，到位后自动结算
```

- **点人物不再弹卡片**（2026-10-10 裁决）：点人只表示「选对象」，目标的名字与公开活动显示在**行为栏底部**；不再有独立的底部卡片。
- **对自己做的事**（第三组）**点按钮直接执行**，不需要选对象。
- **取消**：Esc、再点一次同一个按钮、或点教室空白处，都会取消「已选中但还没点对象」的状态。
- **按钮三态都不隐藏**：可用（正常）｜暂时不可用（橙色 + 原因，如「对方睡着了」）｜本课间已用完（灰色 + 「这节课间问过了」）。隐藏会让玩家以为功能不存在。
- **未实装的行为先按灰置占位放出来**：本批真正可用的是 6 项（闲聊含加入 / 递纸条 / 当众调侃 / 追逐打闹 / 排挤 / 举报）；**观察**与自指行为（学习 / 睡觉 / 听音乐 / 吃零食 / 看课外书 / 出门）**灰置 + 原因「还没做」** —— 与 §21.2.4「看课外书恒灰置但不隐藏」同一原则：让玩家知道有这条路。
- **分组归属**（§10.2 既有口径，不新增组）：
  - 开口说话：闲聊（含加入）；后续批次加 安慰、道歉和解（P1）、提问 / 讲题（P1）
  - 动手做事：递纸条、举报、追逐打闹、排挤；后续批次加 秘密交换、猜拳（P2 降级版）
  - 对自己做的事：学习、睡觉、走动、观察、听音乐（P0）、吃零食（P0）、看书（P0）、出门（P0）
- **冲突处理**：行为栏**不暂停全班**（沿用现有约定），世界继续走；每次刷新重取预览。选中后目标走开 → 就地显示「他们不在一块儿了」并置灰。
- **Q5 已裁决（2026-10-10）**：原「对自己做的事」入口二选一（① 点空白处弹自己的卡片｜② 常驻按钮）→ **选常驻按钮**，并统一为**右侧行为栏**（所有行为都在这里，不再分「他人卡片 / 自己卡片」两套入口）。

### 20.1.3 自身状态条

位置：屏幕底部左侧，避开教室主视野。内容一行，超长截断加省略号。

| 玩家当前 | 状态条文案 |
|---|---|
| 空闲（默认） | `在学习` |
| 学习且进入快速模式（P1） | `专注学习中 · 时间过得更快` |
| 听音乐（P0） | `在听音乐 · 还剩 18 秒` |
| 吃零食（P0） | `在吃零食（还剩 4 份）` |
| 看课外书（P0） | `在看课外书` |
| 出门（P0） | `你出去了` |
| 走动 | `在走动` |
| 被老师逮到（P0 仅提示） | `老师看了你一眼` |

**「默认 = 学习」必须被看见**——这是 P0 学业系统成立的前提（§17.1.2：不忙就是在学习）。现状玩家「什么都不做」时界面无任何反馈，会让玩家以为在浪费时间。

### 20.1.4 头顶行为徽标

- **情绪图标保持原样**：仍是唯一的情绪出口，6 种表情不变，不显示数值（§12.1）。
- **新增行为徽标**（小尺寸，挂在人物脚边 / 椅子旁，不与头顶情绪图标抢位）：`听音乐`、`吃零食`、`看课外书`、`睡着了`、`专注学习中`（仅玩家）。
- 徽标只反映**看得见的公开状态**；不做动画、不参与着色逻辑，避免与活动圈抢视觉。
- **反例（明确不做）**：不给「压力高」「好感高」「正在被排挤」这类隐藏状态做徽标 —— 那是把隐藏状态搬到脸上，直接违反 §20.0.1 第 2 条。
- **实装状态（2026-10-10）**：组件已落地 —— `scripts/game/behavior_badge_presenter.gd`（+ `scenes/game/behavior_badge_presenter.tscn`，挂在教室场景）。**当前只接「手里拿着纸条」**（§21.2.9）；纸条这条有专属规定，徽标挂**人物头侧**而不是脚边（见 §21.2.9「持有者表现」），其余五种仍按本节「脚边 / 椅子旁」的通用规矩。徽标集合完全由内核的公开状态给出（`note_holders()`），组件不自己推断、也不缓存判定结果 —— 新增徽标时接同一个组件即可。

### 20.1.5 活动圈配色扩展

沿用「暖色 = 热闹类、冷色 = 安静类」（§12.1 既有建议）。现只有「个人圈 / 进行中圈」两色，扩为行为族配色（**建议色，最终由美术定，见 Q6**）：

| 行为族 | 行为 | 建议色向 |
|---|---|---|
| 说话类 | 闲聊 / 加入、提问、讲题、安慰 | 暖橙 |
| 热闹类 | 追逐打闹、当众调侃、猜拳 | 亮橙 |
| 冲突类 | 排挤、举报 | 深红 |
| 安静类 | 学习、看课外书 | 冷蓝 |
| 独处类 | 听音乐、吃零食、睡觉 | 浅青 |
| 移动类 | 走动、出门 | 灰蓝 |

同一个人同时只能有一个主行为，**不叠加、不混色**；课间结束时圈随行为结束一起消失。

### 20.1.6 持有区（小）

位置：顶部 HUD 右侧一行小图标 + 数字，或底部状态条右侧。只显示**玩家自己的**持有物：

- 零食（P0）：图标 + 剩余份数，为 0 时图标变暗 + 文案「零食吃完了」
- 课外书（P0 起）：图标 + 本数（P0–P2 恒为 0，图标暗置 + 「你还没有课外书」）
- 免罚卷（P2）：图标 + 张数，hover / 长按说明「下周一次处罚可以免掉」；P3 接通消费点前的口径见 Q4

### 20.1.7 提示与结算反馈的三级层级

| 级别 | 形式 | 用时 | 用在 |
|---|---|---|---|
| 1 即时短句 | 顶部短句（沿用现有提示条），1.5–2.5 秒 | 不打断 | 老师进来了 / 被铃声打断 / 已用完 |
| 2 结果页 | 现有结果页样式（纸感卡片，可跳过） | 玩家手动关闭 | 提问、讲题、信息反哺、猜拳 |
| 3 日终 / 学期 | 每日简报、学期总结画面 | 段落 | 成绩变化、周考、奖项、统计 |

**纪律**：能给短句的不开弹窗；除学期总结外，**同一天不出现第二个全屏弹层**。任何弹层都必须可跳过、不阻塞时钟（选座面板例外，见第二十二章）。

## 20.2 跨批排期纪律（与 10/14 冻结的关系）

当前倒排日历（`docs/production/聚光灯21天冲刺计划.md`）的可视化窗口是 D11–D13，**并未列入本次任何新增 UI**，而 10/14 起冻结。因此所有新增 UI 分三档：

| 档 | 内容 | 理由 |
|---|---|---|
| **必做（进冻结前）** | ① 右侧行为栏（分组 + 两步交互，否则 P1 的提问 / 讲题无处安放）② 自身状态条 + 学习可见化（否则 P0 学业系统玩家无感）③ 成绩 HUD ④ 全部灰置原因文案（无书 / 已用完 / 上课）⑤ 老师到场短句 ⑥ 被逮风险提示 | 不做就等于「功能存在但玩家看不见 / 玩不明白」 |
| **可降级为纯文字** | 出门快进表现 → 只要状态条 + 时间跳跃；选座面板 → 文字列表选座；周考横幅 → 简报段落；猜拳 → 纯文字结果页；老师实体 → 讲台占位 + 位置提示 | 表现可简，信息不能丢 |
| **赛后（P3）** | 五子棋棋盘、石头剪刀布完整版、课外书经济全套、学期总结的「上局回顾」入口 | 与第二十四章一致 |

**建议实施顺序**（时间不足时依次砍尾）：卡片改造 → 状态条 → 成绩 HUD → 老师提示 → 周考与奖项（纯简报行）→ 选座（文字版）→ 学期总结。各批次的细节取舍见第二十一–二十四章「降级与排期」小节。

## 20.3 跨批验收清单

1. **信息纪律**：全流程截屏检查，任何界面都不得出现 NPC 的好感 / 敌对 / 信任 / 压力 / 成绩数字。
2. **默认态可见**：玩家什么都不点的时候，屏幕上有「在学习」的明确反馈。
3. **不可用必给原因**：每一个灰置按钮都能读到「为什么不行」（按钮数 = 有原因文案的按钮数）。
4. **文案无系统词**：新增文案里不出现「数值 / 状态 / 加成 / 倍率 / 触发」等词。
5. **双端可达**：键鼠与触屏都能完成全部新增操作；热区不小于 44×44 px。
6. **弹层纪律**：除学期总结外，同一天不出现第二个全屏弹层；所有弹层可跳过。
7. **降级路径可跑**：按 §20.2「可降级」列表逐项走一遍，确认砍掉表现后信息仍完整可读。
8. **简报覆盖**：成绩变化、周考结果、奖项、出门代价在简报里都有对应行。
