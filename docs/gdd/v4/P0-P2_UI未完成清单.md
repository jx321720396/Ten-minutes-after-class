## P0

### 书包实物入口（2026-10-12）

右下角新增独立「书包」按钮，排在「百科全书／推理板」左侧；三个入口统一纸纹底、青绿描边与线条图标，悬停以金色下缘强调。行动栏移除顶部「打开书包」；原「听音乐／吃零食／看课外书」快捷按钮打开书包并选中对应物品，拿取后才提交动作。面板从右下展开，暂时隐藏行为栏，保留教室、时间卡和底部导航；世界继续运行，门禁与库存持续刷新。点击实物或纸签选择，右侧纸卡显示说明、数量、不可用原因与「拿出来」。关闭按钮、再次点击书包入口或 Esc 收起；点击百科／推理板时也收起书包；Esc 不同时打开暂停菜单。玩家无书时书袋为空、零食耗尽时零食口袋为空，但纸签与原因保留。老师保管数量在书卡提示，免罚卷仍在行为栏持有区。拿取仅发既有自指行为意图，库存由内核开始动作时扣减，表现层不改数值。

素材：透明空包与透明物品层；配置为 `data/ui/backpack.json`，组件为 `scenes/ui/backpack_panel.tscn`。场景已有各座位桌侧书包模型，当前使用独立 UI 按键打开，不新增模型或改变相机。
