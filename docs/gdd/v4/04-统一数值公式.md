# 第四章 统一数值计算公式

## 4.1 好感/敌对/信任的统一公式

所有事件对好感、敌对、信任的影响，全部使用同一个公式：

**Δvalue = base × clamp(1 + Σ(wᵢ × dᵢ), 0.1, 1.2)**

| **符号** | **含义** | **范围** |
| --- | --- | --- |
| base | 事件对该数值的基础变化量（正=增，负=减），策划填表 | 任意整数 |
| dᵢ | MBTI第i维偏差值 = (维度值−50)/50 | [−1, +1]，50为中性 |
| wᵢ | 该事件类型对第i维的敏感度权重，策划填表 | 通常[−1, +1] |
| clamp | 倍率区间 **0.1 ~ 1.2**（性格影响温和：最多放大 20%） | [0.1, 1.2] |

四个维度固定顺序：d₁=E/I, d₂=S/N, d₃=T/F, d₄=J/P。

## 4.2 透明度：种子为准 + 压力系数

透明度不是事件直接加减：

**当前透明度 = 基础透明度 × 压力系数**

- **基础透明度 = 角色种子值（opacity_init）**，由性格派生（§9.14）：
  `opacity_init = clamp(50 + 1.2·(E−50) + 0.3·(F−50), 15, 85)` —— **内向 / 低 F 更不透明**，外向 / 高 F 更通透；角色差异只来自开局种子。
  `data/characters/seeds.csv` 已按该公式填好（如苏晴 15、何川 23、陈阳 82）；新增角色时用同一公式生成。

压力系数（`M_state`）：**以实现为准** —— **v4.0 核对（2026-10-09）：`data/rules/axis_coef.csv` 未落盘**，当前硬编码于 `tools/core_sim.py` 的 `m_state()` 与 `scripts/core/sim_core.gd` 的 `_m_state()`（两处取值一致），落点见 §15.17：

| 压力区间 | 系数 | 含义 |
| --- | --- | --- |
| 0–40（常规区） | ×1.0 | 心态平稳，事件按原幅度结算 |
| 40–70（中度区） | **负面 ×1.5 ／ 正面 ×0.75** | 越慌越敏感（负面被放大）；同时**听不进去劝**（正面被压缩） |
| 70–90（高压区） | ×1.5 | 临界区，事件一律放大 |
| ≥90 | ×1.0 | **阈值相变交给 §6.5 的每日概率爆发**，事件系数不再放大 |

- 「≥90 按性格分化」**不再挂在压力系数上**，改由 §6.5 的**爆发形态**表达（好斗 → 当众指责 / 封闭；敏感 → 崩溃 / 透明度归零；随和 → 退缩）——一处口径，不再两处。
- 中度区「负面放大 + 正面压缩」是同一条耦合的另一面：压力高 → 关系被压低（§2.4.1 的 mean 与爆发放反）。

## 4.4 统一判定公式（决策 / 判定）

所有行为判定统一为**两段式概率判定**，只有一套公式，不因行为而异：

### 决策侧（做不做）——读信念，概率化

```
触发强度 s ∈ (0,1)，没有 0/1 硬门槛
  环境类  s = p_base × Π 修正系数                     // 本来就概率化
  阈值类  s = σ((x − θ) / scale)                      // 越过多少决定概率，低概率也可能发生
  意向类  s = softmax(U_b / τ_i)                      // U_b 含软门槛项（见下）
软门槛项 = w_gate × [σ((A[i][j] − θ_A)/scale_A) + σ((θ_S − Stress[i])/scale_S) − 1]
```

**决策侧只能读两样东西**：我自己的立场（真值 `A[i][*] / H[i][*] / T[i][*]`）与
我眼中别人的态度（信念 `B_A / B_H / B_T`）。**不得出现 `A[j][i]` 这类"别人对我的真值"**（§14.7 不变式 3）。

**玩家跳过决策侧**：玩家是否发起由人自己决定，不再掷"想不想"的骰——这是玩家相对 NPC 的优势（§10.1）。

### 判定侧（成不成）——读真值，sigmoid + 掷骰

```
score = f(参与者 A/H/T + 性格四维 + 当前状态)
p     = σ((score − θ) / scale) = 1 / (1 + exp(−(score − θ)/scale))
结果  = Bernoulli(p)
```

- `p ∈ (0,1)`：**概率再低也可能成功，再高也可能失败**，没有固定门槛。
- `θ` 是 `p = 0.5` 的拐点（不是闸门），`scale` 控制坡度，均落在 `data/rules/behavior_thresholds.csv`。
- **判定侧读真值**：谁接纳谁由参与者的真实 `A/H/T` 决定。
- **唯一例外是展示层**：给玩家的成功率用信念 `B` 重算（§8.22.3）——同一公式两种输入：内部结算用真值、UI 展示用信念。

### 两段式与效果层

```
决策侧（想不想，读 B，玩家跳过）→ 判定侧（成不成，读真值，sigmoid 掷骰）→ 效果层（走 §4.1）
```

> **命名口径**：本节沿用「决策 / 判定」命名。设计讨论中的「触发判定（产生想法）」
> 即本节的**决策侧**，「决策判定（实际能否成功）」即本节的**判定侧**；语义一致，仅名称不同。

## 4.5 选择侧统一公式（行为内部的分岔）

> **用途**：**同一个行为内部的分岔选择**（看不看纸条、销毁还是继续传、守不守密、接不接受道歉……）。
> 它既不是「做不做这个行为」（§4.4 决策侧），也不是「成不成」（§4.4 判定侧），
> 而是**行为已经成立之后，参与者在若干选项之间的倾向**。三者共用同一套性格与状态语言，读的量不同而已。

```text
p(选项 o) = σ((score_o − θ_o) / scale_o)
score_o   = Σ_p ( w_{o,p} · d_p )  +  w_{o,stress} · (Stress[i] − 50)/50  +  Σ 状态项
```

| 符号 | 含义 |
|---|---|
| `d_p` | 性格四维偏差 = (维度值 − 50)/50，固定顺序 **d₁ = E/I、d₂ = S/N、d₃ = T/F、d₄ = J/P** |
| `w_{o,p}` | **该行为、该选项**对第 p 维的敏感度权重（策划填表；**不用的维度填 0**） |
| `w_{o,stress}` | 压力项权重（可省略，缺省 0） |
| 状态项 | 该行为自己的连续量（如「纸条内容与被说者的相关度」）；**必须是已有矩阵 / 状态的函数**，不得读角色名或角色 ID（§14 不变式 1） |
| `θ_o` / `scale_o` | 该选项的拐点与坡度（`p = 0.5` 落在 `θ_o`） |

- **同一套公式，不同的权重行**：每个行为的「性格侧」由它自己填 `w`——纸条看「N（爱八卦）+ F（同理心）」，守密看「N + 内向度」，共情看「F + 敏感」……**不要为每个行为各编一套形状不同的判据**。
- **多选项**：各选项分别算 `score` 后归一化（二选一直接用 sigmoid；三选以上按分数比例或 softmax）。
- **玩家永远自己选**：玩家不走本公式（与「玩家跳过决策侧」同口径，§10.1）。
- **系数全部外置**：`data/rules/choice_weights.csv`（列 `event, option, theta, scale, w_e, w_s, w_f, w_j, w_stress, note`）。
- **与前两条的关系**：§4.1 管「加多少」、§4.4 管「做不做 / 成不成」、本节管「做这件事时选哪一支」——都只读既有矩阵与性格，**都不写死 0/1**。
- **逐步收编**：§8.10–§8.14 里散落的「性格修正：外向成功率 +20%」「高 N 守密 −30%」等写法，实现批次应逐条改为本节的一行权重；标着「未实装」的条目优先。
