# 第十三章 涌现现象对照与开发优先级

> 迁入自 v3.0 §12，**行为名已改用第八章的中文行为名**（不再使用 R1–R13 编号）。
> 本表既是设计验收用例来源，也是"是否真的涌现"的自检清单——**每一行的右列都只能是机制，不能是脚本**。

| 涌现现象 | 形成来源（全部为底层机制，无脚本） |
|---|---|
| 本来开朗的学生被反复调侃后变成小透明 | 当众调侃 + 压力累积 + 透明度下降 + 搭话被敷衍 |
| 小团体自发抱团 | 相邻（概率放大器） + 共同学习 + 话题共鸣（同仇敌忾） + 影响力传导 + 流言染色（簇标签只贴标签） |
| 受委屈的同学积攒情绪后突然爆发 | 压力长期累积 + 90 阈值爆发（上课发酵加速累积） |
| 同一条八卦不同人传出不同版本 | 流言的传播者态度染色 + 高 N 的人脑补 |
| 小团体内部矛盾成员主动脱离 | 强连接断裂（信任 < 阈值）→ 簇标签消失，**无惩罚** |
| 玩家被八卦误伤导致被孤立 | 流言变异 + 玩家是系统一员（§10.1） |
| 内向学生在压力低时意外主动搭话 | 搭话 + 压力阈值放开（门槛 `stress ≤ 80`） |
| 告密者被全班疏远 | 秘密交换泄密 + 信任暴跌 + 流言传播 |
| 一次举报导致班级分裂成两派 | 举报的群体分裂效应 + J/P 性格差异 |
| 压力崩溃后谁安慰谁躲开一目了然 | 安慰 + 周围人按性格分裂 |
| 墙头草在两个阵营间反复横跳 | 影响力传导的竞争归一化 + 双向拉扯 |
| 连最和善的人都不理的人被全班孤立 | 影响力传导 + 全班平均好感下降 |
| 挖墙脚引发原圈子记恨 | 影响力传导（敌意沿信任链扩散），不写死数值 |

## 13.1 第一版（核心循环必做）

- **时间**：三段课间 + 两段上课发酵，tick 定义（§2.2）。
- **底层**：好感 / 敌对 / 信任有向矩阵 + 透明度 + MBTI 四维 + 非线性影响力传导（§3–§5）。
- **情绪**：压力值 + 情绪标签派生 + 爆发（§6）。
- **行为**：闲聊（发起／加入）、话题共鸣（闲聊内）、流言、走动、当众调侃、安慰 + **「所有活动都可加入」（§8.21：`accept` 需对方判定 / `free` 自由跟随）**+ 观察层簇标签器 / 孤立标签 + **活动圈查询**；原“搭话”不再计作独立主行为。
- **可视化**：空间聚散 + 情绪图标 + 关系线 + **活动圈（含加入的绿/红反馈）** + 上课过场（§12.1–15.2）。
- **角色**：8–10 个核心角色（第一版可用简化抽取）。
- **简报**：《每日简报》基础版（§12）。
- **目标**：跑通"聚散 → 聊天 → 调侃 → 崩溃 → 安慰 → 抱团"的单日戏剧循环 + 跨天继承 / 衰减。

## 13.2 第二版（深度扩展）

- **行为**：秘密交换 + 道歉 / 和解 + 举报（§8.11/§8.14/§8.2）。
  > v3.0 此处还列有 R11「拉拢 / 挖墙脚」——v3.1 已**移除该独立行为**，其功能由影响力传导（§5）承担。
- **信息**：情报日志 + 态度面板 + 推理板 + 矛盾高亮（§7.5）。
- **角色**：扩到 24 人完整池（§9.14）。
- **目标**：信任深度、阵营博弈、信息博弈全部跑通；学期格局报告上线（§12）。

## 13.3 第三版（锦上添花）

- **行为 / 事件**：求助 + 匿名纸条 + 起哄围观 + 当面质问 + 故意装傻；社会事件层扩展（§11.5）。
- **功能**：回放动画（§12.3）+ 多局对比 + 玩家 MBTI 自选 + 环境事实扩展。
