## 24.2 逐行为条目

### 24.2.1 课外书经济完整版

| 环节 | 界面条目 |
|---|---|
| 受赠 | 弹层 / 结果页：`XX 塞给你一本课外书：「看这个，别老闷着。」` + 持有区书本数 +1；**首次获得时**给风险提示 `上课的时候被老师看到，书会被收走。`（与第二十一章 §21.2.4 同一句） |
| 看书 | 门控解除，按钮变为可用（第二十一章 §21.2.4 的进行中 / 结算文案不变） |
| 被没收 | 短句 `老师把书收走了。` + 持有区书本数 −1；归零后「看课外书」按钮立刻变灰（原因 `你还没有课外书。`） |
| 取回 | 周考进步奖时：`老师把上次收走的课外书还给你了。`；**若被没收的书与进步奖取回范围不一致，必须明确写出**（避免玩家以为漏发） |
| 纪律 | 不显示「好感 / 信任达到多少才送书」这类条件；赠书是状态触发的结果，不是可刷的按钮 |

### 24.2.2 五子棋 + 围观

| 项 | 内容 |
|---|---|
| 入口 | 他人卡片「动手做事」组：`下棋`（需对方空闲） |
| 对局形态 | 棋盘为**弹层**（不切场景，见 §24.3） |
| 时间约束 | 受课间时间预算约束；未下完的棋局在课间结束时中断，给短句 `没下完，铃就响了。` |
| 围观 | 围观者进入同一个活动圈、音量档位 +1、压力照常涓流；**不产生额外 UI 元素**（复用 §20.1.5 的活动圈） |
| 纪律 | 不显示胜负概率、不显示对手「棋力」数值 |
| 降级 | 不做棋盘 → 改为「一局定胜负的文字对局」结果页；棋盘延后到赛后 |

### 24.2.3 石头剪刀布（完整版）

| 项 | 内容 |
|---|---|
| 相对降级版新增 | 出拳动画（简版手部 / 气泡）、连胜记录展示（`连赢 2 把`）、围观表现（复用活动圈） |
| 保持不变 | 入口、三选一交互、结果文案、一课间 1 次（第二十三章 §23.2.4） |
| 纪律 | 连胜记录只是记录，**不产生额外数值收益**（避免把休闲玩法变成刷分手段） |

## 24.3 本批特有新组件：棋盘弹层

```text
┌──────────────────────────────┐
│ 和林小雨下一局                │
│      ● ○ ○ ● ○ ○            │
│    ○ ● ● ○ ○ ● ○            │  ← 15×15 或按 4×4 座位号的简化盘面
│  ...                         │
│ 该你了 · 课间还剩 42 秒        │  ← 剩余时间提示（未下完会被铃声中断）
└──────────────────────────────┘
```

| 项 | 规定 |
|---|---|
| 盘面 | 标准五子棋盘（尺寸由实现定），落子点热区不小于 44×44 px |
| 落子 | 点 / 触即落子；不做落子动画 |
| 时钟 | 面板**不暂停**课间计时（与选座面板不同，见 Q2 的裁决结论）：课间结束即中断，这是设计意图 |
| 围观 | 面板外的人照常活动，可见活动圈扩大 |
| 降级 | 文字对局（§24.2.2） |

## 24.4 降级与排期

**赛后优先级（建议顺序）**：

| 序 | 项 | 理由 |
|---|---|---|
| 1 | 课外书经济（受赠 / 没收 / 取回） | 与 P0–P2 已埋的钩子（看书灰置、进步奖取回、老师没收）形成闭环，投入产出最高 |
| 2 | 石头剪刀布完整版 | 在降级版之上增量小 |
| 3 | 五子棋 + 围观 | 棋盘是赛后最大工作量项，最后评估 |

**若确定不做**：本章整体保留为形态记录，并在 `CHANGELOG.md` 记一条「赛后未实施」，**不删除本章**（避免下次重新讨论）。

## 24.5 验收

1. 受赠 / 被没收 / 取回三个环节，持有区数字与按钮可用性同步变化，无「数字变了按钮没变」的情况。
2. 被没收归零后按钮立刻灰置并给出原因。
3. 五子棋未下完时给中断短句，不产生「卡在面板里」的状态。
4. 围观者只通过活动圈体现，不新增独立 UI 元素。
5. 猜拳连胜记录不带来任何数值收益（对拍可验证：连胜与收益无关）。
6. 全批界面不出现任何 NPC 数值。
