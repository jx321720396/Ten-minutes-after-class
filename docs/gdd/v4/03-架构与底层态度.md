# 第三章 系统架构与底层态度

## 3.1 三层架构

系统分为三层，各司其职，不冗余、不循环依赖：

| 层级 | 内容 | 特性 |
| --- | --- | --- |
| 行为接口层 | 第八章的人物行为（闲聊（发起／加入） / 举报 / 纸条；状态层：走动 / 睡觉） | 决定这一 tick 谁和谁发生什么互动，快变量 |
| 情绪状态层 | 压力值（唯一累积情绪变量） | 累积-爆发机制，中变量 |
| 底层态度轴 | 好感/敌对/信任（有向矩阵）+ 透明度/性格（个体） | 稳定的关系与人格，慢变量 |

## 3.2 闭环说明

底层态度轴决定规则触发条件（谁能加入闲聊、谁会传八卦、谁能成团）；规则执行后回写底层轴和压力值；状态变化又改变下一次规则的触发条件。玩家的每一次操作，只是在这个闭环中拨动一个节点的数值，然后整个系统自己重新洗牌。



底层态度轴是系统的地基，共五个。其中好感、敌对、信任为有向矩阵（N×N，N=9/17/25 按难度，A对B和B对A独立存储），透明度和性格底色为个体属性。所有轴取值 0–100。

## 3.5 信任（Trust，T[i][j]）

- 定义：i 愿不愿意相信 j 说的话、把秘密告诉 j、指望 j 不伤害自己。
- 与好感的本质区别：好感回答"愿不愿意靠近"，信任回答"愿不愿意暴露脆弱"。可以喜欢但不信任（爱吹牛的朋友），可以信任但不喜欢（严肃但靠谱的班长）。

## 3.6 透明度（Opacity，O[i]）

- 定义：i 的真实立场被他人准确感知的程度。
- 高透明度（80+）：态度一目了然，是班级的信息源。
- 低透明度（<20）：别人看不透他的真实想法，只能靠猜、靠八卦。
- 玩法意义：直接控制 UI 中态度线的呈现（实线/虚线/消失），是信息可见性系统的第一层过滤。

## 3.7 性格底色（MBTI 四维度）

不使用刻板的16型分类，而是将MBTI四个维度做成0-100的连续数值，每个维度直接修正游戏中的行为系数。24个角色即使MBTI类型相同，程度不同，行为也不一样。

| **维度** | **0端** | **100端** | **影响的规则** |
| --- | --- | --- | --- |
| E/I 外向度 | 极度内向 | 极度外向 | 加入闲聊概率、相邻时的压力敏感度、独处压力恢复速度 |
| S/N 直觉度 | 极度实感（记细节） | 极度直觉（爱脑补） | 聊天内容的传达准确度（S 型记得准、N 型易加料）、闲聊话题兴趣 |
| T/F 情感度 | 极度思考（逻辑导向） | 极度情感（共情导向） | 调侃敏感度、安慰效果、道歉接受度 |
| **J 强度** | 极度感知（随性） | **极度判断（守秩序）** | 小团体归属倾向、被拉拢概率、举报倾向 |

**性格层铁律**：性格只有数值，没有行为；一切角色差异必须能写成这四个维度 + 透明度的纯函数。
