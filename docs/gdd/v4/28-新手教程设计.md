# 第二十八章 新手教程

> 状态：策划案 ｜ 实现状态：未开工 ｜ 制定：2026-10-13 ｜ 依据：主文档第二、八、十章；[10-玩家操作映射.md](10-玩家操作映射.md)；[20-UI交互总则与共享组件.md](20-UI交互总则与共享组件.md)
> 本章只回答一个问题：**新玩家第一次进班时，看到什么、被提醒什么、教程什么时候闭嘴。**
> 教程是**纯表现层**的引导：不写任何矩阵、不让 NPC 为教程做任何事、不新增任何影响内核的参数。
> 数值与文案分离（§20.0.1）：全部文案进 `data/ui/tutorial.json`，脚本不硬编码中文字面量（见 [`../../localization/本地化说明.md`](../../localization/本地化说明.md) §2）。
> 本章为策划案；代码触点（组件挂载点、信号名）在实现批次补记到 P0–P2 UI 清单，不写在本章。

## 28.0 设计原则（四条）

1. **删掉即无痕**：把教程整体移除（或清空 JSON、置已读标记），游戏运行零变化。这是本设计通过「检验一」的方式——教程不承载任何玩法功能，只做引导。教程也**不读任何 NPC 隐藏数值**（好感、敌对、信任、压力、成绩）来决定提示内容，只监听玩家动作与公开 UI 状态（§20.0.1 第 2 条）。
2. **世界不等人**：除开场纸卡外，一切提示**不暂停、不锁输入、不强制定位**。错过步骤就错过——「课间只有十分钟，做不了太多事」（§10.2 时间预算）正是新手要学的第一课，教程本身就用它教学。任何一步都有超时自动放行，绝无惩罚。
3. **教规则，不教打法**：只教通用机制——移动、两步交互（§20.1.2）、观察、时间结构。**不教**举报、排挤、递纸条怎么用：破坏性玩法与深层目的留给玩家自己发现，百科词条与行为栏灰置原因兜底。理由有二：教程替玩家预设玩法目的，与「用有限信息拼出班级真相」的核心体验冲突；且把每个行为都过一遍会把首课间吃光。
4. **一次会话**：整包教程默认只在首次新游戏出现；跨局记「已看」标记，之后不再弹。设置菜单提供「重看教程」入口，供老玩家主动回看。

## 28.1 结构总览：三段式

| 段 | 时机 | 世界状态 | 形式 |
|---|---|---|---|
| 一 · 开场纸卡 | 进教室瞬间，第一节课间计时开始前 | 待启动（时间未开跑，玩家零损失） | 3 张纸卡，可跳过 |
| 二 · 首课间分步 | 第 1 天上午课间 | 照常运行 | 步进提示条，条件触发，超时放行 |
| 三 · 里程碑短句 | 贯穿 30 天 | 照常运行 | 复用顶部短句通道，仅首次弹出 |

三段共用同一个「跳过教程」总入口（常驻屏幕角落的小字按钮，热区不小于 44×44，§20.0.4）；跳过即写入已读标记，本段与本局后续段全部静默。

## 28.2 第一段：开场纸卡

- **挂载时机**：教室场景就绪后、第一节上课铃计时启动前弹出（进教室链路：主菜单 → 性别选择 → 教室）。此时世界尚未开跑，玩家读完三张卡**不损失任何课间时间**；关闭最后一张后，第 1 天上午课间才开始。
- **弹层名额**：占用第 1 天的全屏弹层名额（§20.1.7：同一天除学期总结外不出现第二个全屏弹层）。
- **样式**：纸感面板（§20.0.3），右下角「开始上课」逐张推进；右上角常驻「跳过教程」。

| 卡 | 内容方向 |
|---|---|
| ① 你是谁 | 「你是 3 班的转学生。这学期 30 天，没人认识你——一切从零开始。」 |
| ② 一天怎么过 | 「每天三段课间是你的时间。上课铃一响，只能看着班里自己发酵。」 |
| ③ 没有标准答案 | 「想跟谁好、想看谁笑话、想安静读书，都行。下课了。」 |

- 卡面**不放操作教学**（按键说明、界面指引都放到第二段）——纸卡只交代处境与时间结构，读完即玩。

## 28.3 第二段：首课间分步提示

第 1 天上午课间内的 5 步，全部由**玩家动作或超时**推进；同屏最多一条提示，提示条位置避开右侧行为栏与底部书包入口热区。

| 步 | 触发 | 提示文案方向 | 完成条件 | 超时放行 |
|---|---|---|---|---|
| S1 看时间 | 关掉开场卡即弹（高亮时间卡） | 「左上是日子。课间一结束就会上课，别磨蹭。」 | 展示约 3 秒后自动过 | — |
| S2 移动 | S1 完成 | 「点地面走走，或者用 WASD。」 | 玩家位移超过一小段距离 | 约 20 秒 |
| S3 行为栏 | S2 完成 | 「右边是能做的事：先点一件事，再点一个人。」（高亮行为栏） | 玩家首次选中任一行为 | 约 20 秒 |
| S4 第一次闲聊 | S3 完成 | 「走近一个同学，点『闲聊』，再点他。聊什么都行。」 | 玩家提交一次闲聊（发起或加入均可；**成功或被拒都算完成**） | 课间结束 |
| S5 观察（软引导） | S4 完成 | 「想知道谁怎么看你，就『观察』他——只看，不会被发觉。」（§10.3.1） | 观察一次，或课间结束 | 无（课间结束静默收尾） |

补充规则：

- **S4 被拒也算完成**：被拒本身就是要教的东西——S4 完成后若本次闲聊失败，追加一条一次性短句「不是每次都顺利。被拒绝也是情报」。成功则由现有聊天反馈通道结算，教程不重复出词。
- **课间结束未走完的步骤**：静默标为放弃，进入上课段后不再补弹；第二段就此收尾。绝不跨课间追进度。
- **提示条样式**：纸感底、墨色正文，单条不超过两行；高亮只做描边呼吸，不遮目标热区。
- **本段不教**睡觉、学习、书包与破坏性行为——它们由第三段里程碑与百科词条覆盖。

## 28.4 第三段：里程碑短句

全部复用时间 HUD 的顶部短句通道（§20.1.7 第 1 级，不打断），由事件信号触发，**每条仅首次弹出**，第二次起静默：

| 触发 | 文案方向 |
|---|---|
| 第一次进入上课段 | 「上课了。课间种下的因，现在自己长——你插不上手。」（§2 上课发酵层） |
| 第一次日末简报 | 简报顶部一行：「每天的账都记在这里。」（日末停留与自动进入沿用 §2.5 现行规则） |
| 第一次收到邀请或搭话 | 「有人来叫你。接不接都行，班里都会记得。」 |
| 第一次聊天被铃声打断 | 「话没说完就上课了——下次早点开口。」 |
| 第一次围观到有人压力爆发 | 「他绷不住了。你可以离远点，也可以过去说句话。」（压力与爆发的世界观介绍，不给数值） |
| 第一次打开书包 / 推理板 / 百科全书 | 不加教程层——面板内说明与百科词条已覆盖 |

里程碑同样受「跳过教程」总开关约束：跳过后全部静默。

## 28.5 触发机制与状态存储

- **触发源白名单**（只允许这些，不得扩充为读内核隐藏状态）：
  1. 玩家动作：位移、行为栏选中（arm）、行为提交、面板打开；
  2. 阶段信号：进入上课段、日末简报出现（现有 EventBus 通知复用）；
  3. 交互结果通知：邀请出现、聊天被铃声打断（现有通知接线复用，不新增内核信号）。
- **步骤状态机挂表现层**：进度只存在本局内存，**不入存档**——中途退出再进不重弹已完成的部分；「重看教程」从设置菜单手动触发，重看时步骤进度从零开始但已读标记不变。
- **跨局标记**：存档元数据加「已看教程」布尔位（走现有 Save 元数据通道）；无存档的全新安装默认未看。
- **续玩加载目前是占位**：主菜单「继续」的读取链路接线后，续玩局同样不再弹教程（已读标记随元数据走）。

## 28.6 与现有系统的关系（复用优先，不另起一套）

| 教程需要 | 复用的现有组件 | 备注 |
|---|---|---|
| 短句提示 | 时间 HUD 顶部短句通道 | §20.1.7 第 1 级 |
| 开场卡 / 提示条样式 | 纸感面板基线（§20.0.3） | 与确认卡、结果页同一套 |
| 聊天结果反馈 | 现有聊天反馈 HUD | 教程不重复出词 |
| 术语解释 | 术语悬停 + 百科词条 | 教程文案里的机制词用同一套词条标记 |
| 触发信号 | EventBus 现有通知 | 不新增内核信号 |
| 新组件（仅两个） | 教程覆盖层（步进提示 + 锚点高亮）、开场卡场景 | 挂教室场景，纯表现层 |

文案文案基调沿用 §20.0.3：口语、用「你」称呼玩家、不出现系统词；教程词表里禁止「数值 / 状态 / 加成 / 倍率 / 触发」。

## 28.7 配置落点：data/ui/tutorial.json

全部步骤、里程碑与文案集中一个 JSON（先例：`data/ui/backpack.json`），结构草案：

```json
{
  "version": 1,
  "intro_cards": [
    { "id": "card_who", "text": "你是 3 班的转学生……" },
    { "id": "card_day", "text": "每天三段课间是你的时间……" },
    { "id": "card_free", "text": "想跟谁好、想看谁笑话……" }
  ],
  "steps": [
    { "id": "s1_time",   "trigger": "on_classroom_enter", "text": "左上是日子……", "auto_pass_seconds": 3 },
    { "id": "s2_move",   "trigger": "after:s1_time",  "text": "点地面走走……", "done": "player_moved", "timeout_seconds": 20 },
    { "id": "s3_action", "trigger": "after:s2_move",  "text": "右边是能做的事……", "done": "action_armed", "timeout_seconds": 20 },
    { "id": "s4_chat",   "trigger": "after:s3_action", "text": "走近一个同学……", "done": "chat_committed" },
    { "id": "s5_observe","trigger": "after:s4_chat",  "text": "想知道谁怎么看你……", "done": "observe_done" }
  ],
  "milestones": [
    { "id": "m_first_class",  "trigger": "on_phase:class",  "text": "上课了……" },
    { "id": "m_first_report", "trigger": "on_daily_report", "text": "每天的账都记在这里。" }
  ]
}
```

- 字段语义：`trigger` 为触发时机；`done` 为完成判据；`timeout_seconds` 为超时放行秒数（缺省表示跟到课间结束）；`milestones` 隐含仅首次。
- 数值全部可调在表里，改表不改文案模板（§20.0.1 第 3 条）；本章正文不另设参数表。

## 28.8 验收清单

1. **删掉即无痕**：已读标记置位或清空 JSON 后，逐帧对比确认游戏行为与数值零变化；
2. **信息纪律**：全程截屏检查，任何教程提示不出现 NPC 的好感、敌对、信任、压力、成绩数字（§20.0.2）；文案无「数值 / 状态 / 加成 / 倍率 / 触发」字样；
3. **一次会话**：跳过后本局与后续新局均不再弹；设置「重看教程」可恢复；无存档新装默认弹；
4. **弹层纪律**：开场卡之外无任何阻塞时钟的弹层；第 1 天除开场卡外无第二个全屏弹层（§20.1.7）；
5. **世界照跑**：分步与里程碑期间时钟不停、输入不被锁；超时步骤静默放行，无惩罚路径；
6. **双端可达**：键鼠与触屏均可完成全部步骤；「跳过教程」与提示条热区不小于 44×44；提示不与行为栏、书包入口热区重叠；
7. **文案外置**：脚本零中文字面量，全部文案可在 `data/ui/tutorial.json` 改出同效果。
