## 21.2 逐行为条目

### 书包实物入口（2026-10-12）

右下角新增独立「书包」按钮，排在「百科全书／推理板」左侧；三个入口统一纸纹底、青绿描边与线条图标，悬停以金色下缘强调。行动栏移除顶部「打开书包」；原「听音乐／吃零食／看课外书」快捷按钮打开书包并选中对应物品，拿取后才提交动作。面板从右下展开，暂时隐藏行为栏，保留教室、时间卡和底部导航；世界继续运行，门禁与库存持续刷新。点击实物或纸签选择，右侧纸卡显示说明、数量、不可用原因与「拿出来」。关闭按钮、再次点击书包入口或 Esc 收起；点击百科／推理板时也收起书包；Esc 不同时打开暂停菜单。玩家无书时书袋为空、零食耗尽时零食口袋为空，但纸签与原因保留。老师保管数量在书卡提示，免罚卷仍在行为栏持有区。拿取仅发既有自指行为意图，库存由内核开始动作时扣减，表现层不改数值。

素材：透明空包与透明物品层；配置为 `data/ui/backpack.json`，组件为 `scenes/ui/backpack_panel.tscn`。场景已有各座位桌侧书包模型，当前使用独立 UI 按键打开，不新增模型或改变相机。

### 21.2.1 学习（默认态可见化）

| 项 | 内容 |
|---|---|
| 入口 | 行为栏「学习」（**2026-10-10 可点**）；不选任何行为＝什么都没做，**不累积成绩**（§8.23） |
| 可用条件 | 课间与上课段都可（默认态） |
| 进行中 | 状态条 `在学习`；活动圈按「安静类」着色 |
| 结算 | **不逐分弹提示**；成绩变化只在 HUD 数字上体现，并在当日简报汇总一行 |
| 文案 | 简报：`今天你学了不少。` / 被频繁打断时：`今天坐下来学的时间不多。` |

### 21.2.2 听音乐

| 项 | 内容 |
|---|---|
| 入口 | 右侧行为栏「听音乐」（2026-10-11 已接通） |
| 可用条件 | 课间闲置；**默认可用**，不做门控；上课段不可用（`上课呢，下课再说`）；已有占用动作时不可用（`你正忙着 · 做完再说`） |
| 进行中 | 状态条 `在听音乐 · 还剩 18 秒`；徽标 `听音乐`；活动圈「独处类」 |
| 结算 | 短句：`听完一首，心里松快了一点。` |
| 被打断 | 上课铃响：`音乐还没听完，铃声就响了。` |
| 老师 | 进教室**不豁免**（§17.2.3）：被逮到只给短句 `老师看了你一眼。`（P0 无惩罚，见 Q8 与 §24.2.1） |

### 21.2.3 吃零食

| 项 | 内容 |
|---|---|
| 入口 | 右侧行为栏「吃零食」（2026-10-11 已接通），按钮上带剩余份数：`吃零食（4）` |
| 可用条件 | 玩家每局 5 份；用完后按钮灰置 + `零食吃完了`；NPC 无份数限制（常物） |
| 进行中 | 状态条 `在吃零食（还剩 4 份）`；徽标 `吃零食`；活动圈「独处类」；对环境有轻微噪音表现（他人可能被吸引） |
| 结算 | 短句：`你啃了两口，心情好了点。` |
| 最后一份 | `最后一包了，你把它吃完了。` |
| 老师 | 同听音乐，不豁免，被逮到只提示不惩罚 |

### 21.2.4 看课外书

| 项 | 内容 |
|---|---|
| 入口 | 右侧行为栏「看课外书」（2026-10-11 已接通） |
| 可用条件 | **需持有课外书**。P0–P2 玩家默认 0 本 → 按钮**恒为灰置**，原因文案 `你还没有课外书。`（不隐藏按钮，让玩家知道有这条路）；P3 获得书后自动可用 |
| 进行中 | 状态条 `在看课外书`；徽标 `看课外书`；活动圈「安静类」 |
| 结算 | 短句：`看了两页，脑子里的杂事淡了些。` |
| 风险提示 | **首次可用时**（P3 拿到书时）给一次：`被老师看到正在看书，书会被收走。` —— 不给提示等于偷袭玩家 |
| 老师 | 不豁免；当前已接通巡查没收（§24.2.1.2） |

### 21.2.5 出门（玩家独有）

| 项 | 内容 |
|---|---|
| 入口 | 右侧行为栏「出门待一会儿」（2026-10-11 已接通） |
| 可用条件 | 课间；每课间 1 次；上课段不可用；已有占用动作时不可用 |
| 二次确认 | **已给（2026-10-11）**。取消不提交动作，退出场景释放暂停锁。确认卡文案：`出去就赶不上这节课间了，同桌们会有点介意。确定？` / 按钮：`出去` `算了` |
| 进行中 | 短句 `你出去了。` + 时间快进表现（降级：不做动画，改用现有转场留白 + 时间跳跃） |
| 结算 | 回到教室后一句：`你回到教室，刚好听见铃声。` |
| 好处 | 不给数字；出门跳过剩余课间并隔离判定，不额外减压（压力仍是隐藏值） |
| 代价 | 邻居好感下降**不显示数字**：表现为回来时附近的人冷淡；简报行按 §21.4 延后，计划文案为 `你今天不在的时候，旁边的人没怎么提你。` |
| 降级 | 只保留状态条 + 短句 + 时间跳跃，砍掉快进表现 |

### 21.2.6 老师巡查

| 项 | 内容 |
|---|---|
| 老师实体的表现 | 场景里老师**是一个真实走动的角色**（从办公室方向走到讲台）；头顶有唯一标识（如小名牌），**不与学生共用情绪图标** |
| 到场 / 离场 | 短句（1 级）：`老师进来了。` / `老师回办公室了。` |
| 在场期间 | 场景自然变安静：热闹类活动减少、音量视觉下降；**不显式告知「你被压场了」**，只让世界变安静 |
| 玩家自身 | 看书 / 听音乐 / 吃零食被逮到 → 短句 `老师看了你一眼。`；睡觉 / 学习**豁免**，无提示（不给「安全」的正反馈，避免玩家照着刷） |
| 玩家出门时 | 不在教室，不参与判定，无提示 |
| 举报接线 | 举报落点从抽象变为「老师现在在哪」——简报与存档可用「老师就在教室」这类描述，**不改举报数值** |
| 降级 | 老师模型来不及：用**讲台占位道具 + 短句**代替走动角色（2026-10-12 起**不再用位置文字字段**，见 §20.0.2 老师位置一行） |

> **不杀回马枪**（§17.2.2）在 UI 上不做额外解释 —— 玩家只看到「这节课间老师来了一次」，这是设计意图，不需要教学文案。

> **2026-10-11 实装补记**：老师位置**不显示文字字段**（2026-10-12 按用户裁定删除教室顶部「老师在教室 / 办公室」，老师在场以到场短句与压场效果表达）；看书已接通没收一本并中止阅读，音乐/零食仍只提示。持有区同步显示剩余书、老师保管数和免罚卷；模型和讲台道具未实现，未运行验收。

### 21.2.7 成绩 HUD 与期末倒计时

| 项 | 内容 |
|---|---|
| 位置 | **屏幕右上角**，独立卡片（2026-10-10 用户指定；时间卡片在左上角，两者不挤在一起） |
| 格式 | `成绩 250 ｜ 距期末考 30 天`（成绩只显示整数） |
| 变化反馈 | **不逐分弹窗**；数字变化时轻微闪一下即可（**2026-10-10 已实装**） |
| 每日汇总 | **依赖「日末简报」组件（尚未接入）**：当日简报加一行：`今天你学了 N 小时，成绩有了变化。`（N 由状态统计折算游戏内时长，不给玩家看内核计数） |
| 期末考当天 | 倒计时换成 `今天是期末考` |
| 不做 | 不显示 NPC 成绩、不显示班级排名 |

### 21.2.8 上课好感涓流

**无独立 UI**。它在**上课过场**里体现：相邻且都醒着的人之间，关系氛围线偶发地亮一下（§12.1「只在意质变瞬间」）。不做数值提示、不进简报明细。
### 21.2.9 传纸条（纸条链，2026-10-10 新增）

| 项 | 内容 |
|---|---|
| 入口 | 右侧行为栏「递纸条」→ 选一个**被说的人**（从附近的同学里挑）；**写什么由系统按写者自己的态度决定**，玩家不编辑内容 |
| 可用条件 | 课间与**上课段都可**（上课是唯一允许的动作）；需坐位相邻或已走近；已有占用动作时不可用 |
| 收到纸条 |  不打断当前动作，只在界面角落提示；选择框：`不看，传下去` / `不看，撕掉` / `看看写的什么`。选「看」会**打断当前动作**并占一点时间 |
| 看完之后 | 再给一次选择：`撕掉` / `继续传给别人` / `去告诉老师`（举报） |
| 持有者表现 | **需要**：谁手里正拿着纸条要在场景里看得见（**头顶小纸片徽标**，复用 §20 行为徽标组件）；**不显示纸条内容，也不显示是谁写的** |
| 结算 | 不给数字：看完给一句短句（如 `纸条上写着不太中听的话。`）；对某人的态度变化由后续反应体现 |
| 举报 | 纸条算**最低一档把柄**；**被举报的是上一个把纸条递给你的人**（§8.2、§8.6）；**只能当场举报**，撕掉后不能再举 |
| 降级 | 砍掉持有者徽标，只保留选择框与短句；再降级：收到纸条只给纯文字提示（`有人塞给你一张纸条。`） |
| 实装状态 | **2026-10-10**：选择框、短句与**持有者徽标**均已实装（`scripts/ui/note_prompt.gd` + `scripts/game/behavior_badge_presenter.gd`）—— 谁手里正拿着纸条，在场景里看得出来（人物头侧的小纸片），但不显示纸条内容、也不显示是谁写的。「递纸条」的入口落在**点人后的卡片**上（本章原定入口是「自身卡片」，该组件尚未实装，暂以选中同学当「被说的人」；自身卡片做好后再迁）。 |

## 21.3 本批特有新组件

## 21.4 降级与排期

| 优先 | 项 | 降级方案 |
|---|---|---|

## 21.5 验收

1. 什么都不点时屏幕上有「在学习」的反馈。
2. 听音乐 / 吃零食有剩余时间或剩余份数；零食归零后按钮变灰且给原因。
3. 看课外书按钮在无书时是灰置**且可读原因**，不是隐藏。
4. 老师到场 / 离场都有短句；被逮到有提示、睡眠与学习无提示。
5. 全批界面不出现任何 NPC 数值；玩家成绩只出现在 HUD 与简报。
6. 按 §21.4 降级清单逐项走一遍，信息完整可读。
