# 第二十三章 P2 行为 UI 交互规格

> 状态：策划案 ｜ 实现状态：未开工 ｜ 制定：2026-10-09 ｜ 依据：第十九章《P2 功能细分规格》+ 第二十章《UI 交互总则与共享组件》
> 本章只写 **P2 批次**（周考+奖励 / 事件触发状态前置 / 多结局结算报告）的界面条目；共享组件定义见第二十章。
> 本批含**一个新增组件类型**：学期总结画面（§23.3），也是全章唯一允许的全屏弹层。

## 23.0 本批范围与本批不做

| 项 | 内容 |
|---|---|
| 覆盖 | 周考当日横幅与结果简报、进步奖 / 特等奖 / 免罚卷的展示、事件门控的「零 UI 变化」说明、第 30 天学期总结画面、猜拳降级版的文字结果 |
| 依赖 | 第十九章全批 + P0 的成绩 HUD（第二十一章）+ 每日简报 |

**本批明确不做**：

| 不做 | 归属 |
|---|---|
| 考试演出 / 动画 / 交卷过程 | 冻结期不值得（第十九章 §19.0 已定） |
| 考试结果回馈 A/H/T 的任何可视化（学霸光环等） | 第十九章 §19.7 开放问题①，本批顺延 |
| NPC 具体分数、完整排名榜 | 只出前 3 与玩家自己的名次 |
| 总评分 / 评级 / S·A·B 档 | 结局分档是**故事走向**，不是成绩单 |
| 事件门控的玩家侧提示（如「本事件被条件挡住」） | 门控是内核层，玩家不该知道有门 |

## 23.1 本批对共享组件的填充

| 组件 | 本批新增内容 | 章节 |
|---|---|---|
| 顶部 HUD | 考试日横幅：`今天周考` / `今天期末考` | §23.2.1 |
| 持有区 | 免罚卷图标 + 张数（含无消费点期的说明口径） | §23.2.2 |
| 每日简报 | 新增段落：班级前 3 名、玩家名次 / 分数 / 较上次进退量、得奖行 | §23.2.1、§23.2.2 |
| 右侧行为栏 | 「动手做事」组新增 `猜拳`（降级版，带冷却文案） | §23.2.4 |

## 23.2 逐行为条目

### 23.2.1 周考

| 项 | 内容 |
|---|---|
| 当日横幅 | 顶部 HUD 加一行：`今天周考`（期末考当天为 `今天期末考`） |
| 考试过程 | **无玩家操作**，不插入演出（考试在跨天结算时完成，§19.1.1） |
| 结果落点 | 当日简报段落：班级前 3 名（名字）、玩家名次、玩家成绩、较上次的进退量 |
| 文案示例 | `这次周考，前三名是 A、B、C。你考了第 5 名，比上次进步了 42 分。` / 退步时：`这次退了几名，最近可能太闹了。` |
| 纪律 | 不显示 NPC 具体分数、不显示完整排名榜、不做考试动画 |

### 23.2.2 进步奖 / 特等奖 / 免罚卷

| 项 | 内容 |
|---|---|
| 进步奖（P2 降级版） | 简报加一行 `你这次进步很大，老师当众夸了你。`；P3 物品系统就绪后追加 `老师把上次收走的课外书还给你了。` |
| 特等奖 | 简报加一行 `你考进了前三名，拿到了免罚卷。` + 持有区免罚卷 +1 |
| 免罚卷说明 | 持有区 hover / 长按：`下周有一次处罚可以免掉。`；**P3 消费点接通前**改为 `现在还派不上用场，先收着。` —— 不给模糊承诺（Q4） |
| 纪律 | 玩家看不到 NPC 具体分数；得奖行只写结果，不写判定条件 |

### 23.2.3 事件触发状态前置（门控）

**本批 UI 变化：零**（第十九章 §19.2 定案）——门控列默认全部为空，既有事件行为与门控前逐位一致。

- 玩家侧不出现任何「事件被挡」的提示、不计入日志、不进简报。
- **唯一的观察义务**：门控上线后若某类事件明显变少，玩家可能感到「班级变闷」，属体感问题而不是 UI 问题；交由 §23.5 第 4 条观察，必要时回标定调数据（不改 UI）。

### 23.2.4 石头剪刀布（降级版）

| 项 | 内容 |
|---|---|
| 入口 | 他人卡片「动手做事」组：`猜拳` |
| 交互 | 点开后三个按钮 `石头` `剪子` `布`；选中即出拳（无场景动画） |
| 结果（结果页，2 级） | 胜 `你赢了，他有点不服气。` / 负 `你输了。` / 平 `打了个平手。` |
| 限制 | 一课间 1 次，用完灰置 `这节课间玩过了。` |
| 不做 | 手部动画、连胜记录、围观表现（完整版见第二十四章） |

## 23.3 本批特有新组件：学期总结画面

第 30 天期末考结算后弹出，**全章唯一的全屏画面**（§20.1.7 弹层纪律的例外）。

| 区块 | 内容 | 呈现纪律 |
|---|---|---|
| 标题 | `这学期结束了` | — |
| 四格统计 | 学习时长（折算游戏内小时）、成绩净增、交流次数（按行为分类）、关系概况 | **只给玩家自己的数字** |
| 关系盘点 | 双向好感最高的三对（用「你和 X」「A 和 B」这类称呼）+ 玩家关系分桶的分布 | **不给好感数值**，只给分桶名（挚友 / 好友 / 一般 / 疏远 / 敌对） |
| 孤立警示 | 学末仍没人搭话的人（观察层只读输出） | 陈述事实，不带评判 |
| 主结局 | 标题 + 一段文案（按结局档位分派） | 一段话，不写数值条件 |
| 副标签 | 命中即显示，可多个（如「进步奖」「老师眼里的好学生」「总在走廊上的人」） | 标签是荣誉 / 侧写，不是评分 |
| 收尾 | 按钮 `再玩一局` `回主菜单` | — |

- **衔接**：本画面是《学期格局报告》的**切片版**（结构化统计 + 文案模板），不写死叙事（§12）。
- **不算分**：不出现总分、评级、S/A/B 档。
- **可选**（时间富余才做）：主菜单「上局回顾」入口，复用同一画面的只读版本。
- **降级**：时间不足 → 只保留「四格统计 + 主结局标题/文案」，关系盘点与副标签延后（但四格统计与主结局**不可砍**，否则学期没有收束）。

## 23.4 降级与排期

| 优先 | 项 | 降级方案 |
|---|---|---|
| 1（必做） | 周考结果进简报（含玩家名次与进退量） | 不可降级 —— 没有它周考对玩家不存在 |
| 2（必做） | 期末考后必须有一个收束画面 | 只保留四格统计 + 主结局 |
| 3（必做） | 免罚卷在持有区的可见性 + 说明文案 | 不可降级（否则拿了东西看不见） |
| 4（可降） | 周考当日横幅 | → 只留简报段落 |
| 5（可降） | 猜拳 | → 直接砍到赛后（第十九章 §19.4 本就是可选） |
| 6（可降） | 学期总结的关系盘点 / 副标签 / 上局回顾 | → 延后或赛后 |

**排期提示**：本批**依赖每日简报先存在**（简报本身在倒排日历 D13 才做）。若简报延后，周考的落点必须同步后移，不能先做横幅。

## 23.5 验收

1. 四个周考日与期末考都有横幅；结果段落含前 3 名、玩家名次与进退量，且**不含 NPC 分数**。
2. 期末考不发进步奖（只发特等奖）这一规则在界面上不产生矛盾文案。
3. 免罚卷在持有区可见，说明文案与 P3 是否接通消费点一致。
4. 门控上线前后，玩家可见的事件表现无差异（截图对照）；「班级变闷」的体感如实记录进标定观察。
5. 学期总结：不出现 NPC 好感数值、不出现总分评级；弹层可跳过且是当天唯一全屏弹层。
6. 按 §23.4 降级清单走一遍，学期仍有收束。
