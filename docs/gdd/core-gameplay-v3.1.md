# 第一章 游戏概述

## 1.1 游戏定位

《下课十分钟》是一款以高中校园为场景的社交模拟游戏。玩家扮演一名转学生，作为班级社交节点之一（角色池共 24 人，按难度随机抽取 8/16/24 个 NPC 入局，玩家另算，本局共 9/17/25 个节点），在**一个学期（30 个上学日）里每一天的三个课间**通过搭话、递纸条、调侃、安慰、举报等行为，参与并扰动一个自运行的班级社交系统。

游戏核心不是完成固定目标，而是：**你埋下种子，系统自己发酵，长出的班级格局不属于你也不属于任何一个 NPC。** 玩家的每一次操作只是在关系矩阵中拨动一个数值，整个系统自行重新洗牌，涌现出独属于这一局的班级格局。

## 1.2 核心概念

- 玩家不是上帝，而是系统的一部分。NPC 和玩家共用同一套底层规则。
- 即使玩家什么都不做，NPC 之间也会自发社交、传八卦、抱团、对立、崩溃。
- 没有预设剧情、没有固定结局、没有正确答案。谁和谁成了朋友、谁被孤立、哪两个阵营对立、谁在这一天崩溃了——全部从底层规则中涌现。

## 1.3 玩家目标

***用有限的信息，拼出你认为的班级真相。***

玩家不是"观察者"，而是"解释者"：每个课间获取的只言片语、矛盾情报、虚假态度线，都进入玩家的**推理板**。玩家的操作影响班级走向，而推理板记录玩家如何理解这个走向。局末，玩家看到自己拼出的"真相"与系统实际格局的对照——理解对了是洞察，理解错了是这一局独有的故事。

## 1.4 一局流程（一学期 = 30 天）

一局 = 一个完整学期 = 30 个上学日。每个上学日的结构：

1. 上午课间（操作，实时）
2. 上午课堂（发酵过场，快进）
3. 中午午休（操作，实时）
4. 下午课堂（发酵过场，快进）
5. 放学结算（跨天继承 + 每日简报）

第 2 天从上午课间继续，关系矩阵跨天继承

第 30 天放学 → 《学期格局报告》

- 每天三个可操作段 = 上午课间 / 中午午休 / 下午课间；每天实时约 5 分钟，30 天总计约 2.5~3 小时（单日即一个自然游玩/存档单元）。
- 两段上课过场负责"发酵"：课间埋下的矛盾在上课期间继续发展，玩家无法干预。
- 放学后生成《每日简报》并执行跨天结算（关系继承与衰减）；学期末生成《学期格局报告》，回顾 30 天涌现出的班级格局。

# 第二章 涌现主题阐释

## 2.1 两道检验题

本游戏的所有设计都经过以下两道检验题的筛选：

- **检验一**：把涌现的部分换成脚本，游戏还成立吗？如果还成立，主题就只是装饰。
- **检验二**：玩家面对的那个整体，是否拥有任何部分都没有、也没有任何部分想要的性质？

## 2.2 排除假涌现

- **因果链不是涌现**：A 导致 B，B 导致 C，是蝴蝶效应，每一环都能单独解释。
- **数量累加不是涌现**：种满 30 朵花只是部分加在一起，整体没有新性质。


## 2.3 涌现主体：班级格局

没有任何一个 NPC 想要形成小团体、想要排挤某人、想要和另一个阵营对立。每个个体只维护自己的好感、敌对、信任、压力等数值，遵循简单规则。**小团体、孤立、阵营对立、压力崩溃后的关系重塑，是整个系统运行后自发浮现的宏观性质。**

用检验一验证：如果"成团""孤立""对立"换成预设脚本（第 2 个课间 A/B 必然成团、第 3 个课间 C 必然被孤立），游戏失去核心——因为本游戏里**根本没有成团规则，只有读矩阵的标签器**。

# 第三章 时间与节奏系统

## 3.1 一局 = 一个学期 = 30 天

一局游戏覆盖一个完整学期（30 个上学日），每天含 3 个可操作课间段和 2 个上课发酵段。**每段课间的游戏内时间仍是 10 分钟（扣住标题），实时压缩播放；每天实时约 5 分钟，学期总计约 2.5~3 小时。** 关系矩阵跨天继承——今天的恩怨，明天继续发酵。

## 3.2 tick 定义

| **阶段** | **游戏内时长** | **实时时长** | **1 tick** | **每段 tick 数** |
| --- | --- | --- | --- | --- |
| 课间段 ×3 | 10 分钟 | 100 秒 | 6 秒游戏内 = 1 秒实时 | 100 |
| 上课段 ×2 | 45 分钟 | 15 秒（快进） | 30 秒游戏内 | 90 |
- 每天总 tick ≈ **480**（课间 300 + 上课 180）；每天实时 ≈ 3×100 + 2×15 ≈ **5 分钟**（结算界面不计入）。
- 学期总 tick ≈ **14,400**（480 × 30 天）；学期总时长约 2.5~3 小时，单日即一个自然游玩/存档单元。
- 课间 = 高分辨率模拟：全部行为规则 + 玩家操作。
- 上课 = 低分辨率发酵层：只跑规则子集（见 §3.3）。
- 放学后 = 跨天结算层：关系继承 + 衰减 + 每日简报（见 §3.5）。



## 3.3 上课发酵层（低分辨率 · 只跑行为子集）

上课不是暂停，而是「发酵结算层」。上课期间座位固定、玩家不可操作，只运行以下内容：

| 内容 | 上课期间的行为 |
|---|---|
| **共同学习** | 相邻（距离 ≤1 格）且双方主行为均为「学习」的对子，每 `settle_interval`（10 tick）结算一次：好感 +1、信任 +1 |
| **流言传播** | 低频触发（每 3~5 tick 一次，只能传纸条 / 小声说话） |
| **影响力传导** | 继续运行（态度在座位邻近与信任链上缓慢扩散） |
| **压力发酵** | 事件驱动照常；独处恢复减半（每次 −1，上课不是自由活动） |
| **搭话 / 闲聊 / 调侃 / 安慰 / 求助 / 道歉 / 举报** | **禁用**——课间埋下的矛盾上课无法解决，只能积累（但流言仍在暗处扩散） |
| **睡觉** | 若上课前已入睡，则不参与任何交互（见 §10.8） |
| **玩家** | 不可操作，但可查看情报日志 + 推理板（等待变成思考时间） |

> ⚠️ v3.0 快照 §3.3 中的「**座位相邻缓慢加好感**」一条**已废弃**：物理相邻不再直接改数值，只提高自发互动的概率（见 §10.15 注释 5）。

设计意义：

1. **慢积累 + 快相变**：课间埋矛盾 → 上课发酵 → 下个课间爆发，爆发有因果、有铺垫。
2. **"我埋的种子自己发酵"**直接回应检验一：玩家上课时什么都做不了，格局还在自己变。
3. 三阶段形成叙事弧线：上午埋因 → 中午发酵 → 下午爆发/成团，简报可写出"从混乱到秩序"。

## 3.4 数值标定目标（反推所有涓流与事件值）

以每天 480 tick、学期 14,400 tick 为基准，所有数值按以下目标反推，而不是先定数值再凑时长：

1. **好感**：一段友谊从陌生（20）涨到朋友（60）需要 **2~3 天**（多个课间 + 上课发酵 + 跨天继承共同作用），单日不能饱和 → 共同学习的涓流增量（每 `settle_interval`=10 tick 结算一次）与 §3.5 跨天衰减一起标定。
2. **压力爆发**：平均 **每 1~2 天一次**，且集中在每天的第 2、3 段课间（发酵之后），不是开局就爆。
3. **格局弧线（学期尺度）**：第 1 周初步聚散并形成阵营 → 第 2~3 周阵营博弈、孤立与和解交替 → 第 4 周格局稳定或爆发大事件，学期报告才有"从混乱到秩序"的完整弧线。

## 3.5 跨天结算层（放学后）

每天放学后执行一次，让"一天"成为长线涌现的积木：

| **结算项** | **规则** |
| --- | --- |
| 关系继承 | 好感/敌对/信任矩阵完整保留到第二天（今天的恩怨明天继续） |
| 好感衰减 | 当天无互动的对子 ×0.95；有互动的对子 ×0.98 |
| 敌对衰减 | 敌对 ×0.90（时间冲淡矛盾，但不会自动归零） |
| 信任衰减 | 信任 ×0.93（信任需要持续维护） |
| 压力衰减 | 压力 ×0.50 跨天保留（长线心结，不归零）；若当天爆发过，携带"心结"标签 3 天，每天初始压力 +5 |
| 座位重排 | 每天开局可重新选/被调座位，改变相邻格局（**改变的是自发互动的机会，不是直接数值**，见 §10.15） |
| 每日简报 | 生成《每日简报》，归档进学期日志 |

*衰减系数为初始值，需按 3.4 目标批量标定。衰减的意义：关系必须持续经营才维持得住，否则 30 天会全部饱和到 100，涌现提前死亡。*

# 第四章 系统架构总览

## 4.1 三层架构

系统分为三层，各司其职，不冗余、不循环依赖：

| 层级 | 内容 | 特性 |
| --- | --- | --- |
| 行为接口层 | 第十章的人物行为（闲聊 / 搭话 / 举报 / 告密 / 传纸条 / 走动 / 窃听 / 睡觉 / 流言） | 决定这一 tick 谁和谁发生什么互动，快变量 |
| 情绪状态层 | 压力值（唯一累积情绪变量） | 累积-爆发机制，中变量 |
| 底层态度轴 | 好感/敌对/信任（有向矩阵）+ 透明度/性格（个体） | 稳定的关系与人格，慢变量 |

## 4.2 闭环说明

底层态度轴决定规则触发条件（谁能搭话、谁会传八卦、谁能成团）；规则执行后回写底层轴和压力值；状态变化又改变下一次规则的触发条件。玩家的每一次操作，只是在这个闭环中拨动一个节点的数值，然后整个系统自己重新洗牌。

# 第五章 底层态度

## 5.4 透明度（Opacity，O[i]）

- 定义：i 的真实立场被他人准确感知的程度。
- 高透明度（80+）：态度一目了然，是班级的信息源。
- 低透明度（<20）：别人看不透他的真实想法，只能靠猜、靠八卦。
- 玩法意义：直接控制 UI 中态度线的呈现（实线/虚线/消失），是信息可见性系统的第一层过滤。

## 5.5 性格底色（MBTI 四维度）

不使用刻板的16型分类，而是将MBTI四个维度做成0-100的连续数值，每个维度直接修正游戏中的行为系数。24个角色即使MBTI类型相同，程度不同，行为也不一样。

| **维度** | **0端** | **100端** | **影响的规则** |
| --- | --- | --- | --- |
| E/I 外向度 | 极度内向 | 极度外向 | 搭话概率、相邻时的压力敏感度、独处压力恢复速度 |
| S/N 直觉度 | 极度实感（记细节） | 极度直觉（爱脑补） | 流言准确度（S型传得准，N型易传歪）、闲聊话题兴趣 |
| T/F 情感度 | 极度思考（逻辑导向） | 极度情感（共情导向） | 调侃敏感度、安慰效果、道歉接受度 |
| J/P 感知度 | 极度判断（守秩序） | 极度感知（随性） | 小团体归属倾向、被拉拢概率、举报倾向 |

**性格层铁律**：性格只有数值，没有行为；一切角色差异必须能写成这四个维度 + 透明度的纯函数。

# 第六章 统一数值计算公式

## 6.1 好感/敌对/信任的统一公式

所有事件对好感、敌对、信任的影响，全部使用同一个公式：

**Δvalue = base × clamp(1 + Σ(wᵢ × dᵢ), 0.2, 2.5)**

| **符号** | **含义** | **范围** |
| --- | --- | --- |
| base | 事件对该数值的基础变化量（正=增，负=减），策划填表 | 任意整数 |
| dᵢ | MBTI第i维偏差值 = (维度值−50)/50 | [−1, +1]，50为中性 |
| wᵢ | 该事件类型对第i维的敏感度权重，策划填表 | 通常[−1, +1] |
| clamp | 倍率上下限，防止极端性格算爆 | [0.2, 2.5] |

四个维度固定顺序：d₁=E/I, d₂=S/N, d₃=T/F, d₄=J/P。

## 6.2 透明度：种子为准 + 压力系数

透明度不是事件直接加减：

**当前透明度 = 基础透明度 × 压力系数**

- **基础透明度 = 角色种子值（opacity_init）**，见 §11.4 角色池（如苏晴 15、何川 20）；角色差异只来自开局种子。
- MBTI 公式 clamp(50 + d_E × 30 + d_J × 15, 0, 100) 仅作策划新增角色时的默认值生成器，不进运行时。

压力系数：压力0-40→1.0；40-70→0.6；70-90→0.3；90+→按性格，好斗/敏感型爆发=0（封闭），随和/外向型崩溃=1.5（崩溃时什么都说）

| 事件 | 附加状态 | 效果 |

> **关系调制**：上表所有「与特定对象互动」的事件（话题共鸣、被当众调侃、安慰他人…）的 `base` 需乘以 `M(i, s) = clamp((A[i][s] − H[i][s])/50, −1, +1)`——按**净态度**调制：态度不明显时只削弱，**敌对明显压过好感时反转**（同一场聊天可能一方加、一方减）。所有增量写入前**四舍五入到 0.1**。详见 [`../design/统一影响公式.md`](../design/统一影响公式.md) §2.1。

## 7.1 核心原理

好感的方向就是权力的方向：A[i][j] 高，意味着 i 愿意听 j 的话。但传导不是线性求和——**弱态度不扩散，多方拉扯要竞争，传导量有上限**：

1. **阈值（传不传）**：j 对 k 的态度低于阈值时不传导。
2. **竞争归一化（听谁的）**：i 同时被多个 j 拉扯时，按 i 对各 j 的听从度加权平均，而不是简单求和。
3. **tanh 饱和（传多少）**：传导量经过 tanh 压缩，高值饱和。线性传导会让全班态度收敛到同一个均值，抹平分化；饱和让系统存在多个吸引子，派系可以稳定共存。

## 7.2 传导公式

每 `settle_interval` tick（初值 10），对每个接收者 i 和第三方 k：

```
w_ij = A[i][j] / 100                         // i 对 j 的听从度（经性格修正）
A'[j][k] = max(0, A[j][k] - θ_A)           // j 对 k 的超阈值好感
H'[j][k] = max(0, H[j][k] - θ_H)           // j 对 k 的超阈值敌对
net = ( Σ_j w_ij·A'[j][k] - Σ_j w_ij·H'[j][k] ) / ( Σ_j w_ij + ε )
Δ = β × tanh( net / σ )
若 Δ > 0：A[i][k] += Δ       // 好感轴增加，钳制 0-100
若 Δ < 0：H[i][k] += |Δ|      // 敌对轴增加，钳制 0-100（好感不因此扣减，两轴独立）
```

参数表（初始值，待批量局标定）：

| **参数** | **含义** | **初始值** |
| --- | --- | --- |
| θ_A | 好感传导阈值 | 30 |
| θ_H | 敌意传导阈值 | 40 |
| σ | 饱和尺度 | 50 |
| β | 传导系数 | 0.3/tick（好感）、0.5/tick（敌意，敌意更容易传染） |
| ε | 防除零 | 0.01 |

## 7.3 双通道

- **态度通道**：走 §7.2 公式，权重是好感（你模仿你喜欢的人的立场）。
- **事实通道**：不走本公式，走 **流言传播（消息传歪）** 的信任判定——≥70 全信、40–70 半信、<40 不信；这条判定本身带阈值，是非线性的。

## 7.4 传导输入：感知态度（正式条款）

公式中的 `A'[j][k]`、`H'[j][k]` **一律使用"i 感知到的 j 对 k 的态度"**（经透明度 + 信任两层过滤后的值），而不是后台真实值。

含义：**低透明度的人，他的真实态度不扩散，只有他"演出来"的那部分才扩散**——这是"藏得住的人真的藏得住"在机制上的保证。

> 实现细节见 [`../design/统一影响公式.md`](../design/统一影响公式.md) §2.2 与 [`../design/信念矩阵.md`](../design/信念矩阵.md) §11。
## 7.5 涌现现象验证

| **现象** | **新机制如何产生** |
| --- | --- |
| 派系领袖 | 多人对同一 j 的 w 高 → 加权平均中 j 的态度占主导 → 群体复制；tanh 饱和防止无限放大 |
| 墙头草 | 两个阵营 P≈N → net 在 0 附近 → Δ 符号随权重微扰反复翻转 → 态度横跳 |
| 敌意沿链放大 | 每级传导都过 tanh，有上限的放大，不会指数爆炸 |
| 团内隐形等级 | 谁的 w 高谁就是实际话事人，从 A 矩阵直接读出，无需显式角色标签 |

# 第八章 情绪状态层

## 8.1 设计原则

情绪状态层只存压力值这一个累积变量。其他情绪（开心、焦虑、愤怒、低落）全部由压力值、近期事件效价、性格底色派生，不独立存储。

心理学依据：Russell情绪环形模型——所有情绪都可以落在唤醒度（高/低）x效价（正/负）两个维度上。压力值即唤醒度，近期事件的好坏决定效价，两者交叉定位出具体情绪。

## 8.2 压力值

| 属性 | 说明 |
| --- | --- |
| 数据结构 | Stress[i]，个体单值，0-100，快变量 |
| 定义 | 社交焦虑、窘迫、紧张的累积程度 |
| 特点 | 事件驱动不自然涨，达到阈值触发情绪事件 |

## 8.3 情绪标签派生表

| **压力** | **近期效价** | **外向/随和** | **敏感/内向** | **好斗** |
| --- | --- | --- | --- | --- |
| 低 | 正 | 放松、满足 | 安心、自在 | 得意 |
| 低 | 负 | 无聊、无所谓 | 低落、落寞 | 不耐烦 |
| 中 | 正 | 兴奋、活跃 | 羞涩但开心 | 亢奋 |
| 中 | 负 | 有点烦 | 焦虑、不安 | 愠怒 |
| 高 | 正 | 激动、热闹 | 紧张但强撑 | 亢奋到失控 |
| 高 | 负 | 烦躁 | 窘迫、快哭了 | 愤怒、要爆发 |

## 8.4 压力来源与消解

| **事件** | **压力变化** | **结算类型** | **性格修正** |
| --- | --- | --- | --- |
| 被当众拒绝/被打断聊天 | +3 | 事件 | 敏感 ×1.5，外向 ×0.7 |
| 被八卦谣言指向 | +4 | 事件 | 敏感 ×1.5 |
| 被小团体明确排斥 | +5 | 事件 | 随和 ×1.3（更受伤） |
| 被多人同时搭话 | +2 | 事件 | 内向 ×2，外向 −1（人来疯） |
| 信任的人背叛/传秘密 | +5 | 事件 + 状态 | 全性格大幅上涨；附加「心结」3 天，每天 +5 |
| 和高好感+高信任的人聊天 | −3 | 涓流（每 10 tick 结算） | — |
| 独处（不在任何对话中） | −2 | 涓流（每 10 tick 结算） | 内向额外 −1（独处回血快） |
| 离开人群聚集区 | −3 | 事件 | — |

## 8.5 压力阈值与爆发

| **压力区间** | **行为修正** |
| --- | --- |
| 0-40 正常 | 无修正 |
| 40-70 紧绷 | 透明度降低（开始藏立场），对负面事件敏感度x1.5，对示好好感涨幅x0.5 |
| 70-90 临界 | 主动发起闲聊概率骤降，开始回避人群，移动速度变慢 |
| 90+ 爆发 | 按性格触发：敏感型→崩溃趴桌/跑出教室；好斗型→当众指责某人（敌对瞬间拉满）；随和型→沉默退缩，透明度归零 |

爆发是全班事件：爆发瞬间，周围人按性格分裂——高共情的同情（好感+、信任+），低共情的嫌弃（敌对+），八卦型立刻开始传播这件事。一次崩溃自己就长出一轮新阵营分化。

# 第九章 信息可见性系统

## 9.1 核心设计

玩家看到的不是真实数值，而是经过两层过滤的态度信息：

真实态度（后台矩阵）→ 第一层：透明度（这个人有多容易被看穿）→ 第二层：信任（你通过谁获取信息，信息有多可信）→ 你最终看到的信息

## 9.2 透明度控制UI呈现

| **透明度** | **玩家看到的效果** |
| --- | --- |
| 高（80+） | 态度线是实线，颜色清晰（暖=好感，冷=敌对），粗细准确反映强度 |
| 中（40-80） | 态度线是半透明虚线，颜色偏淡，能看出大概方向但不确定强度 |
| 低（20-40） | 态度线时隐时现，旁边带问号，只能猜大概站哪边 |
| 极低（<20） | 完全看不到态度线，这个人是个谜 |

## 9.3 信任值解锁信息

基础可见：所有NPC的态度线默认按透明度显示。

信任解锁：当你和NPC X的信任度过线，X会主动透露他对其他人的真实态度——你看X对别人的态度线时，清晰度强制提升一档。

二手情报：信任度更高时，X还会透露别人对第三方的态度，相当于你通过X解锁了B对C的真实态度线。

信息可信度：X告诉你的信息，准确度 = X的透明度 x 你对X的信任。如果X本身透明度低或者你不信任他，他给的情报可能是错的。

## 9.4 信息可以是错的

透明度低的NPC，态度线可能是假的——他假装对C友好（显示暖色线），实际敌对（后台是冷色）。

信任度低的NPC给你的情报，可能是传歪的八卦。同一个人的态度，你从不同渠道获取的信息可能互相矛盾，需要交叉验证。

这把游戏从观察模拟器变成了信息博弈：你看到的班级格局，取决于你和谁信任度高、谁愿意跟你说实话。不同玩家因为社交路径不同，看到的是完全不同的班级地图。

## 9.5 推理板与矛盾高亮

- **推理板**：玩家构建"班级真相"的工作台，记录玩家对每个 NPC 立场、每个阵营归属、每次事件的解释。
- **矛盾高亮（硬功能）**：任何来源的信息与既有记录冲突时，推理板自动高亮。矛盾来源包括：
1. 某人的态度线与他本人在敏感话题（八卦、评价他人）中的发言冲突；
2. 二手情报与他人的传话内容冲突；
3. 情报与标签层事实（如违规标签）冲突。
- **闭环要求**：假信息必须留下可验证破绽，玩家可以通过交叉验证逼近真相；没有破绽的假信息 = 纯噪声，禁止出现。

## 9.6 标签的可见性

**默认状态：所有标签对玩家不可见。** 玩家通过三条路径获知某人的标签：

| 路径 | 条件 | 能知道什么 |
|---|---|---|
| **① 观察**（靠透明度） | 目标 `O[j]` 达档 | 通透（80+）：全部标签；可见（50–79）：仅「行为标签」；模糊（20–49）与封闭（<20）：均不可见 |
| **② 被告知**（靠信任 + 好感） | `T[j][玩家] ≥ 70` **且** `A[j][玩家] ≥ 50` | 目标**主动告知**自己的标签（愿意让你知道，也认为你值得知道） |
| **③ 推断**（靠行为痕迹） | 反复观察到对应行为 | 推理板解锁该标签（附证据条目） |

关键约束：

- **标签必然留下行为痕迹**：带手机的人课间真的会掏手机，谈恋爱的人会频繁与特定对象互动。否则玩家除了等别人开口别无办法——这违反「假信息必须留下可验证破绽」（§9.5）。
- **三类标签的可见难度不同**：`行为标签`（带手机 / 爱聊天 / 爱学习）最容易被观察到；`关系类`（小情侣）需长期观察或被告知；`秘密类`（泄密者 / 嘴严）几乎只能靠被告知或推断。
- **观察不等于确认**：路径 ① 与 ③ 得到的标签仍需玩家在推理板上自行认定，**可能与真相不符**（见 §9.4）。

# 第十章 人物行为设计

> **行为触发方式总则**（详细算法见 [`../design/NPC行为决策.md`](../design/NPC行为决策.md)）：
>
> | 触发方式 | 判据 | 行为 |
> |---|---|---|
> | **环境类** | 固定基础概率 × 修正系数 | 闲聊、传纸条、走动、窃听、睡觉 |
> | **阈值类** | 确定性（条件满足即发生） | 举报、压力爆发（≥90） |
> | **意向类** | 门槛 → 意向评分 → softmax 采样 | 搭话、调侃、安慰、求助、道歉、秘密交换 |
>
> 三类都必须走统一影响公式结算（§6）；**意向类**中"对方的反应预期"一律取信念矩阵 `B`，自己的立场取真值。
>
> **所有事件的触发条件都是「好感 / 敌对 / 信任 / 透明度 / 压力」的函数**——不存在按天数、轮次或固定剧本触发的「第 N 天必然发生 X」。新增行为时必须给出可判定的数值条件。

## 10.1 流言（附加行为）

1. 触发条件：（1）当A通过对B的流言判定（与好感度和敌对值有关），将对B的流言存入A的记忆，流言倾向根据A对B的好感度或者敌对值生成；（2）举报产生
2. 流言倾向：从-2到2由完全负面到完全正面，0为中立流言，流言倾向只为整数，且无法超出该范围
3. 传播条件：当A记忆中含有流言且A不为流言对象
4. 传播结果：当针对B的流言存入A的记忆，根据流言倾向数值增加A对B的好感值或敌对值（流言倾向大于0，则A对B的好感值加上流言倾向的绝对值；流言倾向小于0，则A对B的敌对值加上流言倾向的绝对值；为0则不改变）
5. 传播偏移：流言具有流言倾向（从-2到2由完全负面到完全正面，0为中立流言），如果传播者对传播对象(好感值-敌对值>0)则流言倾向加一；为0则不变；<0则流言倾向减一
6. 传播方式：（1）闲聊（2）窃听（3）纸条（4）告密
7. 传播限制：（1）单次闲聊只能够传播一条流言，但可以A传播给B的同时B也传给A（2）每条流言都有序号，如果某一条流言已记入过A的记忆则不能记入第二次
8. 流言传播顺序：（1）A接收流言（2）A对流言对象的好感值或敌对值发生改变（3）A对该流言的流言倾向进行更改（4）传播流言并删除记忆/流言自动遗忘
9. 流言消失：（1）一旦通过任何方式传递出去流言会从记忆里清除；（2）流言最多在一个人记忆中停留三个课间，若三个课间流言仍未传播则流言自动清除

## 10.2 举报（主行为）

1. 触发条件：（1）当 A 对 B 的敌对值累积到达阈值，触发举报效果；（2）或特殊行为触发
2. 行为结果：（1）本节课间举报者消失不出现在教室内，与走动到室外相同；（2）举报会大幅提升被举报者的压力值，概率生成针对 A 或 B 的流言（要么直接将一条对A的流言倾向为-2的流言存入B的记忆；要么直接将一条对B的流言倾向为-2的流言存入A的记忆）；（3）举报后A对B的敌对值会下降

## 10.3 告密（主行为）

1. 触发条件：当A记忆中含有对B的流言，且A通过对B的告密判定
2. 行为结果：（1）在本课间B不会移动,A会在课间走向B的位置并对B进行告密（与闲聊纸条不同，是独立的主行为），告密无法被窃听；（2）A与B对互相的好感度增加，根据流言倾向增加A与B对班级其余人的好感值或敌对值（流言倾向大于0则增加好感值，小于0则增加敌对值）；（3）B在被告密后把流言存入记忆并在课间结束后立刻删除

## 10.4 走动（附加行为）

1. 触发条件：下课瞬间立刻执行位置更新
2. 行为结果：角色有概率变更位置

## 10.5 闲聊（主行为）

1. 触发条件：A、B 双方互相处于对方闲聊范围内时，概率触发闲聊
2. 行为结果：（1）闲聊发生后闲聊成员各自判定增加好感度或者敌对值；（2）减小闲聊成员的压力值
3. 闲聊内容可被范围内未处于闲聊状态的同学窃听
4. 闲聊成员中如有成员记忆中含有流言，且流言对象不是剩余的闲聊成员，可进行传播（每一个闲聊成员在本次闲聊中只能传播一次流言）

## 10.6 传纸条（主行为）

1. 触发条件：触发闲聊行为后进行传纸条判定，通过判定闲聊则改为传纸条；否则仍然是闲聊
2. 行为结果：与闲聊一致，但无法被窃听与搭话

## 10.7 搭话（主行为）

1. 触发条件：当A未发生闲聊且闲聊范围内已有人发生闲聊，概率发生搭话判定，通过则加入闲聊；否则A对闲聊二人敌对值增加
2. 行为结果：与闲聊一致

## 10.8 睡觉（主行为）

1. 触发条件：概率触发睡觉判定，通过判定则进行睡眠
2. 行为结果：本次课间无法进行其他任何活动，课间结束压力减少
3. **排除条款**：睡觉中的角色**不参与任何交互**（闲聊 / 搭话 / 共同学习 / 被调侃 / 被安慰 / 被求助…），也**不作为相邻类判定的对象**——坐在睡着的人旁边不产生「共同学习」。唯一的数值变化是课间结束时的压力减少。
4. **策略含义**：睡觉是用「社交机会」换「压力缓解」——你会错过本课间全部互动与观测。

## 10.9 窃听（附加行为）

1. 触发条件：当人物没有进行任何主行为时
2. 行为：捕获自身一定范围内所有人的闲聊内容
3. 行为结果：（1）将闲聊中的流言存入记忆；（2）若窃听者为流言对象本人，则会根据流言倾向改变数值（若流言倾向大于0则压力减小，对闲聊双方的好感值上升；若流言倾向小于0则压力增大，对闲聊双方的敌对值上升；（3）若窃听者为流言对象本人，在窃听后把流言存入记忆并在课间结束后立刻删除

## 10.10 求助（主行为）

1. 触发条件：对目标好感 ≥30（内向型需 ≥50）
2. 发起成本：发起者压力 +2
3. 行为结果：
   - **被拒绝**：发起者压力 +3、对目标敌对 +3、信任 −3
   - **成功**：被求助者对你好感 +2、信任 +3；发起者压力 −2、好感 +3；被求助者进入「被亏欠」状态（3 天内你向他求助成功率 +25%）
4. 性格修正：内向门槛抬高到好感 ≥50、被拒压力 ×1.5；外向门槛降到 20；好斗被拒后敌对 ×2

## 10.11 道歉 / 和解（主行为）

1. 触发条件：双方敌对 ≥30，一方主动发起
2. 发起成本：发起者压力 +3，透明度临时 +10
3. 接受概率 = 对方对你的好感 + 对方随和系数 − 敌对值 ×0.5
4. 行为结果：
   - **接受**：敌对 −5、好感 +3、信任 +2、双方压力 −3
   - **拒绝**：敌对 +2、发起者压力 +4、信任 −3
5. 性格修正：高 F（随和）接受概率 +30%；高 T / 好斗 −25%；敏感型被拒后压力 ×1.5，可能触发爆发

## 10.12 当众调侃（主行为）

1. 触发条件：周围 ≥3 人围观，且发起者对目标好感 ≥40
2. 成本：目标压力 +3，发起者压力 +1
3. 成功概率 = 目标对发起者好感 ×0.5 + 目标外向系数 − 目标敏感系数
4. 行为结果：
   - **成功（玩笑接住了）**：双方好感 +3，围观者对发起者好感 +2，目标压力 −2
   - **失败（玩笑过火）**：目标敌对 +4、压力 +4；围观者按性格分裂——外向 / 八卦好感 +2，随和 / 敏感好感 −2
5. 性格修正：外向成功率 +20%、被调侃压力 ×0.5；敏感被调侃压力 ×1.5、敌对 ×1.5；八卦型失败后把这件事当流言传播（→ 10.1）

## 10.13 安慰（主行为）

1. 触发条件：目标压力 ≥70，且发起者对目标好感 ≥50（内向型需 ≥70）
2. 发起成本：发起者压力 +2
3. 行为结果：目标压力 −5、对你好感 +4、信任 +5
4. 目标正在爆发（压力 ≥90）：效果 ×1.5，但需通过共情判定（成功率 = 随和系数 + 敏感系数 − 好斗系数）
5. 性格修正：高 F + 高敏感（高共情）效果 ×1.5、成功率 +25%；好斗效果 ×0.5、成功率 −20%

## 10.14 秘密交换（主行为）

1. 触发条件：双方信任 ≥60，一方主动发起
2. 行为结果：
   - 发起者把一条秘密告诉对方，对方进入「守密」状态
   - **对方泄密**：发起者对其信任 −5、敌对 +4、压力 +5；泄密者获得「泄密者」标签（3 天）
   - **对方守密超过 5 tick**：双方进入「秘密同盟」——每 `settle_interval` 双方信任 +1（涓流）
3. 性格修正：高 N（爱脑补 / 爱八卦）守密概率 −30%；内向 / 随和 +20%；好斗被背叛后敌对涨幅 ×1.5

> 以上五个社交行为依据 v3.0 规格回填，并按全局数值铁律（`base ∈ [1,5]`、结算类型见 [`../design/统一影响公式.md`](../design/统一影响公式.md) §2.5）改写；它们补齐了 §6.3 事件权重表中「被当众调侃」「安慰他人」等事件的行为来源。

## 10.15 注释：

1. 走到室外的同学不参与任何本次课间的活动
2. 编写的行为顺序也是行为的优先级顺序
3. 所有主行为（包括默认学习）和附加行为在课间前完成决定，课间开始直接执行
4. 闲聊可以减少压力值，若人物没有任何主行为且课间没有发生走动，默认在原位置学习，会增加压力
5. **相邻不直接改数值**：物理相邻只把自发互动（闲聊 / 搭话）的触发概率 ×1.5；数值变化一律来自有内容的事件——包括「共同学习」（相邻且双方都在学习，见 §3.3）。

# 第十二章 玩家操作映射

## 12.1 总原则（玩家不是特权者）

玩家与 NPC **共用同一套行为与同一套判定**：玩家能做的，NPC 都能做；NPC 的判定流程（门槛 → 意向 → 采样 → 效果）对玩家同样生效。差异只有两处：

| | NPC | 玩家 |
|---|---|---|
| 决策来源 | 决策算法（见 [`../design/NPC行为决策.md`](../design/NPC行为决策.md)） | 人的主动选择 |
| 独有能力 | 无 | 仅 3 项（见 §12.3） |

## 12.2 玩家可用行为（与 NPC 完全相同）

| 行为 | 依据 | 行为 | 依据 |
|---|---|---|---|
| 走动 / 换座位 | §10.4 | 睡觉 | §10.8 |
| 闲聊 | §10.5 | 学习（默认） | §10.15 |
| 搭话 | §10.7 | 求助 | §10.10 |
| 传纸条 | §10.6 | 道歉 / 和解 | §10.11 |
| 举报 | §10.2 | 当众调侃 | §10.12 |
| 告密 | §10.3 | 安慰 | §10.13 |
| 窃听 | §10.9 | 秘密交换 | §10.14 |

**时间成本**：每个行为都消耗 tick（一个课间段共 100 tick = 100 秒实时）。走动要花时间、互动要花时间——**课间只有 10 分钟，做不了太多事**。这就是玩家侧天然的操作预算，不需要额外的"每段最多 N 次"限制。

## 12.3 玩家独有能力（仅 3 项）

| 能力 | 说明 |
|---|---|
| **打听** | 消耗一次课间动作，向某人打听另一人的事；透露度 = 他对你的信任（§9.3） |
| **推理板** | 记录与标注、查看矛盾高亮（§9.5）——玩家独有的「显式信念」工作台 |
| **情报日志** | 上课段查看已获得的观测与事件（只读） |

## 12.4 玩家不能做的事

- 直接读写任何数值（好感 / 敌对 / 信任 / 透明度 / 压力）；
- 看到未经 §9 两层过滤（透明度 + 信任）的原始数据；
- 在非课间段操作（上课段只能查看情报日志与推理板）。

## 12.5 一切由数值驱动

玩家的每次操作只是在关系矩阵中拨动一个数值；**其后的一切（谁来找你、谁翻脸、谁抱团、谁崩溃）都由数值条件自动触发**，不存在为玩家预设的剧情分支。
# 第十三章 每日简报与学期格局报告

每天放学生成《每日简报》，第 30 天放学生成《学期格局报告》。每一句话都来自后台日志，不是预制文案。

- 【小团体】列出本局形成的所有簇及成因（如"A、B、C 凑成圈子，因为 C 被 D 排斥后倒向他们"）——数据来自簇标签器与日志。
- 【孤立】列出全程独自坐着没加入任何对话的人及原因。
- 【对立】列出阵营之间的紧张关系及导火索。
- 【大事件】列出压力爆发、举报、秘密泄露等重大事件及周围人的分裂反应。
- 【你的影响】明确指出玩家的哪个操作间接导致了什么格局变化。
- 【真相对照】玩家推理板中的结论与系统实际格局的对照——理解对了是洞察，错了是这一局独有的故事。

《每日简报》聚焦当天发生了什么；《学期格局报告》在每日简报基础上追加：

- 【学期演变】每个阵营、每段孤立、每对宿敌在 30 天内的兴衰时间线；
- 【学期真相对照】玩家 30 天推理结论与学期最终格局的总对照。

简报的核心价值：玩家做了一些操作，然后看到系统自己长出了他没预料到的格局，并且报告告诉他为什么会这样。这就是"看见涌现"。

# 附录：行为速查表

> 本表是第十章「人物行为设计」的速查版，**完整细则（触发判定、数值、记忆与遗忘规则）以第十章为准**。
> 类型说明：**主行为** = 课间主要活动（每角色每课间一项）；**附加行为** = 在主行为之外并行判定。

| 行为 | 类型 | 触发条件 | 结果要点 |
| --- | --- | --- | --- |
| 闲聊 | 主 | A、B 双方互相处于对方闲聊范围内，按概率触发 | 双方各自判定好感/敌对变化；降低双方压力；内容可被范围内未闲聊角色窃听 |
| 搭话 | 主 | A 未发生闲聊，且其闲聊范围内已有人闲聊，按概率判定 | 通过则加入该闲聊（结果同闲聊）；未通过则 A 对闲聊双方敌对值上升 |
| 举报 | 主 | A 对 B 的敌对值累积到阈值，或特殊行为触发 | 本课间举报者离场（同走动到室外）；被举报者压力大幅上升；按概率生成一条倾向 −2 的流言（存入 A 或 B 的记忆）；举报后 A 对 B 敌对值下降 |
| 睡觉 | 主 | 按概率触发睡觉判定 | 本课间无法进行其他任何活动；课间结束压力减少 |
| 传纸条 | 主 | 触发闲聊后按概率判定，通过则改写为传纸条 | 结果同闲聊，但不可被窃听、不可被搭话 |
| 走动 | 附加 | 下课瞬间立即执行位置更新 | 角色按概率变更位置 |
| 窃听 | 附加 | 角色本课间未进行任何主行为 | 捕获自身范围内所有闲聊内容；将流言存入记忆；若窃听者本人是流言对象，则按倾向降低/提升压力与对闲聊双方的好感/敌对，并课间结束后立即删除记忆 |
| 流言 | 附加 | A 对 B 的流言判定通过（与好感、敌对相关），或由举报产生 | 将针对 B 的流言存入 A 的记忆；倾向 ∈ [−2, 2]；A 对 B 的好感或敌对按倾向变化；传播时按传播者态度产生偏移；每条流言最多在一个人记忆中停留 3 个课间 |

> 优先级：行为编写顺序即优先级顺序（见第十章 10.10 注释）。所有主行为（含默认学习）与附加行为在课间开始前决定，课间开始直接执行。
