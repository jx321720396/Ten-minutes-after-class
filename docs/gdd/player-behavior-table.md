## 统一结算规则

- 所有关系轴取值范围为 0–100。
- 与特定对象互动时，常规事件的基础值还要乘关系调制 M = clamp((A-H)/50, -1, +1)，写入前四舍五入到 0.1。
- 正面事件受压力状态系数影响；重大事件通常不做关系调制。
- 透明度通常不是事件直接加减，而是基础透明度乘压力系数；道歉中的“临时透明度 +10”目前未实装。

## 分类说明

- **环境类**：由环境和概率驱动。
- **阈值类**：满足数值条件后触发。
- **意向类**：经过门槛、意向评分和采样后触发。
- **自由状态**：不需要对方同意，主要改变位置、占用或压力。
- **传播行为**：改变流言的持有者、倾向或传播路径。
