## 五类说明

- **交流**：交换话题、流言或情绪信息，主要改变关系、信任、压力或流言状态。
- **合作**：共同完成或支持某件事，通常增加好感与信任。
- **冲突**：造成压力、敌对、信任下降或关系修复分支。
- **休息**：恢复或消耗压力，不直接改变关系轴。
- **移动**：改变位置和可互动范围，本身不改变关系数值。

## 统一结算规则

- 好感、敌对、信任取值范围为 0–100。
- 常规互动的基础变化会乘关系调制 `M = clamp((A-H)/50, -1, +1)`，写入前四舍五入到 0.1。
- 正面事件受压力状态系数影响；重大事件通常不做关系调制。
- 透明度通常由基础透明度与压力系数计算，不作为常规事件直接加减。
