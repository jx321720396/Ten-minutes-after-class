## 当前主文档

**日常阅读从 [老师版移动端 · 按章目录](teacher-mobile/00-总览与目录.md) 开始。** 本目录按当前主策划的 15 章拆分，格式沿用 v4 的编号分册；内容来自老师版主文档，不沿用旧学生版章节。

[core-gameplay-v3.1.md](core-gameplay-v3.1.md) 是当前**老师版玩法唯一事实源**。保留旧文件名以维持链接，正文身份、数值和规则已经重写。

主文档覆盖：老师与 16 名学生、前七天运行与第八天首次考试、压力／动力／今日学业收益、有限干预时间、公开专属被动、鼓励聊天、每课间座位关系、风险预警与失败、监控私聊反馈、涌现检验和实施验收。

规格变更直接改主文档，同批更新受影响文档与 `CHANGELOG.md`；第十五章区分确认事项、整理落点和待裁定参数。

修改后运行 `python tools/split_teacher_gdd.py` 同步阅读分册；`python tools/split_teacher_gdd.py --check` 校验 15 章与目录是否一致。分册不能独立编辑，以免形成两套事实源。
