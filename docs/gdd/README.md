# 玩法设计文档（GDD）体系

> 状态：生效 ｜ 维护者：策划 ｜ 最后更新：2026-10-04

## 1. 唯一事实源

[`core-gameplay-v3.0.md`](core-gameplay-v3.0.md) 是**当前唯一生效的玩法规格**，整合了《核心系统设计文档 v1.0 / v2.0》与评审修订结论。任何冲突以它为准。

v1.0 / v2.0 的原始策划案已归档至 [`../references/`](../references/README.md)（仅作设计历程参考，不再生效）。

## 3. 术语

统一术语见 [`术语表.md`](术语表.md)。代码标识符与中文术语的对应关系在其中维护（如"好感 → `Affinity` / `A[i][j]`"）。

## 4. 修订流程

1. 在 GitHub 用「设计讨论 / 规格变更」Issue 模板发起；
2. 必须回答两道检验题（检验一：把涌现部分换成脚本，游戏还成立吗；检验二：整体是否拥有部分所没有的性质）；
3. 结论落地为 v3.0 的**新版本**（v3.1 / v4.0），旧版本移入 [`../archive/`](../archive/README.md)，并在 `CHANGELOG.md` 记录；
4. 同步更新受影响的 `design/` 与 `data/` 内容。
