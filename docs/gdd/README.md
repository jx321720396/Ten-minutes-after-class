## 4. 修订流程

1. 在 GitHub 用「设计讨论 / 规格变更」Issue 发起（**必须回答两道涌现检验题**：换成脚本还成立吗？整体是否拥有部分所没有的性质？）；
2. 直接改主文档，版本号递增（v3.2 / v4.0）；被取代的旧版移入 [`../archive/`](../archive/README.md) 并在 `CHANGELOG.md` 记录；
3. 同步更新受影响的 [`../design/`](../design/架构总览.md) 文档与 `data/` 参数表；
4. 若改动触及全局数值铁律（常规 `base ≤ 3`、重大 `≤ 5`），PR 描述需说明标定影响。
