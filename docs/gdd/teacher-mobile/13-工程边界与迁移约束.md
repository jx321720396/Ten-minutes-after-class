# 第十三章 工程边界与迁移约束

## 13.1 不变的约束

1. **数据驱动**：角色差异来自公开被动和开局状态；行为逻辑依赖被动配置、关系、环境及当前状态，不判断角色名或固定 ID。
2. **观察层只读**：簇标签、孤立和风险识别不回写任何矩阵。
3. **数值集中**：阈值、增量、窗口、耗时、频率、被动修正放在 `data/`。动力 30／60、关系 +1／−1／+5 也要配置化。
4. **内核纯净**：模拟内核只接收数据和命令，不依赖 UI、表现节点或引擎导航类型。
5. **可复现**：随机数使用带种子的 `RandomNumberGenerator`；同种子、同命令序列得到相同结果。
6. **唯一结算**：事件、每课间关系和跨天成绩各自去重；矩阵访问走访问器，表现层不能直接改数值。

## 13.2 数据与存档

老师版应包含学生阵容、公开被动、好感／敌对矩阵、压力、动力、当前成绩、今日学业收益及明细、当前活动、座位／临时位置、物品、老师位置与行动占用、交流目标、风险所需历史、相位时间和随机状态。玩家手动关系标注与获取过的线索作为独立观察／笔记数据保存，不替代真实关系矩阵。

保存和恢复需要保留未结算收益及结算去重信息，避免读档重复加成绩或重复发被动。学生版存档含第十七个玩家节点和被删除轴，不能未经版本检查直接作为老师版存档读取。

## 13.3 实现状态

监控界面仅保留观察、只读工具与关闭监控入口，右侧老师行动／当前对象纸卡仅在实际进入教室时显示；监控点击学生直接查看档案，不触发现场干预。

**2026-10-16 核查基准**：`main-mobile` 的 `3f52cd0` 为结构迁移基线，当前 HEAD 为后续 `c0a3f66`。本节修正状态，不改变正文目标规格；逐项 M1-A/B/C 缺口见 [路线图](../../production/路线图.md)。

**结构迁移已有实现**：`3f52cd0` 删除第十七个玩家节点、P0 座位及玩家交互服务，运行时为 16 学生和 16×16 好感／敌对矩阵。四维、透明度、信任及相关旧行为已清理，学习自座与闲聊范围前置已补回。旧玩家 UI 部分保留停用；不能再称模拟仍为待迁移的学生版，也不能因此宣称全部老师版完成。

**规则已有实现**：后续提交落地压力／动力／收益独立状态、普通跨天成绩及 −20／−10、30／60 课间状态、学习／娱乐／游戏单位与中断折算、压力→动力一般联动；`c0a3f66` 补上课 >30 学习／≤30 自由、段内粘性及学习收益。`TeacherCommands` 有召唤／遣返／办公室聊天／换座计时、首次进入加压、训斥、安抚与表扬及命令上课挂起；打听／鼓励仅计时，没有相应效果。

D04 座位关系已在课间末清理前一次结算，含资格过滤、睡觉视为学习、好感 +2／0／−1 与单向敌对 +5（`_settle_seat_relations`）。课间末采样是当前实现选择，仍待策划确认。D05 已配置第八天／450、考前 +20／考后 −30，时间卡目标已同步；考试日从 2026-10-19 起除了跳过普通决策、课间关系与压力涓流，还跳过段首睡觉、单位结算与两份上课固定收益，学生当天不产生任何活动、也不产生学业收益（崩溃休息者平时同样不发上课收益）。D06 风险依据实际事件做预警、连续窗口及退学查询；霸凌还要曾经打过一次架。D07 为课间开始的吵架／推搡／打架，友善聊天敌对 −2，调解在无冲突时双向 −10。证据为 `risk_monitor.gd`、`harm_events.gd`、`exam_settle.gd` 及 `test_teacher_rules`、`test_seat_and_exam`、`test_risk_and_harm`；两侧内核已有同步实现，用例存在不等于本轮全部验收通过。

**压力涓流现状（2026-10-19）**：`_stress_drip()` 只剩环境层的偏离氛围通道，而 `environment.csv` 的 `deviance_k` 现为 0.0，该通道也处于关闭状态。原「默认学习 +0.4／独处 −2」两条滴注是学生版 §8.4 遗留（`behavior_probs.csv` 的 `study_stress` 于 2026-10-09 由 1.0 标定到 0.4、`alone_stress` 于 2026-10-05 引入），老师版正文没有这两条，且恒真的 `_doing_study()` 使独处分支从未触发；两个键已从 `behavior_probs.csv` 删除，GDScript 与 Python 基准同步。**老师版的学习加压尚未接入**：`w_events.csv` 的 `study_stress`（base 3）仍无调用点，学习暂不产生压力，压力只来自邻座学习涓流、娱乐减压与伤害等事件；接回时机与口径（D02 每 20 秒学习单位结算，或三轴算账建议的 2.5／20 s 且不联动动力）待定。

**未实现及最新规格差异**：公开被动的多人聊天覆盖与去重口径、百事通的消息结算（打听消息系统未建立，见 §10.2）、鼓励的一次交流目标、打听效果、完整搜包／没收、现场制止入口、整局存档及读档去重尚未完成。初始成绩已按镜像配对落地（330–530、开局均分恒为 430、整数分）。`_check_breakdown` 仍允许压力 <70 当日恢复，`_settle_day` 没有崩溃次日 −50／−50 替代分支；心结仍来自旧概率爆发与关系扩散，不是 §5.3 的真实崩溃时本人及正交邻座三天规则。

**移动端与闭环边界**：办公室、监控、教室和档案已有界面；`office_hub.gd` 的召唤、训斥、遣返、调座位、调解与「去教室」均已接入内核命令（2026-10-16 起入口即生效，不再有未接入提示）；安抚、表扬、训斥、送回四个会面按钮落在可滚动区内，面板放不下时上下滑动。档案动力／今日学业收益已直接接入内核 `vitality()`／`gain_today()`，打开时持续刷新且不暂停；班级概况显示真实平均动力与平均学业收益。公开被动已接入内核并在档案显示（§10.2 实装落点）；交流目标、趋势与干预明细仍有占位。`_class_failed()` 已可查询退学或考试不达标，但尚未连成完整辞退终止与原因反馈。`term_record.gd` 和考试报告仍有末位学生被当成“你”的旧路径，日末收益／干预明细未完成。工作区另有未提交风险关注卡片接入，不计入上述提交完成量，本次保留。

**待裁定与验收**：延后命令目前保留剩余时间；考分仍含旧噪声和压力扣分，考试日跨天仍走普通减量、旧爆发／心结路径，需对照“仅考试”收口。活动时长、加入同步、风险反馈及多种子标定尚未完整验证（成绩整数口径已于 2026-10-18 定为整数值并在内核落地）；目标已改为逐次递增（第 1 次 450、后续 480／500／520），首次考核的实测记录都在旧目标 380 下取得，尚未按新目标复标。旧测试、旧标定及局部实现不构成老师版闭环或真机验收通过证据。
