# 第七章 鼓励与交流目标

## 7.1 鼓励交流与指定交流（D09，2026-10-17）

老师可鼓励学生自主找人聊天，或指定聊天对象；鼓励仅产生一次临时目标，不直接加好感、动力或学业收益。实际聊天才按当前状态和正常活动规则结算。

## 7.2 生命周期与等待

1.有效期：老师完成20秒鼓励后，生成一次聊天目标，有效期为4次课间，包含当前课间。跨上课保留目标，考试日不产生课间次数；上课及老师未完成命令按主策划的延后规则处理。

2.忙碌等待：被鼓励者和目标都符合参与条件后，发起一次聊天尝试。目标忙碌时等待活动结束；等待不占用对方、不保证优先接纳，也不能绕过原活动条件。被鼓励者等待期间仍按正常状态行动，在下一可行动时尝试，不强行打断锁定活动。

3.未指定对象：作为老师鼓励的特殊选人规则，优先选择距离最近、正在娱乐且符合聊天条件的同学；不同于一般自主找伴的最高好感优先。并列使用带种子的随机选择；没有合适对象则等待，不拉走学习／游戏锁定或崩溃者。

4.一次尝试：完成聊天、被关系拒绝或有效期届满后，目标结束。条件不满足（忙碌、空间不够等）只是等待，不当作关系拒绝，也不无限重试已经被拒绝的同一目标。

5.重复鼓励：同一名学生已有未结束的鼓励目标时，重复鼓励无效，不覆盖目标、不扣20秒；完成、拒绝或到期后可以再次接受鼓励。不是要求对方也有鼓励目标，不把同学锁为某人专用。

6.反馈：显示剩余课间次数、指定／自主对象、等待原因及完成／拒绝／到期结果。鼓励本身不直接加好感、动力或学业收益，真实聊天才结算正常效果。

## 7.3 边界

有效期以课间编号去重计数。鼓励完成、关系拒绝、到期均需可见日志；同一学生的未结束目标不叠加。一般自主找伴仍最高好感优先，“最近娱乐对象”仅是未指定鼓励目标的特殊规则。
