# 第十章 公开专属被动

## 10.1 角色差异

每名学生有一条开局配置的公开专属被动，学生档案与相关行为预览直接显示效果。用可计算的差异替代隐藏性格四维，玩家可以据此调整座位、学习安排和交流目标。

角色差异来自配置，统一规则读取被动。禁止在行为脚本中判断角色名或固定角色 ID 来实现加成。老师选择某名学生作为操作目标不属于角色专属逻辑。

**实装落点（2026-10-17，一律按真实完成事件结算，不按画面帧或按钮点击）：**

| 被动 | 生效点 |
|---|---|
| 专注 / 自律 / 收放自如 | 学习单位结算（每 20 秒一次）：收益增减翻倍 → 累计整数减半损失 → 动力消耗少 2 |
| 乐观 | 娱乐行为**自然完成**时（不按 10 秒减压单位重复发） |
| 健谈 / 讨人喜欢 / 不记仇 / 善解人意 | 友善聊天完成时，以完成者对会话内每个其他成员结算一次（沿用基础敌对修复的既有口径） |
| 听劝 | 老师训斥**实际完成**后（办公室训斥与全班训斥都算） |
| 卷王 / 玻璃心 | 邻座学习压力涓流：来源侧与目标侧各 +100%、加法叠加；玻璃心另对伤害这类同学来源的正向加压 +100%，减压不放大 |
| 群策群力 / 善于吸收 / 正反馈 | 跨天把当日学业收益并入成绩时：群策群力先加当天收益 → 善于吸收加成绩 → 钳制成绩上限 → 正反馈按实际提高量给动力 |
| 弹簧 | 每次获得正向压力时累计；只加动力，不反向产生压力、不递归触发 |
| 百事通 | 档案展示「一次打听 6 条消息」；打听消息系统未建立，运行时不结算 |

**本次实装采用的整理口径（与下方待确认项的关系）：**

- **群策群力**的日结顺序按「先并入当天学业收益、再转成成绩」；退学学生仍按关系矩阵计入（本局全池入局，退学不移除关系数据）。
- **弹簧**的累计余量跨天保留、新局清零；减压不回退已发放的动力。
- **正反馈**按钳制后**实际提高量**的整数部分折算动力；开局初始成绩赋值不算提高。
- **收放自如**的累计余量跨行为中断与跨天保留，新局清零。
- **专注与收放自如**不会落在同一名学生身上（一人一条被动）；当前结算顺序为先翻倍、再累计减半，只有改配置后才需要重新确认。
- **群策群力可见性**只做只读展示（学生档案「状态与记录」页列出其他同学对本人好感），不写任何关系矩阵。

待后续明确的结算边界（不在本次记录中擅自决定）：

- **卷王／玻璃心**：各自额外 +100%，加法叠加。基础压力为 5 时，单独生效为 5×(1+100%)＝10；来源卷王、目标玻璃心同时生效为 5×(1+100%+100%)＝15，不是 20。只修正符合各自来源条件的正向压力，不扩大到减压或老师等其他来源；最终数值仍按统一边界钳制。
- **群策群力**：日末一次、严格 >60、方向为他人对本人已按用户本次修改明确；新增他人对本人好感的可见性。与当日收益转成绩的先后顺序，以及退出班级的同学是否计数，仍待确认。
- **正反馈**：所有来源的成绩提升均触发已明确；按实际提高量计算的方式、小数成绩及成绩钳制边界仍待明确。
- **弹簧**：累计获得压力已明确；不足 5 点的累计余量何时重置、减压是否影响累计，以及按钳制前增量还是实际获得压力计算仍待确认。动力额外增加与一般压力联动须区分，不能递归触发。
- **收放自如**：只减免真实存在的学业收益损失，自由娱乐原本不扣分就不产生奖励。整数累计口径：原本连续两次各损失 1 分，实际依次扣 0、1；原本一次损失 2 分，实际扣 1。累计余量跨行为中断与跨天保留，新局清零，防止反复重启行为或跨天刷新减免。此为“不出现 0.5、允许累计”的整理口径。
- **专注**：收益正负方向均翻倍已明确，不再将“减少”解释为动力消耗。直接成绩变化与今日学业收益分开，不将最终成绩再重复翻倍。
- **百事通**：6 条已明确；普通同学的基础消息数、消息不足 6 条时的处理、重复打听的去重和消息可信度需随打听系统一起确定，不为凑数伪造关系事实。
- 其余被动的多人聊天覆盖、真实完成／日结触发点、下限及重复结算保护，随最终规则一起明确。娱乐与游戏状态的可选范围已改由 `data/rules/behavior_probs.csv` 的概率决定（见 §5.1 实装口径），不再固定单一娱乐。老师训斥、表扬、安抚按实际完成触发，不按点击触发。

最终参数应集中到 `data/`，经统一事件规则读取；角色对应关系按 §10.4，仅是数据分配，不按角色名推断或编写专属分支。

## 10.3 清晰与平衡

- 一条被动明确一个效果、一个触发单位、作用对象和生效点。
- 被动按真实完成事件结算，不按画面帧数或按钮点击结算。
- 行为预览显示基础值、被动修正和预计结果，例如“学业收益 +3＝基础 +2＋专注 +1”；此例仅解释展示方式，不定基础值。
- +1 的强度必须结合基础收益和频率标定；基础收益为 1 时，额外 +1 就是翻倍，不能因绝对数小便认定差异轻微。
- 不新增隐藏人格倍率替玩家解释结果，也不让某个被动保证固定社交结局。
