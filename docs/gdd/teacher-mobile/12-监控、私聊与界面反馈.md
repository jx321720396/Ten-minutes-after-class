# 第十二章 监控、私聊与界面反馈

## 12.1 核心可见信息

**2026-10-18 移动端全屏与座位档案**：同学档案入口使用全屏 4×4 网格，按当前真实座位从讲台方向逐排排列 16 名学生，头像复用项目档案画像。查看档案与调整座位可在同页切换；调整模式依次点击两名学生，显示两人姓名与选中边框，点击“确认换座”才提交既有老师命令，可取消选择。换座仍按 §6 的耗时、忙碌限制及上课延后规则执行，不直接写座位或关系矩阵。档案详情、关系对象选择、百科、推理板、班级概况与风险详情、暂停、设置、关于和新局确认采用全屏界面，保留触摸及返回入口；打听结果也使用全屏纸面。界面不会因此额外暂停模拟，百科与既有系统暂停规则保持原口径。检验一：这些布局与确认步骤不替代学生自主互动，座位对后续接触与关系结算的影响仍由现有内核计算。

**2026-10-14 关注卡片实施**：第三张“需要关注”纸卡已接入真实高压名单与实际活动人数。高压预警阈值从 data/ui/attention_card.json 读取，当前试用值为 80，不等于崩溃或辞退判据；点击名单可进入学生档案。学习／娱乐／其他人数按实际活动、在场与移动状态归类，排除旧玩家，不由平均动力推算。普通争吵只接受真实事件记录，按事件 ID 去重并以最后状态为准，已结束不计；当前模拟尚未提供这些记录，因此显示“—”，不从敌对、打闹或压力爆发推断争吵。三张卡片按可用屏高缩放，详情保持完整视口。验收见 [关注卡片验收](../../qa/关注卡片验收-2026-10-14.md)。

老师明确看到学生的压力、动力、今日学业收益、当前成绩与公开被动，以及班级平均成绩、周考目标和倒计时。

**2026-10-14 分步 UI 实施**：左上角纸卡已显示实际日期／阶段、缩短式剩余时间条（不显示具体分秒，剩余不超过 20% 时变暖橙并提示即将上课／下课，暂停时冻结并显示已暂停）、首次周考倒计时、试用目标均分及实际差距。周考当天显示“今天周考”，之后显示“首次周考已结束”；均分仅统计学生，不计旧玩家节点。目标从 data/ui/time_card.json 读取，历史试用值 525，不接入辞退判定；现行时间卡配置已同步第八天／450，考核内核亦已实现；辞退流程和考分口径仍待验收。班级概况纸卡也已接入真实平均成绩与平均压力，并替换原音量卡的位置；其“查看全部概况”可打开只读详情。平均动力和今日平均学业收益在缺少老师版数据时显示“—”，不从压力或旧成绩增长反推，数据齐备后通过快照接入。卡片布局与文案由 data/ui/class_overview_card.json 配置。动力、收益已有内核，老师操作已有部分命令；界面快照、操作接线与完整效果尚未完成（§13.3）。验收见 [时间周考卡片验收](../../qa/时间周考卡片验收-2026-10-14.md)。

**2026-10-16 动力 UI 接入**：档案直接读取 `vitality()` 与 `gain_today()`，实时展示动力条、今日有符号净收益和已有收益计入后的次日成绩预览；打开与关闭档案不持有或释放暂停。时钟快照提供 `class_average_motivation`／`class_average_academic_gain`，班级概况与详情直接显示真实均值。公开被动、目标、趋势与收益明细不在本批接入范围。验收见 [动力 UI 接入验收](../../qa/动力UI接入验收-2026-10-16.md)。

今日学业收益与当前动力分开显示，例如“动力 40｜压力 75｜今日学业收益 +5”。“预计明日成绩”读取已经累计的收益，不把它当作当前成绩，也不凭空保证未来未发生的收益。

## 12.2 监控与私聊分工

- **监控**：复用当前教室场景，观察谁在学习、娱乐、聊天、移动，谁接触谁，谁在打扰或伤害谁。
- **私聊打听**：获取具体关系与近期矛盾，记录对象、方向、来源和发生时间，帮助老师安排交流与调解。
- 不再以透明度或信任阈值遮挡信息。真实关系不默认全量公开，打听数量与信息规则见 §12.7；获取过的旧记录不能伪装成当前实时关系，未知不能当作中立。

## 12.3 行动反馈

行动完成后展示实际变化与来源。巡视加压、训斥加动力、被动额外收益、聊天拒绝和调解减少敌对都需要可见反馈。

**2026-10-18 共同活动朝向表现**：16 名学生各有与现有正面对应的站立背影和坐姿背影。同一真实共同活动中，靠近镜头者转身面向后方同伴，按当前站立／空闲坐姿调用对应背影；横向并排不强制转背，活动结束恢复对应正面。多人活动按其他可见静止成员的平均位置确定朝向，设站位缓冲避免来回闪切。学习姿势、行走和办公室离场不被聊天背影覆盖。朝向仅表现层读取真实会话与站位，不改变活动成立、关系或结算；资源绑定与朝向阈值集中于 `data/ui/student_poses.json`。

**2026-10-18 共同活动靠近与在座聊天**：已成立会话的离座静止成员可通过现有导航靠近同伴，目标中心距 0.82 m，仍遵守 0.72 m 最小间距、家具阻挡、可走面和在途目标预留；路径不安全则保持原位，不瞬移或穿越人物。在座者及学习者不被拉离座位。前后桌聊天只允许同列紧邻、双方都在本座位者；在座距离上限由 1.8 m 校正到 2.1 m，覆盖移动端教室真实 2 m 排距，非在座聊天范围仍为 1.2 m。距离参数分别位于 `data/rules/movement.csv` 与 `chat_space.csv`，关系效果和结算规则不变。

鼓励显示“交流目标：与某某聊天一次”，并记录完成、拒绝或未完成的原因。打开只读档案或切换监控目标不得产生新的关系效果。

## 12.4 每日简报

简报至少包含：个人与全班的学业收益明细、结算后的成绩变化、压力与动力趋势、已发生互动及关系变化、鼓励执行结果、风险预警和老师干预记录。

朋友圈等标签来自实际关系；解释可以指出形成原因，不能用预制剧情替代事件日志。

## 12.5 档案中的玩家手动关系标注

**2026-10-14 移动端档案实施**：现有档案已替换为老师版纸张布局，加入当前成绩、压力、动力、今日学业收益四张卡片，当前活动、座位、公开被动、交流目标，以及“人际关系／状态与记录”页签。移除旧玩家关系对象、信任轴与学生闲聊入口；“叫来办公室”跳转已有办公室选择器，不执行尚未接入的私聊数值效果。关系采用每轴独立的“未判断／较低／一般／较高／很高”触摸档位，可查看反向，笔记不写真实矩阵。旧运行时可读取成绩、压力和实际活动；缺少老师版动力、收益、被动与目标快照时显示“—／暂无记录”，不以旧性格或学习累计推算。本局笔记支持界面重建保留与 JSON 往返；整局存档和继续尚未接通，不能宣称跨启动恢复。详见 [老师版同学档案验收](../../qa/老师版同学档案验收-2026-10-14.md)。

同学档案对每个有向学生对子显示**一组当前好感／敌对标注**，每一轴分别注明来源和记录时间。没有真实消息时，由玩家自行推断与选择；获得真实消息后，覆盖对应方向、对应轴的当前标注，不要求把消息与推测分成两套并排数值。

- 打开学生甲的档案，选择学生乙作为关系对象，明确当前方向为“甲 → 乙”；反向关系单独保存。
- 玩家分别标注好感与敌对，两轴独立，可以同时判断为较高。
- 未标注且未获知的轴显示“未判断”；玩家可以修改或清除自己的推测。未判断不等于中等或零。
- 获得真实消息时，只覆盖消息涉及的方向与轴，并显示“已获知”、获取时间与来源。只获知好感不覆盖敌对，甲对乙不覆盖乙对甲。
- 消息表示获取时的关系，不实时同步后台。玩家以后再次手动修改该轴时，来源改为“我的推测”；获取过的消息继续保留在历史记录中。
- 当前标注、来源、方向、修改时间与历史消息随本局存档保存；它们属于观察／玩家笔记，不写真实关系矩阵，不改变学生行动、压力、动力、风险或随机序列，不根据隐藏状态即时判定推测对错。
- 不恢复信任、透明度或学生对老师的关系轴。

交互整理建议采用每轴独立的档位选择：“未判断／较低／一般／较高／很高”，适合移动端直接点击；这是界面建议，不把档位强行换算成精确后台数值。最终档位、是否支持额外数字估计与备注，需在界面实施前确认。

## 12.6 推理板（2026-10-19 移除）

每日「推理板」界面已整体删除（场景、脚本、配置、日末自动弹出与办公室／档案／教室入口一并移除）。原因：它的公开事件白名单（chat／comfort／tease／apologize／roughhouse）与内核事件流对不上——内核只发 `roughhouse` 且 payload 不含对方索引，事件区长期为空，板上只剩玩家自己在档案里打的关系标注；同时每日放学强制弹出会暂停世界，收益接近零。

档案内的关系标注继续保留为玩家笔记：只写进 `GameState.profile_notebook`，不回写真实关系矩阵，也不参与任何判定。多人关系的推断改由玩家自己结合档案标注、关注卡片与每日简报完成。

## 12.4 班级压力灯光（2026-10-15）

教室环境光与室内灯只读全班学生平均压力，排除迁移期间的旧玩家节点。低压为奶油暖色，中压为灰杏色，高压为低饱和砖红色；按平均值连续插值并平滑过渡。时段窗光继续独立生效，界面不参与染色，个人高压预警保留。色值、压力控制点与过渡时间统一在 `data/ui/classroom_art.json` 的 `pressure_light` 配置，不作为崩溃判据。灯光不改变压力、关系、行为或随机数；移除灯光反馈不改变模拟结果，通过检验一。

## 12.5 考试日漫画演出（2026-10-18）

进入配置指定的考试日后，全屏播放“发卷—答题—收卷”三格漫画，按配置自动展开，也可点击或按确认键提前推进。演出覆盖普通教室，冻结世界，不展示普通上课／下课转场，也不接受现场干预。漫画播完立即完成考试日既有内核 tick 与结算，随后显示已有成绩 UI：真实均分、考核目标、差距和成绩明细；未达标接原有辞退结果。考试日期与分数仍读取规则配置，不由漫画决定。

漫画不新增学生姿态，不规定特定学生表现或结果，不改关系矩阵、不消耗展示随机数。演出时长、分镜区域和文案位于 `data/ui/exam_comic.json`，素材位于 `assets/illustrations/exam_comic/`。检验一：删除漫画后，同一考试日仍可通过同一内核 tick 与结算得到同一成绩；漫画只呈现固定考试制度，不替代学生涌现行为。

## 12.7 打听与信息权限（D10，2026-10-17）

1.默认可见：学生当前压力、动力、今日学业收益、公开被动、已结算的个人成绩及班级平均成绩，以及实际状态和可观察行为。成绩读取上一日结算后的当前成绩，不把今日收益提前算入。开局尚无上一日时显示初始成绩。

2.打听耗时20秒；全班每个课间最多成功打听一次。每次提供一条按下列优先级选择的消息，另外提供最多3条被打听者的有向关系信息，不是总共只给一条。

3.优先消息顺序：正式霸凌消息、正式孤立消息、敌对隐患线索、低好感隐患线索、手机提示、MP3提示、零食提示。选择该学生可提供且尚未告知或已有实质变化的最高优先级消息；不反复用同一条未变化的警告占满后续打听机会。

4.正式风险消息读取已有风险记录：“某同学最近被欺负”“某同学最近持续被排斥”。不要求任意受访者都全知，不用“我们都不想和他玩”替所有人表态。受访者具体知情范围尚待确认；未接入时不得把消息伪装为亲历。

5.敌对隐患线索：至少2名其他学生对同一学生敌对大于50，可提供“某几名同学最近对他不满”。这只是关系线索，不直接判霸凌，不代替两天实际伤害证据。

6.低好感隐患线索：至少13名其他学生对同一学生好感低于20，可提供“他最近与不少同学关系疏远”。该类打听线索仅在超过一周后开放；具体日次边界需与游戏日历统一。此限制不影响既有孤立正式判定、风险预警及关注卡片显示。

7.物品提示：被打听者对某对象敌对大于40，且知道对方携带手机／MP3／零食时，可报告该物品。打听只提供信息，不自动增加任一方向敌对，不自动没收。若以后加入告状被发现，应另设真实事件。

8.关系信息：每次从被打听者对其他学生的关系中提供最多3条，方向为“被打听者→对象”，每条只说明好感或敌对一轴，优先未打听过的信息，不足3条则全部提供；选择使用带种子的随机数。具体披露精度（数值或档位）待确认。

9.无消息时说明“暂无新的相关消息”，不等于什么都没发生或所有关系安全。关系信息可独立提供；全部信息带来源及获取时间，不实时同步，不把未知当作中立。

10.关系消息接入档案时仅覆盖对应方向、对应轴的当前标注，保留历史；打开档案或打听展示本身不回写真实关系。风险预警仍通过关注卡片／简报主动反馈，不要求先打听才能发现。
