# 第一章 游戏定位与目标

## 1.1 玩家身份

《下课十分钟》是一款以高中班级为场景、以涌现为主题的老师管理模拟游戏。玩家扮演刚入职学校的实习老师，受到领导重视，被提拔为班主任。

玩家通过教室监控观察学生，也可以进入教室巡视、调座位、检查书包和没收物品，或把学生叫到办公室私聊。学生根据自身数值、公开被动、当前关系与环境自主行动。

## 1.2 两项任务

1. **提高班级平均成绩**：第八天进行第一次考试，目标均分 450，之后三次分别递增到 480 / 500 / 520；平均成绩不达当次目标，老师被辞退。
2. **维持班级安全与关系**：防止持续霸凌、孤立与崩溃导致退学。风险有预警与处理窗口；退学触发老师被辞退，具体判据见第十一章。

玩家需要在有限时间内兼顾学习、学生的承受能力和关系变化。推动某个学生学习，可能增加他的压力；安排聊天，可能改善关系，也会消耗学习时间。

## 1.2.1 上任漫画与考试制度（2026-10-18 确认）

学校每月一次大考、每周一次小考；这是开场对考试制度的介绍，不新增尚未裁定的后续目标或月考结算实现。接班后的第一次考试安排在七天后（第八天），班级平均分不能低于学校本次均分标准 **450 分**；未达标辞退。450 是本次固定考核目标，不从其他班级动态模拟生成，也不新增各科门槛。

移动端首次新局展示四页斜切漫画：临时接班、考试安排、成绩考验、另一项责任。每页第一格先出现，其余分镜每隔 2 秒依次滑入淡显；播放中每次点击只展开下一格，并重置 2 秒计时，整页展示后再次点击翻页，最后一页再次点击开始任职。整页不会自动翻页；漫画期间时钟 hold，结束、跳过及移除均释放。设置支持重看，老师版入口不再播放学生版教程。

漫画对白与考核说明内嵌于整页图片，运行时不额外创建对话框。考核台词明确学校标准为 450 分，首次考核班级均分需达到 450 分。

漫画仅交代任命、考核与安全职责；课堂插画属于风险示意，不把任何学生写成必然霸凌、孤立、崩溃或退学。检验一：移除漫画不改变学生自主行为、关系矩阵与老师干预效果。

## 1.3 班级规模

- 角色池固定为 **16 名学生，一局全部入局**。
- 老师是玩家控制的管理实体，**不作为第十七个学生社交节点**。
- 学生之间保留好感与敌对两张有向矩阵，尺寸为 16×16。
- 标准座位关系以 4×4 学生座位为基础。`3f52cd0` 已从座位配置和教室场景删除讲桌旁 P0 第十七座及其书包，只保留 P1–P16，不保留旧玩家座或皇帝位加成。

## 1.4 单局范围

本轮没有另行裁定学期长度，保留原有 **30 个上学日**与每日三个课间、两个上课段的时间骨架。第八天考试是第一个明确考核节点；第七天为考前日。

前七天运行加第八天考试可作为最先验证的区间，不能据此把正式学期直接改成七天。后续周考安排、目标递进及学期成功收束条件列入第十五章的待裁定事项。
