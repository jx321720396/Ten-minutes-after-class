# 第四章 数值定义

## 4.1 三个独立数值与当前成绩

个人成绩按整数分展示，只有班级平均成绩保留小数；个人收益结算后的成绩预览也显示整数分。2026-10-14 档案呈现已采用四舍五入，显示格式不回写旧运行时的浮点累计；老师版内核成绩结算口径在迁移时统一处理。

| 名称 | 含义 | 主要职责 |
|---|---|---|
| **压力** | 当前承受的负担 | 风险、崩溃及承受空间 |
| **动力** | 当前学习的意愿 | 决定默认学习或娱乐状态 |
| **今日学业收益** | 当日累计、次日将计入成绩的净变化 | 记录真正发生的学习收益与娱乐损失，允许正负 |
| **当前成绩** | 已完成跨天结算的成绩 | 计算班级平均成绩与周考考核结果 |

压力与动力按 0–100 的个体量管理；今日学业收益是有符号累计量，以成绩分数计，不能按 0–100 钳制。学生当前成绩、班级平均成绩与周考目标采用高考总分尺度，本次先按 750 分制整理，个人成绩范围为 0–750；总分、初始分布及具体收益幅度放入配置。**个人成绩恒为整数分**（2026-10-18 裁定）：开局取整后镜像配对、日结并入净收益与被动加成后四舍五入（half-even，与 Python `round` 对齐），班级平均成绩保留小数。目标均分是全班 16 名学生总成绩的平均目标，不是全班成绩之和，也不默认要求达到满分。

一般事件压力每增加或减少 1 点，动力同向改变 1 点；明确注明“单独”变化的效果除外。反向不成立：单独增加或减少动力不影响压力。两项独立存储并限制在 0–100，不由其中一项反推另一项。

“学习动力”这一旧称退出第三项的命名：促使学习的是动力，已经积累的成绩变化叫学业收益。

## 4.2 好感与敌对

- **好感 A[i][j]**：i 对 j 的亲近意愿。
- **敌对 H[i][j]**：i 对 j 的不满、反感和记恨。
- 两者保留 0–100 值域和方向性：i 对 j 与 j 对 i 分别存储。
- 两轴独立。好感增加不自动扣敌对，敌对增加不自动扣好感；同一对子可以同时高好感、高敌对。
- **2026-10-17 确认并已实装：删除旧版跨天关系自然衰减。** 好感与敌对跨天原值保留，不按有无互动乘保留率；旧 `decay_a_no_interact`、`decay_a_interact`、`decay_h` 不再作为老师版规则，`data/rules/decay.csv` 已删除。关系变化来自明确的座位结算、真实互动及干预，不因时间经过自动增减。本次删除的是跨天比例衰减，第八章每课间的圈外好感 −1 属另一条座位规则，仍按该章执行。

## 4.3 删除与替代

老师版删除透明度、信任度以及隐藏的性格四维修正。学生差异改由开局配置中的**公开专属被动**提供，见第十章。

不得把删除的数值换名后继续作为隐藏修正，也不得因删除信任就把敌对折成好感的负数。旧信念过滤、性格倍率、深层敌对、情绪传染和影响力传导已随本次运行时迁移删除，不迁入。

## 4.4 跨天成绩结算

**次日成绩 = 当前成绩 + 今日学业收益**，再按配置成绩值域处理边界。结算成功后，今日学业收益清零；收益明细进入日末记录。

例如，上午学习累计 +5，下午娱乐减少 2，当日净收益为 +3，次日成绩增加 3。不能因进入娱乐状态而清空上午成果，也不能把剩余动力直接加到成绩上。

跨天压力**单独减少 20 点**；动力**不再统一扣减**（保留前日剩余值，2026-10-17 修订：学习消耗与娱乐联动本身已在扣动力，再固定扣会抵消老师投入），压力钳制到 0–100、动力钳制到 0–100；不用旧保留率，不将本次减压再联动扣动力。初始压力在 **0–45** 随机（2026-10-19 由 0–20 上调），初始动力等于初始压力；初始好感与初始敌对分别为 **10–30** 与 **0–20** 随机（`kernel_params.csv` 的 `init_affinity_base/spread`、`init_hostility_spread`，2026-10-19 用户裁定），再由 `characters/bindings.csv` 覆盖既定关系；成绩在 330–530 随机生成、**开局全班均分恒为 430**（镜像配对、整数分，2026-10-18 裁定）。压力 −20 是否合适，用前七天的收支验证。

**上课段改为黑幕跳过（2026-10-17 裁定，取代 2026-10-16 的上课状态判定）**：上课段不再逐 tick 模拟，也不做段首状态判定 —— 不进入学习／自由状态、不结算学习单位。上课只做两件事：**除当天崩溃休息者外，全员固定 +3 学业收益**（每节课一次，上午＋下午每天 +6；崩溃休息者按 §5.3 不发）与**崩溃判定**（见 §5.3）；**动力不消耗**、无压力涓流、无睡觉、无老师命令挂起。考试日两件都不发放（§11）。成绩生成已按镜像配对裁定（2026-10-18，见 §15.3），不以越界补差凑均分。
