# 第六章 老师操作

## 6.1 操作清单

| 操作 | 耗时及效果 | 待定边界 |
|---|---|---|
| 召唤／遣返 | **召唤与送回都即时完成**（2026-10-17：送回教室不再等待返程，学生直接回教室）；暂时一次只召唤一人 | 延后命令计时方式 |
| 去教室／巡视 | 按实际操作实时进行，无固定耗时；每课间首次到场全班压力 +5，动力按一般规则联动；重复进入不再生效 | 不另添每秒加压 |
| 安抚 | 20 秒，压力 −20，动力按一般规则联动 −20，不改已得学业收益（2026-10-17 裁定实装） | 无 |
| 表扬 | 20 秒，只给该生动力 +15，不加压力，不改已得学业收益 | 无 |
| 办公室训斥 | 20 秒，压力 +30，动力联动 +30，不直接加学业收益 | 无 |
| 全班训斥 | 压力 +30，动力按一般规则联动 | 耗时与操作位置 |
| 打听 | 20 秒，一条优先消息 + 最多 3 条有向单轴关系信息（百事通 6 条），见 §6.4 | 知情范围、披露精度 |
| 鼓励 | 20 秒，产生一次交流目标 | 目标有效期 |
| 调座位 | 10 秒后生效，发起即打断参与者活动 | 延后计时方式 |
| 搜包／没收 | 查找／移除物品，增加压力 | 耗时、增量、恢复 |
| 调解 | 20 秒；任一方向敌对 >50 时完成后双方敌对各 −5，否则无需调解且不扣耗时 | 现场制止另行定义耗时 |

表扬只加动力、不加压力，不走压力联动。训斥仍走一般压力联动。安抚按一般压力联动减压力。所有阈值、耗时与增量放入配置。

## 6.2 有限时间与阶段边界

处理一人时其余学生继续行动，不能同时巡视和办公室聊天。办公室聊天的 20 秒不包含来回路程。上课打断当前执行，老师未完成命令保留、下课再处理，完成后生效，不能提前或重复发放效果。延后时继续剩余时间还是重新计满 10／20 秒保留待定。

召唤途中上课，学生先回课堂，下课来办公室。调座位跨上课也延后到下课，不再使用旧“上课黑幕后直接换好”。换座期间相关学生既不是涓流接收者也不是来源；完成后按新座位参加后续结算，不补发被排除时的效果。

被调座者立即退出原群体活动，中断按 §5.2 结算；其他成员按人数条件继续，人数不足才结束。本口径保留合并稿中的整理解释身份，不扩成整组无条件解散。

界面暂停例外仅百科，见 §3.1；到场被动按“天＋课间”去重，不因打开界面或反复进门刷加压。

## 6.3 物品与取舍

没收可以减少对应娱乐机会或干扰，同时移除一个泄压途径。学生失去物品后，按剩余可用活动重新选择，不直接锁死为学习。

手机、小说和零食的持有属于物品事实，不能成为隐藏人格。旧赠书、免罚券、皇帝位及考试奖励不自动迁入老师版。

## 6.4 打听与信息权限（D10）

老师向办公室里的学生打听，用 20 秒换一条**优先消息**加最多 **3** 条**有向单轴关系信息**（百事通提高到 6 条）。打听只读关系与环境，不改压力、动力、学业收益或真实关系矩阵；关系信息只写入档案观察笔记。全班**每课间最多成功一次**打听，本课间已打听过则不再扣 20 秒。

**优先消息**按以下顺序取最高可用的一条（同一“类型:目标”只告知一次，不反复给未变化的消息）：

1. 正式霸凌（已正式触发的霸凌目标）；
2. 正式孤立；
3. 敌对隐患：至少 2 名其他学生对同一目标敌对**严格超过** 50；
4. 低好感隐患：至少 13 名其他学生对目标好感**严格低于** 20（超过一周、第 8 天起开放）；
5. 手机；6. MP3；7. 零食。

物品消息（手机／MP3／零食）要求受访者对目标敌对严格超过 40 且“知道”其带对应物品；没有可取的优先消息时给出“暂无新的相关消息”。

**关系信息**方向固定为**受访者 → 对象**，每条只含好感或敌对一轴；优先选尚未打听过的方向／轴，不足时从已打听过的补齐。披露为档位（较低／一般／较高／很高，阈值 25／50／75 与档案档位一致），不直接给后台数值。选取走独立带种子随机流（种子取内核 seed），不污染模拟随机序列。每条记录带获取时间与来源，写入档案笔记时**覆盖对应方向与轴的当前标注、保留历史**，不改真实矩阵。

**待定**：物品消息的“知情范围”暂以“目标此刻正在做对应娱乐”为代理（无携带物品模型）；低好感隐患开放日次暂定第 8 天；披露用档位而非精确数值仍待确认。所有阈值、条数与开放日次集中在 `data/rules/teacher_commands.csv`。
