# 第八章 座位与关系结算

## 8.1 邻域定义

基于固定座位表判邻域；只让实际在自己座位、处于学习／娱乐／睡觉的学生参加结算。离座、办公室、崩溃及换座期间的学生不作为来源或接收者。睡觉仅在座位关系中视同学习，不获得学习收益。

所有“周围”和涓流影响统一指前后左右一格，不能用临时靠近或对角替代：

只对不同学生的关系结算，不对自身关系写入增减。

- **正交邻座**：前、后、左、右相邻一格。
- **对角邻座**：斜向相邻一格。
- **圈外关系衰减**：原有远处好感 −1 暂保留；它与 D01“所有涓流只影响正交邻座”的范围是否冲突，列入 §15.3 待裁定，不静默删除或扩大涓流。

## 8.2 每课间一次的基础规则

| 条件 | 基础变化 |
|---|---|
| 前后左右邻座 | 双方各自对对方好感 **+2** |
| 对角邻座 | 不因座位关系增加好感 |
| 周围一圈以外 | 双方各自对对方好感 **−1** |
| 学习状态学生的正交邻座处于娱乐状态 | **学习者对娱乐者敌对 +5**；不自动反向增加 |

四条旧基线暂保留，D01/D04 邻域限定与圈外 −1 的衔接待裁定（§15.3）。好感 +2 与敌对 +5 可以在同一对子同时发生，各自写入，不覆盖、不抵消。

基础 +5 不改写为“只有发生可见噪音才增加”。真实聊天、打闹、友善互动和老师调解等事件可以另行增减关系，与基础变化叠加。

每名符合结算资格的学生，每个正在学习的正交邻座使其压力 +5，多个邻座可叠加，动力按一般规则联动。暂按 §3.3 的课间末采样建议每课间一次，不每秒累加；睡觉是否也作为该加压的学习来源仍待明确。

## 8.3 长期变化

关系好的学生换座后仍可能走到一起聊天，实际交流可以维系关系；长时间远离与持续的 −1 会使联系逐渐变弱。关系不好的学生成为邻座后也会积累好感，但已有敌对需要通过具体事件修复。

角落与中央的邻居数量不同，可能导致结构性关系差异。保留上述原规则，并在多局标定中检查是否出现角落学生无论如何管理都会失去关系的情况；不把远处衰减擅自改为“只有无交流才发生”。

## 8.4 结算与事件去重

每个课间只执行一次基础关系结算，按“天数＋课间编号”去重。具体事件按事件编号结算；聊天被动不能在座位结算时再发一次。

新规则取代旧版八邻域共同学习／上课好感涓流作为默认关系基线。若以后保留其他关系来源，必须列明触发条件和频率，不能无声叠加旧参数。
