# 老师版每日推理板验收

## 本批范围

在 `D:/game/下课十分钟-mobile` 的 main-mobile 实施。老师在学生图之外；16 个预置人物卡、120 个预置学生对子连线槽和 7 个分页事件按钮全部位于 `.tscn`。脚本只绑定信号、读取记录、切换可见性及设置节点属性，不使用 Node.new、instantiate、add_child 或自绘生成推理板界面。

新底图先由 imagegen 生成并保存到 assets；人物复用已有素材。图上没有老师头像、老师好感或信任／透明度数值。

## 数据与每日边界

- 只接收老师处于监控／教室时的公开聊天、安慰、调侃、打闹、道歉事件；办公室期间不补录。旧学生玩家参与的事件整条排除，不把他映射成老师。
- 事件从内核通知记录“观察到的互动”，不推断完成、友谊、敌对或风险；不把秘密行为及后台矩阵变化直接公开。
- 同 tick、同种类、同方向、同结果事件去重。事件与笔记按发生日分组，不把前日事件复制到下一天。
- 从 GameState.profile_notebook 的当日历史读取各方向、各轴最后记录；与档案共享一份玩家笔记。清除判断不当成中立；后来的手动修改保留推测来源。
- 日末由 day_settled 冻结当日内容，report_ready 自动打开。继续后进入次日空页，可按日期回看归档；学期末日页在既有学期报告上方，收起后查看报告。
- 记录只在本局内由 GameState.clue_board_journal 持有，界面重建保留、新局重置；JSON 往返可验证。完整存档／跨启动恢复仍未接通。
- 图中只展现当天事件或标注涉及的人物。点人物筛选当天记录，点事件突出对应人物；超过 8 人采用不重叠网格，密集关系弱化非焦点线，不丢弃日志。事件分页不截断总记录。

## 验证与限制

- `verify_clue_board.gd`：去重、每日隔离、排除老师／私有事件、双轴与反向独立、只读共享笔记、归档 JSON 往返、暂停所有权、16 人无卡片重叠、触摸单次翻页、日末归档与界面节点数量不变。
- `verify_clue_board_flow.gd`：真实教室、办公室不可见事件过滤、监控接线、实际时钟走到放学自动展示、消除旧黑幕遮挡、继续次日与日期回看。
- `test_office_hub.gd`：办公室与教室往返、原生触摸、资料导航与当天记录保持。
- `test_study_navigation.gd`：三条资料界面的六向互通、暂停所有权与人物选择。
- 1080p／720p 截图见 `docs/art/concepts/teacher_clue_board_20261014/`。

本机仅找到 Godot 4.6.3。GUT 9.7.1 在该引擎会报告既有 AccessibilityServer／StringName 兼容错误，不能把它视为无错误的目标版本验收；因此主要验收使用独立 SceneTree 测试。Android 导出环境还缺少 build-tools；没有打包或真机验收。

快门禁 check_config、test_core、verify_formula 通过。全仓库静态检查存在未改文件的既有问题：sim_core.gd 超过 public-methods 与 file-lines 上限，tutorial_overlay.gd 格式检查不通过；本批改动文件单独检查。check_docs 覆盖旧拆分文档，其通过不能替代老师版新规格验收。

三个独立测试的断言全部通过，但进程退出仍可能出现自动加载音频资源释放警告；数据／界面测试的 verbose 指向 bgm_classroom.ogg 与 ui_light_hint.mp3，真实教室流程及办公室测试的提示随播放状态出现。未为消除测试退出提示修改全局音频系统。

旧运行时仍为学生版，老师私聊、主动干预、风险等规则未迁移。这批没有伪造未实现行为的事件，也没有改模拟矩阵或玩法参数。

检验一：图内容来自实际事件与老师记录，按日期配置的只有页面切换；没有按角色或固定日期安排冲突、友谊及孤立。只读视图不会替代学生自主社交，也不会回写推理为真相。
