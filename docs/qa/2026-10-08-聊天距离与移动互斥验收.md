# 聊天距离与移动互斥验收

> 状态：修复已验证；**移动互斥已全线统一**，聊天以外的行为空间口径未统一（见文末复核）；仓库全量门禁仍有失败 ｜ 维护者：程序 ｜ 日期：2026-10-08（含当日复核）
> 规格：主文档 §10.4、§10.5；配置：`data/rules/player_interaction.csv`。

## 根因与修复

- NPC 自主闲聊、旧加入入口绕过玩家交互服务的空间检查；目标池按全班抽样。现于选目标和执行前检查空间与双方移动状态。
- Roam 只看 Walker 是否在走，未看内核行为占用；内核也未收到 NPC 移动状态。现以开始/结束信号即时同步，结束先写位置，行为占用/会话/睡眠期间禁止离座；行走中禁止开始聊天或睡眠。
- 真实时间边界先发归位、下个 tick 才清旧会话。现于真实场景边界先完成到期活动并中断其余跨段活动，再发布归位信号。
- 座位规则依用户描述：双方都在本座位入口时，同列前后紧邻且不超过 1.8 米可转身交流；其他人需至少一人离座，在 1.2 米内、连线不穿家具并停止行走。座位容差 0.1 米；不按角色名或 ID 特判。

## 行为空间口径复核（2026-10-08 复核，**未改代码**）

聊天（含加入）是本次**唯一**按真实几何限制的行为，其余七个社交行为仍是旧口径 —— 不能把本次聊天验收理解为所有行为的空间机制已完成。

| 行为 | 目标候选条件（`sim_core._decide_and_act`） | 实际空间口径 | 与聊天口径 |
|---|---|---|---|
| 闲聊（发起） | `_pick_target(i)` | `chat_pair_in_range` + `_can_interact_with` | —— 本次统一到这里 |
| 加入闲聊 | 全班 `range(n)` | `chat_pair_in_range` + `_can_interact_with` | —— 同上 |
| 当众调侃 `tease` | `_are_neighbors(i, j)` + `_can_interact_with` | **8 邻域座位表**（左右 1.86 m、对角 2.45 m 也算「周围」） | ❌ 不一致 |
| 追逐打闹 `roughhouse` | 全班 `range(n)` + `_can_interact_with` | **无** | ❌ 不一致 |
| 排挤 `exclude` | 全班 `range(n)` | **无** | ❌ 不一致 |
| 流言 `rumor` | 全班 `range(n)` + `_can_interact_with` | **无** | ❌ 不一致 |
| 安慰 `comfort` / 求助 `ask_help` / 道歉 `apologize` | 全班 `range(n)` + 关系门槛 | **无**（规格 §10.10／§10.11／§10.13 也只写关系门槛） | ❌ 不一致 |

实测（Godot 4.7.2 无头；`SimCore.from_npc(12345, 8)`，把 0／1／2 号强制定到 P1／P2／P5 并置入各自座位入口）：

```
左右相邻 P1-P2（1.86 m，双方都在座位）：_are_neighbors = true   chat_pair_in_range = false
对角相邻 P1-P6（2.45 m，双方都在座位）：_are_neighbors = true   chat_pair_in_range = false
前后相邻 P1-P5（1.60 m，双方都在座位）：_are_neighbors = true   chat_pair_in_range = true
```

即：**同一对左右相邻座位，聊天会被拒绝（符合本轮规则），调侃却仍能被选中** —— 这正是「两个人坐在座位上也在交流」在调侃链路上的来源。

**移动互斥这一半已全线统一**（可与上表对照看）：

- 发起者门禁：`_decide_and_act` 对每个 i 先判 `_sleeping[i] or busy[i] or _global_tick < _busy_until[i] or is_moving(i)`；
- 所有行为的候选池都过 `_can_interact_with(j)`（不睡 + 不忙 + **不在移动**）；
- 表现层：`classroom_roam` 每帧 `set_moving(i, walker.is_moving())`，并在 `walk_started` / `walk_finished` 上即时同步（结束先写位置再清移动）；`_decide_batch` 跳过 `is_busy` / 有会话 / 睡眠者，不再把正在交互的人拉走；
- `tests/integration/test_social_movement_scene.gd` 在真实教室整段课间**独立重算**规则判定，实测 0 例「聊天成员仍在移动」。
