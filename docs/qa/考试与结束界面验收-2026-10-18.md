# 考试与结束界面验收（2026-10-18）

## 实装范围

- `scenes/ui/outcome_screen.tscn` 接入真实教室的时钟边界信号；考试达标显示考试纸卡，成绩失败与学生退学分别显示辞退纸卡，正常学期结束使用中性回顾页，不新增成功条件。
- 考试使用已有晨光办公室；成绩失败、退学失败和结束回顾接入 `assets/backgrounds/outcomes/` 中各自的正式背景。`outcome_layout.gd` 按概念图独立排版：成绩页使用大分数与目标／差距卡，退学页使用照片／离校单与三项证据双栏，结束页使用三张统计卡、16 名真实学生的回忆区与两个回顾入口。标题、数字、照片框、滚动明细和按钮都是原生控件，不使用带示例数字的概念图充当界面。
- `scripts/game/outcome_snapshot.gd` 只读已结算考试成绩、当前学生成绩及风险快照。均分与差距保留一位小数，个人成绩按整数显示；不重新掷考分，不改矩阵、风险和随机序列。
- 考试报告打开时持有 `outcome_screen` 时钟暂停；日末倒计时和其他继续入口不能绕过，只有点击“继续带班”才解除并进入次日。失败后没有继续入口。
- 退学页列出实际学生与累计崩溃次数，详情列出所有退学学生、已正式触发的风险及配置中的退学判据。不补造逐事件时间线或把预警直接当作退学。
- 本局结束归档独立副本，早退局也可查看真实关系回放。老师回顾隐藏学生版个人行为统计，不再把末号学生称作老师；可返回结算、回主菜单或重开。
- 以 1920×1080 为布局基准等比居中，明细支持触屏滚动；Windows 与 Android 导出清单显式包含新界面配置及已有报告配置。
