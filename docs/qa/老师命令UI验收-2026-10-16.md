# 老师命令 UI 与办公室人物验收

工作目录：D:/game/下课十分钟-mobile，分支 main-mobile。

## 可操作链路

- 办公室“叫学生来”或档案“叫来办公室”提交召唤；一次只接待一人，途中不提前会面，到达后显示本人坐姿。
- 办公室训斥使用内核既有 20 秒及压力／动力联动；完成后可再次安排或遣返。遣返完成恢复教室显示。
- 实际去教室调用首次到场命令，同一课间不会因反复进出重复生效；监控不调用到场效果。已有办公室来访或命令执行时不能同时到场。
- 教室“调座位”“调解同学矛盾”依次选择两人，提交既有内核命令。调座位即时生效、不耗课间时间（2026-10-19），换完**留在选座页**：卡片按新座位重排、已选清空，可连续调下一组；不符合调解门槛不消耗时间。
- 命令显示剩余秒数，上课挂起时显示延后且不推进；下课按内核既有剩余时间继续。学生选择器不暂停世界。
