# 动力 UI 接入验收（2026-10-16）

分支：`main-mobile`。本批不改变布局、内核规则、数值配置或随机序列。

## 接入内容

- 学生档案读取 `SimCore.vitality()`／`gain_today()`，动力条、正负收益、次日成绩预览在打开期间实时刷新。
- 档案不暂停世界，打开／关闭也不释放外部暂停。成绩上限配置在初始化读取，实时刷新不重复加载配置。
- 班级概况与其详情读取时钟快照中的平均动力与平均学业收益，统计全部学生。缺少快照值仍显示未知，不从压力推算。
- 公开被动、交流目标、趋势、日末收益明细仍待后续接入。
