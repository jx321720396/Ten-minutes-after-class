# 1000 局角色类型统计（2026-10-08）

## 运行条件

- 局数：1000
- 每局：30 天
- 难度：标准档，16 名 NPC
- 种子：1000–1999
- 并行进程：16
- 统计脚本：tools/character_archetype_report.py

## 统计口径

- 孤立：最终“他人给予好感”低于全班均值 15 点以上，且“自己给予他人好感”高于自身收件好感 15 点以上。
- 高敌对：最终收到的敌对均值 ≥ 25。
- 强敌对边：至少有一条收到的敌对边 ≥ 40。
- 高压力：最终压力 ≥ 70。
- 强连接簇：最终处于至少 3 人组成的互相好感 ≥ 60 的连通簇。
- 举报、排挤、羞辱按行为发起者与目标分别计数。

## 主要结果

- 核心抱团型：佳豪（490 局进入强连接簇）、王磊（366）、赵蕊（375）、陈阳（351）、孙悦（354）。
- 孤立边缘型：张渊（126 局孤立）、何川（111）、吴哲（109）、沈浪（109）、苏晴（102）、罗杰（102）。
- 高压受害型：许静（253 局高压力）、何川（237）、白柔（226）、唐糖（221）。
- 冲突制造型：何川、苏晴、唐糖、白柔、叶梓的羞辱发起次数最高。
- 举报相关型：罗杰（262 次被举报）、叶梓（245）、白柔（236）。

“高敌对均值”在本轮全部为 0 局；但强敌对边仍在少数角色身上出现，说明敌对关系通常是局部单边冲突，而不是全班平均敌对。

## 低频奇异分型

除了核心、孤立、高压和冲突等主类型，跨局关系还会组合出一些低频但有辨识度的状态。它们不是固定职业或角色标签，而是某局关系演化后的暂时分型：

| 分型名称 | 约 10 字描述 |
|---|---|
| 受欢迎的麻烦制造者 | 人缘不错，却主动制造冲突 |
| 边缘调停者 | 不属核心圈，却经常介入冲突 |
| 高压旁观者 | 不是主目标，却长期承受环境压力 |
| 冷处理幸存者 | 好感低互动少，却很少被攻击 |
| 被动中心 | 很少主动行动，却总被卷入关系 |
| 孤立传播者 | 自身边缘，同时扩散流言敌意 |
| 短线结盟者 | 快速入团，也快速离开群体 |
| 关系寄居者 | 依附强势角色，独处时关系稀少 |
| 虚假核心 | 连接人数多，但关系都不够深 |
| 冲突避风港 | 周围冲突频发，自己暂时安全 |
| 迟发受害者 | 前期正常，后期集中承受排挤 |
| 迟发施害者 | 前期沉默，后期开始制造冲突 |
| 关系反噬者 | 主动帮助接近，最后积累敌对 |
| 双重边缘者 | 无强连接，也没有明显敌对 |
| 偶发极端者 | 多数普通，少数局突然走向极端 |
| 群体替罪羊 | 冲突非其所起，却总承担后果 |
| 低可见度受害者 | 压力上升，却少触发显性排挤 |
| 关系过渡站 | 短暂连接多圈，却少长期归属 |
| 自我放逐者 | 他人未强烈排斥，自己减少互动 |
| 稳定冷漠者 | 长期低好感、低敌对、低参与 |

这些分型适合用于观察层和结算简报，不能反过来成为行为逻辑中的角色标签或固定命运。
