# “需要关注”卡片验收（2026-10-14）

范围：教室第三张常驻纸卡、只读详情、学生档案跳转与三卡屏高适配；老师版风险／争吵模拟尚未实施。

- 高压名单按真实压力汇总，含阈值边界，排除旧玩家，按压力排序。当前试用阈值 80 可在 data/ui/attention_card.json 调整，不代表崩溃阈值或辞退条件。
- 点击高压提醒打开名单，点击学生经 TimeHUD 信号进入真实同学档案；查看与跳转不改变学生压力或关系。
- 普通争吵记录缺失显示“—”，真实空列表显示 0；同一事件 ID 按最后记录覆盖，已结束的不计入当前数量。详情只展示事件记录，未接入事件源时显示暂无记录，不从敌对或打闹制造争吵。
- 学习、娱乐及其他按实际活动、在场、移动状态分类，分类表在配置中；三类覆盖全体学生且不含旧玩家。睡觉等娱乐活动分类仅用于 UI 汇总，不新增动力或学业收益规则。
- 三张卡片统一按屏高缩放，避免 1280×720 截断；只读详情使用独立 CanvasLayer，不随卡片缩小。
- 新增 5 项单测：预警边界与玩家排除、活动统计、缺失与 0 的区别、事件去重／结束状态、名单及档案信号与只读性。全量 unit 413/413、integration 25/25 通过；unit 既有孤儿节点与资源退出提示保留。
- 真实截图由 tests/integration/capture_time_card.gd 输出到 tools/out/time_card：attention-1920.png、attention-1280.png，以及对应完整教室截图；截图冻结观察，不注入概念图里的 3 人或 1 起。

检验一：统计与标签只读取模拟；阈值只用于 UI 提醒，打开档案不回写关系，也不生成剧情、伤害或失败事件。
