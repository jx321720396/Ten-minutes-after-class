# 办公室第二主界面验收

## 使用

开局教室默认为监控状态，在右侧老师行动面板点击“关闭监控”进入办公室。办公室右侧提供教室监控、去教室、叫学生来；底部为同学档案、推理板、百科全书。实际进入教室时，右侧入口显示“返回办公室”。顶部时间与周考提示读取真实快照。

scenes/game/office.tscn 可以在编辑器中单独预览美术与原生节点布局；完整交互从现有教室进入。背景是独立 imagegen 素材，不含烘焙文字或按钮，完整提示词为 assets/backgrounds/office/prompt.txt。

## 行为与边界

- 办公室覆盖现有教室，时钟和学生继续运行，不切换或复制内核。
- 监控使用保留教室的真实画面，禁用现场输入。卡片缩略图记录上次现场画面，点击才进入实时监控。
- 监控和实际教室保留为两个状态，均使用老师界面。旧学生移动与行为入口保持关闭，实际教室不再恢复学生 UI；推理板仍为同一份。
- 档案先选择学生，办公室中不能触发现有学生版现场聊天；百科、推理板与档案继续沿用各自暂停规则。
- 选择“叫学生来”后显示未接入提示，不移动学生、不伪造安抚／训斥效果。
- 新增按钮支持鼠标和未启用鼠标模拟的原生触摸。取消与拖动不触发点击；列表在滚动脚本消费拖动前取消按钮按下记录。

## 监控／现场界面修订

按用户反馈，将右侧旧行为菜单替换为 scenes/ui/teacher_classroom.tscn 的原生老师界面，配置位于 data/ui/teacher_classroom.json。巡视按钮切到现场状态；办公室私聊回办公室并打开学生选择；调座位／处理冲突明确待开放，不调用学生行为代替。点击人物选中学生，再通过“查看档案”打开原只读面板。

两种状态均停掉旧 Interaction 纸条轮询与 ChatHUD 邀请刷新，关闭现有纸条卡片并隐藏旧现场 UI。旧玩家形象隐藏只影响表现，模拟仍为待迁移的学生版，未声称已改为16节点老师内核。旧学生教程不再自动弹出，设置中的重看入口禁用。

独立集成回归覆盖：默认监控、两种状态差异、旧事件与行为不恢复、旧玩家形象隐藏、选中学生档案、返回入口移到右侧，以及两种横屏尺寸下老师面板不压底部入口。真实截图在 tools/out/office_hub/monitor-1920.png、monitor-1280.png、teacher-classroom-1920.png、teacher-classroom-1280.png。

本轮还验证了真实教室射线拾取：旧玩家控制关闭时仍可选中学生；隐藏旧玩家的拾取体关闭，避免透明遮挡。档案按钮位于老师纸卡内、整卡位于画面内，底部工具和右侧纸卡不重叠。修订后独立回归、四项快门禁及本批格式／静态检查通过；1920×1080 和 1280×720 均已检查实际截图。归档截图位于 docs/art/concepts/office_20261014/，名称以 teacher_monitor_implemented 与 teacher_classroom_implemented 开头。
