## 五、上传自查：把「别人拉取会报错」修干净

起因是一个问题 ——「别人拉取仓库会不会有影响报错」。用 **从零 clone + `--headless --import`** 复现（等价于别人首次打开项目），一共挖出并修掉四处：

1. 新增的 `data/rules/roster.csv` 没有 `.csv.import` → Godot 用 `csv_translation` 认领它，**首次导入报 WARNING**，导出时这张表还会被顶掉（与 2026-10-10 记录过的坑同源）→ 补 `keep` 声明。
2. 本批新入库的 29 张 PNG 缺 `.import` → 别人的工作区会多出一堆未跟踪文件 → 一并入库。
3. `docs/` 下 6 个 `.blend` 源工程 → Godot 导入 `.blend` 必须本机装 Blender（官方要求「所有团队成员都安装」）→ 新增 **`docs/.gdignore`** 隔离整个 docs（顺带移除 69 个已无用的 `.import`）。已核实：全仓对 `res://docs/` 的引用只剩 3 个离线截图工具的输出路径（只写不读），游戏效果与使用不受影响，导出包反而更小。
4. `choice_weights.csv` / `emotion_faces.csv` / fixtures 的 `seeds.csv` 仍是 `csv_translation` → 本机有导入缓存所以看不见，**别人首次导入会报警告、导出会丢这两张运行时表** → 改 `keep`（现全仓 36 个 csv 声明一致）。

顺带做的仓库卫生：`.gitignore` 忽略 Blender 自动备份 `*.blend1`（5 个移出索引、本地保留）；`.gitattributes` 显式声明 `*.glb` / `*.gltf` / `*.blend` / `*.blend1` / `*.gif` 为 binary（此前仅靠 `text=auto` 自动判定）。

**验证**：重新从零克隆 + 首次导入 → **退出码 0、零 WARNING / ERROR、克隆工作区无残留文件**。
