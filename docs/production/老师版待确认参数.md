## 四、可达性实测（2026-10-16，纯内核、无界面）

16 人、三个种子跑满 8 天，第八天考试均分 **268.5 / 253.8 / 219.2**（种子 12345 / 777 / 20261016），全部不达标；第 7 天末均分反而低于开局，成绩是被「游戏状态」的负收益拖下去的。

**每人每天的压力／动力收支**：

| 来源 | 数量 | 是否联动动力 |
|---|---|---|
| 去教室（每课间首次 +5，一天 3 个课间） | +15 | 是 |
| 训斥 2 人 × +20 × 3 课间（集中在那 2 人身上） | +60（仅这 2 人） | 是 |
| 游戏状态减压（每 20 秒一次） | −120 | 否（规格明写「不减少动力」） |
| 娱乐减压（每 10 秒一次） | −240 | 是 |
| 跨天继承 | 压力 −20、动力 −10 | 各自单独 |

处于游戏／娱乐状态的学生每天净 **−165~−345 动力**，而老师加压最多约 **+75/人/天**（且必须集中训斥少数人）：**加压追不上减压**，全班长期锁在游戏状态、成绩逐日下降；排座位策略也无法启动，因为没有任何学习者提供涓流。

**相关实测**：

- 老师干预有效但不改变结论：加「去教室 + 每课间训斥 2 人 + 排座位」后，第 7 天末均分从 281.8 提到 344.8（种子 12345），仍不达标。
- 训斥力度受「个体压力上限」约束：按「最高压力低于上限才训斥」的策略，上限取 55／65／75 三档结果完全相同（都只训斥到 2 次），要到 85 才训斥 4~5 次并逼近崩溃。
- 初始成绩目前只按 min–max 均匀随机，16 人样本均分会在 350 附近波动（实测 319~363）；「精确均分生成算法」仍未实现。

**待标定方向**（择一或组合）：降减压幅度／升老师加压幅度／调学习收益与状态阈值／接受首考不达标。用户 2026-10-16 明确「后续还要修改，目前不达标没关系」，本轮不改数值。
