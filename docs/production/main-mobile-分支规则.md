# `main-mobile` 分支规则

## 用途

`main-mobile` 是移动端适配专用分支，用于维护移动端布局、触摸输入、屏幕方向、响应式界面和移动端导出配置。

## 合并方向

- 允许将 `main` 的更新合并到 `main-mobile`，保持移动端分支能够吸收主干修复。
- **禁止将 `main-mobile` 合并到 `main`。**
- 移动端适配完成后，如需进入主干，必须由协作者单独评审并按新的明确决策执行；本规则默认不允许反向合并。

## 分支生命周期

- `main-mobile` 禁止删除。
- 移动端相关提交优先推送到 `origin/main-mobile`。
- 推送前至少运行格式检查、静态检查和 Godot 无头加载；涉及玩法逻辑时，继续遵守项目六道门要求。

## 当前约定

本文件是 `main-mobile` 的分支操作说明。若其他文档与本文件冲突，以本文件对 `main-mobile` 的合并方向限制为准。
