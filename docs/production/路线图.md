## M1 · 核心循环跑通（当前重点）

**目标**：跑通"聚散 → 聊天 → 调侃 → 崩溃 → 安慰 → 抱团"的单日戏剧循环 + 跨天继承/衰减。

范围（主文档 §16 第一版）：

- [ ] 时间系统：三段课间 + 两段上课发酵，tick 定义落地（§3.2）
- [ ] 底层：A/H/T 有向矩阵 + 透明度 + MBTI 四维 + 非线性影响力传导（§5、§7）
- [ ] 情绪：压力值 + 标签派生 + 爆发（§8）
- [ ] 行为：闲聊 / 搭话 / 调侃 / 安慰等核心行为 + 观察层簇标签（§10）
- [ ] 可视化：空间聚散 + 情绪图标 + 关系线 + 上课过场（§14.1、§14.2）
- [ ] 角色：8–10 个核心角色（`data/characters/seeds.csv` 子集）
- [ ] 简报：《每日简报》基础版（§14）
- [ ] 标定：以 §3.4 的三条目标为准跑批量局，收敛数值

**退出标准**：一局可连续游玩 30 天不崩溃；批量 100 局的统计满足 §3.4（好感 2–3 天成友、爆发每 1–2 天一次、四周格局弧线成立）。

## M2 · 深度扩展

- [ ] 行为深度：告密链、举报的群体分裂效应（秘密交换 / 道歉和解 / 调侃 / 安慰 / 求助已于本次补入主文档 §10.10–§10.14）
- [ ] 信息：情报日志 + 态度面板 + 推理板 + 矛盾高亮（§9）
- [ ] 角色：扩到 24 人完整池（§11.4、§11.5 抽取规则）
- [ ] 《学期格局报告》上线（§14）
- [ ] 传导切换到"感知态度"（§7.4）

**退出标准**：信任深度、阵营博弈、信息博弈全部跑通；推理板的矛盾高亮能真实闭合（假信息有可验证破绽）。

## 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 数值标定不收敛（关系易饱和） | 涌现提前死亡，核心卖点失效 | 严格执行 §3.4 目标 + §3.5 衰减；批量局统计作为 CI 之外的定期任务 |
| 14,400 tick 性能不足 | 单日等待过长，体验崩坏 | 内核无头基准测试；传导改稀疏更新；必要时降上课段分辨率 |
| 信息可见性实现过晚 | 推理板与玩法脱节 | M1 即在数据模型中保留感知态接口，M2 前不写死真实值 |
| 比赛规则细节未知 | 交付物不合要求 | 尽早确认提交要求（见 `比赛提交清单.md`） |
