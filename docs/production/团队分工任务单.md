## 4. 团队间接口契约（跨岗"合同"，改契约须 A 批准）

### 4.1 内核 ↔ 表现（B 提供 / C 消费，D7 晚冻结）

| 契约 | 内容 |
|---|---|
| 初始化 | `SimCore.new(seed: int, difficulty: int)` → 一局新实例 |
| 推进 | `advance_tick()` / `advance_phase()` / `advance_day()`；表现层**永不自算数值** |
| 只读访问 | `affinity(i,j)` `hostility(i,j)` `trust(i,j)` `opacity(i)` `stress(i)`（越界与自反返回 0，不抛错） |
| 观察层查询 | `get_clusters()` / `get_isolated(viewer)` / `get_activity_circles()`（**只读**，C 不得回写） |
| 事件流 | `EventBus` 信号：`event_happened(payload)`、`day_settled(summary)`、`tag_changed(id, tag)`、`stress_burst(i)` |
| 玩家输入 | `player_action(kind: String, target: int, topic: String)` → 返回判定结果（供 UI 显示绿/红） |
| 存档 | `save(path)` / `load(path)`，格式含版本号字段（D13 晚冻结） |

### 4.2 `data/` 表契约（A 决策 / B 读 / F 校验）

- 15 张表（`data/rules` 12 + `data/balance` 2 + `data/characters` 1）**仓库根为唯一事实源**，代码只读。
- 数值铁律：行为 `base ∈ [1,5]`；重大事件用"多轴联动 + 状态标签 + 阈值相变"。
- 任何表改动 → 必须复跑六道门并在 `CHANGELOG.md`（`### 平衡` 或 `### 变更`）记录理由。

### 4.3 资产契约（D/E 产出 / C/F 消费）

- 目录：`assets/{icons,models,textures,audio/{bgm,sfx},fonts}`；命名 `类别_对象_变体[_状态]`（全小写蛇形，`assets/README.md`）。
- 第三方素材**必须**先登记 `assets/CREDITS.md` 才能进仓库（未登记禁止合入；教室场景已登记 CC BY 4.0 / Zeps3D，发布需署名）。
- 单张贴图 ≤1 MB、单音效 ≤200 KB、BGM ≤3 MB；`.import` 文件要提交，`.godot/` 不提交。

### 4.4 场景与脚本契约（C 主导）

- 目录同构：`scenes/{ui,game,components}/` ↔ `scripts/{ui,game,core,npc,systems}/`。
- 全局单例放 `autoload/` 并在 `project.godot` 注册（状态、事件总线、配置、存档）——**单例不承载玩法规则**。
- 场景入口：`run/main_scene = res://scenes/ui/main_menu.tscn`；新增场景须同步 `scenes/` 结构与 README。
