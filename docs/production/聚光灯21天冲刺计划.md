## 0. 引擎账（为什么是 Godot）

| 资产 | 结论 |
|---|---|
| Python 无头内核 + 冻结公式 | **零损失**——移植目标仍是 GDScript，照 `tools/core_sim.py` 逐项对拍 |
| 13+2 张 `data/` 参数表 | **零损失**——CSV 仍由 Godot 直接读（仓库根 `data/` 为唯一事实源） |
| 六道门（`tools/*.py`） | **零损失**——Python 离线工具与引擎无关，继续当 CI 用 |
| Godot 工程（主菜单 / 线索板原型 / `scenes/`·`scripts/`·`autoload/`） | **保留并继续用**——骨架已在仓库内，不需要重建 |
| 教室 3D 场景（`assets/models/classroom/`） | **已导入**——glTF 由 Godot 原生导入，无需第三方导入器或格式转换 |
| 文档 | 已统一为 Godot / GDScript 表述（见 §5 清单） |

**Godot 侧决策**：Godot 4.7.2（标准版）· Mobile 渲染器（沿用现有 `project.godot` 设置，1920×1080 横屏）· GDScript · 存档 `user://` · Windows 导出 + Android 导出（arm64-v8a）· 测试用 GUT / gdUnit4 · 内核 `scripts/core/` 不依赖 UI 与表现层节点类型 · 随机数用种子化 `RandomNumberGenerator`（保可复现）。

## 1. 切片范围（一句话）

**8 人简单难度班 × 30 天学期**，跑通"聚散 → 聊天 → 调侃 → 崩溃 → 安慰 → 抱团"单日戏剧循环 + 跨天继承衰减，可视化让簇标签与孤立标签**在玩家眼前涌现**——同一开局，玩家不同选择长出不同班级格局（§15 演示卖点）。

### 明确不做（冲刺期纪律）

| 不做 | 理由 |
|---|---|
| 24 人完整池 / 标准·困难难度 | 8 人班（N=9）足够演示涌现，抽取走 `seeds.csv` 子集 |
| 推理板 / 情报日志 / 矛盾高亮（M2 §9） | 信息博弈不在第一版 |
| 秘密交换 / 举报 / 道歉（M2 行为） | 内核已有，但 UI/演示不依赖；切片只出 §17.1 的 7 行为 |
| 学期格局报告（M2） | 用《每日简报》收尾 |
| 回放动画 / 多局对比 / MBTI 自选（M3） | 锦上添花 |
| 敌对种子重构（§10.17） | 切片敌对由【当众调侃】常规档 + 传播即可成立 |
| 音频 | 只允许 1 段 BGM + ≤3 个关键 SFX，10/15 前入库，之后不碰 |
| **多语言 / 设置项扩展 / 任何"顺手"优化** | 缓冲归零，一切非交付物工作禁止 |
| 引擎切换（任何形式） | 已定稿 Godot 4.7.2（GDScript），不做任何切换；相关文档已统一（见 §5） |
