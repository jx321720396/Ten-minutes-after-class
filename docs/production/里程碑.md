## M1 · 核心循环

### 工程
- [ ] `autoload/game_state.gd`：局状态持有与推进入口
- [ ] `autoload/config_loader.gd`：读取 `data/` 并做字段校验（缺列/越界时报错）
- [ ] `scripts/core/`：时间系统（天 / 相位 / tick）可无头推进 30 天
- [ ] `scripts/systems/`：主文档 §10 的行为清单（闲聊 / 搭话 / 求助 / 道歉 / 调侃 / 安慰 / 秘密交换 / 举报 / 告密 / 传纸条 / 睡觉 / 走动 / 窃听 / 流言 / 学习）实现，逐条带单测
- [ ] `scripts/systems/transmission`：§7.2 传导，含参数表读取
- [ ] `scripts/systems/observer`：簇标签 + 孤立标签（**只读**，有专门测试断言不回写）
- [ ] `data/characters/seeds.csv`：8–10 个核心角色种子
- [ ] 存档：单日结算点可存可读（`user://savegame.dat`）

### 玩法
- [ ] 一局 30 天连续游玩无崩溃、无卡死
- [ ] 单日循环呈现"聚散 → 聊天 → 调侃 → 崩溃 → 安慰 → 抱团"
- [ ] 跨天继承与衰减生效（关系不因跨天归零、也不饱和到 100）
- [ ] 《每日简报》生成内容全部来自日志，无预制文案
- [ ] 玩家"什么都不做"时，NPC 之间仍自发产生可观察的格局变化

### 标定（§3.4）
- [ ] 好感：陌生(20) → 朋友(60) 需 2–3 天
- [ ] 压力爆发：平均每 1–2 天一次，且集中在每天第 2、3 段课间
- [ ] 学期弧线：第 1 周聚散成阵营 → 第 2–3 周博弈/孤立/和解交替 → 第 4 周稳定或大事件
- [ ] 批量 ≥100 局统计脚本可复现（种子固定）

### 性能
- [ ] 无头跑完 30 天 ≤ 目标耗时（初定 ≤ 10 秒，待实测调整）
- [ ] 实时游玩帧率稳定（目标 60 FPS，移动端 ≥30 FPS）
