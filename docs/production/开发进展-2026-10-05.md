## 二、玩法指标（30 天实测）

| 指标 | 目标 | 实测 | 状态 |
| --- | --- | --- | --- |
| 好感饱和度（≥95 占比） | < 10% | **0.0%** | ✓ |
| 好感均值 | 45–65 | **58.9** | ✓ |
| 好感标准差（分化度） | ≥ 20 | **23.6** | ✓ |
| 压力爆发次数 | 15–30 | **30** | ✓ |

**可复现**：`python tools/calib_experiment.py 30`（内置固定 seed）。

> ⚠️ **已知张力**：「爆发次数」与「好感均值」是**同一个压力旋钮的两端**——压力高则爆发多，但 `M_state` 会同时压制好感使其均值下降。**这两项不可分别调**（实测扫描数据见主文档 §2.4）。

## 三、本轮确立的关键机制

| 机制 | 一句话说明 | 为什么需要它 |
| --- | --- | --- |
| **统一影响公式 + 负反馈** | 所有写入走 `Δ = room · sat(P)`，`room = 1 − feedback·X/100` | 没有负反馈时好感是**正反馈**，30 天全班一起封顶（实测饱和 90.8%） |
| **关系调制**（方向可变） | 常规档事件乘 `M = (A−H)/50`，敌对压过好感则**反转** | 「聊了反而掉好感」不需要额外规则 |
| **重大档不做关系调制** | `tier=major` 时 `M_eff = 1` | 否则「关系好 → 举报反而是好事」，欺凌线会塌 |
| **行为的收益-耗时法则** | 每个行为占用时间槽，**收益越大耗时越长** | 「课间只够做 2–4 件事」成为**算出来的时间预算** |
| **跨相位中断** | 行为未完成即被下课铃打断 → 压力代价 | 让**长行为要挑时机做**（秘密交换 60 tick vs 课间 100 tick） |
| **概率爆发 + 越晚越猛** | 压力过 70 后每日掷骰，`severity` 同时放大波及范围与心结时长 | 高压区是**危险斜区**而非一堵墙，且「拖得越久爆得越大」 |
| **心结可传染** | 爆发按 `|A−H|` 扩散给关系最鲜明的少数人 | 情绪传染沿**关系**传播 → 连环爆发由班级结构决定 |

## 五、已知缺口与下一步

### 5.1 敌对系统缺少「种子」（结构性问题，未解决）

**现象**：30 天实测敌对均值 0.2、单点最大 14.2 —— 全系统几乎**不存在「敌人」**。因此 B 类行为【排挤】（判据 = ≥3 人对目标 `H ≥ 40`）**恒为 0 次**，即便放宽到 `H ≥ 25 / 2 人` 也不触发。

**定量根因**：

```
所有敌对事件都是常规档 +3，且一次只作用于一条边
→ 平均每边 +0.15/天，×0.95 衰减 → 稳态约 3
→ 要稳态 40，需「每条边每天被敌对事件击中 0.67 次」——不可能
```

而能产生**重大档敌对**的三个途径**全部卡在循环依赖**：

| 途径 | 前置 | 为何循环 |
| --- | --- | --- |
| 举报 | `H ≥ 60` | 而 `H` 恰好涨不到 |
| 泄密 | 先有秘密交换 | 该行为未实现 |
| 敌意传导 | `H ≥ θ_H`(40) | 同样循环（`θ_H` 降到 15 后单点最大也仅 14.2） |

**候选方案**（详见主文档 §8.17）：
1. 新增**【冷落】**（读信念，不需高敌对）——**让关系变差最直接的通道**；
2. 新增**重大档羞辱事件**（`base=5`，前置 = 围观 ≥5 人且 `A ≤ 30`）；
3. 把**举报前置**从「敌对达标」改为「掌握证据」，**解开循环依赖**。

> 方案 1 与 3 是同一类解法：**把前置条件从「已经很有敌意」换成「掌握某个事实/状态」**。
