## 1. 构建产物

- [ ] Windows 构建（`.exe` + 数据目录），在干净机器上验证可运行
- [ ] Android 构建（`.apk` / `.aab`），真机验证（至少 1 台中端机）
- [ ] 版本号与 `CHANGELOG.md` 一致
- [ ] 导出预设（`export_presets.cfg`）已入库，团队可复现同构建
- [ ] 首次启动无网络依赖；存档路径使用 `user://`（不写系统目录）

## 2. 仓库与文档

- [ ] `README.md` 的"快速开始"在干净环境按步骤可成功运行
- [ ] `docs/gdd/core-gameplay-v3.1.md` 与实现不矛盾（工程契约、编号锚点已同步）
- [ ] 玩法说明面向玩家版（非策划文档）：一页纸说明"你是谁、要做什么、为什么好玩"
- [ ] 操作说明（键鼠 / 触屏）完整，含移动、搭话、递纸条、调侃、安慰、举报、推理板

## 3. 素材与合规

- [ ] `assets/CREDITS.md` 完整登记全部第三方资源（名称、作者、来源、许可）
