## 1. 游戏概述

### 1.1 游戏定位

《下课十分钟》是一款以高中校园为场景的社交模拟游戏。玩家扮演一名转学生，作为班级 17 个社交节点之一，在**一个学期（30 个上学日）里每一天的三个课间**通过搭话、递纸条、调侃、安慰、举报等行为，参与并扰动一个自运行的班级社交系统。

游戏核心不是完成固定目标，而是：**你埋下种子，系统自己发酵，长出的班级格局不属于你也不属于任何一个 NPC。** 玩家的每一次操作只是在关系矩阵中拨动一个数值，整个系统自行重新洗牌，涌现出独属于这一局的班级格局。

**一句话卖点**：一个学期，三十天，九十次课间——你不改变班级，班级自己改变自己。

### 1.2 核心概念

- 玩家不是上帝，而是系统的一部分。16 个 NPC 和玩家共用同一套底层规则。
- 即使玩家什么都不做，NPC 之间也会自发社交、传八卦、抱团、对立、崩溃。
- 没有预设剧情、没有固定结局、没有正确答案。谁和谁成了朋友、谁被孤立、哪两个阵营对立、谁在这一天崩溃了——全部从底层规则中涌现。

### 1.3 玩家目标（v3 新表述）

> **用有限的信息，拼出你认为的班级真相。**

玩家不是"观察者"，而是"解释者"：每个课间获取的只言片语、矛盾情报、虚假态度线，都进入玩家的**推理板**。玩家的操作影响班级走向，而推理板记录玩家如何理解这个走向。局末，玩家看到自己拼出的"真相"与系统实际格局的对照——理解对了是洞察，理解错了是这一局独有的故事。

### 1.4 一局流程（一学期 = 30 天）

一局 = 一个完整学期 = 30 个上学日。每个上学日的结构：

```
上午课间（操作，实时）
  → 上午课堂（发酵过场，快进）
  → 中午午休（操作，实时）
  → 下午课堂（发酵过场，快进）
  → 下午课间（操作，实时）
  → 放学结算（跨天继承 + 每日简报）
（第 2 天从上午课间继续，关系矩阵跨天继承）
……
第 30 天放学 → 《学期格局报告》
```

- 每天三个可操作段 = 上午课间 / 中午午休 / 下午课间；每天实时约 5 分钟，30 天总计约 2.5~3 小时（单日即一个自然游玩/存档单元）。
- 两段上课过场负责"发酵"：课间埋下的矛盾在上课期间继续发展，玩家无法干预。
- 放学后生成《每日简报》并执行跨天结算（关系继承与衰减）；学期末生成《学期格局报告》，回顾 30 天涌现出的班级格局。

## 2. 涌现主题阐释

### 2.1 两道检验题

所有设计必须通过：

- **检验一**：把涌现的部分换成脚本，游戏还成立吗？如果还成立，主题就只是装饰。
- **检验二**：玩家面对的那个整体，是否拥有任何部分都没有、也没有任何部分想要的性质？

### 2.2 排除假涌现

- **因果链不是涌现**：A 导致 B，B 导致 C，是蝴蝶效应，每一环都能单独解释。
- **数量累加不是涌现**：种满 30 朵花只是部分加在一起，整体没有新性质。

### 2.3 涌现主体：班级格局

没有任何一个 NPC 想要形成小团体、想要排挤某人、想要和另一个阵营对立。每个个体只维护自己的好感、敌对、信任、压力等数值，遵循简单规则。**小团体、孤立、阵营对立、压力崩溃后的关系重塑，是整个系统运行后自发浮现的宏观性质。**

用检验一验证：如果"成团""孤立""对立"换成预设脚本（第 2 个课间 A/B 必然成团、第 3 个课间 C 必然被孤立），游戏失去核心——因为本游戏里**根本没有成团规则，只有读矩阵的标签器**（见第 10 章 O1）。

### 2.4 与《万象纪》对照

| 维度 | 《万象纪》 | 《下课十分钟》 |
|---|---|---|
| 涌现主体 | 文明形态 | 班级格局（小团体、孤立、对立） |
| 个体行为 | 猿人学习、传播、遗忘想法 | 学生搭话、传八卦、抱团、崩溃 |
| 玩家角色 | 上帝，改变环境条件 | 转学生，系统中的一个节点 |
| 实时可视化 | 地图上文明演化 | 教室小人聚散 + 头顶情绪 |
| 事后理解 | 编年史 | 每日简报 + 学期格局报告 + 推理板 |

## 3. 时间与节奏系统（v3 新增）

### 3.1 一局 = 一个学期 = 30 天

一局游戏覆盖一个完整学期（30 个上学日），每天含 3 个可操作课间段和 2 个上课发酵段。**每段课间的游戏内时间仍是 10 分钟（扣住标题），实时压缩播放；每天实时约 5 分钟，学期总计约 2.5~3 小时。** 关系矩阵跨天继承——今天的恩怨，明天继续发酵。

### 3.2 tick 定义

| 阶段 | 游戏内时长 | 实时时长 | 1 tick | 每段 tick 数 |
|---|---|---|---|---|
| 课间段 ×3 | 10 分钟 | 100 秒 | 6 秒游戏内 = 1 秒实时 | 100 |
| 上课段 ×2 | 45 分钟 | 15 秒（快进） | 30 秒游戏内 | 90 |

- 每天总 tick ≈ **480**（课间 300 + 上课 180）；每天实时 ≈ 3×100 + 2×15 ≈ **5 分钟**（结算界面不计入）。
- 学期总 tick ≈ **14,400**（480 × 30 天）；学期总时长约 2.5~3 小时，单日即一个自然游玩/存档单元。
- 课间 = 高分辨率模拟：全部行为规则 + 玩家操作。
- 上课 = 低分辨率发酵层：只跑规则子集（见 3.3）。
- 放学后 = 跨天结算层：关系继承 + 衰减 + 每日简报（见 3.5）。

### 3.3 上课发酵层（规则子集）

上课不是暂停，而是"发酵结算层"。上课期间只运行以下规则：

| 规则 | 上课期间行为 |
|---|---|
| R1 相邻热络 | 按固定座位继续生效（座位相邻缓慢加好感） |
| R5 消息传歪 | 低频触发（每 3~5 tick 一次，只能传纸条/小声说话） |
| 压力 | 事件发酵照常；独处恢复减半（-3 → -1.5/tick，上课不是自由活动） |
| R3 主动搭话 | **禁用**——课间埋下的矛盾上课无法解决，只能积累 |
| 影响力传导 | 继续运行（态度在座位邻近与信任链上缓慢扩散） |
| 玩家 | 不可操作，但可查看**情报日志 + 推理板**（等待变成思考时间） |

设计意义：
1. **慢积累 + 快相变**：课间埋矛盾 → 上课发酵 → 下个课间爆发，爆发有因果、有铺垫。
2. **"我埋的种子自己发酵"**直接回应检验一：玩家上课时什么都做不了，格局还在自己变。
3. 三阶段形成叙事弧线：上午埋因 → 中午发酵 → 下午爆发/成团，简报可写出"从混乱到秩序"。

### 3.4 数值标定目标（反推所有"每 tick"值）

以每天 480 tick、学期 14,400 tick 为基准，所有数值按以下目标反推，而不是先定数值再凑时长：

1. **好感**：一段友谊从陌生（20）涨到朋友（60）需要 **2~3 天**（多个课间 + 上课发酵 + 跨天继承共同作用），单日不能饱和 → R1 每 tick 增量与 3.5 跨天衰减一起标定。
2. **压力爆发**：平均 **每 1~2 天一次**，且集中在每天的第 2、3 段课间（发酵之后），不是开局就爆。
3. **格局弧线（学期尺度）**：第 1 周初步聚散并形成阵营 → 第 2~3 周阵营博弈、孤立与和解交替 → 第 4 周格局稳定或爆发大事件，学期报告才有"从混乱到秩序"的完整弧线。

### 3.5 跨天结算层（放学后）

每天放学后执行一次，让"一天"成为长线涌现的积木：

| 结算项 | 规则 |
|---|---|
| 关系继承 | 好感/敌对/信任矩阵完整保留到第二天（今天的恩怨明天继续） |
| 好感衰减 | 当天无互动的对子 ×0.95；有互动的对子 ×0.98 |
| 敌对衰减 | 敌对 ×0.90（时间冲淡矛盾，但不会自动归零） |
| 信任衰减 | 信任 ×0.93（信任需要持续维护） |
| 压力衰减 | 压力 ×0.50 跨天保留（长线心结，不归零）；若当天爆发过，携带"心结"标签 3 天，每天初始压力 +10 |
| 座位重排 | 每天开局可重新选/被调座位，改变 R1 相邻格局 |
| 每日简报 | 生成《每日简报》，归档进学期日志 |

> 衰减系数为初始值，需按 3.4 目标批量标定。衰减的意义：关系必须持续经营才维持得住，否则 30 天会全部饱和到 100，涌现提前死亡。

## 4. 系统架构总览

### 4.1 三层架构 + 观察层

| 层级 | 内容 | 特性 |
|---|---|---|
| 行为接口层 | R1–R5、R7–R13 共 12 条行为规则 | 决定这一 tick 谁和谁发生什么互动，快变量 |
| 情绪状态层 | 压力值（唯一累积情绪变量） | 累积-爆发机制，中变量 |
| 底层态度轴 | 好感/敌对/信任（有向矩阵）+ 透明度/性格（个体） | 稳定的关系与人格，慢变量 |
| **观察层（v3 新增）** | O1 簇标签器（原 R6）、孤立标签器 | **只读**：读矩阵输出标签，供可视化与简报，不写任何数值 |

### 4.2 闭环说明

底层态度轴决定规则触发条件（谁能搭话、谁会传八卦、谁能抱团）；规则执行后回写底层轴和压力值；状态变化又改变下一次规则的触发条件。影响力传导在每 tick 末尾按第 7 章公式运行。玩家的每一次操作，只是在这个闭环中拨动一个节点的数值，然后整个系统自己重新洗牌。观察层在每个 tick 末尾读一次矩阵，只输出标签。

## 5. 底层态度轴

好感、敌对、信任为有向矩阵（17×17，A 对 B 和 B 对 A 独立存储）；透明度与性格为个体属性。所有轴取值 0–100。

### 5.1 好感（Affinity，A[i][j]）

- 定义：i 对 j 的亲近意愿，愿不愿意靠近、待在一起。
- 非对称性：A 对 B 好感高，B 对 A 不一定高。**高好感 = 愿意听对方的话 = 影响力管道。**
- 主要来源：R1 相邻热络、R2 积极回应、R4 话题共鸣、R8 求助成功、R12 安慰。
- 主要消耗：被拒绝、被调侃、立场分裂、被举报。

### 5.2 敌对（Hostility，H[i][j]）

- 定义：i 对 j 的反感、记恨、不满。**与好感是独立两轴，不是好感的负数。**
- 关键区分："没感觉"（好感低、敌对低）和"讨厌"（敌对高）是两种完全不同的状态。
- 主要来源：被拒绝、被打断、被调侃过火、被举报、秘密被泄露。
- 主要消耗：R9 道歉和解、长时间无冲突共处、对方主动帮忙。

### 5.3 信任（Trust，T[i][j]）

- 定义：i 愿不愿意相信 j 说的话、把秘密告诉 j、指望 j 不伤害自己。
- 与好感的本质区别：好感回答"愿不愿意靠近"，信任回答"愿不愿意暴露脆弱"。可以喜欢但不信任（爱吹牛的朋友），可以信任但不喜欢（严肃但靠谱的班长）。
- 主要来源：R4 话题共鸣（核心）、R7 秘密交换并守密、R8 求助被帮、R12 安慰。
- 主要消耗：R7 泄密、R5 传歪的八卦、R13 诬告被发现。

### 5.4 透明度（Opacity，O[i]）

- 定义：i 的真实立场被他人准确感知的程度。
- 高透明度（80+）：态度一目了然，是班级的信息源。
- 低透明度（<20）：别人看不透他的真实想法，只能靠猜、靠八卦。
- 玩法意义：直接控制 UI 中态度线的呈现（实线/虚线/消失），是信息可见性系统的第一层过滤。

### 5.5 性格底色（MBTI 四维连续值）

不使用刻板 16 型分类，而是将 MBTI 四个维度做成 0–100 连续值，每个维度修正行为系数：

| 维度 | 0 端 | 100 端 | 影响 |
|---|---|---|---|
| E/I 外向度 | 极度内向 | 极度外向 | R3 搭话概率、R1 相邻压力、独处压力恢复 |
| S/N 直觉度 | 极度实感（记细节） | 极度直觉（爱脑补） | R5 八卦准确度（S 传得准，N 易传歪）、R4 新话题兴趣 |
| T/F 情感度 | 极度思考 | 极度情感 | R10 调侃敏感度、R12 安慰效果、R9 道歉接受度 |
| J/P 感知度 | 极度判断（守秩序） | 极度感知（随性） | R11 拉拢忠诚度、R13 举报倾向 |

**性格层铁律**：性格只有数值，没有行为；一切角色差异必须能写成这四个维度 + 透明度的纯函数。

## 6. 统一数值计算公式（整合 v2 方向）

### 6.1 统一增量公式

所有非传导类数值变化统一走一条公式：

```
Δ = clamp( W_event × M_personality × M_state , Δmin, Δmax )
```

- `W_event`：事件基础权重（查表，如"被当众拒绝 +15"）。
- `M_personality`：性格系数，由 MBTI 四维 + 透明度经纯函数得出，范围 0.5~1.5。
- `M_state`：状态系数，由压力区间决定（如紧绷期：负面事件 ×1.5、示好事件 ×0.5）。
- `clamp`：钳制到该事件的上下限，防止数值爆炸。
- 传导类变化（好感/敌意随他人态度变化）**不走本公式**，走第 7 章非线性传导公式。

### 6.2 标定流程

1. 先定第 3.4 节的三条标定目标；
2. 为每个 `W_event` 设初始值（沿用 v1.0 数值表作为初值）；
3. 跑批量局（≥100 局），统计好感增长曲线、爆发频率、格局弧线；
4. 不符合目标 → 调 `W_event` 与性格系数，重新批量验证。

> 注：本文档第 6.1 条为统一公式的框架定义。若与 v2.0 第 5 章已写公式冲突，以"参数能按 3.4 标定流程收敛"为准，形式可微调。

## 7. 影响力传导机制（非线性版）

### 7.1 核心原理

好感的方向就是权力的方向：A[i][j] 高，意味着 i 愿意听 j 的话。但传导不是线性求和——**弱态度不扩散，多方拉扯要竞争，传导量有上限**：

1. **阈值（传不传）**：j 对 k 的态度低于阈值时不传导。
2. **竞争归一化（听谁的）**：i 同时被多个 j 拉扯时，按 i 对各 j 的听从度加权平均，而不是简单求和。
3. **tanh 饱和（传多少）**：传导量经过 tanh 压缩，高值饱和。线性传导会让全班态度收敛到同一个均值，抹平分化；饱和让系统存在多个吸引子，派系可以稳定共存。

### 7.2 传导公式

每 tick，对每个接收者 i 和第三方 k：

```
w_ij = A[i][j] / 100                        // i 对 j 的听从度（经性格修正）
A'[j][k] = max(0, A[j][k] - θ_A)            // j 对 k 的超阈值好感
H'[j][k] = max(0, H[j][k] - θ_H)            // j 对 k 的超阈值敌对

net = ( Σ_j w_ij·A'[j][k] - Σ_j w_ij·H'[j][k] ) / ( Σ_j w_ij + ε )

Δ = β × tanh( net / σ )

若 Δ > 0：A[i][k] += Δ        // 好感轴增加，钳制 0-100
若 Δ < 0：H[i][k] += |Δ|      // 敌对轴增加，钳制 0-100（好感不因此扣减，两轴独立）
```

参数表（初始值，待批量局标定）：

| 参数 | 含义 | 初始值 |
|---|---|---|
| θ_A | 好感传导阈值 | 30 |
| θ_H | 敌意传导阈值 | 40 |
| σ | 饱和尺度 | 50 |
| β | 传导系数 | 0.3/tick（好感）、0.5/tick（敌意，敌意更容易传染） |
| ε | 防除零 | 0.01 |

### 7.3 双通道

- **态度通道**：走 7.2 公式，权重是好感（你模仿你喜欢的人的立场）。
- **事实通道**：不走本公式，走 **R5 消息传歪** 的信任判定——≥70 全信、40–70 半信、<40 不信。R5 本身就是带阈值的非线性结构。

### 7.4 传导输入：感知态度（建议采用）

7.2 公式中的 A'[j][k]、H'[j][k] 先可用后台真实值跑通原型；最终版本应改用 **i 感知到的 j 对 k 的态度**（经第 9 章透明度 + 信任两层过滤后的值）。这样信息可见性系统直接参与涌现：低透明度的人，他的真实态度不扩散，只有他"演出来"的那部分才扩散。

### 7.5 涌现现象验证

| 现象 | 新机制如何产生 |
|---|---|
| 派系领袖 | 多人对同一 j 的 w 高 → 加权平均中 j 的态度占主导 → 群体复制；tanh 饱和防止无限放大 |
| 墙头草 | 两个阵营 P≈N → net 在 0 附近 → Δ 符号随权重微扰反复翻转 → 态度横跳 |
| 敌意沿链放大 | 每级传导都过 tanh，有上限的放大，不会指数爆炸 |
| 团内隐形等级 | 谁的 w 高谁就是实际话事人，从 A 矩阵直接读出，无需显式角色标签 |

## 8. 情绪状态层

### 8.1 设计原则

情绪状态层只存**压力值**这一个累积变量。其他情绪（开心、焦虑、愤怒、低落）全部由压力值、近期事件效价、性格底色派生，不独立存储。

依据：Russell 情绪环形模型——情绪落在唤醒度（高/低）× 效价（正/负）两维上。压力值即唤醒度，近期事件好坏决定效价。

### 8.2 压力值（Stress[i]）

- 数据结构：个体单值，0–100，快变量。
- 定义：社交焦虑、窘迫、紧张的累积程度。
- 特点：事件驱动，不自然涨；达到阈值触发情绪事件。

### 8.3 情绪标签派生表（压缩版）

| 压力 × 效价 | 外向/随和 | 敏感/内向 | 好斗 |
|---|---|---|---|
| 低 × 正 | 放松、满足 | 安心、自在 | 得意 |
| 低 × 负 | 无聊、无所谓 | 低落、落寞 | 不耐烦 |
| 中 × 正 | 兴奋、活跃 | 羞涩但开心 | 亢奋 |
| 中 × 负 | 有点烦 | 焦虑、不安 | 愠怒 |
| 高 × 正 | 激动、热闹 | 紧张但强撑 | 亢奋到失控 |
| 高 × 负 | 烦躁 | 窘迫、快哭了 | 愤怒、要爆发 |

### 8.4 压力来源与消解

| 事件 | 压力变化 | 性格修正 |
|---|---|---|
| 被当众拒绝/被打断聊天 | +15 | 敏感 ×1.5，外向 ×0.7 |
| 被八卦谣言指向 | +20 | 敏感 ×1.5 |
| 被小团体明确排斥 | +25 | 随和 ×1.3（更受伤） |
| 被多人同时搭话 | +10 | 内向 ×2，外向 -5（人来疯） |
| 信任的人背叛/传秘密 | +40 | 全性格大幅上涨 |
| 和高好感+高信任的人聊天 | 每 tick -5 | — |
| 独处（不在任何对话中） | 每 tick -3（上课 -1.5） | 内向 -5（独处回血快） |
| 离开人群聚集区 | 瞬间 -10 | — |

### 8.5 压力阈值与爆发

| 压力区间 | 行为修正 |
|---|---|
| 0–40 正常 | 无修正 |
| 40–70 紧绷 | 透明度降低（开始藏立场），负面事件敏感度 ×1.5，示好好感涨幅 ×0.5 |
| 70–90 临界 | 主动闲聊概率骤降，回避人群，移动速度变慢 |
| 90+ 爆发 | 按性格触发：敏感型 → 崩溃趴桌/跑出教室；好斗型 → 当众指责某人（敌对瞬间拉满）；随和型 → 沉默退缩，透明度归零 |

**爆发是全班事件**：周围人按性格分裂——高共情的同情（好感+、信任+），低共情的嫌弃（敌对+），八卦型立刻开始传播这件事。一次崩溃自己就长出一轮新阵营分化。

**爆发即宣泄**：爆发者自身压力瞬间 **-40**（情绪释放，避免反复爆）；同时携带"心结"标签 3 天，跨天初始压力 +10（见 3.5）。

## 9. 信息可见性与推理板

### 9.1 两层过滤

玩家看到的不是真实数值，而是经过两层过滤的态度信息：

```
真实态度（后台矩阵）→ 第一层：透明度（这个人有多容易被看穿）→ 第二层：信任（你通过谁获取信息，信息有多可信）→ 你最终看到的信息
```

### 9.2 透明度控制 UI 呈现

| 透明度 | 玩家看到的效果 |
|---|---|
| 高（80+） | 态度线实线，颜色清晰（暖=好感，冷=敌对），粗细准确反映强度 |
| 中（40–80） | 半透明虚线，颜色偏淡，能看出方向但不确定强度 |
| 低（20–40） | 时隐时现，旁边带问号，只能猜大概站哪边 |
| 极低（<20） | 完全看不到态度线，这个人是个谜 |

### 9.3 信任解锁信息

- 基础可见：所有 NPC 的态度线默认按透明度显示。
- 信任解锁：你和 X 的信任度过线，X 主动透露他对其他人的真实态度——你看 X 对别人的态度线时，清晰度强制提升一档。
- 二手情报：信任度更高时，X 还会透露别人对第三方的态度（通过 X 解锁 B 对 C 的真实态度线）。
- 信息可信度：X 给你的信息，准确度 = X 的透明度 × 你对 X 的信任。

### 9.4 信息可以是错的

- 透明度低的 NPC，态度线可能是假的——他假装对 C 友好（显示暖色线），实际敌对（后台冷色）。
- 信任度低的 NPC 给你的情报，可能是传歪的八卦。同一个人的态度，从不同渠道获取的信息可能互相矛盾。
- 不同玩家因社交路径不同，看到的是完全不同的班级地图。

### 9.5 推理板与矛盾高亮（闭环，v3 强化）

- **推理板**：玩家构建"班级真相"的工作台，记录玩家对每个 NPC 立场、每个阵营归属、每次事件的解释。
- **矛盾高亮（硬功能）**：任何来源的信息与既有记录冲突时，推理板自动高亮。矛盾来源包括：
  1. 某人的态度线与他本人在 R4 敏感话题中的发言冲突；
  2. 二手情报与他人 R5 传话内容冲突；
  3. 情报与标签层事实（如违规标签）冲突。
- **闭环要求**：假信息必须留下可验证破绽，玩家可以通过交叉验证逼近真相；没有破绽的假信息 = 纯噪声，禁止出现。

## 10. 行为接口层（12 条规则 + 1 个观察层）

行为规则决定这一 tick 谁和谁发生什么互动，互动结果回写底层轴和压力值。玩家和 NPC 共用同一套规则。

> 编号说明：沿用 v1.0 的 R1–R13 编号以降低迁移成本。**R6 已降级为观察层标签器 O1，不参与数值计算。**

---

### R1 相邻热络

- 触发：两个角色物理距离 ≤1 格，持续超过 2 tick。
- 好感：每 tick 缓慢 +1~2（自然熟络）。
- 压力：双方敌对 ≥50，相邻反而各 +2/tick（尴尬）；双方好感 ≥70，相邻压力 -1/tick。
- 信任：相邻但不说话不变；相邻且有搭话，信任 +1。
- 性格修正：内向好感涨速 ×0.6、压力涨速 ×1.5；外向 ×1.3、×0.5。
- 玩家可见：相邻小人偶尔浮现小对话气泡；敌对高时两人侧身不看对方。

### R2 被动破冰

- 触发：某人对自己发起搭话（R3）。
- 回应判定：积极回应条件 = 对搭话者好感 ≥40 且自身压力 ≤70，否则敷衍/拒绝。
- 积极回应：双方好感 +5~8，被搭话者压力 -3，搭话者压力 -5。
- 敷衍回应：搭话者好感 -3、压力 +8；被搭话者压力 +2。
- 拒绝回应：搭话者敌对 +10、压力 +15；被搭话者对搭话者好感 -5。
- 透明度修正：高透明者回应态度一目了然；低透明者敷衍也装得像积极。

### R3 主动搭话

- 触发：对目标好感 ≥30 且自身压力 ≤80 且目标不在其他对话中。
- 发起成本：发起者压力 +3（内向 +6，外向 +1）。
- 结果：进入 R2 回应判定。
- 话题选择：普通话题只影响好感；敏感话题（八卦某人）走 R4。
- 性格修正：外向发起概率 ×1.5，可对好感仅 20 的人发起；内向需好感 ≥50；好斗对敌对 ≥40 的人也会发起（挑衅）。

### R4 话题共鸣

普通话题：
- 双方同话题 → 信任 +12~18，好感 +5~8，压力 -3；
- 一方有话题 → 好感 +3，信任不变；
- 都没话题 → 尬聊，好感 -2，压力 +5。

敏感话题（八卦/评价某人）：

| 双方对当事人态度 | 效果 |
|---|---|
| 都讨厌（敌对 ≥50） | 同仇敌忾：好感 +10，信任 +15，对当事人敌对各 +5，压力 -5 |
| 都喜欢（好感 ≥50） | 一起夸人：好感 +8，信任 +8 |
| 一方讨厌一方喜欢 | 立场分裂：喜欢方信任 -10，讨厌方好感 -5，双方压力 +8 |
| 一方中立一方强烈 | 中立方被带节奏，态度被强烈方拉动（走第 7 章传导） |

透明度修正：高透明者聊敏感话题直接表露立场；低透明者含糊带过，立场隐藏。

### R5 消息传歪

- 传播意愿（取决于信任）：对接收者信任 ≥60 愿意传；40–60 五五开；<40 不传。
- 内容变异（染色机制）：八卦每经过一个人，被传讯者对当事人的态度染色：
  - 敌对 ≥60 → 往坏里传（"被老师叫走"→"被老师骂了可能要退学"）；
  - 好感 ≥60 → 往好里传/淡化；
  - 中立 → 基本不变，只丢细节。
- 接收与相信：对传讯者信任 ≥70 全信（态度被拉动）；40–70 半信（拉一半）；<40 不信。
- 对当事人影响：≥3 人相信 → 当事人压力 +20；≥5 人相信 → 周围人对其好感 -5/人；当事人透明度高时知道谁在传，对传谣者敌对 +15。
- 上课期间：每 3~5 tick 低频触发一次（传纸条/小声说话）。

### O1 簇标签器（原 R6，观察层 · 只读）

- **定位**：O1 不是行为规则，不写任何轴。每 tick 末尾读取当前状态，输出"簇"标签，供可视化和局末简报使用。
- 标签判定：
  - 对任意两人 i、j，若 A[i][j] ≥ 60 且 A[j][i] ≥ 60 且 T[i][j] ≥ 50 且 T[j][i] ≥ 50，则 i 与 j 连一条"强连接"边；
  - 强连接图求连通分量 → 每个分量是一个候选簇。
- 稳定性（防闪烁）：候选簇连续存在 ≥5 tick 才显示"成团"标签；已显示标签的簇连续 ≥5 tick 不满足则标签消失（簇自然解散，无任何数值惩罚）。
- 标签只做三件事：可视化（圈出淡轮廓）、局末简报【小团体】、日志（供回放标记）。
- **标签不回写任何矩阵。**
- 孤立标签同理：连续 ≥10 tick 未进入对话且距最近者 ≥2 格 → 标记"孤立"，只读。

### R7 秘密交换

- 触发：双方信任 ≥60，一方主动发起。
- 机制：A 告诉 B 一个秘密，B 进入守密状态。
  - B 泄密 → A 对 B 信任 -40、敌对 +20，A 压力 +25；
  - B 守密超 5 tick → 每 tick 双方信任 +2，形成秘密同盟。
- 性格修正：高 N（爱脑补/八卦）守密概率 -30%；内向/随和 +20%；好斗被背叛后敌对涨幅 ×1.5。

### R8 求助/借东西

- 触发：对目标好感 ≥30。
- 成本：发起者压力 +5。
- 被拒：压力 +15、敌对 +8、信任 -10。
- 成功：被求助者好感 +5、信任 +8；发起者压力 -8、好感 +8；被求助者进入"被亏欠"状态，后续向发起者求助成功率 +25%。
- 性格修正：内向门槛抬高到好感 ≥50，被拒压力 ×1.5；外向门槛降到 20；好斗被拒后敌对 ×2。

### R9 道歉/和解

- 触发：双方敌对 ≥30，一方主动发起。
- 成本：发起者压力 +10，透明度临时 +20。
- 接受概率 = 对方对发起者好感 + 对方随和系数 - 敌对值 ×0.5。
- 对方接受：敌对 -25，好感 +10，信任 +5，双方压力 -10。
- 对方拒绝：敌对 +5，发起者压力 +20，信任 -10。
- 性格修正：高 F（随和）接受概率 +30%；高 T/好斗 -25%；敏感被拒后压力 ×1.5，可能触发爆发。

### R10 当众调侃

- 触发：周围 ≥3 人围观，发起者对目标好感 ≥40。
- 成本：目标压力 +10，发起者压力 +3。
- 成功概率 = 目标对发起者好感 ×0.5 + 目标外向系数 - 目标敏感系数。
- 成功（玩笑接住了）：双方好感 +8，围观者对发起者好感 +5，目标压力 -5。
- 失败（玩笑过火）：目标敌对 +15、压力 +20；围观者分裂——外向/八卦好感 +3，随和/敏感好感 -5。
- 性格修正：外向成功率 +20%、被调侃压力 -50%；敏感被调侃压力翻倍、敌对 ×1.5；八卦型失败后把这件事当八卦传出去。

### R11 拉拢/挖墙脚（重写，不依赖团体标签）

> 因 O1 标签只读，原 R11"发起者属于某个小团体"的触发条件改为**逐对判定**，不读取观察层标签，也不产生团级数值效果。

- 触发：发起者对目标好感 ≥50，且发起者至少与 2 名其他角色互为强连接（A≥60 双向）——即发起者处于一个三人及以上的强连接集合中（由矩阵逐对判定得出）。
- 目标无强连接集合：接受后进入"融入期"——目标需与发起者的强连接同伴逐个建立双向好感 ≥40，否则压力持续 +2/tick，最终自行退出相邻圈（排挤自然产生）。
- 目标已属另一强连接集合（挖墙脚）：原同伴对发起者的敌意**通过第 7 章影响力传导自然产生**，不写死"原团体敌对 +15"；目标加入新圈子后信任增长速度减半（融入成本）。
- 群体规模效应：发起者强连接集合 ≥5 人时，拉拢成功率下降（排外性）。
- 性格修正：好斗挖墙脚倾向 ×1.5；随和被拉接受概率 +20%；高 J 被挖走概率 -30%。

### R12 安慰

- 触发：目标压力 ≥70，发起者对目标好感 ≥50。
- 成本：发起者压力 +5。
- 效果：目标压力 -25，对发起者好感 +15、信任 +20。
- 目标正在爆发（≥90）：效果翻倍，但需通过共情判定：成功率 = 随和系数 + 敏感系数 - 好斗系数。
- 性格修正：高 F + 高敏感（高共情）效果 ×1.5、成功率 +25%；好斗效果 ×0.5、成功率 -20%；内向发起门槛抬高到好感 ≥70。

### R13 举报

- 触发：举报者发现目标有违规行为标签（玩手机、聊天、抄作业、谈恋爱等）。
- 匿名举报：举报者透明度不暴露；被举报者压力 +25，全班平均信任 -3；被举报者透明度高时怀疑最近有矛盾的人，对其敌对 +15。
- 实名举报：举报者透明度临时 +30；被举报者对举报者敌对 +35、压力 +20；周围人按性格分裂。
- 诬告（内容不实）：被发现概率 = 举报者透明度 ×0.3；发现后举报者信任 -35、全班好感 -10、被举报者敌对 +40。
- 群体分裂：举报事件被全班知道后，高 J 对举报者好感 +8，高 P 敌对 +10，高 F 对被举报者同情、压力 +5。
- 性格修正（全部由四维派生，不写角色名）：匿名倾向 = f(低透明度, 高 F)；举报倾向 = f(高 J)；开朗型几乎不举报 = f(高 E, 低 J)。

## 11. 人物系统：四层分离

### 11.1 四层与铁律

| 层 | 只负责什么 | 铁律（违反 = 脚本化） |
|---|---|---|
| 性格层 | MBTI 四维连续值 + 透明度 | 只有数值，没有行为 |
| 身份层 | 姓名、原型、初始关系矩阵、初始标签 | **只能写开局种子**，不参与运行中的公式 |
| 行为层 | 规则 R1–R13 + 影响力传导 + 压力 | 必须是 `(性格四维 + 透明度 + 当前状态)` 的纯函数，**禁止出现角色名/角色 ID 判断** |

### 11.2 分层纪律（判定口诀）

## 13. 每日简报与学期格局报告

每天放学生成《每日简报》，第 30 天放学生成《学期格局报告》。每一句话都来自后台日志，不是预制文案。

- 【小团体】列出本局形成的所有簇及成因（如"A、B、C 凑成圈子，因为 C 被 D 排斥后倒向他们"）——数据来自 O1 标签器与日志。
- 【孤立】列出全程独自坐着没加入任何对话的人及原因。
- 【对立】列出阵营之间的紧张关系及导火索。
- 【大事件】列出压力爆发、举报、秘密泄露等重大事件及周围人的分裂反应。
- 【你的影响】明确指出玩家的哪个操作间接导致了什么格局变化。
- 【真相对照】玩家推理板中的结论与系统实际格局的对照——理解对了是洞察，错了是这一局独有的故事。

《每日简报》聚焦当天发生了什么；《学期格局报告》在每日简报基础上追加：
- 【学期演变】每个阵营、每段孤立、每对宿敌在 30 天内的兴衰时间线；
- 【学期真相对照】玩家 30 天推理结论与学期最终格局的总对照。

简报的核心价值：玩家做了一些操作，然后看到系统自己长出了他没预料到的格局，并且报告告诉他为什么会这样。这就是"看见涌现"。

## 14. 可视化方案

### 14.1 三层实时可视化

1. **空间聚散**：小人在教室的物理位置就是涌现的第一画面。好感高的不自觉靠近，敌对高的保持距离，小团体肉眼可见凑成圈（O1 标签描淡轮廓），被排斥的人移到边缘。
2. **情绪图标**：每个小人头顶极简表情图标（开心、平静、焦虑、愤怒、低落、兴奋），是唯一直接暴露情绪的窗口，不暴露数值。
3. **关系氛围线**：小人之间偶尔闪现极淡视觉线索——好友闪过柔和细线，敌对闪过小闪电。只在质变瞬间出现，不常驻。

### 14.2 上课过场

上课段以快进动画呈现：NPC 回到座位，座位相邻关系慢慢发酵，纸条偶尔传递，情绪图标在头顶缓慢变化，玩家可随时切到情报日志/推理板查看。

### 14.3 回放功能（进阶）

放学后可回看加速动画：看着一团乱的小人慢慢聚成几个圈子，看着某个人被慢慢边缘化，看着一次八卦如何在人群中扩散变形。玩家亲眼看到秩序从混乱中自己浮上来。

## 16. 开发优先级

### 第一版（核心循环必做）

- 时间系统：三段课间 + 两段上课发酵，tick 定义。
- 底层：好感/敌对/信任有向矩阵 + 透明度 + MBTI 四维 + 非线性影响力传导。
- 情绪：压力值 + 情绪标签派生 + 爆发。
- 规则：R1–R5 + R10 + R12（共 7 条）+ 观察层 O1。
- 可视化：空间聚散 + 情绪图标 + 关系线 + 上课过场。
- 角色：8–10 个核心角色。
- 简报：《每日简报》基础版。
- **目标：跑通"聚散 → 聊天 → 调侃 → 崩溃 → 安慰 → 抱团"的单日戏剧循环 + 跨天继承/衰减。**

### 第二版（深度扩展）

- 规则：R7 秘密交换 + R9 道歉 + R11 拉拢/挖墙脚 + R13 举报。
- 信息：情报日志 + 态度面板 + 推理板 + 矛盾高亮。
- 角色：扩到 24 人完整池。
- **目标：信任深度、阵营博弈、信息博弈全部跑通；学期格局报告上线。**

### 第三版（锦上添花）

- 规则：R8 求助 + 匿名纸条 + 起哄围观 + 当面质问 + 故意装傻。
- 功能：回放动画 + 多局对比 + 玩家 MBTI 自选 + 环境事实扩展。
