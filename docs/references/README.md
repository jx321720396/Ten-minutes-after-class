## v3.0 相对旧版的关键修订（便于快速理解考古差异）

1. **成团机制**：R6 行为规则 → 降级为观察层标签器 **O1**（只读）。
2. **影响力传导**：线性求和 → **阈值 + 竞争归一化 + tanh 饱和**（非线性）。
3. **时间系统**：单段十分钟、tick 未定义 → **一局 = 一学期 30 天**，每天 3 段课间 + 2 段上课发酵，tick 明确定义。
4. **人物设计**：角色级硬编码特权 → **性格/身份/行为/标签四层分离**，禁止角色 ID 判断。
5. **推理板**：仅作记录 → **矛盾高亮闭环**（假信息必须留下可验证破绽）。
6. **玩家目标**：观察班级 → **"用有限信息拼出你认为的班级真相"**。
