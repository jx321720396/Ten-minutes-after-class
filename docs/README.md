## 新读者导读

### 一、五个轴是什么（主文档 §5）

| 轴 | 存储 | 回答什么问题 | 会被运行时改写吗 |
|---|---|---|---|
| **好感** `A[i][j]` | 有向矩阵 N×N | i **愿不愿意靠近** j | ✓ |
| **敌对** `H[i][j]` | 有向矩阵 N×N | i 对 j 的**反感 / 记恨**（**与好感独立的两轴**） | ✓ |
| **信任** `T[i][j]` | 有向矩阵 N×N | i 愿不愿意**暴露脆弱**给 j | ✓ |
| **透明度** `O[i]` | 个体属性 | i 有多**容易被看穿** | ✓（方式特殊，见下） |
| **性格底色** | 个体属性（固定） | MBTI 四维连续值 0–100 | ✗ 只作系数 |

> **压力不属于五轴**——它是**状态量**（主文档 §8），被事件累积 / 消解，作用是修正其他一切（`M_state`）与触发爆发（≥90）。

### 二、它们怎么工作（一条完整链路）

```
① 初始化   角色种子表 → A/H/T/O/性格
② 决策     门槛读 A/H/T/压力；"对方的反应预期"读信念 B → 意向评分 → softmax 采样
③ 事件     行为执行 → E = base × clamp(1 + Σwᵗdᵗ) × M(i,s)
④ 传导     C = Σwᵢⱼσ / (Σwᵢⱼ + ε)，σ 用**感知值**（经透明度 + 信任过滤），带阈值 θ
⑤ 合成写入 P = E + β·C → 软饱和 sat(u) = u/(1+|u|/U) → round(Δ, 0.1) → clamp(0, 100)
⑥ 观察层   读矩阵输出簇标签 / 孤立标签（**只读，不回写**）
⑦ 观测     互动 / 旁观 / 二手情报 → 更新各节点信念 B（噪声 σ 由对方透明度决定）
⑧ 跨天     关系衰减 + 座位重排 + 每日简报（见下）
```

五轴在链路里**既是被写的结果、又是下一次判定的依据**——这就是 §4.2 的闭环：关系决定谁能搭话 → 行为回写关系 → 关系又改变下一次的触发条件。

### 三、三个最容易误解的点

**1. 好感与敌对是两轴，永不互相扣减**

```
"没感觉"  = 好感低 + 敌对低
"讨厌"    = 好感低 + 敌对高
"又爱又恨" = 好感高 + 敌对高      ← 单轴表达不出来
```

规则：`Δ > 0` 只加好感、`Δ < 0` 只加敌对（主文档 §7.2 明文）。但**算互动收益时两者合并看**：`M = clamp((A − H)/50, −1, +1)` —— 净值低则削弱收益，净值很负则**反转**（聊了反而掉好感）。

**2. 透明度的写入方式与别的轴不同**

`A/H/T` 是**直接增量**写入；`O` 是「**乘性基座 + 事件偏移 + 回归**」：

```
O ← clamp( O + Δ_O + λ_O · ( O_init × M_stress − O ) , 0, 100 )
```

即：种子值 `opacity_init` 乘压力系数构成"基座"（§6.2），事件（实名举报、当众爆发）产生**临时偏移**，`λ_O` 让它缓慢回到基座。别把它当成"和好感一样直接加减"。

**3. 跨天衰减各轴系数不同（§3.5）**

| 轴 | 衰减 |
|---|---|
| 好感 | 当天**无互动** ×0.95；**有互动** ×0.98 |
| 敌对 | ×0.90 |
| 信任 | ×0.93（需要持续维护） |
| 压力 | **×0.50 跨天保留，不归零**；当天爆发过则带「心结」3 天，每天初始压力 +5 |

衰减的意义：关系必须持续经营才维持得住，否则 30 天会全部饱和到 100，涌现提前死亡。

## 维护规则

1. **单一事实源**：玩法规格只在 [`gdd/core-gameplay-v3.1.md`](gdd/core-gameplay-v3.1.md) 里维护——要改规格就改它，并在 `CHANGELOG.md` 记录。工程契约（公式、数据结构、可见性、数值铁律）在 [`design/`](design/架构总览.md)；两处不得互相复制结论，只能互相引用章节号。
2. **状态标记**：每篇文档头部标注 `状态：骨架 / 草案 / 评审中 / 生效 / 归档` 与 `维护者`。
3. **同步义务**：影响实现的规格改动，须在同一 PR 内更新 `design/` 文档并在 `CHANGELOG.md` 记录。
4. **禁止新增顶层分类**：新文档归入现有目录；确需新增须在 PR 说明理由。
5. CI 会校验文档内的相对链接有效性（`.github/scripts/check_docs_links.py`）。
