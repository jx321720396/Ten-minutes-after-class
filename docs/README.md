## 当前核心定义

| 项目 | 当前含义 |
|---|---|
| 玩家 | 实习老师／班主任，在学生社交网络之外 |
| 班级 | 16 名学生，一局全池入局 |
| 压力 | 当前承受负担，影响崩溃风险 |
| 动力 | 默认学习／娱乐意愿；>50 学习，<50 娱乐，=50 保持状态 |
| 今日学业收益 | 当天累计的有符号成绩变化，跨天计入成绩 |
| 好感／敌对 | 两张独立有向矩阵，基础关系每课间结算一次 |
| 角色差异 | 公开、配置驱动的专属被动 |
| 老师操作 | 有时间成本；监控、私聊、巡视、鼓励、调位及事件处理 |
| 风险 | 有证据、预警与介入窗口，短暂独处／普通争吵不直接判失败 |

透明度、信任度和隐藏性格四维修正退出老师版。旧学生版代码、配置和标定仍保留，迁移后需重新验收。

## 维护规则

1. 玩法变更直接更新 [主策划案](gdd/core-gameplay-v3.1.md)，同步受影响文档和 `CHANGELOG.md`。
2. 明确区分已确认规则、整理落点、待裁定参数和实现状态；示例计算不能写成已落盘参数。
3. 历史正文保留来源与适用版本，旧章节号不解释为新主文档章节号。
4. 工程文档引用主策划案，不另立玩法事实源；跨天收益、每课间关系、事件完成分别结算并去重。
5. 文档校验命令：`python -X utf8 tools/check_docs.py` 与 `python -X utf8 .github/scripts/check_docs_links.py`。现有一致性门仍扫描旧 v4 分册，新主文档需另做规则与引用核对；门通过不代表老师版已实现。
