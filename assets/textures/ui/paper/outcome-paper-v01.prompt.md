# 结算素纸底框

- 生成方式：内置 imagegen，透明背景。
- 参考：`docs/art/concepts/exam_end_20261018/failure_dropout_v01.webp`（已确认概念图）。
- 实装：`data/ui/outcome_screen.json` → `concept.paper_texture`。

提示词：

从参考游戏概念图提炼一张正式可用的空白UI纸张底框素材。只要纸张，不要场景、任何人物、照片、标题、数字、文字、表格、图标、按钮、彩条、叶片、树枝、花朵、纸飞机、绘画。横向约16:10比例的一整张米白档案纸，几张略错位叠放的浅棕厚纸，柔和不规则撕纸边缘，左上角小巧金属回形针与一小段浅棕纸胶带，角落纸纤维及极轻微折痕。中央95%为空白且纹理低对比、几乎均匀，便于原生UI叠加长文本和数据。纸张外侧轻微自然阴影，四周背景真正透明alpha，不能白底或棋盘格。纸张占画面约96%，边缘完整不裁切，风格与参考图米白纸张一致。绝对不添加底部装饰，不能有深青色背衬。
