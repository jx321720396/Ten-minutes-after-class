# 正面低头学习坐姿 v1

2026-10-15。按当前 16 人名册生成剩余 15 名学生学习坐姿，并补齐陈阳的低头版，共 16 张独立 1024×1536 RGBA PNG。

统一要求：正面相机、低头看书页或笔尖、自然连接的肩肘腕和双手、蓝白运动校服、炭灰长裤、完整坐姿腿部与双鞋。包含笔及书本，不包含桌椅，沿用既有分层组合方案。视线不看玩家或摄像头。

- manifest.json：当前角色编号、姓名、外观资源名、原站姿参考和生成源路径。
- validation.json：尺寸、透明边界、透明像素比例和 SHA-256。16 张图均通过 RGBA、尺寸、四角透明及唯一性检查。
- generation_sources.json：原始生成文件位置。
- index.html：可点击查看独立原图的全班图册。
- 总览图：docs/art/concepts/study_roster_20261015/study_roster_overview.png。

映射按姓名核对，不能用旧 24 人素材文件编号直接当当前 16 人编号。例如当前赵蕊 05 对应旧素材 06，叶梓 13 对应旧素材 20。

已全部绑定移动端运行时：data/ui/student_poses.json 保存 16 人学习与站姿映射、逐图前景 UV 轮廓、身体分割与桌面落点。放大比例属于运行时米制映射，不烘焙进 PNG，沿用用户确认的累计 1.3225 倍尺寸。上课空闲或在座学习显示低头学习图，聊天／移动／离座恢复同款站姿。档案与推理板共用站姿上半身裁切映射 data/ui/npc_profile.json。
