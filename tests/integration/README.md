# tests/integration/ —— 无头集成

> 状态：骨架落地 ｜ 维护者：程序 / 测试 ｜ 最后更新：2026-10-07
> 策略依据：[`../../docs/qa/测试策略.md`](../../docs/qa/测试策略.md) §3

## 这里测什么

内核**脱离渲染**跑整局（`docs/design/架构总览.md` 的边界约束）：

- **整局推进**：固定种子跑满 30 天不崩、指标落在标定区间；
- **确定性**：同一 `seed` 必须产出**完全相同**的日志（这是回放 §14.3 与标定的前提）；
- **快照**：固定种子满局后的关系矩阵摘要（哈希）作为回归基线；
- **存档往返**：每日存档 → 读档 → 继续推进，结果与不读档一致。

## 当前状态（重要）

`scripts/core/` 的 GDScript 内核尚未移植（冲刺计划 D8–D9 的交付物），
所以 [`run_term.gd`](run_term.gd) 现在**只做入口与参数解析，然后明确 SKIP** ——
它不会假绿：内核缺失时打印 `SKIP：内核未落地` 并以 0 退出。

内核落地后，同一个入口直接接管整局运行，不需要改测试调用方式。

## 运行

```bash
# 无头整局（-- 之后的参数是脚本自己的）
godot --headless --path . --script tests/integration/run_term.gd -- --days=30 --seed=12345
```

## 与对拍的关系

[`test_tick_parity.py`](test_tick_parity.py)（Python 侧）负责 **Python 内核 vs GDScript 内核**的
逐 tick 对拍（误差 ≤ 1%），对应冲刺计划 D8–D9 的硬闸门；它是本目录的验收工具，
但以 Python 运行（本机没有 Godot 也能跑到「明确 SKIP」为止）。
