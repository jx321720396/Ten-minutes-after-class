# shaders/ —— 着色器

> 状态：骨架 ｜ 维护者：程序 / 美术 ｜ 最后更新：2026-10-04

## 用途规划

本项目以 2D 为主（`renderer/rendering_method = "mobile"`），着色器预计用于：

| 用途 | 场景 | 状态 |
|---|---|---|
| 关系氛围线 | 好友柔和细线 / 敌对小闪电的质变闪现（`docs/art/视觉风格指南.md` 第 2 节） | ⬜ 待做 |
| 情绪图标动效 | 头顶表情的轻微起伏与切换 | ⬜ 待做 |
| 上课发酵过场 | 画面轻微降饱和 / 颗粒感，表达与课间的对比（`docs/gdd/core-gameplay-v3.0.md` §14.2） | ⬜ 待做 |
| 推理板纸张质感 | 粉笔与纸面的质感叠加 | ⬜ 待做 |
| 焦点引导 | 强调某个角色或某条线时的柔化背景 | ⬜ 待做 |

## 约定

- 文件命名：`<用途>_<变体>.gdshader`，如 `relation_line_glow.gdshader`。
- 着色器参数必须暴露为 `uniform` 且带范围限制，避免美术在编辑器外手改数值。
- 移动端优先：避免高开销循环与全屏多通道后处理；单个后处理效果需实测目标机帧率。
- 副作用需谨慎：着色器**不得**暗示玩家看不到的信息（与 `docs/gdd/core-gameplay-v3.0.md` §9 信息可见性规则一致），例如不要用特效泄露低透明度角色的真实态度。
